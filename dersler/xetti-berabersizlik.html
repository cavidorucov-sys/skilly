Xətti bərabərsizliklər

Tənliyin cavabı ədəd(lər)dir, bərabərsizliyin cavabı isə adətən bütöv bir aralıqdır: x > 3, −2 < x ≤ 5. Burada aralıqları yazmağı, xətti bərabərsizliyi həll etməyi, ikiqat bərabərsizlikləri və sistemləri öyrənəcəksən. Əsas tələ birdir: mənfi ədədə vuranda və ya bölərkən bərabərsizlik işarəsinin istiqaməti dəyişir.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Ədədi aralıqlar və bərabərsizliklərin xassələri

1 Niyə lazımdır

Liftin yazısı: "ən çox 8 nəfər". Bu, bir ədəd deyil — 0, 1, 2, …, 8 hamısı olar. Yay düşərgəsi: "12 yaşdan böyük, 16 yaşdan kiçik". Belə şərtləri riyaziyyatda bərabərsizliklə yazırıq, cavabı isə aralıqla.

2 Ədədi aralıqlar

Kvadrat mötərizə [ ] — uc daxildir (≤, ≥). Dairəvi mötərizə ( ) — uc daxil deyil (<, >). Sonsuzluğun (∞) yanında həmişə dairəvi mötərizə olur.

a < x < b → (a; b) interval a ≤ x ≤ b → [a; b] parça a ≤ x < b → [a; b) yarımaralıq x > a → (a; +∞) şüa x ≤ b → (−∞; b] şüa

Ədəd oxunda daxil olan uc dolu nöqtə ilə, daxil olmayan uc boş dairə ilə çəkilir.

3 Kəsişmə və birləşmə

Kəsişmə (∩) — hər iki aralığa düşən ədədlər. Birləşmə (∪) — ən azı birinə düşən ədədlər.

[−2; 3) ∩ (0; 5] = (0; 3) sol uc: böyük olan sol uc → 0 (daxil deyil) sağ uc: kiçik olan sağ uc → 3 (daxil deyil) Tam ədədlər: 1; 2 → cəmi 2 [−2; 3) ∪ (0; 5] = [−2; 5] Tam ədədlər: −2; −1; 0; 1; 2; 3; 4; 5 → cəmi 8

Yuxarıda [−2; 3), ortada (0; 5]. Ədəd oxundakı qalın hissə — onların kəsişməsi (0; 3): hər iki xətt onun üstündən keçir.

4 Bərabərsizliklərin xassələri

a < b olarsa: a + c < b + c (istənilən c) a·c < b·c (c > 0) a·c > b·c (c < 0 — bərabərsizlik işarəsinin istiqaməti dəyişir!)

Niyə dönür? 2 < 5. Hər tərəfi −3-ə vuraq: −6 və −15. Ədəd oxunda −15 daha soldadır, yəni −6 > −15. Mənfiyə vurmaq ədəd oxunu "güzgüdə əks etdirir" — sıra tərsinə çevrilir.

−1 < a < 3. 5 − 2a hansı aralıqdadır? −2-yə vur (işarələr dönür): 2 > −2a > −6, yəni −6 < −2a < 2 5 əlavə et: −1 < 5 − 2a < 7 Tam qiymətlər: 0; 1; 2; 3; 4; 5; 6 → 7 qiymət
Həyatdan. Fikrətin 10 manatı var, bazarda x manat xərcləyəcək: 2 ≤ x ≤ 7. Qalan pul: −7 ≤ −x ≤ −2 → 3 ≤ 10 − x ≤ 8. Çox xərcləyəndə az qalır — mənfiyə vuranda sıra dönür.
Tipik səhvlər
  • Mötərizəni qarışdırmaq: x ≥ 3 üçün (3; +∞) yazmaq. Düzü: [3; +∞).
  • +∞-un yanında kvadrat mötərizə qoymaq. Sonsuzluq ədəd deyil — o, daxil ola bilməz.
  • Mənfi ədədə vurub işarəni saxlamaq.
  • Tam ədədləri sayarkən uc daxil deyilsə onu da saymaq: (0; 3)-də 0 və 3 yoxdur.
Yadda saxla
[ ] — uc daxil (≤, ≥); ( ) — daxil deyil (<, >, ∞) ∩ — hər ikisində; ∪ — ən azı birində Mənfiyə vur/böl → bərabərsizlik işarəsinin istiqaməti dəyişir.
Özünü yoxla: 3 sual
  1. (−3; 2] aralığında neçə tam ədəd var? −2; −1; 0; 1; 2 — 5 ədəd (−3 daxil deyil, 2 daxildir).
  2. 3 < 4. Hər tərəfi −2-yə vursaq, hansı işarə olar? −6 > −8. Bərabərsizlik işarəsinin istiqaməti dəyişir: >.
  3. [1; 6] ∩ (4; 9) kəsişməsində neçə tam ədəd var? Kəsişmə (4; 6]: tam ədədlər 5 və 6 — 2 ədəd.

Dərs 2. Birdəyişənli xətti bərabərsizliklərin həlli

1 Niyə lazımdır

Xətti tənliyi sən yaxşı həll edirsən. Xətti bərabərsizlik də eyni yolla həll olunur — mötərizəni aç, hədləri köçür, əmsala böl. Fərq bircə yerdədir, və imtahan məhz onu yoxlayır.

2 Eynigüclü çevirmələr

Bərabərsizliyin həllər çoxluğunu dəyişməyən çevirmələrə eynigüclü deyilir:

1. Həddi o biri tərəfə keçir — işarəsini dəyiş. 2. Hər tərəfi müsbət ədədə vur/böl — işarə qalır. 3. Hər tərəfi mənfi ədədə vur/böl — bərabərsizlik işarəsinin istiqaməti dəyişir: < ↔ > ≤ ↔ ≥

Yoxlama: −x > 3. x = −5 götürək: 5 > 3 ✓. Deməli həllər mənfidir: x < −3. İşarəni dəyişmədən "x > −3" yazsaydıq, səhv olardı.

3 Həll olunmuş nümunələr

Nümunə 1. 3(x − 2) + 4 ≤ 5x + 6 Mötərizəni aç: 3x − 2 ≤ 5x + 6 Köçür: 3x − 5x ≤ 6 + 2 → −2x ≤ 8 −2-yə böl (dönür): x ≥ −4 Cavab: [−4; +∞); ən kiçik tam həll −4
Nümunə 2. (x + 1)/2 − (x − 3)/3 > 1 Ortaq məxrəc 6 — hər tərəfi 6-ya vur (müsbət, işarə qalır): 3(x + 1) − 2(x − 3) > 6 3x + 3 − 2x + 6 > 6 → x + 9 > 6 → x > −3 Cavab: (−3; +∞); ən kiçik tam həll −2
Nümunə 3. 7 − 4x > 2x − 11 Köçür: −4x − 2x > −11 − 7 → −6x > −18 −6-ya böl (dönür): x < 3 Cavab: (−∞; 3); ən böyük tam həll 2

4 Xüsusi hallar: 0·x

Bəzən x-lər tamamilə yox olur. Onda qalan ədədi bərabərsizliyə bax:

2(x + 3) > 2x + 1 → 2x + 6 > 2x + 1 → 0·x > −5 6 > 1 həmişə doğrudur → həll: bütün ədədlər (−∞; +∞) 2(x + 3) < 2x + 1 → 0·x < −5 6 < 1 heç vaxt doğru deyil → həll yoxdur
Həyatdan. Fikrət 5 manata dəftər və hər biri 2 manatlıq qələmlər alır, pulu 20 manatdır: 5 + 2x ≤ 20 → x ≤ 7,5. Qələm yarım alınmır — ən çox 7 qələm.
Tipik səhvlər
  • Mənfi əmsala bölüb işarəni saxlamaq: −2x ≤ 8 → "x ≤ −4". Düzü: x ≥ −4.
  • Mötərizə qarşısında minus olanda işarəni yalnız birinci həddə dəyişmək: −2(x − 3) = −2x + 6.
  • "Ən kiçik tam həll" soruşulanda x > −3 üçün −3 yazmaq. −3 daxil deyil — cavab −2.
  • x ≥ 4,5 üçün ən kiçik tam həll 4 yazmaq. 4 < 4,5 — cavab 5.
Yadda saxla
Aç → köçür → əmsala böl. Mənfiyə bölürsən — işarəni çevir. 0·x qalsa: ədədi bərabərsizlik doğrudursa — bütün ədədlər, deyilsə — həll yoxdur.
Özünü yoxla: 3 sual
  1. 4 − 3x ≥ 10. Ən böyük tam həll? −3x ≥ 6 → x ≤ −2. Cavab: −2.
  2. 5x − 7 < 2x + 8. Ən böyük tam həll? 3x < 15 → x < 5. 5 daxil deyil — cavab 4.
  3. 3(x − 1) ≥ 3x + 2. Həlli nədir? 3x − 3 ≥ 3x + 2 → 0·x ≥ 5 → yanlışdır. Həll yoxdur.

Dərs 3. İkiqat bərabərsizliklər, sistem və heyət

1 Niyə lazımdır

Şərt çox vaxt iki tərəfli olur: "çəki 2 kq-dan az olmamalı, 5 kq-dan çox olmamalı". Bu ya ikiqat bərabərsizlikdir (2 ≤ m ≤ 5), ya da iki bərabərsizliyin sistemi. İmtahanda adətən soruşulur: "neçə tam həll var?", "tam həllərin cəmi?".

2 İkiqat bərabərsizlik

Üç hissənin hər birinə eyni əməli tətbiq et. Mənfiyə bölürsənsə — hər iki bərabərsizlik işarəsinin istiqaməti dəyişir, sonra sıranı soldan sağa yenidən yaz.

Nümunə 1. −3 < 2x + 1 ≤ 7 1 çıx: −4 < 2x ≤ 6 2-yə böl: −2 < x ≤ 3 Tam həllər: −1; 0; 1; 2; 3 → 5 ədəd, cəmi 5
Nümunə 2. 1 ≤ (5 − 3x)/2 < 4 2-yə vur: 2 ≤ 5 − 3x < 8 5 çıx: −3 ≤ −3x < 3 −3-ə böl (dönür): 1 ≥ x > −1, yəni −1 < x ≤ 1 Tam həllər: 0; 1 → 2 ədəd. Aralığın uzunluğu: 1 − (−1) = 2

3 Bərabərsizliklər sistemi

Sistem — bərabərsizliklərin hamısı ödənməlidir. Hər birini ayrıca həll et, sonra həllərin kəsişməsini götür.

{ 2x − 3 > 1 { 10 − x ≥ 4 Birinci: 2x > 4 → x > 2 İkinci: −x ≥ −6 → x ≤ 6 Kəsişmə: (2; 6] Tam həllər: 3; 4; 5; 6 → 4 ədəd

Yuxarıda x > 2 (sağa gedən şüa), ortada x ≤ 6 (sola gedən şüa). Hər ikisinin örtdüyü hissə — (2; 6].

Şüalar "üz-üzə" deyilsə və kəsişmirsə (məs. x > 5 və x < 1), sistemin həlli yoxdur. Hər iki şüa eyni tərəfə baxırsa (x > 2 və x > 5), kəsişmə "daha sərt" şərtdir: x > 5.

4 Bərabərsizliklər heyəti

Heyət — bərabərsizliklərdən ən azı biri ödənməlidir. Həllərin birləşməsini götürürük. Heyət kvadrat mötərizə ilə yazılır (sistem — fiqurlu mötərizə ilə).

[ 3x + 2 < −1 [ x − 4 ≥ −1 Birinci: 3x < −3 → x < −1 İkinci: x ≥ 3 Birləşmə: (−∞; −1) ∪ [3; +∞) Həll olmayan tam ədədlər: −1; 0; 1; 2 → 4 ədəd
Həyatdan. Velosiped yarışına yaş şərti: 12 yaşdan kiçik deyil və 17 yaşdan böyük deyil — sistem, [12; 17]. Avtobusda pulsuz gediş: 7 yaşdan kiçik və ya 65 yaşdan böyük — heyət, iki şüanın birləşməsi.
Tipik səhvlər
  • İkiqat bərabərsizlikdə yalnız orta hissəni dəyişmək. Əməl hər üç hissəyə tətbiq olunur.
  • Mənfiyə bölüb yalnız bir işarəni çevirmək. İkisi də dönür: 1 ≥ x > −1.
  • Sistem ilə heyəti qarışdırmaq: "və" — kəsişmə, "və ya" — birləşmə.
Yadda saxla
İkiqat: hər üç hissəyə eyni əməl. Sistem { — hamısı ödənir → kəsişmə ∩ Heyət [ — ən azı biri → birləşmə ∪
Özünü yoxla: 3 sual
  1. −1 ≤ 3x + 2 < 11. Neçə tam həll? −3 ≤ 3x < 9 → −1 ≤ x < 3: −1; 0; 1; 2 — 4 həll.
  2. Sistem: x + 4 > 1 və 2x ≤ 6. Neçə tam həll? x > −3 və x ≤ 3: −2; −1; 0; 1; 2; 3 — 6 həll.
  3. Heyət: x ≤ 0 və ya x > 4. Neçə tam ədəd həll deyil? 1; 2; 3; 4 — 4 ədəd.

Dərs 4. Bərabərsizliklərin tətbiqi ilə məsələ həlli

1 Niyə lazımdır

Büdcə, limit, ən az bal, ən çox yük — gündəlik həyatda "dəqiq bərabər" az olur, "çox olmamalı" və "az olmamalı" isə hər yerdədir. Belə məsələlər bərabərsizliklə həll olunur.

2 Sözdən işarəyə

"ən azı", "az olmayan", "-dən az deyil" → ≥ "ən çox", "çox olmayan", "keçməsin" → ≤ "-dən çox", "-dən böyük" → > "-dən az", "-dən kiçik" → <

Cavab tam ədəd olmalıdırsa (adam, kitab, həftə), düzgün tərəfə yuvarlaqlaşdır: x ≤ 21,6 → ən çox 21; x ≥ 12,5 → ən az 13.

3 Həll olunmuş məsələlər

1) Taksidə minmə 2 manat, hər km 0,6 manat. 15 manata ən çox neçə tam kilometr? 2 + 0,6x ≤ 15 → 0,6x ≤ 13 → x ≤ 21,66… Cavab: 21 km (dəqiq 65/3 = 21⅔ km, tam kilometr soruşulduğu üçün 21) 2) 4 testin balları: 78, 85, 90, 72. 5 testin ortası ən azı 82 olsun. 5-ci testdə ən azı neçə bal? (325 + x)/5 ≥ 82 → 325 + x ≥ 410 → x ≥ 85 Cavab: 85 bal
3) Tarif A: 5 manat abunə + 2 qəpik/dəq. Tarif B: 7 qəpik/dəq. Ən azı neçə dəqiqədə A ucuzdur? (hamısını qəpiklə yaz) 500 + 2x < 7x → 500 < 5x → x > 100 Cavab: 101 dəqiqə

4 Üçbucaq bərabərsizliyi

Üçbucağın hər tərəfi o biri iki tərəfin cəmindən kiçik, fərqindən böyükdür. Bu, ikiqat bərabərsizlikdir:

|a − b| < c < a + b
Tərəflər 5 və 9, üçüncü tərəf tam ədəd. Neçə variant? 9 − 5 < x < 9 + 5 → 4 < x < 14 x = 5; 6; …; 13 → 9 variant
Həyatdan. Liftdə yazılıb: "600 kq". 80 kq-lıq adam 25 kq-lıq qutular aparır: 80 + 25x ≤ 600 → x ≤ 20,8. Ən çox 20 qutu — 21-ci artıq limiti keçir.
Tipik səhvlər
  • Yuvarlaqlaşdırmanı səhv tərəfə etmək: x ≥ 12,5 üçün 12 yazmaq. 12 həftə azdır — 13 lazımdır.
  • Vahidləri qarışdırmaq: manat və qəpik bir bərabərsizlikdə. Hamısını bir vahidə gətir.
  • "-dən çox" (>) ilə "ən azı" (≥) arasındakı fərqi itirmək: sərhəd ədədi daxil olub-olmadığını dəyişir.
Yadda saxla
x — nə? → şərt → bərabərsizlik → həll et Tam cavab lazımdırsa — şərtə uyğun tərəfə yuvarlaqlaşdır. Üçbucaq: |a − b| < c < a + b
Özünü yoxla: 3 sual
  1. 200 manat lazımdır, 50 manat var, hər həftə 12 manat yığılır. Ən azı neçə həftə? 50 + 12x ≥ 200 → x ≥ 12,5 → 13 həftə.
  2. Lift 600 kq götürür. 80 kq-lıq adam 25 kq-lıq qutulardan ən çox neçəsini götürə bilər? 80 + 25x ≤ 600 → x ≤ 20,8 → 20 qutu.
  3. Üçbucağın tərəfləri 4 və 10, üçüncü tərəf tam ədəddir. Neçə variant? 6 < x < 14: 7; 8; …; 13 — 7 variant.
