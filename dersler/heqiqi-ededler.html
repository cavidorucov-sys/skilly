Riyaziyyat · Buraxılış · DİM: Həqiqi ədədlər

İrrasional və həqiqi ədədlər; tam və kəsr hissə; ədədi və həndəsi orta

√2, π kimi ədədlər kəsrlə yazılmır — onlar irrasionaldır. Kalkulyatorsuz onların təxmini qiymətini tapmağı, müqayisə etməyi, ədədin tam və kəsr hissəsini və iki növ ortanı öyrənəcəksən. Testdə bunlar həm ayrıca sual, həm də böyük məsələnin bir addımı kimi çıxır.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. İrrasional ədədlər və həqiqi ədədlər

1 Niyə lazımdır

Kvadratın sahəsi 2 m²-dir. Tərəfi neçə metrdir? Elə ədəd lazımdır ki, kvadratı 2 olsun: √2. 1,4² = 1,96 — az; 1,5² = 2,25 — çox. 1,41² = 1,9881, 1,42² = 2,0164… Bu ədəd heç vaxt "bitmir" və heç bir kəsrlə dəqiq yazılmır.

Belə ədədlər irrasional adlanır. Onlarla rasional ədədlər birlikdə həqiqi ədədlərdir.

2 Onluq yazılışa bax

Rasional ədəd → sonlu və ya dövri onluq kəsr 1/4 = 0,25 1/3 = 0,333… = 0,(3) 2/11 = 0,(18) 0,(6) = 6/9 = 2/3 İrrasional ədəd → sonsuz, DÖVRİ OLMAYAN onluq kəsr √2 = 1,41421356… π = 3,14159265… 0,1010010001… (birlər arasında sıfırlar artır)

Diqqət: 3,14 rasionaldır (314/100). π isə 3,14-ə yalnız təxminən bərabərdir.

3 Kök nə vaxt rasionaldır?

Natural n üçün √n yalnız n tam kvadrat olanda (1, 4, 9, 16, …) rasionaldır. Qalan hallarda irrasionaldır: √2, √3, √5, √20, √99.

Kəsr və ya onluq kəsr kök altındadırsa — əvvəl sadələşdir:

√49 = 7 — rasional √0,04 = 0,2 — rasional (0,2² = 0,04) √0,4 = √(4/10) = √(2/5) — irrasional! (0,4 tam kvadrat deyil) √(9/16) = 3/4 — rasional √2 · √8 = √16 = 4 — rasional √50 : √2 = √25 = 5 — rasional (√7)² = 7 — rasional 5 + √3 — irrasional

Qayda: rasional + irrasional = irrasional; sıfırdan fərqli rasional · irrasional = irrasional. İki irrasionalın hasili isə hər şey ola bilər: √2 · √3 = √6 (irrasional), √2 · √8 = 4 (rasional).

4 Həqiqi ədədlər ədəd oxunda

Tərəfi 1 olan kvadratın diaqonalı Pifaqor teoreminə görə √(1² + 1²) = √2-dir.

Pərgarla diaqonalı oxa köçürsək, √2 nöqtəsini alırıq. Deməli irrasional ədədlərin də oxda öz nöqtəsi var.

Hər həqiqi ədədə oxda bir nöqtə, hər nöqtəyə bir həqiqi ədəd uyğundur.

Həyatdan. Kvadrat formalı kafel 30 sm × 30 sm-dir. Diaqonalı 30√2 ≈ 30 · 1,41 ≈ 42,4 sm. Usta bunu bilir: kafeli diaqonal kəsəndə uzun xətkeş lazım olacaq.
Tipik səhvlər
  • √0,4 = 0,2 yazmaq. 0,2² = 0,04, 0,4 yox. √0,4 irrasionaldır.
  • "Kök işarəsi var — deməli irrasionaldır". √49 = 7 rasionaldır. Əvvəl sadələşdir.
  • π = 3,14 hesab etmək. 3,14 — π-nin təxmini qiymətidir, özü rasionaldır.
Yadda saxla
Rasional — sonlu və ya dövri onluq kəsr İrrasional — sonsuz, dövri olmayan √n rasionaldır ⇔ n tam kvadratdır Həqiqi = rasional + irrasional
Özünü yoxla: 3 sual
  1. Neçəsi irrasionaldır: √36; √0,9; 2/7; π − 1; √3 · √12? 2: √0,9 və π − 1. (√36 = 6, √3 · √12 = √36 = 6.)
  2. 0,(4) ədədini adi kəsrlə yaz. 4/9.
  3. √2 · √18 rasionaldır? Bəli: √36 = 6.

Dərs 2. Kökləri qiymətləndirmək və müqayisə etmək

1 Niyə lazımdır

İmtahanda kalkulyator yoxdur. Amma "√50 hansı iki tam ədəd arasındadır?", "3√2 və 2√3-dən hansı böyükdür?" kimi suallar tez-tez çıxır. Hamısı bir fikirlə həll olunur: tam kvadratları bil.

2 Tam kvadratlar və əsas qayda

k² < n < (k + 1)² ⇒ k < √n < k + 1 Böyük ədədin kökü də böyükdür: a < b ⇒ √a < √b

1 < 2 < 4, ona görə 1 < √2 < 2.

16 < 20 < 25, ona görə 4 < √20 < 5.

3 Həll olunmuş nümunələr

Nümunə 1. √50 hansı iki ardıcıl tam ədəd arasındadır? 49 < 50 < 64 ⇒ 7 < √50 < 8. Nümunə 2. −√50 hansı iki ardıcıl tam ədəd arasındadır? 7 < √50 < 8. −1-ə vuranda işarələr çevrilir: −8 < −√50 < −7. (Kiçiyi −8-dir, −7 yox!) Nümunə 3. 3√5 hansı iki tam ədəd arasındadır? Vuruğu kök altına sal: 3√5 = √(9 · 5) = √45. 36 < 45 < 49 ⇒ 6 < 3√5 < 7. Nümunə 4. √50 hansı tam ədədə daha yaxındır? 7 ilə 8-in ortası 7,5; 7,5² = 56,25. 50 < 56,25 ⇒ √50 < 7,5 ⇒ 7-yə daha yaxındır.

4 Müqayisə: vuruğu kök altına sal

a√b = √(a² · b) (a ≥ 0) 3√2 = √18, 2√3 = √12, 5 = √25
Nümunə 5. Ən böyüyü hansıdır: 3√3; 2√7; 5? 3√3 = √27, 2√7 = √28, 5 = √25. 25 < 27 < 28 ⇒ 5 < 3√3 < 2√7. Ən böyüyü 2√7. Nümunə 6. −3√2 və −2√3: hansı kiçikdir? 3√2 = √18 > √12 = 2√3. Mənfilərdə tərsinə: −3√2 < −2√3.

5 Aralıqda neçə tam ədəd var?

Nümunə 7. −√10 ilə √30 arasında neçə tam ədəd var? 3 < √10 < 4 ⇒ −4 < −√10 < −3. 5 < √30 < 6. Tam ədədlər: −3; −2; −1; 0; 1; 2; 3; 4; 5 — 9 ədəd.
Həyatdan. Kvadrat otağın sahəsi 20 m²-dir. Döşəmə üçün plintus alırsan. Otağın tərəfi √20 m: 16 < 20 < 25, deməli 4 m ilə 5 m arasındadır (√20 ≈ 4,47). Perimetr təxminən 4 · 4,47 ≈ 17,9 m — 18 m plintus bəs edər.
Tipik səhvlər
  • 3√2 = √6 yazmaq. Vuruq kök altına kvadratı ilə girir: 3√2 = √18.
  • −√50 üçün "−7 ilə −6 arasında" və ya "kiçiyi −7" demək. Düzü: −8 < −√50 < −7.
  • "√50 ≈ 7,5, çünki 50 49 ilə 64-ün ortasındadır" — yox. 50 49-a çox yaxındır, √50 ≈ 7,07.
Yadda saxla
k² < n < (k+1)² ⇒ k < √n < k+1 a√b = √(a²b) — sonra kök altındakıları müqayisə et Mənfi işarə bərabərsizliyi çevirir
Özünü yoxla: 3 sual
  1. √90 hansı iki ardıcıl tam ədəd arasındadır? 81 < 90 < 100: 9 ilə 10.
  2. Ən böyüyü: 4√2; 3√3; 5? √32, √27, √25 — ən böyüyü 4√2.
  3. −√20 ilə √12 arasında neçə tam ədəd var? −5 < −√20 < −4 və 3 < √12 < 4. Tam ədədlər: −4; −3; …; 3 — 8 ədəd.

Dərs 3. Ədədin tam və kəsr hissəsi

1 Niyə lazımdır

Film 2,75 saat çəkir: bu 2 tam saat və 0,75 saat (45 dəqiqə) deməkdir. 2 — tam hissə, 0,75 — kəsr hissə. Müsbət ədədlərdə hər şey sadədir. Tələ mənfi ədədlərdədir — imtahan da məhz onu soruşur.

2 Tərif

[x] — x-i aşmayan ən böyük tam ədəd (x-in tam hissəsi) {x} = x − [x] (x-in kəsr hissəsi) [x] ≤ x < [x] + 1 0 ≤ {x} < 1 x = [x] + {x}

Başqa sözlə: ədəd oxunda x-dən solda (və ya onun özündə) duran ən yaxın tam ədəd — [x]. Kəsr hissə — ondan x-ə qədər olan məsafə. Ona görə kəsr hissə heç vaxt mənfi olmur.

3 Müsbət ədədlər

[5,7] = 5, {5,7} = 5,7 − 5 = 0,7 [7/3] = 2, {7/3} = 7/3 − 2 = 1/3 (7/3 = 2 + 1/3) [8] = 8, {8} = 0 [0,4] = 0, {0,4} = 0,4

4 Mənfi ədədlər — əsas tələ

−2,3 ədədi −3 ilə −2 arasındadır. Soldakı tam ədəd −3-dür, ona görə [−2,3] = −3.

{−2,3} = −2,3 − (−3) = 0,7 — −3-dən −2,3-ə qədər olan məsafə.

[−2,3] = −3 (−2 yox! −2 > −2,3, yəni −2 ədədi x-i aşır) {−2,3} = −2,3 − (−3) = 0,7 (0,3 yox!) [−7/3]: −7/3 = −3 + 2/3 ⇒ [−7/3] = −3, {−7/3} = 2/3 [−0,4] = −1, {−0,4} = 0,6 [−5] = −5, {−5} = 0

5 Köklərlə və iki faydalı fakt

Nümunə 1. [√30] və {√30}. 25 < 30 < 36 ⇒ 5 < √30 < 6. [√30] = 5, {√30} = √30 − 5. Nümunə 2. [−√30] və {−√30}. −6 < −√30 < −5. [−√30] = −6, {−√30} = −√30 − (−6) = 6 − √30. Nümunə 3. x = −3,4 olarsa, [x] − 2{x} = ? [x] = −4, {x} = −3,4 + 4 = 0,6. [x] − 2{x} = −4 − 1,2 = −5,2.
x tam deyilsə: [x] + [−x] = −1, {x} + {−x} = 1 Məs.: [2,6] + [−2,6] = 2 + (−3) = −1 {2,6} + {−2,6} = 0,6 + 0,4 = 1
Həyatdan. Avtobusa 47 şagird minməlidir, bir avtobusda 12 yer var. 47/12 = 3,91…: [47/12] = 3 avtobus dolur, kəsr hissə 11/12 — daha 11 şagird qalır. Ona görə 4 avtobus lazımdır.
Tipik səhvlər
  • [−2,3] = −2 yazmaq (sadəcə vergüldən sonranı atmaq). Mənfi ədəddə tam hissə bir vahid kiçikdir: −3.
  • {−2,3} = 0,3 yazmaq. Düzü: −2,3 − (−3) = 0,7.
  • Kəsr hissəni mənfi almaq. Həmişə 0 ≤ {x} < 1.
  • [x]-i yuvarlaqlaşdırma ilə qarışdırmaq: [4,9] = 4, 5 yox.
Yadda saxla
[x] — x-dən solda (və ya özündə) olan ən yaxın tam {x} = x − [x], 0 ≤ {x} < 1 [−2,3] = −3, {−2,3} = 0,7
Özünü yoxla: 3 sual
  1. [−5,2] = ? −6.
  2. {−5,2} = ? −5,2 − (−6) = 0,8.
  3. {√11} = ? 9 < 11 < 16, [√11] = 3, {√11} = √11 − 3.

Dərs 4. Ədədi orta və həndəsi orta

1 Niyə lazımdır

Şəkildəki plitənin diaqonalına bax: tərəfi 1 olan kvadratın diaqonalı √2-dir və bu ədədi heç bir kəsrlə dəqiq yazmaq olmur.

"Orta bal", "həftənin orta temperaturu", "orta xərc" — bunların hamısı ədədi ortadır. Həndəsi orta isə daha az tanışdır, amma həndəsədə (düzbucaqlı üçbucaqda hündürlük) və proqressiyalarda qarşına çıxacaq.

2 Ədədi orta

Ədədi orta = (a₁ + a₂ + … + aₙ) / n Buradan: cəm = orta · say
Nümunə 1. 7; −3; 5; 0; 6 ədədlərinin ədədi ortası. Cəm: 7 − 3 + 5 + 0 + 6 = 15. Say: 5 (0 da sayılır!). Orta: 15 : 5 = 3. Nümunə 2. 2, 9 və x ədədlərinin ədədi ortası 4. x = ? Cəm = 3 · 4 = 12. x = 12 − 2 − 9 = 1.

3 Həndəsi orta

a > 0, b > 0 ədədlərinin həndəsi ortası = √(a · b)
Nümunə 3. 4 və 9: √(4 · 9) = √36 = 6. Nümunə 4. 2 və 6: √(2 · 6) = √12 = √(4 · 3) = 2√3. Nümunə 5. 8 və x ədədlərinin həndəsi ortası 6. x = ? √(8x) = 6 ⇒ 8x = 36 ⇒ x = 4,5.

Həndəsi mənası: ölçüləri a və b olan düzbucaqlı ilə eyni sahəli kvadratın tərəfi √(ab)-dir. 4 × 9 düzbucaqlının sahəsi 36-dır, eyni sahəli kvadratın tərəfi 6.

Üç müsbət ədədin həndəsi ortası — ∛(a · b · c): məsələn, 2, 4, 8 üçün ∛64 = 4.

4 Hansı böyükdür?

a, b > 0: (a + b) / 2 ≥ √(ab) Bərabərlik yalnız a = b olanda.
2 və 8: ədədi orta 5, həndəsi orta √16 = 4. 5 > 4. 6 və 6: ədədi orta 6, həndəsi orta 6. Bərabər. Niyə? (√a − √b)² ≥ 0 ⇒ a − 2√(ab) + b ≥ 0 ⇒ (a + b)/2 ≥ √(ab).
Həyatdan. Üç sınaqdan 78, 85, 80 bal almısan. Dörd sınağın orta balının 82 olması üçün 4-cü sınaqdan neçə lazımdır?
Cəm 4 · 82 = 328 olmalıdır. Artıq var: 78 + 85 + 80 = 243. Lazımdır: 328 − 243 = 85 bal.
Tipik səhvlər
  • Sayda 0-ı və ya mənfi ədədləri unutmaq. 0 da ədəddir, say artır.
  • Həndəsi ortanı (a + b)/2 ilə qarışdırmaq. Həndəsi — vurma və kök.
  • Orta sürəti sürətlərin ədədi ortası saymaq. Gedişdə 60 km/saat, qayıdışda 40 km/saat — orta sürət 50 deyil, 48 km/saat (ümumi yol : ümumi vaxt).
Yadda saxla
Ədədi orta = cəm / say; cəm = orta · say Həndəsi orta = √(ab) (a, b > 0) (a + b)/2 ≥ √(ab)
Özünü yoxla: 3 sual
  1. −4; 6; 10; −2 ədədlərinin ədədi ortası? 10 : 4 = 2,5.
  2. 3 və 27 ədədlərinin həndəsi ortası? √81 = 9.
  3. İki ədədin ədədi ortası 7, biri −3. O biri? 14 − (−3) = 17.
