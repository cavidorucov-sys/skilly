Riyaziyyat · Buraxılış · DİM: Funksiyalar və qrafiklər

Kvadrat funksiya, parabola

y = ax² + bx + c (a ≠ 0) — qrafiki parabola olan funksiya. Yuxarı atılan top, fəvvarənin suyu, körpünün tağı bu əyri ilə gedir. Burada parabolanın hara açıldığını, təpəsini, simmetriya oxunu, oxlarla kəsişməsini, ən kiçik və ən böyük qiyməti tapmağı, qrafikdən əmsalları oxumağı öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Parabola. a əmsalı: hara açılır

1 Niyə lazımdır

Topu yuxarı at: əvvəl qalxır, yavaşlayır, ən yuxarı nöqtədə bir anlıq dayanır, sonra düşür. Top şaquli düz xətt boyunca hərəkət edir; hündürlüyünün zamandan asılılıq qrafiki isə paraboladır. "Top ən çox neçə metr qalxar?" sualının cavabı parabolanın təpəsidir.

2 Ən sadə parabola: y = x²

x−3−2−10123
y = x²9410149

Nöqtələr düz xəttə düşmür, "U" şəklində əyri alınır. İki şeyə bax:

  • Simmetriya: x = 2 və x = −2 eyni y = 4 verir. Parabola bir şaquli xəttə — simmetriya oxuna — görə güzgü kimidir. Burada o, Oy oxudur.
  • Təpə: ən aşağı nöqtə (0; 0)-dır. Parabolanın bütün sirri təpədədir.

3 a: parabola hara açılır

y = ax² + bx + c-də a — x²-nın əmsalıdır (a ≠ 0, yoxsa funksiya xətti olardı).

y = x², y = 2x² (daha dar), y = 0,5x² (daha enli), y = −x² (aşağı açılır).

  • a > 0: qollar yuxarı. Təpə — ən aşağı nöqtə: funksiyanın ən kiçik qiyməti var, ən böyüyü yoxdur.
  • a < 0: qollar aşağı. Təpə — ən yuxarı nöqtə: ən böyük qiymət var.
  • |a| böyüdükcə parabola daralır, kiçildikcə enlənir.

4 Həll olunmuş nümunələr

1) y = 3 − 2x + x² Sıraya düz: y = x² − 2x + 3 a = 1, b = −2, c = 3. a > 0 → qollar yuxarı 2) y = −4x² + x a = −4, b = 1, c = 0. a < 0 → qollar aşağı 3) y = (x − 1)(x + 3) Mötərizəni aç: x² + 3x − x − 3 = x² + 2x − 3 a = 1, b = 2, c = −3 4) A(−2; m) nöqtəsi y = 2x² − 3 qrafikindədir. m = ? m — ordinatdır: y = 2·(−2)² − 3 = 2·4 − 3 = 5
Həyatdan. Bəzi körpülərin tağları, fəvvarədən çıxan su şırnağı, maşın farasının güzgüsü parabola formasındadır. Fəvvarədə qollar aşağıdır (a < 0) — suyun ən yüksək nöqtəsi təpədir.
Tipik səhvlər
  • (−2)²-ni −4 saymaq. Mənfi ədədin kvadratı müsbətdir: (−2)² = 4. Amma −2² = −4 (mötərizə yoxdur).
  • Əmsalları sıra ilə yox, yazıldığı yerə görə götürmək: y = 3 − 2x + x²-də a = 3 deyil. a — həmişə x²-nın yanındakı ədəddir.
  • Qolları c-yə və ya b-yə görə təyin etmək. Qolların istiqamətini yalnız a-nın işarəsi müəyyən edir.
Yadda saxla
y = ax² + bx + c, a ≠ 0 — kvadrat funksiya, qrafiki parabola. a > 0 — qollar yuxarı, təpə ən aşağı nöqtə. a < 0 — qollar aşağı, təpə ən yuxarı nöqtə. |a| böyük — dar, kiçik — enli.
Özünü yoxla: 3 sual
  1. y = 5 + x − 3x² üçün a, b, c? y = −3x² + x + 5: a = −3, b = 1, c = 5.
  2. y = −0,5x² + 7 parabolasının qolları hara yönəlib? a = −0,5 < 0 — aşağı.
  3. y = x² − 4x. x = −1 olanda y = ? (−1)² − 4·(−1) = 1 + 4 = 5.

Dərs 2. Təpə, simmetriya oxu, ən kiçik və ən böyük qiymət

1 Niyə lazımdır

"Funksiyanın ən kiçik qiymətini tap", "top ən çox neçə metr qalxar", "sahə ən çox nə qədər ola bilər" — bütün bu suallar bir şeyə gəlir: parabolanın təpəsinə.

2 Təpənin düsturu haradan gəlir

x = 0 qoy: y = c. İndi x = −b/a qoy: a·b²/a² − b·b/a + c = b²/a − b²/a + c = c. Eyni hündürlük! Bu iki nöqtə simmetriya oxuna görə güzgüdür, ona görə ox onların düz ortasından keçir: (0 + (−b/a))/2 = −b/(2a). (b = 0 olduqda bu iki nöqtə üst-üstə düşür; onda y = ax² + c cüt funksiyadır, oxu x = 0-dır və düstur yenə x₀ = 0 verir.)

x₀ = −b / (2a) y₀ = a·x₀² + b·x₀ + c (x₀-ı funksiyaya qoy) Simmetriya oxu: x = x₀

y₀-ı başqa düsturla da tapmaq olar: y₀ = −D/(4a), burada D = b² − 4ac. Amma x₀-ı funksiyaya qoymaq daha az səhvlidir.

3 Ən kiçik və ən böyük qiymət: y₀, x₀ yox!

y = x² − 4x + 3. Təpə (2; −1).

Funksiya ən kiçik qiymətini x = 2-də alır, bu qiymət y = −1-dir.

"Ən kiçik qiymət" — y-dir (−1). "Hansı x-də alır" — x-dir (2).

SualCavab
"Təpənin absisi", "simmetriya oxu x = ?", "ən kiçik qiyməti hansı x-də alır"x₀
"Təpənin ordinatı", "ən kiçik (ən böyük) qiymət", "qiymətlər çoxluğunun sərhədi"y₀

Qiymətlər çoxluğu: a > 0 olanda [y₀; +∞), a < 0 olanda (−∞; y₀]. Artma-azalma: a > 0 olanda funksiya (−∞; x₀]-da azalır, [x₀; +∞)-da artır; a < 0 olanda tərsinə.

4 Həll olunmuş nümunələr

1) y = x² − 4x + 3 funksiyasının ən kiçik qiyməti. a = 1 > 0 → təpə ən aşağı nöqtədir x₀ = −(−4)/(2·1) = 2 y₀ = 2² − 4·2 + 3 = 4 − 8 + 3 = −1 Cavab: −1 (2 yox — 2, qiymətin alındığı x-dir) 2) y = −2x² + 8x − 5 funksiyasının ən böyük qiyməti. a = −2 < 0 → təpə ən yuxarı nöqtədir x₀ = −8/(2·(−2)) = 2 y₀ = −2·4 + 16 − 5 = 3. Cavab: 3 3) y = 2(x + 1)² − 5 — təpə formasında yazılıb. (x + 1)² ≥ 0, ən kiçiyi 0 (x = −1-də) Təpə (−1; −5), ən kiçik qiymət −5 4) y = x² − 4x + 3, [3; 5] parçasında ən kiçik qiymət. x₀ = 2 parçadan kənardadır. [3; 5]-də funksiya artır Ən kiçik — sol ucda: y(3) = 9 − 12 + 3 = 0

Ümumi qayda: y = a(x − m)² + n yazılışında təpə (m; n)-dir. Diqqət: (x + 1)² → m = −1.

Həyatdan. 20 m tor ilə düzbucaqlı hasar çəkirsən. Bir tərəf x, o biri 10 − x, sahə S = x(10 − x) = −x² + 10x. x₀ = −10/(−2) = 5: ən böyük sahə 5·5 = 25 m² — kvadrat olanda.
Tipik səhvlər
  • Ən çox edilən səhv: "ən kiçik qiymət" soruşulanda x₀-ı yazmaq. Qiymət — y-dir. x₀-ı tapdın? Onu funksiyaya qoy, alınan y₀ cavabdır.
  • x₀ = −b/(2a)-da minusu unutmaq: y = x² − 4x + 3-də b = −4, x₀ = −(−4)/2 = +2.
  • a < 0 olanda "ən kiçik qiymət" axtarmaq. Aşağı açılan parabolanın ən kiçik qiyməti yoxdur — yalnız ən böyüyü var.
Yadda saxla
x₀ = −b/(2a), y₀ = y(x₀). Təpə (x₀; y₀), simmetriya oxu x = x₀. a > 0: ən kiçik qiymət y₀. a < 0: ən böyük qiymət y₀. y = a(x − m)² + n → təpə (m; n). Cavabdan əvvəl: "qiymət" (y) soruşulur, yoxsa "harada" (x)?
Özünü yoxla: 3 sual
  1. y = x² + 6x + 1 parabolasının təpəsi? x₀ = −6/2 = −3, y₀ = 9 − 18 + 1 = −8 → (−3; −8).
  2. y = −x² + 4x + 5-in ən böyük qiyməti? x₀ = −4/(−2) = 2, y₀ = −4 + 8 + 5 = 9. Cavab: 9.
  3. y = 3(x − 4)² + 7 ən kiçik qiymətini hansı x-də alır? x = 4 (qiymətin özü 7-dir).

Dərs 3. Parabolanın oxlarla kəsişməsi

1 Niyə lazımdır

Top nə vaxt yerə düşür? Hündürlük sıfır olanda — yəni parabola Ox oxunu kəsəndə. Oxlarla kəsişmə qrafiki çəkməyə də kömək edir: təpə + oxlarla kəsişmə = parabolanın skeleti.

2 Oy və Ox oxları

Oy oxu: x = 0 → y = c → (0; c) Ox oxu: y = 0 → ax² + bx + c = 0 (kvadrat tənlik)

Ox oxu ilə neçə kəsişmə olduğunu diskriminant deyir:

D = b² − 4ac D > 0 → iki nöqtədə kəsir D = 0 → bir nöqtədə toxunur (təpə Ox üstündədir) D < 0 → kəsmir

y = x² − 2x − 3: D = 16 > 0, iki kəsişmə.

y = x² − 6x + 9: D = 0, (3; 0)-da toxunur.

y = x² + 4x + 6: D = −8 < 0, Ox-u kəsmir.

3 Köklər və təpə

Parabola simmetrikdir, ona görə iki kök təpənin iki tərəfində eyni məsafədədir. Təpə köklərin düz ortasındadır:

x₀ = (x₁ + x₂) / 2

a = 1 olanda Viyet tez işləyir: köklərin cəmi −b, hasili c.

4 Həll olunmuş nümunələr

1) y = x² − 2x − 3 — hamısı bir yerdə Oy: x = 0 → y = −3 → (0; −3) Ox: x² − 2x − 3 = 0, Viyet: cəm 2, hasil −3 → x = −1, x = 3 Təpə: x₀ = (−1 + 3)/2 = 1, y₀ = 1 − 2 − 3 = −4 Köklər arası məsafə: 3 − (−1) = 4 2) y = 2(x − 1)(x + 3) Köklər: x = 1, x = −3 (vuruq sıfırdır) x₀ = (1 + (−3))/2 = −1 c: x = 0 → y = 2·(−1)·3 = −6 3) y = x² − 6x + c qrafiki Ox-u (1; 0)-da kəsir. İkinci nöqtə? x₀ = 6/2 = 3. Simmetriya: 1 təpədən 2 solda → o biri 2 sağda x₂ = 5 → (5; 0) 4) y = x² + 8x + k Ox oxuna toxunur. k = ? Toxunur → D = 0: 64 − 4k = 0 → k = 16
Həyatdan. Top h = −5t² + 20t qanunu ilə uçur. Yerə nə vaxt düşür? h = 0: −5t² + 20t = 0 → t(−5t + 20) = 0 → t = 0 (atıldığı an) və t = 4 s. Ən yuxarıda — düz ortada, t = 2 s.
Tipik səhvlər
  • "Oy oxu ilə kəsişmə" soruşulanda kvadrat tənliyi həll etmək. Oy üçün sadəcə x = 0 qoy: cavab c.
  • y = (x − 1)(x + 3)-də kökləri −1 və 3 yazmaq. x − 1 = 0 → x = 1; x + 3 = 0 → x = −3.
  • D-ni sayanda b²-nin işarəsini səhv salmaq: b = −6 → b² = 36, mənfi olmur.
Yadda saxla
Oy: (0; c). Ox: ax² + bx + c = 0. D > 0 — 2 nöqtə, D = 0 — toxunur, D < 0 — kəsmir. Təpə köklərin ortasındadır: x₀ = (x₁ + x₂)/2.
Özünü yoxla: 3 sual
  1. y = x² − 5x + 4 Ox oxunu hansı nöqtələrdə kəsir? Viyet: cəm 5, hasil 4 → x = 1, x = 4: (1; 0) və (4; 0).
  2. y = x² + 2x + 5 Ox oxunu kəsirmi? D = 4 − 20 = −16 < 0 — kəsmir.
  3. y = −3(x − 2)(x − 6). Oy oxu ilə kəsişmənin ordinatı? x = 0: −3·(−2)·(−6) = −36.

Dərs 4. Qrafikdən oxumaq, əmsalları tapmaq

1 Niyə lazımdır

Sınaqda parabola tez-tez şəkillə verilir: "qrafikə görə c-ni tap", "b-ni tap", "funksiyanın düsturunu yaz". Düsturu yox, şəkli oxumağı bacarmalısan.

2 Şəkildən nə oxunur

  • a-nın işarəsi: qollar yuxarı → a > 0, aşağı → a < 0.
  • a-nın özü: təpədən 1 vahid sağa get — parabola |a| qədər qalxır (və ya enir). Ümumiyyətlə: təpədən d sağa → a·d² qədər.
  • c: parabolanın Oy oxunu kəsdiyi nöqtənin ordinatı.
  • b: x₀ = −b/(2a)-dan: b = −2a·x₀.
  • Təpə formasından: y = a(x − x₀)² + y₀, sonra mötərizəni aç.

3 Həll olunmuş nümunə: qrafikdən

Təpə (2; 3), qollar aşağı.

Təpədən 1 sağa: (3; 2) — 1 endi → a = −1.

y = −(x − 2)² + 3 = −x² + 4x − 1.

b = 4, c = −1. Yoxla: qrafik Oy-u (0; −1)-də kəsir ✓

4 Həll olunmuş nümunələr: verilənlərdən

1) y = x² + bx + c, təpə (3; −2). b və c? x₀ = −b/2 = 3 → b = −6 y(3) = 9 − 18 + c = −2 → c = 7 y = x² − 6x + 7 2) y = x² + bx + c, (1; 2) və (3; 2) nöqtələrindən keçir. 1 + b + c = 2, 9 + 3b + c = 2 Çıx: 8 + 2b = 0 → b = −4; c = 2 − 1 + 4 = 5 Qısa yol: y-lər bərabərdir → ox ortadan, x₀ = 2 → b = −4 3) Təpə (−1; 4), parabola (0; 2)-dən keçir. a = ? y = a(x + 1)² + 4. x = 0: a + 4 = 2 → a = −2
Həyatdan. Mühəndis körpünün tağını çəkir: tağın ən yuxarısı (təpə) ortada, 8 m hündürlükdə, ayaqları 20 m aralıdadır. Təpə (0; 8), ayaqlar (±10; 0): y = a·x² + 8, 0 = 100a + 8 → a = −0,08. Qrafikdən düstur — bu, mühəndisin gündəlik işidir.
Tipik səhvlər
  • c-ni təpənin ordinatı ilə qarışdırmaq. c — Oy oxu ilə kəsişmədir; təpə Oy üstündə deyilsə, onlar fərqlidir.
  • Təpə formasında işarə: təpə (2; 3) → (x − 2)², (x + 2)² yox.
  • a-nı oxuyanda tor düyünündə olmayan nöqtəyə baxmaq. Yalnız dəqiq düyünə düşən nöqtəni götür.
Yadda saxla
Qollar → a-nın işarəsi; təpədən 1 sağa → a. c — Oy ilə kəsişmə; b = −2a·x₀. Təpə (m; n) → y = a(x − m)² + n → aç. Eyni y-li iki nöqtə → ox onların ortasında.
Özünü yoxla: 3 sual
  1. Parabolanın təpəsi (1; −4), a = 1. Düsturu ax² + bx + c şəklində yaz. (x − 1)² − 4 = x² − 2x − 3.
  2. y = x² + bx + 5 parabolasının simmetriya oxu x = −2. b = ? −b/2 = −2 → b = 4.
  3. Qollar yuxarı, qrafik Oy oxunu mənfi hissədə kəsir. a və c-nin işarələri? a > 0, c < 0.

Dərs 5. Həyatdan: top, hasar, ən böyük hasil

1 Niyə lazımdır

"Ən çox", "ən az", "ən yüksək" sözləri məsələdə kvadrat funksiya olduğunu xəbər verir. Cavab — təpədir. Yalnız soruşulanın vaxt (x₀), yoxsa hündürlük/sahə (y₀) olduğuna diqqət et.

2 Yuxarı atılan top

v m/s sürətlə yuxarı atılan topun hündürlüyü (g = 10 m/s², hava müqaviməti yoxdur):

h = −5t² + v·t + h₀ t₀ = v/10 — ən yuxarıya çatma vaxtı h(t₀) — ən böyük hündürlük

h = −5t² + 20t.

t₀ = −20/(2·(−5)) = 2 s.

h(2) = −20 + 40 = 20 m — ən böyük hündürlük.

Yerə düşür: h = 0 → t = 4 s.

3 Həll olunmuş nümunələr

1) Top 15 m hündürlükdəki eyvandan atılır: h = −5t² + 10t + 15. t₀ = −10/(−10) = 1 s h(1) = −5 + 10 + 15 = 20 m — ən böyük hündürlük Yerə düşmə: −5t² + 10t + 15 = 0 → t² − 2t − 3 = 0 t = 3 s (t = −1 atılır: vaxt mənfi olmur) 2) 40 m torla bir tərəfi divar olan düzbucaqlı sahə hasarlanır. Divara perpendikulyar tərəflər x, paralel tərəf 40 − 2x. S = x(40 − 2x) = −2x² + 40x x₀ = −40/(−4) = 10; S = 10·20 = 200 m² 3) Cəmi 14 olan iki ədədin hasili ən çox neçədir? x(14 − x) = −x² + 14x; x₀ = 7; 7·7 = 49
Həyatdan. Futbolçu topu dik yuxarı 20 m/s sürətlə vurursa, top 2 saniyəyə 20 m qalxır və 4-cü saniyədə yerə qayıdır. Sürəti iki dəfə artırsa (40 m/s), hündürlük dörd dəfə artır — 80 m: t₀ = 4, h = −80 + 160 = 80.
Tipik səhvlər
  • "Neçə metr qalxar?" sualına t₀ yazmaq. Saniyə — x-dir, metr — y-dir.
  • Yerə düşmə vaxtını ən yuxarı vaxtla qarışdırmaq. h₀ = 0 olanda düşmə vaxtı 2t₀-dır.
  • Mənfi kökü cavab yazmaq. Vaxt, uzunluq mənfi olmur.
Yadda saxla
"Ən çox/ən az" → təpə. Nə vaxt / hansı ölçüdə → x₀ = −b/(2a). Nə qədər (hündürlük, sahə, hasil) → y₀ = y(x₀). Top: h = −5t² + vt + h₀, t₀ = v/10.
Özünü yoxla: 3 sual
  1. h = −5t² + 30t. Top neçə saniyədən sonra ən yuxarıdadır? t₀ = −30/(−10) = 3 s.
  2. Həmin top ən çox neçə metr qalxır? h(3) = −45 + 90 = 45 m.
  3. Perimetri 24 m olan düzbucaqlının ən böyük sahəsi? S = x(12 − x), x₀ = 6 → 6·6 = 36 m².
