Tam üstlü qüvvət, ədədin standart şəkli

Natural üstlü qüvvəti bilirsən: 2³ = 8. İndi üst sıfır və mənfi də ola bilər: 2⁰ = 1, 2⁻³ = 1/8. Bunun sayəsində çox böyük və çox kiçik ədədləri qısa yazırıq: Yerdən Günəşə qədər 1,5·10⁸ km, atomun ölçüsü 10⁻¹⁰ m. Bu yazılış ədədin standart şəklidir.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Sıfır və mənfi üstlü qüvvət

1 Niyə lazımdır

Bakteriya hər saat iki dəfə çoxalır. İndi 800-dür. 1 saat sonra 800·2, 3 saat sonra 800·2³. Bəs 2 saat əvvəl neçə idi? 800 : 2² = 200. Yazılışı eyni saxlamaq üçün "keçmiş vaxtı" mənfi üstlə yazırıq: 800·2⁻². Deməli, 2⁻² elə 1/2² deməkdir.

2 Əsas fikir

Qüvvətlərə bax: hər addımda üst 1 azalır, qiymət isə 2 dəfə azalır.

2³ = 8 2² = 4 2¹ = 2 2⁰ = 1 2⁻¹ = 1/2 2⁻² = 1/4

Bu qayda bütün a ≠ 0 üçün işləyir:

a⁰ = 1 (a ≠ 0) a⁻ⁿ = 1/aⁿ (a ≠ 0) (a/b)⁻ⁿ = (b/a)ⁿ (a ≠ 0, b ≠ 0)

0⁰ və 0⁻ⁿ ifadələrinin mənası yoxdur (sıfıra bölmə alınır).

3 Həll olunmuş nümunələr

1) 3⁻⁴ = 1/3⁴ = 1/81 2) (2/5)⁻² = (5/2)² = 25/4 3) (−2)⁻³ = 1/(−2)³ = 1/(−8) = −1/8 (üst tək — işarə mənfi) 4) (0,2)⁻³ = (1/5)⁻³ = 5³ = 125 5) −5⁰ + (−5)⁰ = −1 + 1 = 0 −5⁰-da qüvvətə yalnız 5 yüksəlir, minus sonra yazılır: −(5⁰) = −1. 6) 7⁰ + 2⁻¹ + 4⁻¹ = 1 + 1/2 + 1/4 = 7/4
Həyatdan. Kompüter yaddaşında: ikilik qəbulda 1 KiB (kibibayt) = 2¹⁰ bayt (onluq qəbulda 1 KB = 1000 bayt). Bir bayt isə 1 KiB-ın 2⁻¹⁰ = 1/1024 hissəsidir. Elmi kalkulyator "2^−10" yazanda məhz bunu hesablayır: 0,0009765625.
Tipik səhvlər
  • 2⁻³ = −8 yazmaq. Mənfi üst ədədi mənfi etmir, onu tərsinə çevirir: 2⁻³ = 1/8.
  • 5⁰ = 0 yazmaq. Sıfırdan fərqli istənilən ədədin sıfırıncı qüvvəti 1-dir.
  • −3² ilə (−3)²-ni qarışdırmaq: −3² = −9, (−3)² = 9.
Yadda saxla
a⁰ = 1, a⁻ⁿ = 1/aⁿ, (a/b)⁻ⁿ = (b/a)ⁿ Mənfi üst — tərs ədəd, mənfi ədəd yox.
Özünü yoxla: 3 sual
  1. 10⁻³ = ? 1/10³ = 1/1000 = 0,001.
  2. (3/4)⁻² = ? (4/3)² = 16/9.
  3. (−3)⁻² + 2⁰ = ? 1/(−3)² + 1 = 1/9 + 1 = 10/9.

Dərs 2. Tam üstlü qüvvətin xassələri

1 Niyə lazımdır

2⁻⁵ · 2⁸ : 2² ifadəsini hər qüvvəti ayrıca hesablayıb tapmaq uzundur. Xassələrlə bir sətirdə: üstləri topla-çıx, qiyməti sonda tap.

2 Xassələr

Natural üst üçün bildiyin xassələr tam (mənfi və sıfır) üst üçün də doğrudur (a ≠ 0, b ≠ 0):

aᵐ · aⁿ = aᵐ⁺ⁿ üstlər toplanır aᵐ : aⁿ = aᵐ⁻ⁿ üstlər çıxılır (aᵐ)ⁿ = aᵐⁿ üstlər vurulur (ab)ⁿ = aⁿbⁿ (a/b)ⁿ = aⁿ/bⁿ

Əsaslar fərqlidirsə, əvvəl onları eyni əsasa gətir: 4 = 2², 8 = 2³, 1/2 = 2⁻¹, 9 = 3², 1/27 = 3⁻³.

3 Həll olunmuş nümunələr

1) 2⁻⁵ · 2⁸ : 2² Üst: −5 + 8 − 2 = 1 → 2¹ = 2 2) (3⁻²)³ · 3⁸ (3⁻²)³ = 3⁻⁶; −6 + 8 = 2 → 3² = 9 3) 4³ · 8⁻² : 2⁻¹ 4³ = 2⁶, 8⁻² = 2⁻⁶ Üst: 6 + (−6) − (−1) = 1 → 2 4) 2⁻⁴ · 5⁻⁴ = (2·5)⁻⁴ = 10⁻⁴ = 1/10000 5) x⁻³ · x⁷ : (x²)⁻² = xᵏ. k = ? (x²)⁻² = x⁻⁴; k = −3 + 7 − (−4) = 8

4 Üstü tapmaq

Bəzən bərabərlikdə naməlum üstdə olur. Hər iki tərəfi eyni əsasla yaz — a > 0, a ≠ 1 olduqda üstlər bərabər olmalıdır (1ˣ = 1 üstü müəyyən etmir).

3ˣ = 1/81 1/81 = 3⁻⁴ → x = −4 (1/2)ˣ = 16 (1/2)ˣ = 2⁻ˣ, 16 = 2⁴ → −x = 4, x = −4 10ˣ = 0,001 0,001 = 10⁻³ → x = −3
Həyatdan. Fotokamerada diafraqma hər "bir pillə" işığı 2 dəfə azaldır. 3 pillə bağlasan, işıq 2⁻³ = 1/8 olur; sonra 1 pillə açsan — 2⁻³ · 2¹ = 2⁻² = 1/4. Fotoqraflar məhz üstləri toplayıb-çıxırlar.
Tipik səhvlər
  • Vurmada üstləri vurmaq: 2³ · 2⁴ ≠ 2¹². Düzü: 2⁷. Üstlər yalnız (aᵐ)ⁿ-də vurulur.
  • Mənfi üstü çıxanda işarəni itirmək: a⁵ : a⁻² = a⁵⁻⁽⁻²⁾ = a⁷, a³ yox.
  • Fərqli əsaslı qüvvətlərin üstlərini birbaşa toplamaq: 2³ · 3²-də heç nə toplanmır.
Yadda saxla
vurma → üstlər toplanır; bölmə → çıxılır; qüvvətin qüvvəti → vurulur Əvvəl eyni əsasa gətir, sonra üstlərlə işlə.
Özünü yoxla: 3 sual
  1. 5⁻³ · 5⁶ : 5² = ? −3 + 6 − 2 = 1 → 5.
  2. 9² · 27⁻¹ = ? 3⁴ · 3⁻³ = 3¹ = 3.
  3. 2ˣ = 1/32. x = ? 1/32 = 2⁻⁵ → x = −5.

Dərs 3. Ədədin standart şəkli

1 Niyə lazımdır

İşığın sürəti 300 000 000 m/s, qırmızı qan hüceyrəsinin diametri 0,000007 m. Sıfırları saymaq çətindir və səhv etmək asandır. Standart şəkildə: 3·10⁸ m/s və 7·10⁻⁶ m — qısa və aydın.

2 Əsas fikir

Standart şəkil: a·10ⁿ, 1 ≤ a < 10, n — tam ədəd n — ədədin tərtibi

Necə yazırıq: vergülü elə sürüşdür ki, ondan əvvəl bir sıfırdan fərqli rəqəm qalsın. Neçə yer sürüşdürdünsə, |n| odur.

Ədəd ≥ 10 → vergül sola gedir → n müsbət 0 < ədəd < 1 → vergül sağa gedir → n mənfi 1 ≤ ədəd < 10 → n = 0

Tam ədəddə vergül görünmür, amma o, ədədin sonunda dayanır: 52 000 = 52 000,0.

3 Həll olunmuş nümunələr

1) 52 000 a = 5,2; vergül 4 yer sola → 5,2·10⁴ 2) 0,00034 a = 3,4; vergül 4 yer sağa → 3,4·10⁻⁴ 3) 7 artıq 1 ≤ 7 < 10 → 7·10⁰ 4) 0,045·10⁷ 0,045 = 4,5·10⁻² 4,5·10⁻² · 10⁷ = 4,5·10⁵ 5) 2,07·10⁻³ onluq kəsrlə: vergül 3 yer sola → 0,00207

4 Standart şəkildə əməllər

a-ları ayrıca, 10-un qüvvətlərini ayrıca hesabla. Sonda 1 ≤ a < 10 olduğunu yoxla — olmasa, düzəlt.

1) (4·10⁵)·(3·10⁻²) = 12·10³ = 1,2·10⁴ 2) (1,2·10⁻³) : (4·10⁵) = 0,3·10⁻⁸ = 3·10⁻⁹ 3) (5·10⁻³)² = 25·10⁻⁶ = 2,5·10⁻⁵ 4) 6·10⁴ + 3·10³ = 60·10³ + 3·10³ = 63·10³ = 6,3·10⁴

Toplamada əvvəl 10-un qüvvətləri eyniləşdirilir, sonra a-lar toplanır.

5 Həyatdan

Həyatdan: Günəşin işığı. Günəşdən Yerə qədər 1,5·10⁸ km, işığın sürəti 3·10⁵ km/s. İşıq nə qədər vaxta gəlir?
1,5·10⁸ : (3·10⁵) = 0,5·10³ = 500 saniyə — təxminən 8 dəqiqə 20 saniyə. Gördüyün Günəş 8 dəqiqə əvvəlki Günəşdir.
Ölkənin büdcəsi 3,6·10¹⁰ manat, əhalisi 9·10⁶ nəfər. Adambaşına: 3,6·10¹⁰ : (9·10⁶) = 0,4·10⁴ = 4000 manat.
Tipik səhvlər
  • a-nı 10 və ya ondan böyük saxlamaq: 12·10³ standart şəkil deyil, 1,2·10⁴ lazımdır.
  • Kiçik ədəddə üstün işarəsini səhv yazmaq: 0,0005 = 5·10⁻⁴, 5·10⁴ yox.
  • Vergülün yerini səhv saymaq. Yoxla: 10⁻⁴-ə vurmaq — vergülü 4 yer sola aparmaqdır, geri qayıdanda 0,0005 alınmalıdır.
Yadda saxla
a·10ⁿ, 1 ≤ a < 10 böyük ədəd → n > 0, kiçik ədəd (< 1) → n < 0 Əməldə: a-lar ayrıca, 10-lar ayrıca, sonda a-nı düzəlt.
Özünü yoxla: 3 sual
  1. 0,0071 ədədini standart şəkildə yaz. 7,1·10⁻³ (vergül 3 yer sağa).
  2. (2·10⁻⁴)·(6·10⁹) — standart şəkildə? 12·10⁵ = 1,2·10⁶.
  3. 480 000 000 ədədinin tərtibi neçədir? 4,8·10⁸ → tərtib 8.
