Funksiyanın xassələri; tərs və mürəkkəb funksiya

Olimpiadada funksiya çox vaxt düsturla verilmir. Deyirlər: "f tək funksiyadır", "f dövrüdür", "f artandır" — və bu bir cümlədən çoxlu məlumat çıxarmaq lazımdır. Burada cüt/tək, dövrü və monoton funksiyaların "gizli gücünü", sonra mürəkkəb funksiyanı, tərs funksiyanı və f(f(x)) tipli məsələləri öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, olimpiada məsələlərini əvvəl özün həll etməyə çalış, sonra həllə bax. Sonra Oyun və Sınaq.

Dərs 1. Cüt, tək və dövrü funksiyalar

1 Niyə lazımdır

Məsələdə deyilir: "f tək funksiyadır, f(5) = 7. f(−5) neçədir?" Düstur yoxdur, qrafik yoxdur — amma cavab var: −7. Xassənin özü məlumat daşıyır.

Həyatdan. Saat 24 saatdan bir təkrarlanır. İndi saat 15:00-dırsa, 100 saat sonra neçədir? 100 = 4·24 + 4 — yəni 4 saat sonrakı vaxt: 19:00. Dövrü funksiyanın bütün fikri budur: tam dövrləri atırıq.

2 Əsas fikir

Cüt: f(−x) = f(x) (qrafik Oy oxuna görə simmetrik) Tək: f(−x) = −f(x) (qrafik başlanğıca görə simmetrik) Dövrü: f(x + T) = f(x) ⇒ f(x + kT) = f(x), k tam

Cüt və tək üçün təyin oblastı simmetrik olmalıdır (x varsa, −x də var). Tək funksiya x = 0-da təyin olunubsa, f(0) = 0 (çünki f(0) = −f(0)).

cüt · cüt = cüt tək · tək = cüt cüt · tək = tək Hər f üçün: f(x) = [f(x) + f(−x)]/2 + [f(x) − f(−x)]/2 (cüt hissə) (tək hissə)

İkinci düstur çox işə yarayır: f(x) + f(−x) həmişə cütdür, f(x) − f(−x) həmişə təkdir. Əgər f(x + a) = −f(x) olarsa, iki addımda f(x + 2a) = f(x) — period 2a-dır.

3 Həll olunmuş nümunə

f(x + 4) = f(x), f(1) = 2. f(2025) = ? 2025 = 4 · 506 + 1 → 2025 ≡ 1 (mod 4) f(2025) = f(1) = 2. f tək funksiya, f(3) = 5. f(−3) + f(3) + f(0) = ? f(−3) = −5, f(0) = 0 → −5 + 5 + 0 = 0.

4 Olimpiada məsələləri

Məsələ 1. f(x) = x⁵ + ax³ + bx − 8 və f(−2) = 10. f(2) = ? Həll. a və b naməlumdur, onları tapmağa ehtiyac yoxdur. g(x) = f(x) + 8 = x⁵ + ax³ + bx — tək funksiyadır (yalnız tək qüvvətlər). g(−2) = f(−2) + 8 = 18 → g(2) = −18 (tək olduğu üçün). f(2) = g(2) − 8 = −18 − 8 = −26. Fikir: sabiti ayır, qalan hissə təkdir.
Məsələ 2. Bütün x üçün f(x + 1) + f(x − 1) = √2 · f(x). İsbat et ki, f dövrü funksiyadır. Həll. a = f(x − 1), b = f(x) götürək. Tənlikdən ardıcıl tapırıq: f(x + 1) = √2·b − a f(x + 2) = √2·f(x + 1) − f(x) = √2(√2·b − a) − b = b − √2·a f(x + 3) = √2·f(x + 2) − f(x + 1) = √2·b − 2a − √2·b + a = −a Deməli f(x + 3) = −f(x − 1). x yerinə x + 1 qoysaq: f(x + 4) = −f(x). Onda f(x + 8) = −f(x + 4) = f(x). Period 8-dir. ∎ Fikir: f(x + a) = −f(x) ⇒ period 2a.
Tipik səhvlər
  • "Bütün funksiyalar ya cütdür, ya tək." Yox! Çoxu nə cütdür, nə tək (məsələn, x² + x).
  • Tək funksiya üçün f(−x) = f(x) yazmaq. İşarə dəyişir.
  • Dövrü funksiyada qalığı səhv götürmək. Qalıq 0 çıxırsa, arqument dövrün sonuna düşür: məsələn, period 4 və f(8) üçün f(4) kimi oxu (verilmiş qiymətlərə bax).
Yadda saxla
Tək: f(−x) = −f(x), f(0) = 0. Cüt: f(−x) = f(x). Sabiti ayır: f(x) − c tək ola bilər. f(x + kT) = f(x): arqumenti T-yə böl, qalıq vacibdir. f(x + a) = −f(x) ⇒ period 2a.
Özünü yoxla: 3 sual
  1. f tək funksiyadır, f(−4) = 7. f(4) = ? −7
  2. f(x + 5) = f(x), f(2) = 9. f(2027) = ? 2027 = 5·405 + 2, deməli f(2027) = f(2) = 9.
  3. f(x) = ax³ + bx − 2, f(1) = 5. f(−1) = ? f(x) + 2 təkdir: f(1) + 2 = 7, deməli f(−1) + 2 = −7, f(−1) = −9.

Dərs 2. Artan və azalan funksiyalar

1 Niyə lazımdır

Tənliyi x³ + x = 10 həll etmək üçün düstur lazım deyil: x = 2 uyğun gəlir, 8 + 2 = 10. Amma başqa kök varmı? Monotonluq deyir: yox. Sol tərəf artır, hər qiyməti bir dəfə alır. Bu üsul olimpiadada "təxmin et və yeganəliyi isbat et" adlanır.

Həyatdan. Hovuza hər dəqiqə su tökülür və səviyyə yalnız qalxır. Səviyyə 1 m olan anı bir dəfə tapacaqsan — iki ayrı vaxtda eyni səviyyə ola bilməz.

2 Əsas fikir

Ciddi artan: x₁ < x₂ ⇒ f(x₁) < f(x₂) Ciddi azalan: x₁ < x₂ ⇒ f(x₁) > f(x₂) Ciddi monoton funksiyada: f(u) = f(v) ⇒ u = v
artan + artan = artan artan ∘ artan = artan artan ∘ azalan = azalan −f artanın əksidir (azalan olur)

Artan funksiyada bərabərsizliyin istiqaməti saxlanır: f(u) < f(v) ⇔ u < v. Azalanda istiqamət dönür: f(u) < f(v) ⇔ u > v.

3 Həll olunmuş nümunə

x⁷ + x³ + x = 3 tənliyini həll et. x = 1 yoxlayırıq: 1 + 1 + 1 = 3. Uyğundur. Sol tərəf üç artan funksiyanın cəmidir → artandır, hər qiyməti bir dəfə alır. Deməli x = 1 yeganə kökdür. f artandır, f(2x − 1) < f(x + 3). x-i tap. Artanda istiqamət qalır: 2x − 1 < x + 3 → x < 4.

4 Olimpiada məsələsi

Məsələ 3. f: ℝ → ℝ artan funksiyadır və hər x üçün f(f(x)) = x. İsbat et ki, f(x) = x. Həll. Əksini fərz edək: bir a üçün f(a) ≠ a. Hal 1: f(a) > a. f artandır → f(f(a)) > f(a). Amma f(f(a)) = a. Deməli a > f(a) — fərziyyə ilə ziddiyyət. Hal 2: f(a) < a. f artandır → f(f(a)) < f(a), yəni a < f(a) — yenə ziddiyyət. Deməli hər a üçün f(a) = a. ∎ Qeyd: azalan funksiya ola bilər, məsələn f(x) = −x üçün də f(f(x)) = x. Artan olması vacibdir.
Tipik səhvlər
  • Azalan funksiyada bərabərsizliyin istiqamətini saxlamaq. f azalandırsa, f(u) < f(v) ⇒ u > v.
  • "Bir kök tapdım, bəsdir." Monotonluq göstərilməyibsə, başqa kök ola bilər. Yeganəliyi mütləq əsaslandır.
  • Artan və azalan funksiyanın cəmini artan sanmaq. Cəm artan da, azalan da olmaya bilər.
Yadda saxla
Ciddi monoton ⇒ f(u) = f(v) olanda u = v. Artan: bərabərsizlik istiqaməti qalır. Azalan: dönür. Təxmin et + monotonluqla yeganəliyi isbat et. f(f(x)) = x və f artan ⇒ f(x) = x.
Özünü yoxla: 3 sual
  1. f ciddi artandır, f(3x − 1) = f(x + 5). x = ? 3x − 1 = x + 5 → x = 3.
  2. f ciddi azalandır, f(x) < f(2). x haqqında nə demək olar? x > 2 (azalanda istiqamət dönür).
  3. x³ + x = 10 tənliyinin kökü neçədir? 2 (8 + 2 = 10); sol tərəf artandır, kök yeganədir.

Dərs 3. Mürəkkəb və tərs funksiya; f(f(x))

1 Niyə lazımdır

Şəkildəki yelləncəkdə bir uc nə qədər qalxırsa, o biri uc o qədər enir — tək funksiya da belədir: f(−x) = −f(x).

Mağaza əvvəl 10 manat endirim edir, sonra qiymətin üstünə 20% əlavə edir. Bunu tərsinə etsən (əvvəl 20%, sonra 10 manat), eyni nəticə almazsan. Əməllərin sırası vacibdir — mürəkkəb funksiya belə yazılır. Tərs funksiya isə əməli geri qaytarır: son qiyməti bilirsən, ilk qiyməti tapırsan.

Həyatdan. Selsi → Farenheyt: F = 1,8·C + 32. Tərsi: C = (F − 32)/1,8. Əvvəl 32-ni çıxırıq (sonuncu əməli əvvəl geri alırıq), sonra 1,8-ə bölürük.

2 Əsas fikir

(f∘g)(x) = f(g(x)) əvvəl g, sonra f y = f(x) ⇔ x = f⁻¹(y) f⁻¹(f(x)) = x, f(f⁻¹(y)) = y

Tərsi necə tapmaq olar: y = f(x) tənliyindən x-i y vasitəsilə ifadə et. Tərsi olması üçün f hər qiyməti bir dəfə almalıdır — ciddi monoton funksiyalar belədir.

f və f⁻¹ qrafikləri y = x düz xəttinə görə simmetrikdir. Kəsişmə nöqtələri adətən f(x) = x tənliyindən tapılır. Diqqət: f⁻¹(x) ≠ 1/f(x)

3 Həll olunmuş nümunə

f(x) = (2x + 1)/(x − 3). f⁻¹(5) = ? f(x) = 5 olan x-i axtarırıq: 2x + 1 = 5(x − 3) 2x + 1 = 5x − 15 → 16 = 3x → x = 16/3. Yoxlama: f(16/3) = (32/3 + 1)/(16/3 − 3) = (35/3)/(7/3) = 5. ✓ f(x) = 3x − 1, g(x) = x². f(g(2)) və g(f(2)) neçədir? f(g(2)) = f(4) = 11. g(f(2)) = g(5) = 25. Sıra vacibdir!

4 f(f(x)) tipli məsələlər

İki fikir var. Birinci: f-in şəklini təxmin et (adətən ax + b), əmsalları müqayisə et. İkincisi: f-i təkrar tətbiq edəndə nəticələr dövrü təkrarlanırsa, dövrü tap.

f xətti artan funksiyadır və f(f(f(x))) = 8x + 21. f(x) = ? f(x) = ax + b. f(f(x)) = a²x + (a + 1)b. f(f(f(x))) = a³x + (a² + a + 1)b. a³ = 8 → a = 2. (4 + 2 + 1)b = 21 → b = 3. f(x) = 2x + 3. Yoxla: f(f(x)) = 4x + 9, f(f(f(x))) = 8x + 21. ✓
Məsələ 4. f(x) = 1/(1 − x). f funksiyasını 2 ədədinə 2026 dəfə ardıcıl tətbiq edirik: f(f(…f(2)…)). Nəticə neçədir? Həll. f(2) = 1/(1 − 2) = −1. f(−1) = 1/(1 + 1) = 1/2. f(1/2) = 1/(1 − 1/2) = 2. — başlanğıc ədədə qayıtdıq! Dövr 3-dür: f(f(f(x))) = x. 2026 = 3 · 675 + 1. 675 tam dövr heç nə dəyişmir, qalır 1 tətbiq: nəticə f(2) = −1. ∎
Tipik səhvlər
  • f(g(x)) ilə g(f(x))-i qarışdırmaq. Daxildəki funksiya əvvəl işləyir.
  • f⁻¹(x)-i 1/f(x) kimi oxumaq. Bunlar fərqli şeylərdir.
  • f(f(x)) = 4x + 9 görüb f(x) = 2x + 9 yazmaq. Düz: f(x) = ax + b götürüb a² = 4, (a + 1)b = 9 həll et.
  • Dövrü tapmadan 2026 dəfə hesablamağa çalışmaq. Üç-dörd addımdan sonra təkrar axtar.
Yadda saxla
f(g(x)): əvvəl g, sonra f. f⁻¹(y): f(x) = y tənliyini x-ə görə həll et. f(x) = ax + b: f(f(x)) = a²x + (a + 1)b. Təkrar tətbiq: dövrü tap, n-i dövrə böl, qalığa bax.
Özünü yoxla: 3 sual
  1. f(x) = 2x + 6. f⁻¹(10) = ? 2x + 6 = 10 → x = 2.
  2. f(x) = 3x − 1, g(x) = x². g(f(1)) = ? f(1) = 2, g(2) = 4.
  3. f(x) = 1/x. f-i 4 ədədinə 2027 dəfə tətbiq etsək nə alarıq? f(f(x)) = x, dövr 2-dir; 2027 tək olduğundan nəticə f(4) = 1/4.
