Kəsr-rasional tənliklər

Dəyişən məxrəcdə olan tənliklər: 3/(x − 2) = 1, x + 6/x = 5. Həll yolu sadədir — DMQ daxilində hər iki tərəfi ortaq məxrəcə vurub xətti və ya kvadrat tənlik alırıq. Tələ isə birdir: tapdığın kök məxrəci sıfır edə bilər. Belə kökü atmağı burada öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Dəyişənin mümkün qiymətləri (DMQ)

1 Niyə lazımdır

12 alma 3 nəfərə bölünür — hərəyə 4. Bəs 0 nəfərə? Sual mənasızdır: sıfıra bölmək olmaz. Kalkulyator da "Error" yazır.

Məxrəcdə x olanda bəzi x-lər məxrəci sıfır edir. Həmin x-lərdə ifadənin mənası yoxdur. Tənliyi həll etməzdən əvvəl onları tapıb kənara qoyuruq.

2 Əsas fikir

Kəsr-rasional tənlik — dəyişəni məxrəcdə olan tənlikdir. Məsələn: 5/(x − 3) = 2, x/(x + 1) = 4/x.

DMQ (dəyişənin mümkün qiymətləri) — bütün məxrəcləri sıfırdan fərqli edən x-lər. Tapmaq üçün hər məxrəci sıfıra bərabər edirik — çıxan qiymətlər qadağandır.

Məxrəc ≠ 0 x − 3 ≠ 0 → x ≠ 3

Surətə baxmırıq: surət sıfır ola bilər (0/5 = 0 — normal ədəddir).

3 Həll olunmuş nümunələr

1) (x + 1)/(2x − 5) 2x − 5 = 0 → 2x = 5 → x = 5/2 DMQ: x ≠ 2,5 2) 7/(x² − 9) + 1/x x² − 9 = 0 → x² = 9 → x = 3 və x = −3 x = 0 DMQ: x ≠ −3; 0; 3 (üç qadağan qiymət) 3) 4/(x² − 5x + 6) x² − 5x + 6 = 0 → (x − 2)(x − 3) = 0 → x = 2, x = 3 DMQ: x ≠ 2; 3 4) 8/(x² + 4) x² + 4 həmişə ≥ 4, heç vaxt sıfır olmur DMQ: bütün ədədlər

Nümunə 2-nin DMQ-su: bütün ədəd oxu, yalnız üç deşik var — −3, 0, 3. Cavab bu deşiklərdən birinə düşsə, o cavab deyil.

Həyatdan. Sinif 120 manatlıq ekskursiya pulunu x şagird arasında bərabər bölür: hər birinə 120/x manat. x = 0 mənasızdır — şagird yoxdursa, bölünəcək adam da yoxdur. Riyaziyyat bunu DMQ ilə deyir: x ≠ 0.
Tipik səhvlər
  • x² − 9 = 0-dan yalnız x = 3 yazmaq. Kvadratın iki kökü var: ±3.
  • Surəti sıfıra bərabər edib "qadağan" saymaq. Qadağan olan yalnız məxrəcin sıfırıdır.
  • x² + 4 kimi məxrəcdə qadağan qiymət axtarmaq. Kvadrat + müsbət ədəd heç vaxt sıfır olmur.
Yadda saxla
Hər məxrəci = 0 qoy və həll et. Çıxan x-lər — qadağandır (DMQ-ya daxil deyil). Tənliyin cavabı qadağan qiymətə düşə bilməz.
Özünü yoxla: 3 sual
  1. 7/(x + 4) ifadəsinin DMQ-su nədir? x + 4 ≠ 0 → x ≠ −4.
  2. 1/(x² − 16) üçün neçə qadağan qiymət var? İki: x = 4 və x = −4.
  3. (x − 3)/5 ifadəsinin qadağan qiyməti varmı? Yox. Məxrəc 5-dir, heç vaxt sıfır olmur. x = 3 olanda ifadə sadəcə 0-a bərabərdir.

Dərs 2. Xətti tənliyə gətirilən kəsr-rasional tənliklər

1 Niyə lazımdır

Kəsrlərlə işləmək çətindir, xətti tənliyi isə sən artıq yaxşı həll edirsən. Fikir: tənliyi məxrəcə vurub kəsrlərdən qurtulmaq. Qalan iş — adi ax = b.

2 Həll alqoritmi

1. DMQ: qadağan qiymətləri yaz. 2. Hər iki tərəfi ortaq məxrəcə vur. Tənasüb a/b = c/d → a·d = b·c 3. Alınan tənliyi həll et. 4. Kökü DMQ ilə yoxla.

Tənasübdə bu, "çarpaz vurma"dır: birinci kəsrin surəti ikincinin məxrəcinə, ikincinin surəti birincinin məxrəcinə vurulur.

3 Həll olunmuş nümunələr

Nümunə 1. 3/(x − 2) = 5/(x + 2) DMQ: x ≠ 2, x ≠ −2 Çarpaz vur: 3(x + 2) = 5(x − 2) 3x + 6 = 5x − 10 16 = 2x → x = 8 8 qadağan deyil. Yoxla: 3/6 = 1/2, 5/10 = 1/2 ✓ Cavab: x = 8
Nümunə 2. (x + 4)/(x − 1) = 3 DMQ: x ≠ 1 (x − 1)-ə vur: x + 4 = 3(x − 1) x + 4 = 3x − 3 7 = 2x → x = 3,5 Yoxla: 7,5/2,5 = 3 ✓ Cavab: x = 3,5
Nümunə 3. 1/x + 2/(3x) = 5/6 DMQ: x ≠ 0. Ortaq məxrəc: 6x 6x-ə vur: 6 + 4 = 5x → x = 2 Yoxla: 1/2 + 2/6 = 1/2 + 1/3 = 5/6 ✓ Cavab: x = 2

4 Həyatdan

Həyatdan: qatar və maşın. Eyni vaxtda maşın 120 km, qatar 180 km yol gedir. Qatarın sürəti maşınınkından 20 km/saat çoxdur. Maşının sürəti nədir?
x — maşının sürəti. Vaxt = yol ÷ sürət, vaxtlar bərabərdir:
120/x = 180/(x + 20) → 120(x + 20) = 180x → 2400 = 60x → x = 40.
Maşın 40 km/saat, qatar 60 km/saat. Yoxla: 120 ÷ 40 = 3 saat, 180 ÷ 60 = 3 saat ✓
Tipik səhvlər
  • Ortaq məxrəcə vurarkən kəsr olmayan həddi vurmağı unutmaq: 1/x + 2 = 3/x → 1 + 2x = 3, "1 + 2 = 3" yox.
  • Mötərizəni açarkən işarə səhvi: −2(x − 3) = −2x + 6.
  • Kökü DMQ ilə yoxlamamaq. Növbəti dərsdə görəcəksən ki, bu, əsas tələdir.
Yadda saxla
DMQ → məxrəcə vur → həll et → yoxla. a/b = c/d → a·d = b·c
Özünü yoxla: 3 sual
  1. 4/(x − 1) = 2. x = ? 4 = 2(x − 1) → 4 = 2x − 2 → x = 3. 3 ≠ 1 ✓
  2. 2/(x + 3) = 1/(x − 1). x = ? 2(x − 1) = x + 3 → x = 5. Yoxla: 2/8 = 1/4 ✓
  3. x/(x − 2) = 2/(x − 2). x = ? x = 2 alınır, amma DMQ: x ≠ 2. Kök yoxdur. (Növbəti dərsin mövzusu.)

Dərs 3. Kvadrat tənliyə gətirilən tənliklər və kənar köklər

1 Niyə lazımdır

İmtahanda belə sual tez-tez olur: "tənliyin kökünü tap", amma kvadrat tənliyin iki kökündən biri məxrəci sıfır edir. O kök "saxta"dır — buna kənar kök deyilir. Kim yoxlamır, iki cavab yazır və ya çaşıb sualı boş buraxır. Sən alqoritmlə gedəcəksən — ilişməyəcəksən.

2 Kənar kök haradan çıxır

Məxrəcə vuranda tənlik "genişlənir": yeni tənlik məxrəci sıfır edən x-ə də icazə verir. Ona görə yeni tənliyin bütün kökləri əsl tənliyə uyğun olmaya bilər.

Məxrəcə vurdun → kökləri tapdın Hər kökü DMQ ilə yoxla: qadağan qiymətdirsə — at (kənar kök) heç biri qalmırsa — "kök yoxdur"

Xüsusi hal — kəsr sıfıra bərabərdir:

A/B = 0 ⇔ A = 0 və B ≠ 0

3 Hər iki kök yarayır

x + 6/x = 5 DMQ: x ≠ 0 x-ə vur: x² + 6 = 5x → x² − 5x + 6 = 0 Viyet: x₁ + x₂ = 5, x₁·x₂ = 6 → x = 2, x = 3 İkisi də 0 deyil → ikisi də kökdür. Yoxla: 2 + 3 = 5 ✓ 3 + 2 = 5 ✓ Cavab: 2 və 3

4 Bir kök atılır

Nümunə 1. x²/(x − 3) = 9/(x − 3) DMQ: x ≠ 3 Məxrəclər eynidir → surətlər bərabərdir: x² = 9 x = 3 və x = −3 x = 3 qadağandır → atılır. Yoxla x = −3: 9/(−6) = 9/(−6) ✓ Cavab: x = −3
Nümunə 2. (x² − x − 6)/(x − 3) = 0 Surət = 0: x² − x − 6 = 0 → x = 3, x = −2 Məxrəc ≠ 0: x ≠ 3 → x = 3 atılır. Cavab: x = −2
Nümunə 3. x/(x − 1) − 2/(x + 1) = 4/(x² − 1) x² − 1 = (x − 1)(x + 1) — ortaq məxrəc. DMQ: x ≠ 1, x ≠ −1 Ortaq məxrəcə vur: x(x + 1) − 2(x − 1) = 4 x² + x − 2x + 2 = 4 x² − x − 2 = 0 → x = 2, x = −1 x = −1 qadağandır → atılır. Yoxla x = 2: 2/1 − 2/3 = 4/3, 4/(4 − 1) = 4/3 ✓ Cavab: x = 2

5 Heç bir kök qalmır

x/(x − 2) − 8/(x² − 4) = 1 DMQ: x ≠ 2, x ≠ −2 (x² − 4)-ə vur: x(x + 2) − 8 = x² − 4 x² + 2x − 8 = x² − 4 2x = 4 → x = 2 x = 2 qadağandır → atılır. Cavab: kök yoxdur (köklərin sayı 0)

"Kök yoxdur" da tam hüquqlu cavabdır. Testdə belə variant varsa, onu seçməkdən qorxma — yoxlama sənin tərəfindədir.

Tipik səhvlər
  • Kənar kökü saxlamaq: x²/(x − 3) = 9/(x − 3) üçün "x = ±3" yazmaq. Düzü: yalnız x = −3.
  • Kəsr sıfırdırsa, surəti həll edib məxrəci yoxlamamaq.
  • Bütün köklər atılanda çaşıb sualı boş buraxmaq. Cavab var: "kök yoxdur", köklərin sayı — 0.
  • Köklərin cəmi soruşulanda Viyetlə x₁ + x₂-ni birbaşa yazmaq. Əvvəl kənar kökü at, sonra qalanları topla.
Yadda saxla
1. DMQ 2. Ortaq məxrəcə vur 3. Həll et 4. Hər kökü DMQ ilə yoxla — qadağanı at. A/B = 0 ⇔ A = 0, B ≠ 0
Özünü yoxla: 3 sual
  1. x − 8/x = 2. Köklərin cəmi? x² − 2x − 8 = 0 → x = 4, x = −2. İkisi də 0 deyil. Cəm: 2.
  2. x²/(x + 5) = 25/(x + 5). Kökü tap. x² = 25 → x = ±5. x = −5 məxrəci sıfır edir — atılır. Cavab: x = 5.
  3. (x² − 1)/(x − 1) = 0. Neçə kök var? x² − 1 = 0 → x = ±1. x = 1 atılır. Bir kök: x = −1.

Dərs 4. Rasional tənliklərin tətbiqi ilə məsələ həlli

1 Niyə lazımdır

Sürət, vaxt, iş, qiymət — bunların çoxu bölmə ilə bağlıdır: vaxt = yol ÷ sürət, iş sürəti = 1 ÷ vaxt, say = pul ÷ qiymət. Naməlum məxrəcə düşür — və kəsr-rasional tənlik alınır.

2 Plan

1. x — nə? (sürət, vaxt, qiymət...) 2. Qalan kəmiyyətləri x ilə yaz. 3. Bərabərliyi tap → tənlik. 4. Həll et, mənasız kökü at: mənfi sürət / vaxt / qiymət olmur. 5. Cavabı şərtlə yoxla.

3 Hərəkət: çay axını

Qayıq axınla 24 km, geri axına qarşı 24 km üzdü — cəmi 5 saat. Axının sürəti 2 km/saat. Qayığın öz sürəti? x — qayığın öz sürəti. Axınla: x + 2, axına qarşı: x − 2; şərt: x > 2 24/(x + 2) + 24/(x − 2) = 5 (x² − 4)-ə vur: 24(x − 2) + 24(x + 2) = 5(x² − 4) 48x = 5x² − 20 5x² − 48x − 20 = 0 D = 48² + 4·5·20 = 2304 + 400 = 2704 = 52² x = (48 + 52)/10 = 10, x = (48 − 52)/10 = −0,4 (atılır) Yoxla: 24/12 + 24/8 = 2 + 3 = 5 ✓ Cavab: 10 km/saat

4 Birgə iş və qiymət

İki boru hovuzu birlikdə 2 saata doldurur. Birinci boru təkbaşına ikincidən 3 saat tez doldurur. Birinci neçə saata doldurar? x — birincinin vaxtı, x + 3 — ikincinin; şərt: x > 0 1 saatda: 1/x və 1/(x + 3) hissə; birlikdə 1/2 hissə. 1/x + 1/(x + 3) = 1/2 2x(x + 3)-ə vur: 2(x + 3) + 2x = x(x + 3) x² − x − 6 = 0 → x = 3, x = −2 (atılır) Yoxla: 1/3 + 1/6 = 1/2 ✓ Cavab: 3 saat
60 manata dəftərlər alındı. Hər dəftər 1 manat ucuz olsaydı, eyni pula 2 dəftər çox almaq olardı. Dəftər neçəyədir? x — qiymət (şərt: x > 1). Say: 60/x, ucuz olsa: 60/(x − 1) 60/(x − 1) − 60/x = 2 x(x − 1)-ə vur: 60x − 60(x − 1) = 2x(x − 1) 60 = 2x² − 2x → x² − x − 30 = 0 x = 6, x = −5 (atılır) Yoxla: 60/6 = 10 dəftər, 60/5 = 12 dəftər — 2 çox ✓ Cavab: 6 manat
Həyatdan. "Birlikdə" işdə vaxtlar toplanmır — iş sürətləri (1 saatda görülən hissə) toplanır. 3 saatlıq və 6 saatlıq boru birlikdə 9 saat yox, 2 saat işləyir: hər saatda hovuzun 1/3 + 1/6 = 1/2-si dolur.
Tipik səhvlər
  • Mənfi kökü cavab yazmaq. Sürət, vaxt, qiymət mənfi olmur — atılır.
  • Axınla və axına qarşı sürəti qarışdırmaq: axınla x + u (çay itələyir), axına qarşı x − u.
  • Birgə işdə vaxtları toplamaq. Toplanan — 1/x kimi iş sürətləridir.
Yadda saxla
vaxt = yol ÷ sürət iş sürəti = 1 ÷ vaxt; birgə: 1/x + 1/y = 1/t say = pul ÷ qiymət Mənasız (mənfi) kök atılır.
Özünü yoxla: 3 sual
  1. Bir boru hovuzu 6 saata, digəri 3 saata doldurur. Birlikdə neçə saata doldurarlar? 1/6 + 1/3 = 1/2 hissə saatda → 2 saat.
  2. Qayıq axınla 15 km, geri 15 km üzdü, cəmi 4 saat. Axın 2 km/saat. Qayığın öz sürəti? 15/(x + 2) + 15/(x − 2) = 4 → 2x² − 15x − 8 = 0 → x = 8 (x = −0,5 atılır). Yoxla: 15/10 + 15/6 = 1,5 + 2,5 = 4 ✓. Cavab: 8 km/saat.
  3. 40 manata kitablar alındı. Hər kitab 2 manat baha olsaydı, 1 kitab az alınardı. Kitab neçəyədir? 40/x − 40/(x + 2) = 1 → x² + 2x − 80 = 0 → x = 8 (x = −10 atılır). Yoxla: 40/8 = 5, 40/10 = 4 ✓. Cavab: 8 manat.
