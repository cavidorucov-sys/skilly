Sinuslar və kosinuslar teoremi

Düzbucaqlı üçbucaqda sin α = qarşı/hipotenuz kifayət edirdi. Ancaq istənilən üçbucaqda, düz bucaq olmayanda, tərəfləri və bucaqları necə bağlamaq olar? İki teorem: sinuslar teoremi (tərəf / qarşısındakı bucağın sinusu = 2R) və kosinuslar teoremi (Pifaqorun ümumiləşməsi). Üçbucağın sahəsi üçün S = ½ab sin C də bu mövzudadır. Bunlarla hər üçbucağı "həll etmək" olur: üç ölçüdən qalanlarını tapırsan.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Sinuslar teoremi və çevrəxarici çevrənin radiusu

1 Niyə lazımdır

Çayın qarşı sahilində ağac var. Sənin sahildə iki nöqtən var, A və B, aralarındakı məsafə ölçülüb. Ağaca baxış bucaqlarını da ölçdün. Burada düz bucaq yoxdur, sin = qarşı/hipotenuz işləmir. Ağaca qədər məsafəni sinuslar teoremi verir.

2 Teorem və isbatı

a / sin A = b / sin B = c / sin C = 2R (a, b, c — tərəflər, A, B, C — qarşısındakı bucaqlar, R — üçbucağın çevrəxarici çevrəsinin radiusu)

İsbat. Üçbucağın ətrafına çevrə çək, mərkəzi O. B nöqtəsindən diametr çək, o çevrəni A' nöqtəsində kəsir: BA' = 2R.

∠BA'C və ∠BAC eyni BC qövsünə söykənən daxilə çəkilmiş bucaqlardır, ona görə bərabərdirlər: ikisi də A. BA' diametrdir, ona görə ∠BCA' = 90°.

BCA' düzbucaqlı üçbucağında BC qarşı katetdir, BA' hipotenuzdur: BC = BA'·sin A' → a = 2R·sin A. Eyni mühakimə b = 2R sin B və c = 2R sin C verir. ∎ Əgər A obtuzdursa, A' nöqtəsi başqa qövsdə düşür və ∠BA'C = 180° − A olur. Amma sin(180° − A) = sin A, ona görə a = 2R sin A yenə doğrudur.

3 Həll olunmuş nümunələr

Nümunə 1. ABC üçbucağında A = 30°, B = 45°, a = 10. b və R = ? R = a/(2 sin A) = 10/(2·1/2) = 10. b = 2R sin B = 20·(√2/2) = 10√2. (və ya b = a sin B/sin A = 10·(√2/2)/(1/2) = 10√2)
Nümunə 2. Üçbucağın tərəfi a = 6, çevrəxarici çevrənin radiusu R = 5. A bucağı? sin A = a/(2R) = 6/10 = 3/5. sin 3/5 olan iki bucaq var: kəskin A₁ ≈ 36,87° (cos = 4/5) və obtuz A₂ = 180° − A₁ ≈ 143,13°. İkisi də mümkündür (A₂ obtuz olanda digər iki bucağın cəmi 36,87°-dir). Deməli A bucağının iki mümkün qiyməti var; bu verilənlər üçbucağı müəyyən etmir (sonsuz sayda üçbucaq mümkündür). Sinus bucağı birqiymətli vermir; bu, sinuslar teoreminin əsas tələsidir.
Nümunə 3. Tərəfləri 3, 4, 5 olan üçbucağın çevrəxarici çevrəsinin radiusu? 3² + 4² = 5², deməli üçbucaq düzbucaqlıdır, hipotenuza qarşı bucaq 90°, sin 90° = 1. 2R = 5/sin 90° = 5, R = 5/2. Nəticə: düzbucaqlı üçbucaqda çevrəxarici çevrənin mərkəzi hipotenuzun ortasındadır, R = hipotenuz/2.
Həyatdan: çaydan o tərəfdəki ağac. Sahildə A və B nöqtələri arasında AB = 100 m. Ağaca A-dan 75°, B-dən 45° bucaq altında baxırsan (bucaqlar AB ilə ağaca istiqamət arasındadır). Üçüncü bucaq C = 180° − 75° − 45° = 60°. AC/sin B = AB/sin C: AC = 100·sin 45°/sin 60° = 100·(√2/2)/(√3/2) = 100√6/3 ≈ 81,6 m. Çayı keçmədən məsafə tapıldı.
Tipik səhvlər
  • Tərəfi qarşısında olmayan bucaqla bölmək: a/sin A (eyni hərf), a/sin B yox.
  • sin A = 3/5-dən yalnız kəskin bucağı götürmək. Obtuz bucaq da (180° − A) mümkün ola bilər, şərtə baxıb seç (cəmi 180° olmalıdır).
  • a/sin A = R yazmaq (2 unudulur): düz olan 2R-dir.
  • Bucaqları dərəcə yerinə radianla hesablayıb kalkulyatoru səhv rejimdə işlətmək.
Yadda saxla
a/sin A = b/sin B = c/sin C = 2R a = 2R sin A, sin A = a/(2R), R = a/(2 sin A) sin A = sin(180° − A): bucaq iki cür ola bilər
Özünü yoxla: 3 sual
  1. A = 150°, a = 10. R = ? sin 150° = 1/2, 2R = 10/(1/2) = 20, R = 10.
  2. A = 45°, B = 60°, a = 2. b = ? b = 2·sin 60°/sin 45° = 2·(√3/2)/(√2/2) = 2√3/√2 = √6.
  3. Hipotenuzu 13 olan düzbucaqlı üçbucağın R-i? 13/2 = 6,5.

Dərs 2. Kosinuslar teoremi

1 Niyə lazımdır

İki tərəf və aralarındakı bucaq məlumdur, üçüncü tərəf lazımdır. Yaxud üç tərəf məlumdur, bucağı tapmaq lazımdır. Bu hallarda sinuslar teoremi kifayət etmir (bir cütlük yoxdur). Düzbucaqlı üçbucaqda c² = a² + b² Pifaqor teoremi var. Kosinuslar teoremi onun istənilən üçbucaq üçün düzəlişli formasıdır.

2 Teorem və isbatı

c² = a² + b² − 2ab·cos C (c — C bucağının qarşısındakı tərəf; a, b — C-ni əmələ gətirən tərəflər) cos C = (a² + b² − c²) / (2ab)

İsbat. C nöqtəsini koordinat başlanğıcına qoy, CA tərəfini üfüqi ox boyunca yerləşdir: A(b; 0). CB = a və C bucağı olan B nöqtəsinin koordinatları triqonometriyadan: B(a cos C; a sin C).

B nöqtəsi CA üzərindəki təsvirindən a cos C məsafədədir, hündürlüyü a sin C-dir. AB məsafəsini düz koordinatlarla yaz.

c² = AB² = (a cos C − b)² + (a sin C − 0)² = a² cos²C − 2ab cos C + b² + a² sin²C = a²(cos²C + sin²C) − 2ab cos C + b² = a² + b² − 2ab cos C. ∎ C = 90° olsa, cos C = 0 və Pifaqor teoremi alınır. C obtuzdursa, cos C < 0 və c² > a² + b² (−2ab cos C müsbətdir). C kəskindirsə, c² < a² + b².

3 Həll olunmuş nümunələr

Nümunə 1. a = 3, b = 5, C = 120°. c = ? cos 120° = −1/2. c² = 9 + 25 − 2·3·5·(−1/2) = 34 + 15 = 49. c = 7.
Nümunə 2. Tərəfləri 5, 7, 8 olan üçbucağın 7 uzunluqlu tərəfinin qarşısındakı bucağı? cos = (5² + 8² − 7²)/(2·5·8) = (25 + 64 − 49)/80 = 40/80 = 1/2. Bucaq 60°. (7 sorulan bucağın qarşısındadır, ona görə c = 7; 5 və 8 isə bucağı əmələ gətirən tərəflərdir.)
Nümunə 3. Tərəfləri 2, 3, 4. Üçbucaq kəskin, düz yoxsa obtuzdur? Ən böyük bucağın kosinusu? Ən böyük bucaq ən böyük tərəfin (4) qarşısındadır. cos = (4 + 9 − 16)/(2·2·3) = −3/12 = −1/4. Mənfidir: obtuz bucaqdır (≈ 104,5°). Qısa yoxlama: 2² + 3² = 13 < 16 = 4².
Həyatdan: dağ aşırı yol. O nöqtəsindən iki kənd görünür: biri 3 km, digəri 5 km məsafədə, istiqamətləri arasındakı bucaq 120°. Kəndlər arası məsafə düz xəttlə: √(9 + 25 + 15) = 7 km. (Bucaq 90° olsaydı √34 ≈ 5,8 km olardı. Genişləndikcə kəndlər uzaqlaşır.)
Tipik səhvlər
  • 2ab əvəzinə ab yazmaq və ya bucağın kosinusunu 2-yə vurmağı unutmaq. Yoxlama: C = 90° ola bilərmi? Onda Pifaqor çıxmalıdır.
  • Obtuz bucaqda işarəni itirmək: cos 120° = −1/2, minus mənfi ilə müsbət verir: c² = a² + b² + ab.
  • Yanlış tərəfi c seçmək: bucağın qarşısındakı tərəf təkdir, qalan ikisi bucağı əmələ gətirir.
  • Kökü almağı unutmaq: c² = 49-dan c = 7 alınır, 49 yox.
Yadda saxla
c² = a² + b² − 2ab cos C cos C = (a² + b² − c²)/(2ab) 60°: c² = a² + b² − ab; 120°: c² = a² + b² + ab Ən böyük tərəfin qarşısında ən böyük bucaq durur.
Özünü yoxla: 3 sual
  1. a = 8, b = 15, C = 60°. c = ? c² = 64 + 225 − 120 = 169, c = 13.
  2. Tərəfləri 7, 8, 13 olan üçbucağın ən böyük bucağı? cos = (49 + 64 − 169)/(2·7·8) = −56/112 = −1/2, bucaq 120°.
  3. c² > a² + b² olsa, C bucağı necədir? cos C = (a² + b² − c²)/(2ab) < 0, yəni C obtuzdur.

Dərs 3. Üçbucağın sahəsi: ½ab·sin C

1 Niyə lazımdır

Sahə üçün S = ½ · əsas · hündürlük bilirsən. Amma hündürlük çox vaxt verilmir: iki tərəf və aralarındakı bucaq məlumdur. Yaxud yalnız üç tərəf var. Bu dərsdə hündürlüyü sinus vasitəsilə ifadə edib sahəni və R-i tapırıq.

2 Düsturlar

Əsas — CA = b. B-dən endirilən hündürlük h. Düzbucaqlı üçbucaqdan (C bucağı olan): h = a·sin C.

S = ½·b·h = ½·b·(a sin C) = ½ab sin C. sin C = c/(2R) (sinuslar teoremi). Yerinə qoy: S = ½ab·c/(2R) = abc/(4R). Üç tərəf məlumdursa: cos C (kosinuslar teoremindən) → sin C = √(1 − cos²C) → S.
S = ½·a·b·sin C (C — a və b arasındakı bucaq) S = abc/(4R), R = abc/(4S)

3 Həll olunmuş nümunələr

Nümunə 1. Tərəfləri 13, 14, 15. S, R = ? C — 15 uzunluqlu tərəfin qarşısındakı bucaq. cos C = (13² + 14² − 15²)/(2·13·14) = (169 + 196 − 225)/364 = 140/364 = 5/13. sin C = √(1 − 25/169) = 12/13. S = ½·13·14·(12/13) = 84. R = abc/(4S) = 13·14·15/(4·84) = 2730/336 = 65/8.
Nümunə 2. Tərəfləri a = 6, b = 8, sahəsi S = 12√3. Aralarındakı bucaq? Üçüncü tərəf? sin C = 2S/(ab) = 24√3/48 = √3/2. Deməli C = 60° və ya C = 120°. İkisi də mümkündür! C = 60°: c² = 36 + 64 − 48 = 52, c = 2√13. C = 120°: c² = 36 + 64 + 48 = 148, c = 2√37.
Nümunə 3. Tərəfləri 5, 5, 6. S və R = ? 6 uzunluqlu tərəfin qarşısındakı C üçün: cos C = (25 + 25 − 36)/(2·5·5) = 14/50 = 7/25, sin C = 24/25. S = ½·5·5·(24/25) = 12. R = 5·5·6/(4·12) = 150/48 = 25/8.
Həyatdan: torpaq sahəsi. Üçbucaq formalı sahənin tərəfləri 13 m, 14 m, 15 m-dir. Hündürlük ölçmək çətindir, amma sahə yuxarıdakı kimi hesablanır: 84 m². Sahənin ətrafına çevrə çəkilsə (məsələn, dairəvi çəpər), onun radiusu 65/8 = 8,125 m-dir.
Tipik səhvlər
  • Yarını unutmaq: S = ½ab sin C. Yoxlama: C = 90°-də S = ½ab olmalıdır.
  • Bucaq iki tərəfin arasında olmalıdır. a və b ilə sin A işlətmək olmaz.
  • Nümunə 2-də sin C = √3/2-dən yalnız 60° götürmək. 120° də sinusu eyni verir, iki cavab var.
  • R = abc/(4S) yerinə abc/(2S) yazmaq.
Yadda saxla
S = ½ab sin C = abc/(4R) sin C = 2S/(ab); R = abc/(4S) sin C = sin(180° − C): iki üçbucaq mümkündür
Özünü yoxla: 3 sual
  1. a = 6, b = 8, C = 30°. S = ? ½·6·8·(1/2) = 12.
  2. Tərəfləri 13, 14, 15 olan üçbucağın R-i? 65/8 (S = 84-dən: 2730/336).
  3. a = 6, b = 8, S = 12 (sin C = ?) sin C = 24/48 = 1/2, C = 30° və ya 150°.

Dərs 4. Üçbucağın həlli və olimpiada məsələləri

1 Hansı hal, hansı teorem

Üçbucağı "həll etmək" — üç məlum ölçüdən qalanlarını tapmaqdır. Hansı teoremin işləməsi verilənlərdən asılıdır:

Verilənlərİlk addım
iki bucaq və bir tərəf (BBT, BTB)üçüncü bucaq = 180° − cəm; sonra sinuslar teoremi
iki tərəf və aralarındakı bucaq (TBT)kosinuslar teoremi → üçüncü tərəf
üç tərəf (TTT)kosinuslar teoremi → bucaq (ən böyükdən başla)
iki tərəf və biri qarşısındakı bucaq (TTB)sinuslar teoremi, iki həll ola bilər

Axırıncı halda sin B = b sin A / a alınır. Sinus eyni qalır (B və 180° − B), ona görə hər iki variantı yoxla: A + B < 180° şərti ödənərsə, ikisi də üçbucaq verir.

2 Məsələ 1. sin A : sin B : sin C = 3 : 5 : 7. Ən böyük bucaq?

Sinuslar teoremindən a = 2R sin A, b = 2R sin B, c = 2R sin C: a : b : c = sin A : sin B : sin C = 3 : 5 : 7. Tərəfləri a = 3k, b = 5k, c = 7k götür (k > 0). Ən böyük bucaq ən böyük tərəfin (7k) qarşısındadır: cos C = (9k² + 25k² − 49k²)/(2·3k·5k) = −15k²/(30k²) = −1/2. Deməli C = 120°.

3 Məsələ 2. Median: tərəfləri 5, 7, 8. 8 uzunluqlu tərəfə çəkilmiş median?

M — AB = c tərəfinin ortası, CM = m. ∠AMC = θ olsun, onda ∠BMC = 180° − θ.

AMC üçbucağında (kosinuslar teoremi): b² = m² + c²/4 − 2·m·(c/2)·cos θ BMC üçbucağında: a² = m² + c²/4 − 2·m·(c/2)·cos(180° − θ) = m² + c²/4 + mc cos θ Topla (cos θ-lı hədlər ixtisar olur): a² + b² = 2m² + c²/2 Buradan m² = (2a² + 2b² − c²)/4. c = 8, a = 5, b = 7: m² = (50 + 98 − 64)/4 = 84/4 = 21, m = √21 ≈ 4,58.

4 Məsələ 3. ∠A = 2∠B olarsa, a² = b(b + c). b = 4, c = 5 üçün a = ?

Sinuslar teoremi ilə (A = 2B, C = 180° − 3B): a = 2R sin 2B = 4R sin B cos B = 2b cos B (b = 2R sin B) c = 2R sin C = 2R sin 3B = b·sin 3B/sin B = b(3 − 4 sin²B) = b(4cos²B − 1) (sin 3B = 3 sin B − 4 sin³B) Onda b(b + c) = b·b(1 + 4cos²B − 1) = 4b²cos²B = (2b cos B)² = a². ∎ b = 4, c = 5: a² = 4·(4 + 5) = 36, a = 6. Yoxlama: tərəfləri 6, 4, 5 üçbucaqda cos B = (36 + 25 − 16)/(2·6·5) = 3/4, cos A = (16 + 25 − 36)/(2·4·5) = 1/8, cos 2B = 2·9/16 − 1 = 1/8 = cos A. ✓
Həyatdan: dam konstruksiyası. Dam tirinin uzunluğu 8 m, yan tirlər 5 m və 7 m-dir. Təpədən tirin ortasına dayaq dirəyi qoyulur. Uzunluğu median düsturu verir: √21 ≈ 4,58 m.
Tipik səhvlər
  • Üç tərəf verildikdə sinuslar teoremi ilə başlamaq: orada bucaqların sinusu naməlumdur. TTT halında kosinuslar teoremi.
  • TTB halında ikinci həlli unutmaq. Bucağın sinusu eyni qalan 180° − B bucağını da yoxla.
  • Nisbətdən tərəflərə keçəndə üçbucaq bərabərsizliyini yoxlamamaq: 3 : 5 : 7 üçün 3 + 5 > 7 ✓, amma 2 : 3 : 6 üçbucaq vermir.
  • Median düsturunda /4-ü unutmaq.
Yadda saxla
BBT → sinuslar; TBT, TTT → kosinuslar; TTB → sinuslar (iki həll!) a : b : c = sin A : sin B : sin C m_c² = (2a² + 2b² − c²)/4 A = 2B ⇒ a² = b(b + c)
Özünü yoxla: 3 sual
  1. Tərəfləri 3, 5, 7. Ən böyük bucaq? cos = (9 + 25 − 49)/30 = −1/2, 120°.
  2. Tərəfləri 6, 8, 10 olan üçbucaqda 10-a çəkilmiş median? m² = (72 + 128 − 100)/4 = 25, m = 5 (düzbucaqlıda hipotenuzun yarısı ✓).
  3. a = 7, b = 5, ∠A = 60°. TTB halında B bucağının sinusu? sin B = 5·(√3/2)/7 = 5√3/14 ≈ 0,62; B kəskin (≈ 38,2°): b < a olduğu üçün B bucağı A = 60°-dən kiçikdir, obtuz variant yoxdur.
