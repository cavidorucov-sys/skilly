Tam və rasional ədədlər, ədəd oxu, modul

Bu mövzunu çoxdan keçmisən — burada təkrar edirik və imtahanın sevdiyi tələlərə baxırıq: −3² ilə (−3)², mənfi ədədlərin müqayisəsi, modulun mənası. Bütün buraxılışda bu bacarıqlar lazım olur: tənlikdə, funksiyada, həndəsədə.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Tam və rasional ədədlər: işarələr və əməllər

1 Niyə lazımdır

Qışda termometr −5° göstərir, bank kartında −20 AZN borc var, dalğıc dəniz səviyyəsindən 12 m aşağıdadır (−12 m). Mənfi ədədlər hər yerdədir.

İmtahanda isə məsələ çox vaxt çətin olduğu üçün yox, bir işarə səhvinə görə səhv həll olunur. Bu dərs həmin səhvləri tutmaq üçündür.

2 Ədəd çoxluqları

  • Natural ədədlər: 1, 2, 3, … — saymaq üçün.
  • Tam ədədlər: …, −3, −2, −1, 0, 1, 2, 3, … — natural ədədlər, onların əksləri və 0.
  • Rasional ədədlər: p/q şəklində yazıla bilən ədədlər (p tam, q natural). Məsələn, −3/4; 2,5 = 5/2; 7 = 7/1; 0,(3) = 1/3.

Hər tam ədəd rasionaldır (7 = 7/1). Hər sonlu onluq kəsr və hər dövri onluq kəsr də rasionaldır.

Əks ədədlər — yalnız işarəsi ilə fərqlənən ədədlər: 5 və −5. Cəmləri 0-dır. Qarşılıqlı tərs ədədlər — hasili 1 olan ədədlər: 2/3 və 3/2; −4 və −1/4.

3 İşarə qaydaları

Vurma və bölmə: (+) · (+) = (+) (−) · (−) = (+) (+) · (−) = (−) (−) · (+) = (−) Mənfi vuruqların sayı cütdürsə — nəticə müsbət, təkdirsə — mənfi. Toplama: eyni işarəli — modulları topla, işarəni saxla; fərqli işarəli — böyük moduldan kiçiyi çıx, böyük modulun işarəsini yaz. Çıxma: a − b = a + (−b); a − (−b) = a + b

Əməllərin sırası: əvvəl mötərizə, sonra qüvvət, sonra vurma-bölmə, sonra toplama-çıxma.

Ən çox düşülən tələ: −3² və (−3)² fərqlidir.

−3² = −(3 · 3) = −9 (−3)² = (−3) · (−3) = 9 (−2)³ = (−2)(−2)(−2) = −8

Mötərizə yoxdursa, qüvvət yalnız rəqəmə aiddir, minus sonra yazılır. Mənfi ədədin cüt qüvvəti müsbət, tək qüvvəti mənfidir.

4 Həll olunmuş nümunələr

Nümunə 1. −2³ − (−3)² + (−12) : (−4) Addım 1. Qüvvətlər: −2³ = −8, (−3)² = 9. Addım 2. Bölmə: (−12) : (−4) = 3 (iki mənfi — müsbət). Addım 3. −8 − 9 + 3 = −17 + 3 = −14. Cavab: −14.
Nümunə 2. −2/3 + 5/6 Addım 1. Ortaq məxrəc 6: −2/3 = −4/6. Addım 2. −4/6 + 5/6 = 1/6. Cavab: 1/6.
Nümunə 3. (−1/2) : (−3/4) Addım 1. Bölmək — tərsinə vurmaq: (−1/2) · (−4/3). Addım 2. İşarə: iki mənfi — müsbət. 1 · 4 / (2 · 3) = 4/6. Addım 3. İxtisar: 4/6 = 2/3. Cavab: 2/3.
Həyatdan. Kartında −35 AZN (borc) var. 50 AZN yatırırsan, sonra 20 AZN-lik alış edirsən.
−35 + 50 − 20 = 15 − 20 = −5 AZN. Hələ 5 AZN borcdasan.
Tipik səhvlər
  • −4² = 16 yazmaq. Düzü: −16. 16 olan (−4)²-dir.
  • 5 − (−3) = 2 yazmaq. Mənfi ədədi çıxmaq onu toplamaqdır: 5 + 3 = 8.
  • Bir neçə vuruqda işarəni itirmək. Əvvəl mənfiləri say: (−2)·3·(−1)·(−5) — üç mənfi, nəticə mənfi: −30.
  • Kəsrə bölərkən tərsini almağı unutmaq: a : (c/d) = a · (d/c).
Yadda saxla
(−)·(−) = (+), (−)·(+) = (−) −a² = −(a²), (−a)² = a² a − (−b) = a + b Əvvəl qüvvət, sonra vurma-bölmə, sonra toplama-çıxma
Özünü yoxla: 3 sual
  1. (−2)⁴ − 2⁴ = ? 16 − 16 = 0.
  2. (−6) · (−5) : (−3) = ? 30 : (−3) = −10.
  3. −1/4 − 1/3 = ? −3/12 − 4/12 = −7/12.

Dərs 2. Ədəd oxu və ədədlərin müqayisəsi

1 Ədəd oxu

Ədəd oxu — üzərində başlanğıc nöqtəsi (0), istiqamət (ox) və vahid parça seçilmiş düz xətdir. Hər ədədə oxda bir nöqtə uyğundur. Ədəd nöqtənin koordinatıdır: A(−2,5) yazılışı "A nöqtəsinin koordinatı −2,5-dir" deməkdir.

A(−2,5) — sıfırdan 2,5 vahid solda. B(3) — 3 vahid sağda.

Sağdakı nöqtənin koordinatı həmişə böyükdür: −2,5 < 3.

2 Müqayisə qaydası

  • Hər müsbət ədəd 0-dan böyük, hər mənfi ədəd 0-dan kiçikdir.
  • İki mənfi ədəddən modulu böyük olan kiçikdir: −7 < −3 (−7 daha soldadır). −20° şaxta −3°-dən soyuqdur.
  • Kəsrləri ortaq məxrəcə gətir və ya onluq kəsrə çevir.
Nümunə. −2/3, −3/4 və −0,7 ədədlərini artan sıra ilə düz. Addım 1. Onluğa çevir: −2/3 ≈ −0,667; −3/4 = −0,75; −0,7. Addım 2. Modullar: 0,667 < 0,7 < 0,75. Addım 3. Mənfilərdə sıra tərsinə: −0,75 < −0,7 < −0,667. Cavab: −3/4 < −0,7 < −2/3.

3 Bölgünün qiymətini tap

Testdə oxda çox vaxt yalnız 0 və 1 yazılır. Əvvəl say: 0 ilə 1 arasında neçə bölgü var?

0 ilə 1 arasında 4 bölgü var → bir bölgü 1/4 = 0,25. A nöqtəsi 0-dan 6 bölgü soldadır → A = −6 · 0,25 = −1,5.

4 İki nöqtə arasındakı məsafə

A(a) və B(b) nöqtələri arasında məsafə: AB = |a − b| AB parçasının ortası: (a + b) / 2
A(−4), B(6). AB = |−4 − 6| = |−10| = 10. Orta nöqtə: (−4 + 6) / 2 = 1. A ilə B arasında tam ədədlər (uclar daxil deyil): −3; −2; …; 5 — 9 ədəd (10 − 1).
Həyatdan. Termometr — şaquli ədəd oxudur. Gecə −6°, gündüz 9° idi. Temperatur oxda −6-dan 9-a qədər qalxdı: 9 − (−6) = 15°.
Tipik səhvlər
  • "−7 > −3, çünki 7 > 3". Mənfilərdə tərsinədir: −7 < −3.
  • Bölgünü 1 vahid saymaq. Əvvəl 0 ilə 1 arasındakı bölgüləri say.
  • Aradakı tam ədədləri sayanda ucları da saymaq. "Arasında" — uclar daxil deyil.
Yadda saxla
Sağdakı böyükdür Mənfilərdə: modulu böyük olan kiçikdir AB = |a − b|, orta = (a + b) / 2
Özünü yoxla: 3 sual
  1. −0,6; −2/3; −1/2 ədədlərini artan sıra ilə düz. −2/3 < −0,6 < −1/2 (−0,667 < −0,6 < −0,5).
  2. A(−7), B(2). AB = ? Ortanın koordinatı? AB = 9, orta (−7 + 2)/2 = −2,5.
  3. −3,5 ilə 2,5 arasında neçə tam ədəd var? −3; −2; −1; 0; 1; 2 — 6 ədəd.

Dərs 3. Ədədin modulu (mütləq qiyməti)

1 Modul — məsafədir

|a| — ədəd oxunda a nöqtəsindən 0-a qədər məsafə. Məsafə mənfi ola bilməz, ona görə modul həmişə ≥ 0.

5 və −5 sıfırdan eyni məsafədədir — 5 vahid.

Ona görə |5| = |−5| = 5, |0| = 0.

2 Tərif

|a| = a, əgər a ≥ 0 |a| = −a, əgər a < 0

İkinci sətirdə qorxma: a mənfidirsə, −a müsbətdir. Məsələn, a = −7: |−7| = −(−7) = 7.

Buradan: a < 0 olarsa, |a| + a = −a + a = 0, |a| − a = −2a. Məsələn, a = −3: |a| − a = 3 + 3 = 6.

3 |a − b| — iki ədəd arasındakı məsafə

|a − b| = a ilə b arasındakı məsafə |x − 3| = x ilə 3 arasındakı məsafə |x + 2| = |x − (−2)| = x ilə −2 arasındakı məsafə

Bu fikir modullu məsələlərin çoxunu hesablamadan həll edir.

Nümunə 1. |−8| − |3 − 10| + |−2| · |4| Addım 1. |−8| = 8. Addım 2. 3 − 10 = −7, |−7| = 7. Addım 3. |−2| · |4| = 2 · 4 = 8. Cavab: 8 − 7 + 8 = 9.

4 Sadə modullu tənlik və bərabərsizlik

Nümunə 2. |x − 3| = 5. x ilə 3 arasındakı məsafə 5-dir: 3-dən 5 sağa və ya 5 sola. x − 3 = 5 → x = 8; x − 3 = −5 → x = −2. Köklər: 8 və −2 (cəmi 6). Nümunə 3. |x| = −4. Modul mənfi ola bilməz — kök yoxdur. Nümunə 4. |x − 1| ≤ 3 bərabərsizliyinin neçə tam həlli var? x ilə 1 arasındakı məsafə ən çox 3: −2 ≤ x ≤ 4. Tam ədədlər: −2; −1; 0; 1; 2; 3; 4 — 7 ədəd. (|x − 1| < 3 olsaydı, uclar düşərdi: −1; …; 3 — 5 ədəd.)
Nümunə 5. −2 ≤ x ≤ 3 olarsa, |x + 2| + |x − 3| = ? |x + 2| — x ilə −2 arasındakı məsafə, |x − 3| — x ilə 3 arasındakı məsafə. x bu iki nöqtənin arasındadır, deməli məsafələrin cəmi bütün parçanın uzunluğudur: 3 − (−2) = 5. Yoxla: x = 0 → 2 + 3 = 5; x = 1 → 3 + 2 = 5. Cavab: 5.
Həyatdan. Səhər Şəkidə −3°, Bakıda 4° idi. Fərq: |−3 − 4| = |−7| = 7°. Hansından hansını çıxmağın fərqi yoxdur: |4 − (−3)| = 7 — məsafə eynidir.
Tipik səhvlər
  • −|−5| = 5 yazmaq. Əvvəl modul: |−5| = 5, sonra minus: −5.
  • |x| = −4 üçün "x = ±4" yazmaq. Modul mənfi olmur — kök yoxdur.
  • |x − 3| = 5 tənliyində yalnız bir kök tapmaq (x = 8). İkinci hal: x − 3 = −5.
  • Tam həlləri sayanda < ilə ≤ fərqini unutmaq: |x| < 3 — 5 tam həll, |x| ≤ 3 — 7 tam həll.
Yadda saxla
|a| ≥ 0; |a| = |−a| a < 0 olarsa |a| = −a |a − b| — a ilə b arasındakı məsafə |x − a| = b (b > 0) → x = a + b və ya x = a − b |x − a| ≤ b → a − b ≤ x ≤ a + b (2b + 1 tam həll)
Özünü yoxla: 3 sual
  1. |−8| − |3 − 10| = ? 8 − 7 = 1.
  2. |x + 4| = 6 tənliyinin köklərinin cəmi? x + 4 = 6 → x = 2; x + 4 = −6 → x = −10. Cəm: −8.
  3. |x − 2| < 4 bərabərsizliyinin neçə tam həlli var? −2 < x < 6: −1; 0; …; 5 — 7 ədəd.
