Bərabərsizliklərin isbatı, orta qiymətlər

Hasilləri verilmiş düzbucaqlılardan hansının perimetri ən kiçikdir? Cəmi verilmiş iki ədədin hasili ən çox nə qədər ola bilər? Bu suallara diferensial hesabsız, yalnız bir neçə sadə fikirlə cavab vermək olar: kvadratın qeyri-mənfiliyi və orta qiymətlər (HM ≤ GM ≤ AM ≤ QM). Olimpiadada bərabərsizlik isbat etmək və ən böyük/kiçik qiyməti tapmaq məhz bunlarla həll olunur.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Kvadratın qeyri-mənfiliyi və tam kvadrat

1 Niyə lazımdır

Bərabərsizlik isbat etmək üçün ən güclü alət çox sadədir: hər həqiqi ədədin kvadratı sıfırdan kiçik deyil. Qalan hər şey bu fikrin ağıllı istifadəsidir. Bu dərsdə onu necə işlətməyi öyrənəcəksən.

2 Əsas fikir

(a − b)² ≥ 0 ⇒ a² + b² ≥ 2ab Bərabərlik yalnız a = b olduqda Tam kvadrat: ax² + bx + c = a(x − h)² + k a > 0 olduqda minimum = k (x = h-da), a < 0 olduqda maksimum = k

İsbat üçün plan: bərabərsizliyin bir tərəfini sıfıra gətir, fərqi kvadratların cəmi kimi yaz. Kvadratlar mənfi olmadığı üçün fərq də mənfi deyil.

3 Həll olunmuş nümunələr

1) x² − 6x + 11 ifadəsinin ən kiçik qiyməti? x² − 6x + 11 = (x − 3)² + 2 ≥ 2. Bərabərlik x = 3 olduqda. Minimum = 2. 2) x(10 − x) ifadəsinin ən böyük qiyməti? x(10 − x) = 10x − x² = 25 − (x − 5)² ≤ 25. Bərabərlik x = 5 olduqda. Maksimum = 25. 3) a > 0 üçün a + 1/a ≥ 2. a + 1/a − 2 = (a² − 2a + 1)/a = (a − 1)²/a ≥ 0. Bərabərlik a = 1 olduqda.

4 Olimpiada məsələləri

Məsələ 1. Sübut et: a² + b² + c² ≥ ab + bc + ca. Həll. Fərqi iki dəfə böyüdək: 2(a² + b² + c²) − 2(ab + bc + ca) = (a − b)² + (b − c)² + (c − a)² ≥ 0. (Açıb yoxla: (a − b)² + (b − c)² + (c − a)² = 2a² + 2b² + 2c² − 2ab − 2bc − 2ca.) Deməli a² + b² + c² ≥ ab + bc + ca. Bərabərlik a = b = c olduqda. ∎ Məsələ 2. Sübut et: x² + y² + 1 ≥ x + y + xy. Həll. 2(x² + y² + 1 − x − y − xy) = (x − y)² + (x − 1)² + (y − 1)² ≥ 0. Yoxla: (x² − 2xy + y²) + (x² − 2x + 1) + (y² − 2y + 1) = 2x² + 2y² + 2 − 2x − 2y − 2xy ✓. Bərabərlik x = y = 1 olduqda. ∎
Həyatdan. Yuxarı atılan topun hündürlüyü h(t) = −5t² + 20t metrdir (t saniyədir). Tam kvadrat: h = 20 − 5(t − 2)². Ən yüksək nöqtə 20 m-dir və top ona 2-ci saniyədə çatır. Bu da "ən böyük qiymət" məsələsidir.

5 Özünü yoxla

Tipik səhvlər
  • (x − 3)² əvəzinə (x + 3)² yazmaq: x² − 6x + 11 = (x − 3)² + 2, çünki (x − 3)² = x² − 6x + 9.
  • Bərabərlik halını yoxlamamaq: "ən kiçik qiymət" demək üçün həmin qiymətin alındığını göstərmək lazımdır.
  • a² + b² ≥ 2ab yalnız ab müsbət olanda deyil, istənilən həqiqi a, b üçün doğrudur.
  • İşarəni dəyişmək: a < 0 olanda parabolanın qolu aşağıdır, minimum yox, maksimum olur.
Yadda saxla
(a − b)² ≥ 0 ⇒ a² + b² ≥ 2ab Tam kvadrat: a(x − h)² + k Fərqi kvadratlar cəmi kimi yaz Bərabərlik halını hər dəfə yoxla
Özünü yoxla: 3 sual
  1. x² − 4x + 7 ifadəsinin ən kiçik qiyməti? (x − 2)² + 3 ≥ 3; minimum 3 (x = 2).
  2. 6x − x² ifadəsinin ən böyük qiyməti? 9 − (x − 3)² ≤ 9; maksimum 9 (x = 3).
  3. a > 0 olduqda a + 1/a nə vaxt 2-yə bərabərdir? (a − 1)² = 0, yəni a = 1.

Dərs 2. Ədədi və həndəsi orta (AM ≥ GM)

1 Niyə lazımdır

Perimetri 40 m olan düzbucaqlı sahənin sahəsi ən çox nə qədər ola bilər? Cavab kvadratdadır: 10 × 10 = 100 m². Bunu AM ≥ GM bərabərsizliyi bir sətirdə göstərir. Bu, olimpiada bərabərsizliklərinin ən çox işlədilən alətidir.

2 Əsas fikir

a, b ≥ 0: (a + b)/2 ≥ √(ab) Bərabərlik yalnız a = b olduqda Üç ədəd: (a + b + c)/3 ≥ ∛(abc) n ədəd: ədədi orta ≥ həndəsi orta Cəm sabitdirsə → hasil ən böyük, bərabərlik a = b Hasil sabitdirsə → cəm ən kiçik, bərabərlik a = b

İsbat. (√a − √b)² ≥ 0 açsaq a − 2√(ab) + b ≥ 0, yəni a + b ≥ 2√(ab). ∎

Şərt: ədədlər mənfi olmamalıdır. Mənfi ədədlərdə AM-GM tətbiq etmək olmaz.

3 Həll olunmuş nümunələr

1) x > 0 üçün x + 4/x-in ən kiçik qiyməti? x + 4/x ≥ 2√(x · 4/x) = 2√4 = 4. Bərabərlik x = 4/x → x² = 4 → x = 2 olduqda. Minimum = 4. 2) x + y = 10 (x, y > 0). xy-in ən böyük qiyməti? √(xy) ≤ (x + y)/2 = 5 → xy ≤ 25. Bərabərlik x = y = 5. Maksimum = 25. 3) xy = 16 (x, y > 0). x + y-in ən kiçik qiyməti? x + y ≥ 2√(xy) = 2√16 = 8. Bərabərlik x = y = 4. Minimum = 8. 4) Bərabərlik halı alınmayanda tələ: √(x² + 4) + 1/√(x² + 4)-in ən kiçik qiyməti? u = √(x² + 4) ≥ 2. AM-GM: u + 1/u ≥ 2, amma bərabərlik üçün u = 1 lazımdır, u isə ən azı 2-dir! Deməli 2 alınmır. u ≥ 2 üçün u + 1/u artandır, minimum u = 2-də: 2 + 1/2 = 5/2.

4 Olimpiada məsələsi

Məsələ. a, b, c > 0. Sübut et: (a + b)(b + c)(c + a) ≥ 8abc. Həll. Hər mötərizəyə AM-GM tətbiq edək: a + b ≥ 2√(ab), b + c ≥ 2√(bc), c + a ≥ 2√(ca). Hamısı müsbətdir, ona görə vura bilərik: (a + b)(b + c)(c + a) ≥ 8 · √(ab) · √(bc) · √(ca) = 8 · √(a²b²c²) = 8abc. Bərabərlik a = b = c olduqda. ∎
Həyatdan. Fermer 40 m hasar alıb və düzbucaqlı sahə hasarlamaq istəyir. Tərəflər x və 20 − x olarsa, sahə x(20 − x) olur. AM-GM: √(x(20 − x)) ≤ (x + 20 − x)/2 = 10, yəni sahə ≤ 100. Ən çox sahə kvadratdadır: 10 × 10.

5 Özünü yoxla

Tipik səhvlər
  • AM-GM-i mənfi ədədlərə tətbiq etmək: x < 0 üçün x + 1/x ≤ −2 olur, 2-dən kiçik deyil.
  • Bərabərlik halının mümkün olub-olmadığını yoxlamamaq (yuxarıdakı 4-cü nümunə).
  • (a + b)/2 əvəzinə a + b ilə müqayisə etmək: düstur a + b ≥ 2√(ab)-dir.
  • Hasili sabit olmayan ifadəyə AM-GM tətbiq etmək: x + 2x ≥ 2√2 · x alınır, sağ tərəf x-dən asılıdır və ən kiçik qiymət vermir.
Yadda saxla
(a + b)/2 ≥ √(ab), bərabərlik a = b Cəm sabit → hasil max; hasil sabit → cəm min Ədədlər ≥ 0 olmalı, bərabərlik halı mümkün olmalı
Özünü yoxla: 3 sual
  1. x > 0 üçün x + 9/x-in ən kiçik qiyməti və hansı x-də? 2√9 = 6, x = 3-də.
  2. xy = 16, x, y > 0. x + y-in ən kiçik qiyməti? 8 (x = y = 4).
  3. x < 0 üçün x + 1/x-in ən kiçik qiyməti 2-dirmi? Xeyr: x < 0 üçün x + 1/x ≤ −2, yəni 2-dən kiçikdir; ən kiçik qiymət yoxdur.

Dərs 3. Orta qiymətlər: HM ≤ GM ≤ AM ≤ QM

1 Niyə lazımdır

Avtomobil A şəhərindən B-yə 60 km/saat, geri 40 km/saat sürətlə gedir. Orta sürət 50 km/saat deyil! Haradan çıxır 48? Bu cür "orta" fərqli düsturlarla hesablanır. Dörd məşhur orta qiymət var və aralarındakı bərabərsizlik olimpiadanın əsas silahlarındandır.

2 Əsas fikir

a, b > 0 üçün: HM = 2ab/(a + b) harmonik orta GM = √(ab) həndəsi orta AM = (a + b)/2 ədədi orta QM = √((a² + b²)/2) kvadratik orta HM ≤ GM ≤ AM ≤ QM (hamısında bərabərlik yalnız a = b) GM² = AM · HM

Niyə? GM ≤ AM — keçən dərsdən. HM ≤ GM: 2ab/(a + b) ≤ √(ab) ⇔ 2√(ab) ≤ a + b (hər tərəfi √(ab)-yə bölürük və yenə AM-GM-ə gəlirik). AM ≤ QM: ((a + b)/2)² ≤ (a² + b²)/2 ⇔ 0 ≤ (a − b)²/4.

Hər biri nə vaxt işlədilir: HM — "yolun uzunluğu eyni, sürətlər fərqli" (orta sürət); GM — hasil sabit olanda; AM — adi orta; QM — kvadratların cəmi iştirak edəndə.

3 Həll olunmuş nümunələr

1) a = 2, b = 8: HM = 2 · 16 / 10 = 3,2 GM = √16 = 4 AM = 5 QM = √((4 + 64)/2) = √34 ≈ 5,83 3,2 ≤ 4 ≤ 5 ≤ 5,83 ✓. Yoxla: GM² = 16 = 5 · 3,2 ✓. 2) Avtomobil: gedişdə 60, qayıdışda 40 km/saat. Yolun uzunluğu S olsun. Vaxt: S/60 + S/40 = S · 5/120 = S/24. Orta sürət = 2S / (S/24) = 48 km/saat. Bu dəqiq 60 və 40-ın HM-idir: 2 · 60 · 40 / 100 = 48.

4 Olimpiada məsələləri

Məsələ 1. a, b > 0 və a + b = 1. Sübut et: 1/a + 1/b ≥ 4. Həll. AM ≥ HM: (a + b)/2 ≥ 2ab/(a + b). a + b = 1 qoyaq: 1/2 ≥ 2ab → ab ≤ 1/4. 1/a + 1/b = (a + b)/(ab) = 1/(ab) ≥ 4. Bərabərlik a = b = 1/2 olduqda. ∎ Məsələ 2. a, b real, a + b = 1. Sübut et: a² + b² ≥ 1/2. Həll. QM ≥ AM: √((a² + b²)/2) ≥ (a + b)/2 = 1/2. Kvadrata yüksəldək: (a² + b²)/2 ≥ 1/4 → a² + b² ≥ 1/2. Bərabərlik a = b = 1/2 olduqda. ∎
Həyatdan. 12 km yolu 4 km/saat sürətlə gedib, geri 12 km yolu 6 km/saat qaçırsan. Orta sürət 5 deyil, HM = 2 · 4 · 6 / 10 = 4,8 km/saat. Ona görə yavaş hissədə daha çox vaxt keçirirsən. Elektrikdə paralel müqavimətlər də buna bənzər düsturla hesablanır: 1/R = 1/R₁ + 1/R₂.

5 Özünü yoxla

Tipik səhvlər
  • Orta sürəti iki sürətin ədədi ortası kimi hesablamaq. Eyni yol üçün HM lazımdır.
  • Bərabərsizlik zəncirində sırasını qarışdırmaq: ən kiçik HM, ən böyük QM.
  • GM = √(a + b) yazmaq. Düzü: √(ab).
  • QM düsturunda 2-yə bölməyi unutmaq: √((a² + b²)/2).
Yadda saxla
HM ≤ GM ≤ AM ≤ QM, bərabərlik a = b GM² = AM · HM Orta sürət (eyni yol) = HM a + b = S ⇒ ab ≤ S²/4, a² + b² ≥ S²/2
Özünü yoxla: 3 sual
  1. a = 2, b = 8: HM və GM? HM = 3,2; GM = 4.
  2. Gediş 30, qayıdış 60 km/saat. Orta sürət? 2 · 30 · 60 / 90 = 40 km/saat.
  3. a + b = 4, a, b > 0: 1/a + 1/b-nin ən kiçik qiyməti? AM ≥ HM: 2 ≥ 2/(1/a + 1/b) → 1/a + 1/b ≥ 1. Minimum 1 (a = b = 2).

Dərs 4. Ən böyük və ən kiçik qiymətin tapılması

1 Niyə lazımdır

Eyni uzunluqda iplə həm uzun düzbucaqlı, həm kvadrat qurmaq olar — kvadrat həmişə daha çox sahə tutur. Bunu sübut edən bərabərsizlikləri bu mövzuda öyrənəcəksən.

"Ən çox", "ən az", "ən qənaətli" — real həyatın sualları. Olimpiadada məsələ belə qoyulur: ifadənin ən kiçik qiymətini tap. Cavab iki hissədən ibarətdir: (1) "ifadə ≥ C" isbatı; (2) bərabərliyin doğrudan da alındığını göstərmək.

2 Əsas fikir

Alqoritm: 1) Hədləri elə böl ki, AM-GM-dən sonra dəyişən yox olsun (hasil sabit) 2) AM-GM tətbiq et → ifadə ≥ C 3) Bərabərlik şərti: bütün hədlər bərabər 4) Həmin x həqiqətən mümkündürmü? Yoxla 5) Cavab: ən kiçik qiymət = C

Çəkili hal. Bərabər hədlər alınması üçün bəzən həddi hissələrə bölürük: x = x/2 + x/2 və üç hədli AM-GM: (u + v + w)/3 ≥ ∛(uvw).

3 Həll olunmuş nümunələr

1) x > 1. x + 9/(x − 1)-in ən kiçik qiyməti? x + 9/(x − 1) = (x − 1) + 9/(x − 1) + 1. x − 1 > 0, ona görə AM-GM: (x − 1) + 9/(x − 1) ≥ 2√9 = 6. Cəmi ≥ 6 + 1 = 7. Bərabərlik x − 1 = 9/(x − 1) → (x − 1)² = 9 → x = 4. Minimum 7. 2) x, y > 0, 2x + 3y = 12. xy-in ən böyük qiyməti? xy = (1/6) · (2x)(3y) ≤ (1/6) · ((2x + 3y)/2)² = (1/6) · 36 = 6. Bərabərlik 2x = 3y = 6 → x = 3, y = 2. Maksimum 6. 3) x > 0. x + 4/x²-in ən kiçik qiyməti? x = x/2 + x/2. x/2 + x/2 + 4/x² ≥ 3∛((x/2)(x/2)(4/x²)) = 3∛1 = 3. Bərabərlik x/2 = 4/x² → x³ = 8 → x = 2. Yoxla: 2 + 4/4 = 3 ✓. Minimum 3. 4) a + b = 6. a² + b²-in ən kiçik qiyməti? QM ≥ AM: (a² + b²)/2 ≥ 9 → a² + b² ≥ 18. Bərabərlik a = b = 3.

4 Olimpiada məsələsi

Məsələ. x, y > 0, x + y = 1. (1 + 1/x)(1 + 1/y)-nin ən kiçik qiymətini tap. Həll. Mötərizələri açaq: (1 + 1/x)(1 + 1/y) = 1 + 1/x + 1/y + 1/(xy). 1/x + 1/y = (x + y)/(xy) = 1/(xy). Deməli ifadə = 1 + 2/(xy). AM-GM: xy ≤ ((x + y)/2)² = 1/4, ona görə 1/(xy) ≥ 4. İfadə ≥ 1 + 2 · 4 = 9. Bərabərlik x = y = 1/2 olduqda: (1 + 2)(1 + 2) = 9 ✓. Cavab: ən kiçik qiymət 9. ∎
Həyatdan. Bilet qiyməti p manat, gündə 100 − 4p bilet satılır. Gəlir p(100 − 4p) = 4p(25 − p). p(25 − p) ≤ ((p + 25 − p)/2)² = 156,25 (bərabərlik p = 12,5). Ən böyük gəlir 4 · 156,25 = 625 manat.

5 Özünü yoxla

Tipik səhvlər
  • Bərabərlik halını yoxlamamaq. Misal: 2-ci dərsdəki 4-cü nümunə.
  • Hasili sabit etməmək. x + 4/x² üçün x + 4/x² ≥ 2√(4/x) yazmaq düzgün nəticə vermir (sağ tərəf x-dən asılıdır); hədləri bölmək lazımdır.
  • Bölmədə bərabərlik şərtini səhv yazmaq: x/2 = 4/x², x = 4/x² yox.
  • Maksimumu minimumla qarışdırmaq: cəm sabit → hasil max; hasil sabit → cəm min.
Yadda saxla
Hasil sabit olana qədər hədləri böl AM-GM → qiymət ≥ C Bərabərlik şərti: hədlər bərabər x-in mümkünlüyünü yoxla, sonra cavab ver
Özünü yoxla: 3 sual
  1. x > 0 üçün 4x + 25/x-in ən kiçik qiyməti? 2√(4x · 25/x) = 2√100 = 20. Bərabərlik 4x = 25/x → x = 5/2.
  2. a + b = 6. a² + b²-in ən kiçik qiyməti? 18 (a = b = 3).
  3. x > 2 üçün x + 1/(x − 2)-nin ən kiçik qiyməti? (x − 2) + 1/(x − 2) + 2 ≥ 2 + 2 = 4. Bərabərlik x − 2 = 1, yəni x = 3.
