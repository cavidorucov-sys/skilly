Modullu tənliklər və bərabərsizliklər

Modul — məsafədir: |x − 3| ədəd oxunda x ilə 3 arasındakı məsafədir. Bu bir fikir modullu məsələlərin çoxunu həll edir: |x − 3| = 5 — "3-dən 5 vahid uzaqda olan nöqtələr", |x − 2| ≤ 3 — "2-dən ən çox 3 vahid uzaqda olan nöqtələr". Qalanları üçün — modulu açmağın iki halı.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. |f(x)| = a şəklində tənliklər

1 Niyə lazımdır

Naviqator deyir: "dayanacaq 5 km uzaqlıqdadır". Hansı tərəfdə? Bilmirik — irəlidə də ola bilər, geridə də. Məsafə istiqaməti "unudur". Modul da belədir: |x| = 5 olarsa, x = 5 və ya x = −5.

2 Modul — məsafə

|a| = a, a ≥ 0 olanda |a| = −a, a < 0 olanda (|−7| = 7) |x − a| — ədəd oxunda x ilə a arasındakı məsafə

|x − 3| = 5: 3 nöqtəsindən 5 vahid uzaqda olan nöqtələr. Sola — −2, sağa — 8. İki kök.

3 Qayda

|f(x)| = a: a > 0 → f(x) = a və ya f(x) = −a (iki hal) a = 0 → f(x) = 0 (bir hal) a < 0 → kök yoxdur (modul mənfi olmur)
Nümunə 1. |2x + 1| = 7 2x + 1 = 7 → x = 3 2x + 1 = −7 → x = −4 Köklərin cəmi: −1
Nümunə 2. |x − 4| + 3 = 1 |x − 4| = −2 → modul mənfi ola bilməz Kök yoxdur (köklərin sayı 0)
Nümunə 3. ||x| − 2| = 1 |x| − 2 = 1 → |x| = 3 → x = ±3 |x| − 2 = −1 → |x| = 1 → x = ±1 4 kök: −3; −1; 1; 3

4 Həyatdan

Həyatdan. Fikrət bir ədəd fikirləşdi: o, 12-dən 5 vahid fərqlənir. |x − 12| = 5 → x = 17 və ya x = 7. "Fərqlənir" sözü modul deməkdir — böyük də ola bilər, kiçik də.
Tipik səhvlər
  • Yalnız bir hal yazmaq: |2x + 1| = 7 → yalnız x = 3. İkinci hal 2x + 1 = −7 unudulur.
  • |x − 4| = −2 üçün "x = 2, x = 6" yazmaq. Modul mənfi ola bilməz — kök yoxdur.
  • |x − 4| + 3 = 1-də 3-ü köçürmədən modulu açmaq. Əvvəl modulu tək saxla.
Yadda saxla
|x − a| — x ilə a arasındakı məsafə. |f| = a > 0 → f = ±a. a = 0 → f = 0. a < 0 → kök yoxdur. Əvvəl modulu bir tərəfdə tək saxla.
Özünü yoxla: 3 sual
  1. |x + 2| = 6. Köklərin cəmi? x + 2 = 6 → x = 4; x + 2 = −6 → x = −8. Cəm: −4.
  2. |3x − 6| = 0. Neçə kök? 3x − 6 = 0 → x = 2. Bir kök.
  3. ||x| − 3| = 3. Neçə kök? |x| = 6 və ya |x| = 0: x = −6; 0; 6 — 3 kök.

Dərs 2. |f| = |g| və |f| = g(x) tənlikləri

1 Niyə lazımdır

Bəzən hər iki tərəfdə modul olur, bəzən də sağda ədəd yox, x-li ifadə durur. İlk halda iş asandır, ikincidə isə bir tələ var: sağ tərəf mənfi ola bilər, modul isə yox.

2 |f| = |g|

Modulları bərabər olan iki ədəd ya bərabərdir, ya da əks ədədlərdir:

|f(x)| = |g(x)| ⇔ f(x) = g(x) və ya f(x) = −g(x)
Nümunə 1. |2x − 3| = |x + 6| 2x − 3 = x + 6 → x = 9 2x − 3 = −(x + 6) → 3x = −3 → x = −1 Yoxla: |15| = |15| ✓ |−5| = |5| ✓ Köklərin cəmi: 8
Nümunə 2. |x − 1| = |x + 5| x − 1 = x + 5 → −1 = 5 — mümkün deyil x − 1 = −(x + 5) → 2x = −4 → x = −2 Məsafə ilə: 1 və −5 nöqtələrindən eyni uzaqlıqda olan nöqtə — ortası: (1 + (−5))/2 = −2

3 |f| = g(x) — yoxlama vacibdir

|f(x)| = g(x): 1. f = g və ya f = −g — kökləri tap. 2. Hər kökdə g(x) ≥ 0 olmalıdır — yoxsa at.
|x − 4| = 2x + 1 (şərt: 2x + 1 ≥ 0) Hal 1: x − 4 = 2x + 1 → x = −5 2·(−5) + 1 = −9 < 0 → atılır Hal 2: −(x − 4) = 2x + 1 → −x + 4 = 2x + 1 → x = 1 2·1 + 1 = 3 ≥ 0 ✓ Yoxla: |1 − 4| = 3 ✓ Cavab: bir kök, x = 1
Həyatdan. Səhər temperatur −5°, günorta 1° idi. Axşam temperatur elə oldu ki, hər ikisindən eyni qədər fərqlənirdi: |t − 1| = |t + 5| → t = −2° — düz ortada.
Tipik səhvlər
  • |f| = g(x)-də kökü yoxlamamaq. g(x) < 0 olan kök kənar kökdür.
  • f = −g halında mötərizəni unutmaq: 2x − 3 = −x + 6 yox, 2x − 3 = −x − 6.
  • "Mümkün deyil" halını (−1 = 5) səhv sanıb çaşmaq. Bu, sadəcə həmin halın kökü olmadığını göstərir.
Yadda saxla
|f| = |g| ⇔ f = g və ya f = −g |f| = g → iki hal + yoxlama g(x) ≥ 0 |x − a| = |x − b| → x = (a + b)/2 (a ≠ b; a = b olsa, bütün həqiqi ədədlər həldir)
Özünü yoxla: 3 sual
  1. |x − 3| = |x + 7|. x = ? (3 + (−7))/2 = −2.
  2. |x − 2| = |3x + 2|. Köklərin cəmi? x − 2 = 3x + 2 → x = −2; x − 2 = −3x − 2 → x = 0. Cəm: −2.
  3. |x + 1| = 2x − 4. Neçə kök? Hal 1: x + 1 = 2x − 4 → x = 5, 2·5 − 4 = 6 ≥ 0 ✓. Hal 2: −x − 1 = 2x − 4 → x = 1, 2·1 − 4 = −2 < 0 — atılır. Bir kök: 5.

Dərs 3. Modullu bərabərsizliklər

1 Niyə lazımdır

Zavodda detalın uzunluğu 50 mm olmalıdır, icazə verilən xəta 0,2 mm: |x − 50| ≤ 0,2. Termostat temperaturu 22°-dən ən çox 2° fərqlə saxlayır: |t − 22| ≤ 2. "Ən çox bu qədər fərqlənir" — modullu bərabərsizlikdir.

2 |x − a| ≤ b — parça

|x − a| ≤ b: x nöqtəsi a-dan ən çox b uzaqdadır. Bu, mərkəzi a, "radiusu" b olan parçadır.

|x − 2| ≤ 3: 2-dən hər iki tərəfə 3 vahid. Həll [−1; 5], tam həllər 7 ədəddir. Tərsinə: [L; R] parçası |x − a| ≤ b şəklində yazılır, burada a = (L + R)/2 — orta nöqtə, b = (R − L)/2 — yarım uzunluq.

3 Qaydalar

|f| < a ⇔ −a < f < a (ikiqat — "və") |f| > a ⇔ f < −a və ya f > a (iki şüa — "və ya") a < 0: |f| < a — həll yoxdur; |f| > a — bütün ədədlər |f| ≤ 0 ⇔ f = 0
Nümunə 1. |2x + 1| < 5 −5 < 2x + 1 < 5 → −6 < 2x < 4 → −3 < x < 2 Tam həllər: −2; −1; 0; 1 → 4 ədəd
Nümunə 2. |x − 1| ≥ 4 x − 1 ≤ −4 və ya x − 1 ≥ 4 → x ≤ −3 və ya x ≥ 5 Həll olmayan tam ədədlər: −2; −1; …; 4 → 7 ədəd
Nümunə 3. 2 ≤ |x| ≤ 4 0-dan məsafə 2-dən 4-ə qədər: [−4; −2] ∪ [2; 4] Tam həllər: ±2; ±3; ±4 → 6 ədəd
Həyatdan. Termostat: |t − 22| ≤ 2 → 20 ≤ t ≤ 24. Termometr tam dərəcə göstərirsə — 20, 21, 22, 23, 24: beş qiymət. "2°-dən az fərq" (<) olsaydı — 21, 22, 23: üç qiymət.
Tipik səhvlər
  • |f| > a üçün ikiqat bərabərsizlik yazmaq (−a < f < a). Bu, |f| < a-nın cavabıdır. "Böyük" — iki şüa.
  • İkiqat bərabərsizlikdə ədədi yalnız orta hissədən çıxarmaq.
  • |x| < −1 üçün cavab axtarmaq. Modul mənfidən kiçik olmur — həll yoxdur.
Yadda saxla
|x − a| ≤ b → [a − b; a + b] (parça, mərkəz a) "Kiçik" (<, ≤) → ikiqat: −a < f < a "Böyük" (>, ≥) → iki şüa: f < −a və ya f > a
Özünü yoxla: 3 sual
  1. |x + 1| < 3. Neçə tam həll? −4 < x < 2: −3; −2; −1; 0; 1 — 5 həll.
  2. |3x − 2| ≤ 4. Neçə tam həll? −4 ≤ 3x − 2 ≤ 4 → −2 ≤ 3x ≤ 6 → −2/3 ≤ x ≤ 2: 0; 1; 2 — 3 həll.
  3. |x − 5| > 2. Ən kiçik müsbət tam həll? x < 3 və ya x > 7. Cavab: 1.

Dərs 4. İki modul: |x − a| + |x − b|

1 Niyə lazımdır

Yolda iki dayanacaq var. Kafeni harada tiksək, iki dayanacağa qədər yolların cəmi ən az olar? Bu suala |x − a| + |x − b| ifadəsi cavab verir. İmtahanda belə ifadəli tənlik və bərabərsizliklər tez-tez olur.

2 Məsafə ilə bax

|x − a| + |x − b| — x nöqtəsindən a və b nöqtələrinə qədər məsafələrin cəmidir.

|x − 1| + |x + 3|, x = 3: məsafələr 2 və 6, cəm 8. Əgər x rənglənmiş parçada (−3 ilə 1 arasında) olsa, məsafələrin cəmi parçanın uzunluğuna — 4-ə bərabərdir. Bu, ən kiçik qiymətdir.

a < b olarsa: a ≤ x ≤ b → |x − a| + |x − b| = b − a (ən kiçik qiymət) kənarda → b − a ədədindən böyükdür

3 İntervallar üzrə açma

Universal üsul: modulların sıfırları ədəd oxunu hissələrə bölür, hər hissədə hər modul ya "+" ilə, ya "−" ilə açılır.

|x − 1| + |x + 3| = 6 sıfırlar: −3 və 1 x < −3: −(x − 1) − (x + 3) = 6 → −2x − 2 = 6 → x = −4 ✓ (−4 < −3) −3 ≤ x ≤ 1: (1 − x) + (x + 3) = 6 → 4 = 6 — kök yoxdur x > 1: (x − 1) + (x + 3) = 6 → 2x + 2 = 6 → x = 2 ✓ (2 > 1) Köklər: −4 və 2; cəmi −2

Hər hissədə tapılan kök həmin hissəyə düşməlidir — düşmürsə atılır.

4 Üç hal və bərabərsizlik

|x − 1| + |x + 3| = c (ən kiçik qiymət 4) c > 4 → iki kök (parçadan solda və sağda) c = 4 → bütün [−3; 1] parçası! Tam köklər: −3; −2; −1; 0; 1 → 5 c < 4 → kök yoxdur |x − 1| + |x + 3| ≤ 8 Sərhədlər (= 8): −2x − 2 = 8 → x = −5; 2x + 2 = 8 → x = 3 Həll: [−5; 3] — 9 tam həll. Yoxla: x = −5: 6 + 2 = 8 ✓
Həyatdan. Dayanacaqlar yolun 12-ci və 20-ci kilometrindədir. Kafeni 12 ilə 20 arasında harada tiksən, iki dayanacağa yolların cəmi eynidir — 8 km. Kənara çıxdıqca cəm artır. Ona görə "cəm ən çox 10 km olsun" şərti kafeni [11; 21] aralığına salır.
Tipik səhvlər
  • Hissədə tapılan kökün həmin hissəyə düşdüyünü yoxlamamaq.
  • c = b − a halında "iki kök" yazmaq. Burada parçanın bütün nöqtələri tənliyin kökləridir.
  • Modulu açarkən mötərizə qarşısındakı minusu bir həddə tətbiq etmək: −(x + 3) = −x − 3.
Yadda saxla
|x − a| + |x − b| — iki nöqtəyə məsafələrin cəmi. Ən kiçik qiymət |a − b| — a ilə b arasındakı hər nöqtədə. Universal üsul: sıfırlar → hissələr → hər hissədə modulu aç → kökü yoxla.
Özünü yoxla: 3 sual
  1. |x + 2| + |x − 5| ifadəsinin ən kiçik qiyməti? 5 − (−2) = 7.
  2. |x| + |x − 2| = 6. Köklərin cəmi? x < 0: −2x + 2 = 6 → x = −2. x > 2: 2x − 2 = 6 → x = 4. Cəm: 2.
  3. |x − 1| + |x − 4| < 5. Neçə tam həll? Sərhədlər: 5 − 2x = 5 → x = 0; 2x − 5 = 5 → x = 5. Həll (0; 5): 1; 2; 3; 4 — 4 həll.
