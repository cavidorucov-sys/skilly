Riyaziyyat · Buraxılış · DİM: Funksiyalar və qrafiklər

y = k/x, y = √x, y = |x|, y = x³ funksiyaları

Xətti funksiya və parabola ilə yanaşı imtahanda dörd "əsas" funksiya var: hiperbola y = k/x, y = √x, y = |x| və kub parabola y = x³. Hər birinin qrafikini tanımağı, nöqtədən k-nı tapmağı, ən böyük və ən kiçik qiymətləri, qrafiklərin kəsişmə nöqtələrini tapmağı öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Tərs mütənasiblik: y = k/x

1 Niyə lazımdır

120 km yolu 40 km/saatla 3 saata, 60 km/saatla 2 saata gedirsən. Sürət iki dəfə artanda vaxt iki dəfə azalır, hasil isə sabitdir: v·t = 120. Belə asılılıq — tərs mütənasiblikdir: t = 120/v.

2 Düstur və qrafik

y = k/x, k ≠ 0 (x·y = k) D(f): x ≠ 0 E(f): y ≠ 0

Qrafik — hiperbola: iki ayrı qol. Qollar oxlara yaxınlaşır, amma onlara heç vaxt toxunmur (x = 0 qadağandır, y isə 0 olmur).

k > 0: qollar I və III rübdə. Hər qolda funksiya azalır.

Qrafikdəki hər nöqtədə x·y = 6: 2·3 = 3·2 = (−2)·(−3) = 6.

k < 0: qollar II və IV rübdə. Hər qolda funksiya artır.

2·(−2) = (−1)·4 = −4.

3 k-nı nöqtədən tapmaq

A(a; b) qrafikə aiddir → k = a·b
Nümunə 1. y = k/x qrafiki A(−3; 4) nöqtəsindən keçir. x = 6 olduqda y = ? k = (−3)·4 = −12. y = −12/x. x = 6: y = −12/6 = −2 Nümunə 2. y = 18/x qrafikində B(m; −3) nöqtəsi. m = ? m·(−3) = 18 → m = −6 Nümunə 3. y = 12/x funksiyasının [2; 6] parçasında ən böyük qiyməti? k > 0, x > 0 olanda azalır → ən böyük qiymət sol ucda: 12/2 = 6. Ən kiçik: 12/6 = 2
Həyatdan. 6 usta hasarı 10 günə hörür. İş həcmi 6·10 = 60 "usta-gün". Ustaların sayı x olsa, gün sayı y = 60/x: 4 usta — 15 gün, 12 usta — 5 gün.
Tipik səhvlər
  • k-nı bölmə ilə tapmaq (k = b/a). Düzü: k = x·y, vurma.
  • "y = k/x bütün ədəd oxunda azalır" demək. Yox: hər qolda ayrıca azalır. −1 < 1, amma 6/(−1) = −6 < 6/1 = 6.
  • Hiperbolanın oxları kəsdiyini düşünmək. y = k/x-in sıfırı yoxdur.
Yadda saxla
y = k/x: x·y = k, k = (nöqtənin absisi)·(ordinatı). k > 0: I, III rüb, hər qolda azalır. k < 0: II, IV rüb, hər qolda artır. x ≠ 0, y ≠ 0 — oxları kəsmir.
Özünü yoxla: 3 sual
  1. y = k/x qrafiki (4; −2)-dən keçir. k = ? Qollar hansı rüblərdədir? k = 4·(−2) = −8. k < 0 — II və IV rüb.
  2. y = 15/x. x = −5 olduqda y = ? 15/(−5) = −3.
  3. y = −8/x funksiyasının [1; 4] parçasında ən kiçik qiyməti? k < 0 — artır, ən kiçik qiymət sol ucda: −8/1 = −8.

Dərs 2. y = √x və y = |x| funksiyaları

1 Niyə lazımdır

Kvadrat otağın sahəsi S-dirsə, tərəfi √S-dir. İki şəhər arasındakı məsafə "mənfi" ola bilməz — bu, moduldur. Hər iki funksiya mənfi qiymət almır, amma qrafikləri tam fərqlidir.

2 y = √x

D(f) = [0; +∞) E(f) = [0; +∞)

Qrafik (0; 0)-dan başlayır və yalnız sağa gedir. Funksiya artır, amma getdikcə yavaş: x 1-dən 4-ə artanda y 1-dən 2-yə artır, 4-dən 9-a artanda isə yalnız 2-dən 3-ə.

Qrafik çəkmək üçün tam kvadratları götür: (0; 0), (1; 1), (4; 2), (9; 3), (16; 4).

3 y = |x|

|x| = x, x ≥ 0 olanda |x| = −x, x < 0 olanda

İki şüa: sağda y = x, solda y = −x. Təpə (0; 0)-dır.

D(f) — bütün ədədlər, E(f) = [0; +∞). (−∞; 0]-da azalır, [0; +∞)-da artır. Qrafik Oy oxuna nəzərən simmetrikdir: |−3| = |3|.

4 Həll olunmuş nümunələr

Nümunə 1. A(m; 7) nöqtəsi y = √x qrafikinə aiddir. m = ? √m = 7 → m = 49 Nümunə 2. y = √x qrafikində absisi 12 olan nöqtənin ordinatı? √12 = √(4·3) = 2√3 Nümunə 3. y = √x funksiyasının [4; 25] parçasında ən böyük və ən kiçik qiyməti? Artandır: ən kiçik √4 = 2, ən böyük √25 = 5 Nümunə 4. y = |x| funksiyasının [−6; 2] parçasında ən böyük və ən kiçik qiyməti? 0 parçaya daxildir → ən kiçik |0| = 0 Ən böyük — uclardan biri: |−6| = 6, |2| = 2 → 6
Həyatdan. Kvadrat həyətin sahəsi 196 m²-dir. Tərəfi √196 = 14 m, hasarın uzunluğu 4·14 = 56 m. Sahə 4 dəfə artsa (784 m²), tərəf cəmi 2 dəfə artar: √784 = 28.
Tipik səhvlər
  • √x = 7-dən x = √7 yazmaq. Düzü: kvadrata yüksəlt, x = 49.
  • √x qrafikini sola da uzatmaq. Mənfi x-də √x yoxdur.
  • |x|-in parçadakı ən kiçik qiymətini ucda axtarmaq. Parçada 0 varsa, ən kiçik qiymət 0-dır.
Yadda saxla
√x: x ≥ 0, y ≥ 0, artır. Nöqtələr (1;1), (4;2), (9;3). |x|: hər x, y ≥ 0. Təpə (0;0), solda azalır, sağda artır. √x = c (c ≥ 0) → x = c². |x| = c (c > 0) → x = ±c.
Özünü yoxla: 3 sual
  1. y = √x qrafikində ordinatı 0,5 olan nöqtənin absisi? x = 0,5² = 0,25.
  2. |x| = 5 tənliyinin köklərinin hasili? x = 5 və x = −5, hasil −25.
  3. y = |x| funksiyasının [−7; −3] parçasında ən kiçik qiyməti? Parçada 0 yoxdur, x < 0 — azalır. Ən kiçik sağ ucda: |−3| = 3.

Dərs 3. Kub parabola: y = x³

1 Niyə lazımdır

Kubun tili 2 dəfə artanda həcmi 2³ = 8 dəfə artır. Bu "sürətli böyümə" y = x³ ilə yazılır. Kvadratdan fərqi: kub mənfi ədədin işarəsini saxlayır.

2 Qrafik və xassələr

Qrafik — kub parabola. (0; 0)-dan keçir, solda aşağıda, sağda yuxarıdadır (I və III rüb).

Qırıq xətt — y = x²: o, x < 0-da yuxarı qalxır, kub isə aşağı enir.

D(f) = (−∞; +∞) E(f) = (−∞; +∞) Bütün ədəd oxunda artır (−x)³ = −x³ → qrafik O-ya nəzərən simmetrik

Cədvəl: (±1)³ = ±1, (±2)³ = ±8, (±3)³ = ±27, (±4)³ = ±64, (±5)³ = ±125.

3 Həll olunmuş nümunələr

Nümunə 1. f(x) = x³. f(−2) + f(3) = ? −8 + 27 = 19 Nümunə 2. B(m; −64) nöqtəsi y = x³ qrafikinə aiddir. m = ? m³ = −64 → m = −4 (bir kök! x² = 64 isə iki kök verərdi) Nümunə 3. y = x³ funksiyasının [−3; 2] parçasında ən böyük və ən kiçik qiyməti? Artandır: ən kiçik (−3)³ = −27, ən böyük 2³ = 8 Nümunə 4. Müqayisə et: (−1,5)³ və (−1,4)³ −1,5 < −1,4 və x³ artır → (−1,5)³ < (−1,4)³
Həyatdan. Kub formalı akvariumun tili 5 dm-dir: V = 5³ = 125 dm³ = 125 litr. Tili 10 dm olan akvarium 1000 litr tutur — 2 dəfə uzun til, 8 dəfə çox su.
Tipik səhvlər
  • (−3)³ = 27 yazmaq. Tək qüvvətdə işarə qalır: −27.
  • x³ = −8 üçün "kök yoxdur" demək. Var: x = −2. Kökü olmayan x² = −8-dir.
  • y = x³ qrafikini parabola kimi (iki qolu yuxarı) çəkmək.
Yadda saxla
x³: D və E — bütün ədədlər, həmişə artır, O-ya nəzərən simmetrik. x³ = a — həmişə bir kök. Kubda işarə qalır. Parçada: ən kiçik — sol ucda, ən böyük — sağ ucda.
Özünü yoxla: 3 sual
  1. x³ = −125. x = ? x = −5.
  2. y = x³ qrafiki (3; m)-dən keçir. m = ? 27.
  3. y = x³ funksiyasının [−4; 1] parçasında ən kiçik qiyməti? Artandır — sol ucda: (−4)³ = −64.

Dərs 4. Qrafiklərin kəsişmə nöqtələri

1 Niyə lazımdır

İki maşın, iki tarif, iki qiymət — "nə vaxt bərabər olur?" sualı qrafiklərin kəsişməsidir. Kəsişmə nöqtəsi hər iki qrafikə aiddir, ona görə onun koordinatları hər iki düsturu ödəyir.

2 Alqoritm

1. y-ləri bərabərləşdir: f(x) = g(x) 2. Tənliyi həll et → kəsişmənin absisləri 3. Ordinat: x-i istənilən düstura yaz 4. √ və ya məxrəc varsa — kökü yoxla

3 Hiperbola və düz xətt

4/x = x + 3 (x ≠ 0) x-ə vur: 4 = x² + 3x x² + 3x − 4 = 0 x = 1 və x = −4 y = x + 3: (1; 4), (−4; −1)

Yoxla: 4/1 = 4 ✓, 4/(−4) = −1 ✓. Absislərin cəmi −3 — Viyet teoremindən də görünür.

4 √x, |x|, x³ ilə kəsişmələr

√x = x − 2 Kvadrata yüksəlt: x = x² − 4x + 4 x² − 5x + 4 = 0 → x = 4, x = 1 x = 1: √1 = 1, amma 1 − 2 = −1 ✗

Kvadrata yüksəldəndə kənar kök yarana bilər. Cavab: yalnız (4; 2).

Nümunə 2. y = |x| və y = x + 6 x ≥ 0: x = x + 6 — həll yoxdur x < 0: −x = x + 6 → x = −3, y = 3. Bir nöqtə: (−3; 3) Nümunə 3. y = x³ və y = 4x x³ = 4x → x(x² − 4) = 0 → x = 0, x = 2, x = −2 Üç nöqtə: (0; 0), (2; 8), (−2; −8) Nümunə 4. y = 12/x və y = −3 12/x = −3 → x = −4. Nöqtə (−4; −3)
Həyatdan. Hovuzun həcmi 60 m³-dir. Nasos saatda x m³ vurursa, doldurma vaxtı y = 60/x saat. Hovuzun 5 saata dolması üçün: 60/x = 5 → x = 12 m³/saat. Bu, y = 60/x və y = 5 qrafiklərinin kəsişməsidir.
Tipik səhvlər
  • Yalnız absisi tapıb dayanmaq, sual isə ordinatı soruşur. Sualı axıra qədər oxu.
  • √x = x − 2-də kökləri yoxlamamaq — iki "cavab" yazmaq.
  • x³ = 4x-də x-ə bölüb x = 0-ı itirmək. Bölmə yox — vuruqlara ayır.
Yadda saxla
Kəsişmə: f(x) = g(x) → x-lər → y-lər. k/x = mx + b → x-ə vur → kvadrat tənlik. √ olan tənlik: kvadrata yüksəlt, sonra mütləq yoxla. |x| olan tənlik: x ≥ 0 və x < 0 halları.
Özünü yoxla: 3 sual
  1. y = 6/x və y = x + 1 kəsişmə nöqtələrinin absisləri? x² + x − 6 = 0 → x = 2 və x = −3. Nöqtələr (2; 3), (−3; −2).
  2. y = √x və y = 3 kəsişmə nöqtəsi? √x = 3 → x = 9: (9; 3).
  3. y = x³ və y = 9x neçə nöqtədə kəsişir? x(x² − 9) = 0 → x = 0, ±3. Üç nöqtədə.
