n-ci dərəcədən kök, rasional üstlü qüvvət, irrasional ifadələr

Kvadrat kökü bilirsən: √49 = 7. İndi kub kök (∛8 = 2), dördüncü dərəcədən kök və ümumiyyətlə n-ci dərəcədən kök. Sonra kökü qüvvət kimi yazmağı (∛5 = 5¹ᐟ³), kökləri sadələşdirməyi və kəsrin məxrəcindən kökü "çıxarmağı" öyrənəcəksən. İmtahanda bu mövzudan sual demək olar ki, həmişə olur.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. n-ci dərəcədən kök və onun xassələri

1 Niyə lazımdır

Kub şəkilli akvariumun həcmi 27 litrdir (27 dm³). Tili nə qədərdir? Elə ədəd lazımdır ki, kubu 27 olsun: 3³ = 27, deməli til 3 dm. Bu əməl kub kök çıxarmaqdır: ∛27 = 3.

2 Tərif

ⁿ√a = b ⇔ bⁿ = a (n = 2, 3, 4, …) n — kökün dərəcəsi, a — kökaltı ifadə (n cüt olanda b ≥ 0 də tələb olunur)

Cüt dərəcə (√, ∜, ⁶√): kökaltı ifadə a ≥ 0 olmalıdır, kök də ≥ 0 götürülür (hesabi kök). ∜(−16)-nın mənası yoxdur.

Tək dərəcə (∛, ⁵√): istənilən ədəddən çıxarılır: ∛(−27) = −3, çünki (−3)³ = −27.

ⁿ√(aⁿ) = |a|, n cüt məs. ∜((−5)⁴) = 5 ⁿ√(aⁿ) = a, n tək məs. ∛((−5)³) = −5

3 Xassələr

a ≥ 0, b ≥ 0 (məxrəcdə b > 0) olanda:

ⁿ√(ab) = ⁿ√a · ⁿ√b ⁿ√(a/b) = ⁿ√a / ⁿ√b (ⁿ√a)ᵏ = ⁿ√(aᵏ) ⁿ√(ᵏ√a) = ⁿᵏ√a dərəcələr vurulur ⁿᵏ√(aᵐᵏ) = ⁿ√(aᵐ) dərəcə və üst eyni ədədə bölünür
1) ∜81 = 3, çünki 3⁴ = 81 2) ∛(−125/8) = −5/2, çünki (−5/2)³ = −125/8 3) ∛2 · ∛32 = ∛64 = 4 4) ∜162 : ∜2 = ∜81 = 3 5) √(∛729) = ⁶√729 = 3, çünki 3⁶ = 729 6) ∜((−2)⁴) + ∛((−3)³) = 2 + (−3) = −1

4 İrrasional ifadənin DMQ-su

Cüt dərəcəli kökün altı mənfi ola bilməz. Tək dərəcəli kök üçün məhdudiyyət yoxdur. Kök məxrəcdədirsə: cüt dərəcəli kökdə kökaltı ifadə ciddi müsbət olmalıdır, tək dərəcəli kökdə isə sıfırdan fərqli (məsələn, 1/∛(x+1) üçün x ≠ −1).

√(x − 2) + ∜(6 − x): x − 2 ≥ 0 və 6 − x ≥ 0 → 2 ≤ x ≤ 6 tam ədədlər: 2, 3, 4, 5, 6 — beş ədəd ∛(x + 1): bütün x 1/√(4 − x): 4 − x > 0 → x < 4
Həyatdan. Kubun tili 2 dəfə artanda həcmi 2³ = 8 dəfə artır. Tərsinə: həcm 8 dəfə artıbsa, til ∛8 = 2 dəfə artıb. Paketləmə zavodunda qutunun həcmini 27 dəfə artırmaq istəyirlərsə, tilləri ∛27 = 3 dəfə böyüdürlər.
Tipik səhvlər
  • ∜((−3)⁴) = −3 yazmaq. Cüt dərəcəli kök mənfi olmur: = |−3| = 3.
  • Fərqli dərəcəli kökləri birbaşa vurmaq: √2 · ∛2 ≠ ∛4. Vurmaq üçün dərəcələr eyni olmalıdır.
  • Kökü cəmə "paylamaq": √(9 + 16) ≠ 3 + 4. Düzü: √25 = 5.
Yadda saxla

  2. ∛4 · ∛54 = ? ∛216 = 6.
  3. √(x + 3) ifadəsinin DMQ-suna daxil olan ən kiçik tam ədəd? x + 3 ≥ 0 → x ≥ −3. Cavab: −3.

Dərs 2. Rasional üstlü qüvvət. Qüvvətlərin müqayisəsi

1 Niyə lazımdır

Kökləri qüvvət kimi yazanda onlarla bildiyin xassələrlə işləyirsən: üstləri toplayır, çıxır, vurursan. Ayrı "kök qaydaları" əzbərləmək lazım olmur.

2 Tərif

a^(m/n) = ⁿ√(aᵐ) (a > 0, n ≥ 2 natural, m tam) a^(1/n) = ⁿ√a

Yazılış: 8²ᐟ³ — "8-in 2/3 qüvvəti". Kəsrin məxrəci — kökün dərəcəsi, surəti — qüvvətin üstü. Bütün qüvvət xassələri (aᵖ·aᵠ = aᵖ⁺ᵠ, (aᵖ)ᵠ = aᵖᵠ və s.) burada da doğrudur.

3 Həll olunmuş nümunələr

1) 8²ᐟ³ = (∛8)² = 2² = 4 2) 16⁻³ᐟ⁴ = 1/(∜16)³ = 1/2³ = 1/8 3) 32³ᐟ⁵ = (2⁵)³ᐟ⁵ = 2³ = 8 ← əsası qüvvət kimi yaz, üstləri vur 4) (1/4)⁻³ᐟ² = 4³ᐟ² = (2²)³ᐟ² = 2³ = 8 5) 5¹ᐟ³ · 5⁵ᐟ³ = 5⁶ᐟ³ = 5² = 25 6) (∛7)⁶ = (7¹ᐟ³)⁶ = 7² = 49 7) √3 · 3³ᐟ² = 3¹ᐟ² · 3³ᐟ² = 3² = 9

4 Qüvvətlərin və köklərin müqayisəsi

Eyni əsas: a > 1 olanda böyük üst — böyük qüvvət; 0 < a < 1 olanda əksinə.

2¹ᐟ² > 2¹ᐟ³, çünki 1/2 > 1/3 və 2 > 1 (1/2)¹ᐟ² < (1/2)¹ᐟ³, çünki əsas 1-dən kiçikdir

Fərqli dərəcəli köklər: hamısını dərəcələrin ƏKOB-u qədər qüvvətə yüksəlt — köklər yox olur, adi ədədləri müqayisə edirsən.

√2 və ∛3: ƏKOB(2, 3) = 6 (√2)⁶ = 2³ = 8, (∛3)⁶ = 3² = 9 → ∛3 > √2 √3, ∛5, ⁶√30: 6-cı qüvvət 27, 25, 30 → ən böyüyü ⁶√30, ən kiçiyi ∛5
Həyatdan: piano. Pianoda oktava 12 yarımtona bölünür, oktavada tezlik 2 dəfə artır. Hər yarımtonda tezlik eyni sayda dəfə artır — 2¹ᐟ¹² = ¹²√2 ≈ 1,059 dəfə. 12 yarımton sonra: (2¹ᐟ¹²)¹² = 2. Pianonun köklənməsi rasional üstlü qüvvət üzərində qurulub.
Tipik səhvlər
  • Surət və məxrəci qarışdırmaq: 8²ᐟ³ — "8-in kvadratının kub kökü", "8-in kubunun kvadrat kökü" yox.
  • Mənfi üstü mənfi ədəd saymaq: 16⁻³ᐟ⁴ = 1/8, −8 yox.
  • Müqayisədə yalnız kökaltı ədədlərə baxmaq: ∛5 "5 > 3 olduğu üçün" √3-dən böyük deyil (25 < 27).
Yadda saxla
a^(m/n) = ⁿ√(aᵐ), a > 0 Əsası qüvvət kimi yaz (8 = 2³), sonra üstləri vur. Müqayisə: ƏKOB qədər qüvvətə yüksəlt.
Özünü yoxla: 3 sual
  1. 27²ᐟ³ = ? (∛27)² = 3² = 9.
  2. 4⁻¹ᐟ² = ? 1/√4 = 1/2.
  3. Hansı böyükdür: ∜5 yoxsa √2? 4-cü qüvvət: 5 və 4. ∜5 böyükdür.

Dərs 3. İrrasional ifadələrin eynilik çevrilmələri

1 Niyə lazımdır

Testdə cavab variantları adətən sadələşdirilmiş şəkildə olur: 6√2, √72 yox. √50 + √18-i toplamaq üçün də əvvəl onları "oxşar" etmək lazımdır.

2 Vuruğu kökaltından çıxarmaq və kökaltına salmaq

√(a²b) = a√b (a ≥ 0, b ≥ 0) ∛(a³b) = a∛b a√b = √(a²b) (a ≥ 0)

Kökaltı ifadədəki ədədi elə vuruqlara ayır ki, biri tam kvadrat (4, 9, 16, 25, 36, 49, …) — kub kökdə tam kub (8, 27, 64, 125) — olsun.

√72 = √(36·2) = 6√2 ∛54 = ∛(27·2) = 3∛2 3√5 = √(9·5) = √45 4∛3 = ∛(64·3) = ∛192

3 Oxşar köklər

Kökaltı ifadəsi və dərəcəsi eyni olan köklər oxşardır. Onlar oxşar hədlər kimi toplanır: əmsallar toplanır, kök dəyişmir.

√50 + √18 − √8 = 5√2 + 3√2 − 2√2 = 6√2 2√12 − √27 = 2·2√3 − 3√3 = 4√3 − 3√3 = √3 ∛54 − ∛16 = 3∛2 − 2∛2 = ∛2

4 Müxtəsər vurma düsturları ilə

(√7 − √3)(√7 + √3) = 7 − 3 = 4 (a − b)(a + b) = a² − b² (√3 + √5)² = 3 + 2√15 + 5 = 8 + 2√15 (a + b)² = a² + 2ab + b² (2√3)² = 4·3 = 12 √((2 − √5)²) = |2 − √5| = √5 − 2 √(x²) = |x|, √5 ≈ 2,24 > 2
Həyatdan. Kvadrat şəkilli bağın sahəsi 50 m²-dir. Tərəfi √50 = 5√2 ≈ 5·1,41 = 7,05 m. Hasar üçün perimetr: 4·5√2 = 20√2 ≈ 28,3 m. Sadələşdirilmiş şəkillə hesablamaq daha asandır.
Tipik səhvlər
  • Kökaltından ədədin özünü çıxarmaq: √(16·3) ≠ 16√3. Çıxan √16 = 4-dür: 4√3.
  • Fərqli kökləri toplamaq: √2 + √3 ≠ √5. Yalnız oxşar köklər toplanır.
  • Oxşar köklərdə kökaltı ifadəni də toplamaq: 2√5 + 3√5 = 5√5, 5√10 yox.
Yadda saxla
√(a²b) = a√b; tam kvadratı (kubu) tap və çıxar. Oxşar köklər: əmsalları topla, kök eyni qalır. (√a − √b)(√a + √b) = a − b

  2. √75 − √12 = ? 5√3 − 2√3 = 3√3.
  3. (√11 − √2)(√11 + √2) = ? 11 − 2 = 9.

Dərs 4. Kəsrin məxrəcinin irrasionallıqdan azad edilməsi

1 Niyə lazımdır

1/√2-ni kalkulyatorsuz hesablamaq üçün 1-i 1,414-ə bölmək lazımdır — çətindir. Amma 1/√2 = √2/2 = 1,414 : 2 = 0,707 — asandır. Cavab variantları da məxrəcində kök olmayan şəkildə verilir.

2 Məxrəcdə bir kök

a/√b = a√b/b (surət və məxrəci √b-yə vur) a/∛b = a∛(b²)/b (∛b²-yə vur: ∛b·∛b² = b)
6/√3 = 6√3/3 = 2√3 5/(2√5) = 5√5/(2·5) = √5/2 4/∛2 = 4∛4/∛8 = 4∛4/2 = 2∛4

3 Məxrəcdə cəm və ya fərq: qoşma ifadə

√m − √n və √m + √n qoşma ifadələrdir. Onların hasilində kök itir: (√m − √n)(√m + √n) = m − n.

4/(√7 − √3) = 4(√7 + √3)/((√7)² − (√3)²) = 4(√7 + √3)/4 = √7 + √3 6/(3 − √3) = 6(3 + √3)/(9 − 3) = 6(3 + √3)/6 = 3 + √3 2/(√5 + 1) = 2(√5 − 1)/(5 − 1) = (√5 − 1)/2

4 Qoşma kəsrlərin cəmi

(√5 + √3)/(√5 − √3) + (√5 − √3)/(√5 + √3) Ortaq məxrəc: 5 − 3 = 2 Surət: (√5 + √3)² + (√5 − √3)² = (8 + 2√15) + (8 − 2√15) = 16 Cavab: 16/2 = 8
Həyatdan. Kvadratın diaqonalı 10 sm-dir. Tərəfi 10/√2 = 10√2/2 = 5√2 ≈ 7,07 sm. Usta ölçünü məhz ikinci şəkildə hesablayır — 1,414·5 vurmaq bölməkdən asandır.
Tipik səhvlər
  • Yalnız məxrəci vurub surəti unutmaq. Kəsrin qiyməti dəyişməsin deyə hər ikisi eyni ifadəyə vurulur.
  • Qoşma əvəzinə eyni ifadəyə vurmaq: (√7 − √3)²-də kök qalır. Lazım olan √7 + √3-dür.
  • Məxrəcdə m − n əvəzinə m + n yazmaq.
Yadda saxla
