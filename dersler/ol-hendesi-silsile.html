Həndəsi silsilə

Bakteriyalar hər saat iki dəfə çoxalır, bank pulu hər il eyni faizlə artırır, top hər yerə dəyəndə əvvəlkindən aşağı qalxır. Bu hallarda ədədlər toplanmır, vurulur. Belə ardıcıllığa həndəsi silsilə deyilir. Dərslərdə sıfırdan başlayıb sonsuz azalan silsilə və dövri onluq kəsrlərə qədər gedəcəyik.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Məxrəc q və n-ci hədd

1 Niyə lazımdır

Bir kağızı yarıya qatlasan, qat sayı 1, 2, 4, 8, 16, … olur. Hər dəfə 2 ilə vurulur. 10 qatdan sonra neçə qat var? Hamısını yazmaq lazım deyil: 2¹⁰. Belə ardıcıllığı düsturla idarə edəcəyik.

2 Əsas fikir

Hər hədd əvvəlkini eyni q ədədinə vurmaqla alınırsa (b₁ ≠ 0, q ≠ 0), bu həndəsi silsilədir, q isə onun məxrəcidir:

bₙ₊₁ = bₙ·q, q = b₂ : b₁ = b₃ : b₂ = … bₙ = b₁·qⁿ⁻¹ bₘ : bₖ = q^(m − k)

q-nun mənası. q > 1 — modulça artır; 0 < q < 1 — modulça azalır (məs. q = 1/2); q < 0 — işarə növbələşir (3; −6; 12; −24); q = 1 — bütün hədlər eynidir.

Ədədi silsilədə fərq (+d) idi, burada nisbət (·q). Ona görə q-nu tapanda bölürük, çıxmırıq.

3 Həll olunmuş nümunələr

1) 3; 6; 12; 24; … silsiləsinin 8-ci həddi q = 6 : 3 = 2. b₈ = 3·2⁷ = 3·128 = 384 2) 162; 54; 18; … silsiləsinin 6-cı həddi q = 54 : 162 = 1/3. b₆ = 162·(1/3)⁵ = 162/243 = 2/3 3) b₃ = 12, b₆ = −96. b₉ = ? b₆ : b₃ = q³ → −96 : 12 = −8, q = −2 (tək qüvvət: işarə birqiymətlidir) b₉ = b₆·q³ = −96·(−8) = 768 4) b₂ = 6, b₄ = 54, bütün hədlər müsbətdir. b₅ = ? b₄ : b₂ = q² = 9 → q = 3 (müsbət, çünki hədlər müsbətdir; q = −3 işarəni dəyişərdi) b₅ = 54·3 = 162
Həyatdan. Bakteriya hər saat 3 dəfə çoxalır, başlanğıcda 4-dür. 5 saatdan sonra 4·3⁵ = 972. Belə sürətli artıma "eksponensial artım" deyirlər. Əksinə, qiymət hər il 10% ucuzlaşırsa, qiymətlər q = 0,9 məxrəcli silsilədir: 1000; 900; 810; 729; …

4 Nömrəni tapmaq və "ilk dəfə aşmaq"

Verilən ədədin nömrəsini tapanda b₁·qⁿ⁻¹ = x bərabərliyindən qⁿ⁻¹-i ayırıb 2-nin (3-ün…) qüvvəti kimi yaz. Məsələn, 5; 10; 20; …-də 1280: 2ⁿ⁻¹ = 256 = 2⁸, n = 9.

"Hansı həddi ilk dəfə 1000-dən böyükdür" kimi suallarda hədləri ardıcıl yaz: 3; 6; 12; 24; 48; 96; 192; 384; 768; 1536 → 10-cu. Logaritm lazım deyil, 2-nin qüvvətlərini bilmək kifayətdir: 2⁸ = 256, 2⁹ = 512, 2¹⁰ = 1024.

5 Olimpiada məsələləri

Məsələ 1. Həndəsi silsilədə b₂ = 6, b₅ = 162. b₇-ni tap. Həll. b₅ : b₂ = q³ = 27 → q = 3. b₁ = b₂ : q = 2. b₇ = 2·3⁶ = 2·729 = 1458. Yoxla: 2; 6; 18; 54; 162 ✓. Məsələ 2. 3; 6; 12; … silsiləsində 1000-dən kiçik neçə hədd var? Həll. 3·2ⁿ⁻¹ < 1000 → 2ⁿ⁻¹ < 333,3. 2⁸ = 256 < 333, 2⁹ = 512 > 333 → n − 1 ≤ 8, n ≤ 9. Cavab: 9 hədd (b₉ = 3·256 = 768, b₁₀ = 1536).
Tipik səhvlər
  • q-nu fərq kimi tapmaq: q = b₂ − b₁. Düz: q = b₂ : b₁.
  • bₙ = b₁·qⁿ yazmaq. Düz: qⁿ⁻¹ (n = 1 üçün b₁ alınmalıdır).
  • Cüt qüvvətdə q² = 9 ⟹ yalnız q = 3 demək. İki variant var: ±3; ikinci şərt (müsbətlik və ya başqa hədd) seçir.
  • Mənfi q-ni qüvvətə yüksəldəndə mötərizəni unutmaq: (−2)⁴ = 16, −2⁴ = −16.
Yadda saxla
bₙ = b₁·qⁿ⁻¹; q = b₂ : b₁ bₘ : bₖ = q^(m − k) Cüt qüvvət ⟹ ±; tək qüvvət ⟹ yeganə q
Özünü yoxla: 3 sual
  1. 2; −6; 18; … silsiləsində b₅ = ? q = −3, b₅ = 2·(−3)⁴ = 162.
  2. b₂ = 4, b₅ = 108. q = ? q³ = 27, q = 3.
  3. 1; 2; 4; … silsiləsinin hansı həddi ilk dəfə 100-dən böyükdür? 2⁶ = 64, 2⁷ = 128: 2ⁿ⁻¹ = 128 → n = 8.

Dərs 2. Xarakteristik xassə

1 Niyə lazımdır

Çox vaxt məsələdə b₁ və q ayrıca verilmir. Məsələn: "b₃·b₉ = 144, b₆ neçədir?" Hər ikisini tapmadan cavab almaq üçün silsilənin simmetriya xassəsi lazımdır. Bu, Dərs 2 (ədədi silsilə)-dəki xassənin vurma ilə analoqudur.

2 Əsas fikir

bₙ₋₁ = bₙ/q və bₙ₊₁ = bₙ·q. Bunları vursaq q ixtisar olur:

bₙ² = bₙ₋₁·bₙ₊₁ (hətta bₙ² = bₙ₋ⱼ·bₙ₊ⱼ) m + n = k + l ⟹ bₘ·bₙ = bₖ·bₗ

Hədlər müsbətdirsə, bₙ = √(bₙ₋₁·bₙ₊₁) — həndəsi orta. Hədlərin işarəsi növbələşərsə, bₙ² = … bərabərliyi yenə doğrudur, amma bₙ-in özü kvadrat kökdən birqiymətli çıxmır — şərtə bax.

3 Həll olunmuş nümunələr

1) Müsbət hədli silsilədə b₃·b₉ = 144. b₆ = ? 3 + 9 = 6 + 6 → b₃·b₉ = b₆² = 144 → b₆ = 12 2) b₂·b₁₁ = 20. b₅·b₈ = ? 2 + 11 = 5 + 8 = 13 → b₅·b₈ = 20 3) x; 6; 18 həndəsi silsilənin ardıcıl üç həddidir. 6² = 18x → 36 = 18x → x = 2. (q = 3) 4) x − 1; x + 3; 6x həndəsi silsilənin ardıcıl üç həddidir. x = ? (x + 3)² = 6x(x − 1) → x² + 6x + 9 = 6x² − 6x → 5x² − 12x − 9 = 0 D = 144 + 180 = 324 = 18² → x = (12 ± 18)/10 → x = 3 və ya x = −3/5 x = 3: 2; 6; 18 (q = 3). x = −3/5: −8/5; 12/5; −18/5 (q = −3/2). İkisi də yarayır.
Həyatdan. Maşının qiyməti hər il 10% ucuzlaşır: 1000; 900; 810 manat. Ortadakı qiymət qonşularının həndəsi ortasıdır: 900² = 810 000 = 1000·810. Ədədi orta isə (1000 + 810)/2 = 905 olardı — düz deyil.

4 Üç hədd üçün orta ilə yazılış

3 hədd: m/q, m, m·q (hasil = m³) 5 hədd: m/q², m/q, m, mq, mq² (hasil = m⁵)

Hasil verilibsə, orta hədd dərhal çıxır. Qalan bir tənlik q üçün olur.

5 Olimpiada məsələləri

Məsələ 1. Üç müsbət ədəd artan həndəsi silsilə təşkil edir, cəmləri 26, hasilləri 216-dır. Ədədləri tap. Həll. m/q, m, mq. Hasil m³ = 216 → m = 6. Cəm: 6/q + 6 + 6q = 26 → 6q + 6/q = 20 → 3q² − 10q + 3 = 0. D = 100 − 36 = 64 → q = (10 ± 8)/6 → q = 3 və ya q = 1/3. Artan → q = 3. Ədədlər: 2; 6; 18. Yoxla: 2 + 6 + 18 = 26; 2·6·18 = 216 ✓. Məsələ 2. Ədədi silsilənin 1-ci, 3-cü və 7-ci hədləri həndəsi silsilə təşkil edir (d ≠ 0). Həndəsi silsilənin məxrəcini tap. Həll. a₁, a₁ + 2d, a₁ + 6d. Xassə: (a₁ + 2d)² = a₁(a₁ + 6d). a₁² + 4a₁d + 4d² = a₁² + 6a₁d → 4d² = 2a₁d. d ≠ 0 → a₁ = 2d. Hədlər: 2d; 4d; 8d → q = 2. Məsələ 3. a, b, c həndəsi silsilədirsə, sübut et: (a² + b²)(b² + c²) = (ab + bc)². Həll. b² = ac. Sol tərəf: a²b² + a²c² + b⁴ + b²c². Sağ tərəf: a²b² + 2ab²c + b²c². Fərq: a²c² + b⁴ − 2ab²c = (ac − b²)² = 0. ∎
Tipik səhvlər
  • bₘ·bₙ = bₘ₊ₙ yazmaq. Yanlışdır: b₂·b₃ ≠ b₅.
  • Nömrələrin cəmini yoxlamamaq: b₂·b₉ ilə b₄·b₆ eyni deyil (11 ≠ 10).
  • Həndəsi ortanı ədədi orta kimi hesablamaq: 2 və 18-in arasında həndəsi orta 6-dır, 10 deyil.
  • b² = 36 ⟹ b = 6 yazmaq. İşarə növbələşərsə −6 da ola bilər; şərtə bax.
Yadda saxla
bₙ² = bₙ₋₁·bₙ₊₁ m + n = k + l ⟹ bₘ·bₙ = bₖ·bₗ 3 hədd: m/q, m, mq (hasil m³)
Özünü yoxla: 3 sual
  1. Müsbət hədlərlə b₄·b₁₂ = 81. b₈ = ? 4 + 12 = 8 + 8, b₈² = 81, b₈ = 9.
  2. 4; x; 36 müsbət həndəsi silsilədir. x = ? x² = 144, x = 12.
  3. b₃·b₇ = 20. b₄·b₆ = ? 3 + 7 = 4 + 6, cavab 20.

Dərs 3. İlk n həddin cəmi

1 Niyə lazımdır

Zəncirvari məktub: sən 3 nəfərə göndərirsən, onların hər biri 3 nəfərə, və s. 6 dövrədə neçə nəfər məktub alıb? 3 + 9 + 27 + 81 + 243 + 729. Bu cəmi düsturla tapacağıq. Qədim rəvayətdə şahmat ixtiracısı birinci xanaya 1, ikinciyə 2, üçüncüyə 4 dən istəyib — yekunda dənlərin sayı kainatdakı bütün buğdadan çox olub.

2 Düstur və sübut

Sₙ = b₁ + b₁q + b₁q² + … + b₁qⁿ⁻¹. Hər iki tərəfi q-yə vur və çıx:

Sₙ·q = b₁q + b₁q² + … + b₁qⁿ Sₙ·q − Sₙ = b₁qⁿ − b₁ (ortadakılar ixtisar olur) Sₙ = b₁·(qⁿ − 1)/(q − 1), q ≠ 1 q = 1 olsa: Sₙ = n·b₁

Eyni fikir qısa vurma düsturudur: (q − 1)(1 + q + … + qⁿ⁻¹) = qⁿ − 1. İkinci hal: q < 1 olanda Sₙ = b₁(1 − qⁿ)/(1 − q) bərabər düsturdur (surət və məxrəci −1-ə vurmaq).

3 Həll olunmuş nümunələr

1) 3; 6; 12; … ilk 6 hədd: S₆ = 3·(2⁶ − 1)/(2 − 1) = 3·63 = 189 2) b₁ = 2, q = −3, n = 4: S₄ = 2·((−3)⁴ − 1)/(−3 − 1) = 2·80/(−4) = −40 Yoxla: 2 − 6 + 18 − 54 = −40 ✓ 3) 5; 10; 20; …, Sₙ = 315. n = ? 5·(2ⁿ − 1) = 315 → 2ⁿ − 1 = 63 → 2ⁿ = 64 → n = 6 4) b₁ = 1, q = 3: b₃ + b₄ + b₅ + b₆ = ? İlk həddi b₃ = 9, say 4: 9·(3⁴ − 1)/(3 − 1) = 9·40 = 360 Yoxla: 9 + 27 + 81 + 243 = 360 ✓
Həyatdan. Ay ərzində ilk gün 1 manat, hər gün əvvəlki günün iki mislini yığırsan. 10-cu gün 512 manat qoyursan, ilk 10 gündə cəmi 1·(2¹⁰ − 1) = 1023 manat. Sonuncu gün qoyduğun 512, əvvəlki bütün günlərin cəmindən (511) düz 1 çoxdur.

4 Tərs məsələ və hissə cəmi

Hissə cəmi: bₖ + … + bₘ üçün ilk həd bₖ götürülür, say m − k + 1. n-i tapmaq: qⁿ-i ayırıb qüvvət kimi yaz.

Hesabda 2-nin qüvvətləri cədvəli lazımdır: 2⁷ = 128, 2⁸ = 256, 2⁹ = 512, 2¹⁰ = 1024, 2¹² = 4096; 3-ün: 3⁴ = 81, 3⁵ = 243, 3⁶ = 729.

5 Olimpiada məsələləri

Məsələ 1. Tərəzi və çəkilər: 1, 2, 4, 8, …, 512 qram çəkiləri var (hər biri bir dənə). Sübut et ki, 1-dən 1023-ə qədər istənilən tam çəkini bu çəkilərlə çəkmək olar. Həll. Cəm: 1 + 2 + … + 512 = (2¹⁰ − 1)/(2 − 1) = 1023 — maksimal çəki. Hər ədədin 2-lik sistemdə yazılışı 0 və 1-lərdən ibarətdir; "1" olan mövqelərdəki çəkiləri götürürük: 37 = 32 + 4 + 1. 10 çəkinin alt çoxluqlarının sayı 2¹⁰ = 1024 (boş çoxluq daxil), cəmlər fərqlidir (2-lik yazılış yeganədir) → 0-dan 1023-ə qədər hamısı alınır. ∎ Məsələ 2. 1 + 11 + 111 + 1111 + 11111 = ? Həll. Hər hədd (10ᵏ − 1)/9 şəklindədir. 9S = (10 − 1) + (100 − 1) + … + (10⁵ − 1) = (10 + 100 + … + 10⁵) − 5 = 111 110 − 5 = 111 105. S = 111 105 : 9 = 12 345. (Ümumi: Sₙ = (10ⁿ⁺¹ − 10 − 9n)/81.) Məsələ 3. Həndəsi silsilənin ilk 3 həddinin cəmi 21, ilk 6 həddinin cəmi 189. İlk həddi tap. Həll. S₆ = S₃ + q³S₃ = S₃(1 + q³) → 189 = 21·(1 + q³) → 1 + q³ = 9 → q = 2. S₃ = b₁(1 + 2 + 4) = 7b₁ = 21 → b₁ = 3.
Tipik səhvlər
  • Düsturda qⁿ − 1 əvəzinə qⁿ⁻¹ − 1 yazmaq. Cəmdə üstün n, hədd üçün isə n − 1 işlənir.
  • q = 1 halını unutmaq: bu halda düstur 0/0 verir, cəm sadəcə n·b₁-dir.
  • Mənfi q-də mötərizəni unutmaq: (−3)⁴ = 81.
  • Hissə cəmində ilk həddi b₁ götürmək. Düz: bₖ.
Yadda saxla
Sₙ = b₁(qⁿ − 1)/(q − 1) (q ≠ 1); q = 1 ⟹ n·b₁ 1 + 2 + 4 + … + 2ⁿ⁻¹ = 2ⁿ − 1 S₂ₙ = Sₙ(1 + qⁿ)
Özünü yoxla: 3 sual
  1. 1 + 2 + 4 + … + 256 = ? 9 hədd, 2⁹ − 1 = 511.
  2. 2; 6; 18; … ilk 5 həddin cəmi? q = 3, 2·(3⁵ − 1)/2 = 242.
  3. 3; 6; 12; … cəmi 93 olarsa, n = ? 3(2ⁿ − 1) = 93 → 2ⁿ = 32 → n = 5.

Dərs 4. Sonsuz azalan həndəsi silsilə

1 Niyə lazımdır

Zenon paradoksu: Axilles tısbağanı qova-qova gedir. Hər dəfə onun qaldığı yerə çatanda tısbağa bir az irəli getmiş olur. Sonsuz sayda məsafə var — amma onların cəmi sonludur. Bu silsilə mövzusunun ən güclü fikridir: sonsuz sayda müsbət ədədin cəmi sonlu ola bilər.

2 Əsas fikir

Əgər |q| < 1 olarsa, qⁿ n artdıqca sıfıra yaxınlaşır ((1/2)¹⁰ ≈ 0,001). Onda Sₙ = b₁(1 − qⁿ)/(1 − q) düsturunda qⁿ → 0 və:

S = b₁ / (1 − q), |q| < 1 Məs.: 1/2 + 1/4 + 1/8 + … = (1/2)/(1 − 1/2) = 1 |q| ≥ 1 olsa, cəm sonlu deyil (yoxsa mənası yoxdur).

3 Həll olunmuş nümunələr

1) 12 + 4 + 4/3 + … b₁ = 12, q = 1/3 S = 12/(1 − 1/3) = 12 : (2/3) = 18 2) 9 − 3 + 1 − 1/3 + … q = −1/3 S = 9/(1 + 1/3) = 9 : (4/3) = 27/4 3) Cəm 12, q = 3/4. b₁ = ? 12 = b₁/(1/4) → b₁ = 12·(1/4) = 3 4) b₁ = 20, S = 25. q = ? 1 − q = 20/25 = 4/5 → q = 1/5
Həyatdan. Top 10 m-dən düşür və hər dəfə əvvəlki hündürlüyün 2/3-i qədər sıçrayır. Bütün yol: 10 + 2·(10·2/3 + 10·(2/3)² + …) = 10 + 2·(20/3)/(1/3) = 10 + 40 = 50 m (sıçrayışlar yuxarı-aşağı iki dəfə sayılır).

4 Dövri onluq kəsr

0,(27) = 0,27 + 0,0027 + 0,000027 + … — b₁ = 0,27, q = 0,01. S = 0,27/0,99 = 27/99 = 3/11. Qısa qayda: dövr ab iki rəqəmdirsə 99-a, üç rəqəmlidirsə 999-a bölünür:

0,(a) = a/9; 0,(ab) = ab/99; 0,(abc) = abc/999 (sonra ixtisar et) 0,(9) = 9/9 = 1 Qarışıq: 0,1(6): x = 0,1666… ; 10x = 1,666… ; 100x = 16,666… 100x − 10x = 15 → x = 15/90 = 1/6

0,(9) = 1 təəccüblü görünür, amma düsturdan çıxır: 0,9/(1 − 0,1) = 1.

5 Olimpiada məsələləri

Məsələ 1. 0,(36) kəsrini adi kəsr kimi yaz. Həll. x = 0,(36). 100x = 36,(36). 100x − x = 36 → 99x = 36 → x = 36/99 = 4/11. Məsələ 2. Sonsuz azalan həndəsi silsilənin cəmi 6, hədlərinin kvadratlarının cəmi 12-dir. Silsilənin ilk həddini tap. Həll. Kvadratlar b₁², b₁²q², … — məxrəci q² olan sonsuz azalan silsilə: b₁²/(1 − q²) = 12. Birinci şərt: b₁/(1 − q) = 6. Kvadratını alıb bölək: (b₁²/(1 − q)²) : (b₁²/(1 − q²)) = 36/12 = 3 → (1 − q²)/(1 − q)² = (1 + q)/(1 − q) = 3. 1 + q = 3 − 3q → q = 1/2. b₁ = 6·(1 − 1/2) = 3. Yoxla: 3/(1/2) = 6; 9/(1 − 1/4) = 12 ✓. Məsələ 3. Tərəfi 1 olan kvadratın içinə mərkəzləri üst-üstə düşən, tərəfi əvvəlkinin yarısı olan kvadratlar yazılır və s. (sonsuz). Hamısının sahələrinin cəmi? Həll. Sahələr: 1; 1/4; 1/16; … q = 1/4. S = 1/(1 − 1/4) = 4/3.
Tipik səhvlər
  • |q| ≥ 1 olanda b₁/(1 − q) tətbiq etmək. Sonsuz cəm yoxdur (və ya məsələ düzgün deyil).
  • Mənfi q-də: 1 − q = 1 + |q|, 1 − |q| deyil.
  • Dövri kəsrdə ixtisarı unutmaq: 0,(36) = 36/99 = 4/11, 36/99 düzgün qiymətdir; ixtisarolunmaz şəkil tələb olunursa, 4/11 yazılır.
  • Topun yolunda sıçrayışları bir dəfə saymaq: hər sıçrayış yuxarı və aşağıdır, iki dəfə.
Yadda saxla
|q| < 1: S = b₁/(1 − q) 0,(ab) = ab/99, sonra ixtisar; 0,(9) = 1 S₂ = b₁²/(1 − q²) (kvadratlar silsiləsi)
Özünü yoxla: 3 sual
  1. 8 + 4 + 2 + … = ? 8/(1 − 1/2) = 16.
  2. 0,(45) = ? (ixtisarlı) 45/99 = 5/11.
  3. S = 10, q = 1/5. b₁ = ? 10·(4/5) = 8.
