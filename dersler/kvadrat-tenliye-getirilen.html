Kvadrat tənliyə gətirilən və sadə irrasional tənliklər

x⁴ − 13x² + 36 = 0, (x² − 2x)² − 11(x² − 2x) + 24 = 0, √(x + 5) = x − 1 — ilk baxışda mürəkkəb görünür, amma hamısı uyğun əvəzləmə ilə adi kvadrat tənliyə çevrilir. Kvadrat tənliyi həll etməyi bilirsən — bu mövzu onun üstündə qurulur.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Bikvadrat tənliklər

1 Niyə lazımdır

Dördüncü dərəcəli tənlik üçün sadə düstur yoxdur. Amma x⁴ = (x²)². Əgər tənlikdə yalnız x⁴, x² və ədəd varsa, o, əslində gizlənmiş kvadrat tənlikdir.

2 Əsas fikir

ax⁴ + bx² + c = 0 (a ≠ 0) t = x², t ≥ 0 at² + bt + c = 0

Əvvəl t-ni tapırıq, sonra x² = t-dən x-i. Hər t üçün:

t > 0 → x = ±√t (2 kök) t = 0 → x = 0 (1 kök) t < 0 → kök yoxdur (kvadrat mənfi olmur)

3 Həll olunmuş nümunələr

Nümunə 1. x⁴ − 13x² + 36 = 0 t = x²: t² − 13t + 36 = 0 Viyet: t₁ + t₂ = 13, t₁·t₂ = 36 → t = 4, t = 9 x² = 4 → x = ±2; x² = 9 → x = ±3 Cavab: −3; −2; 2; 3 (4 kök)
Nümunə 2. x⁴ + 3x² − 4 = 0 t² + 3t − 4 = 0 → t = 1, t = −4 x² = 1 → x = ±1; x² = −4 → kök yoxdur Cavab: −1; 1 (2 kök)
Nümunə 3. x⁴ − 5x² = 0 x²(x² − 5) = 0 x² = 0 → x = 0; x² = 5 → x = ±√5 Cavab: −√5; 0; √5 (3 kök)

Diqqət: bikvadrat tənliyin kökləri həmişə cüt-cüt gəlir (x və −x), ona görə köklərin cəmi həmişə 0-dır (0 kökü varsa, ayrıca sayılır). İmtahanda adətən köklərin sayını, ən böyüyünü və ya hasilini soruşurlar.

4 Həyatdan

Həyatdan: ekran. Düzbucaqlı ekranın diaqonalı 10 sm, sahəsi 48 sm². Tərəfləri? Bir tərəf x, o biri 48/x. Pifaqor: x² + (48/x)² = 100 → x⁴ − 100x² + 2304 = 0. t = x²: t = 36 və ya t = 64 → tərəflər 6 sm və 8 sm. Yoxla: 6 · 8 = 48, 6² + 8² = 100 ✓
Tipik səhvlər
  • t = −4-dən x = ±2 yazmaq. x² = −4-ün kökü yoxdur.
  • t-ləri cavab kimi yazmaq. Soruşulan x-dir: iki müsbət t → dörd x.
  • x⁴ − 5x² = 0-da x²-a bölüb x = 0 kökünü itirmək. Bölmə yox — mötərizə xaricinə çıxar.
Yadda saxla
t = x² (t ≥ 0) → kvadrat tənlik → t-lər → x-lər t > 0: ±√t; t = 0: 0; t < 0: kök yoxdur
Özünü yoxla: 3 sual
  1. x⁴ − 10x² + 9 = 0. Ən böyük kök? t = 1, t = 9 → x = ±1, ±3. Ən böyüyü 3.
  2. x⁴ + 5x² + 4 = 0. Neçə kök var? t = −1, t = −4 — ikisi də mənfi. Kök yoxdur: 0.
  3. x⁴ − 16 = 0. Neçə kök var? t² = 16 → t = 4 (t = −4 yaramır) → x = ±2. 2 kök.

Dərs 2. Yeni dəyişən daxil etmək (əvəzləmə)

1 Niyə lazımdır

(x² − 2x)² − 11(x² − 2x) + 24 = 0. Mötərizələri açsan, 4-cü dərəcəli uzun çoxhədli alınır — çox iş, çox səhv. Amma diqqət et: x² − 2x iki dəfə təkrarlanır. Onu bir hərflə əvəz etsək, tənlik qısalır.

2 Əsas fikir

Təkrarlanan ifadə = t 1. t ilə kvadrat tənlik → t₁, t₂ 2. Hər t üçün: ifadə = t → x-ləri tap 3. Bütün x-ləri yığ

Bikvadrat tənlik də əvəzləmədir: orada t = x² idi. İndi t istənilən təkrarlanan ifadə ola bilər: x² − 2x, (x + 1)², √x...

3 Həll olunmuş nümunələr

Nümunə 1. (x² − 2x)² − 11(x² − 2x) + 24 = 0 t = x² − 2x: t² − 11t + 24 = 0 → t = 3, t = 8 x² − 2x = 3 → x² − 2x − 3 = 0 → x = 3, x = −1 x² − 2x = 8 → x² − 2x − 8 = 0 → x = 4, x = −2 Cavab: −2; −1; 3; 4 (4 kök)
Nümunə 2. (x² + x)² − 4(x² + x) − 12 = 0 t = x² + x: t² − 4t − 12 = 0 → t = 6, t = −2 x² + x = 6 → x² + x − 6 = 0 → x = 2, x = −3 x² + x = −2 → x² + x + 2 = 0 → D = 1 − 8 < 0, kök yoxdur Cavab: −3; 2 (2 kök)
Nümunə 3. (x + 1)⁴ − 5(x + 1)² + 4 = 0 t = (x + 1)², t ≥ 0: t² − 5t + 4 = 0 → t = 1, t = 4 (x + 1)² = 1 → x + 1 = ±1 → x = 0, x = −2 (x + 1)² = 4 → x + 1 = ±2 → x = 1, x = −3 Cavab: −3; −2; 0; 1 (4 kök, cəmi −4)

Nümunə 2-də t = −2 mənfidir, amma bu, avtomatik "atılır" demək deyil — x² + x mənfi ola bilər (məs. x = −0,5-də). Burada sadəcə diskriminant mənfi çıxdı. t = x² və ya t = (x + 1)² olanda isə mənfi t dərhal atılır.

4 Həyatdan

Həyatdan. Bu üsul hər yerdə işləyir: mürəkkəb bir hissəni "qutuya" qoy, qutunun içinə baxmadan məsələni həll et, sonra qutunu aç. Proqramçılar da belə edir — uzun ifadəyə ad verirlər. Fizikada da v²-ni bir kəmiyyət kimi hesablayıb sonra kök alırıq.
Tipik səhvlər
  • t-ni tapıb dayanmaq. Cavab x-lərdir — hər t üçün tənliyi axıra qədər həll et.
  • Hər t-nin bir kök verdiyini düşünmək. Bir t iki, bir, ya da sıfır x verə bilər.
  • Mötərizəni açıb 4-cü dərəcəli çoxhədli ilə əlləşmək. Təkrarlanan ifadəni görən kimi əvəz et.
Yadda saxla
Təkrarlanan ifadə → t → t-lər → hər t üçün x-lər. t = x² və ya t = (...)² olanda t ≥ 0.
Özünü yoxla: 3 sual
  1. (x² + x)² − 8(x² + x) + 12 = 0. Ən böyük kök? t = 2, t = 6. x² + x − 2 = 0 → 1, −2; x² + x − 6 = 0 → 2, −3. Ən böyüyü 2.
  2. (x − 3)⁴ − 3(x − 3)² − 4 = 0. Neçə kök var? t = (x − 3)²: t = 4, t = −1 (atılır). x − 3 = ±2 → x = 5, x = 1. 2 kök.
  3. (x² − 5x)² + 2(x² − 5x) − 24 = 0 tənliyində hansı əvəzləmə edilir? t = x² − 5x. Onda t² + 2t − 24 = 0.

Dərs 3. Sadə irrasional tənliklər: √(ax + b) = c

1 Niyə lazımdır

Dəyişən kök işarəsi altındadırsa, tənlik irrasional adlanır: √(2x + 3) = 5. Kökdən qurtulmağın yolu — hər iki tərəfi kvadrata yüksəltmək. Amma əvvəl bir sual ver.

2 Əsas fikir

Kvadrat kök heç vaxt mənfi olmur: √9 = 3, "−3" yox. Ona görə:

√(ax + b) = c c < 0 → kök yoxdur c ≥ 0 → ax + b = c²

DMQ: kökaltı ifadə ≥ 0. √(ax + b) = c tipində bunu ayrıca yoxlamaq lazım deyil: ax + b = c² onsuz da ≥ 0-dır.

3 Həll olunmuş nümunələr

Nümunə 1. √(2x + 3) = 5 5 ≥ 0 → kvadrata yüksəlt: 2x + 3 = 25 → x = 11 Yoxla: √(22 + 3) = √25 = 5 ✓
Nümunə 2. √(x − 4) = −2 Sol tərəf ≥ 0, sağ tərəf mənfi. Cavab: kök yoxdur.
Nümunə 3. √(3x + 1) + 2 = 6 Əvvəl kökü tək saxla: √(3x + 1) = 4 3x + 1 = 16 → x = 5 Yoxla: √16 + 2 = 6 ✓
Nümunə 4. √(5 − x) = 3 5 − x = 9 → x = −4 Yoxla: √(5 + 4) = √9 = 3 ✓ (x mənfidir — problem deyil!)

Nümunə 4 vacibdir: x mənfi ola bilər. Mənfi olmamalı olan — kökaltı ifadədir və kökün qiymətidir, x özü yox.

4 Həyatdan

Həyatdan: daşın düşməsi. Hündürlükdən buraxılan daşın düşmə vaxtı təxminən t = √(h/5) (t — saniyə, h — metr). Körpüdən buraxılan daş 3 saniyəyə suya düşdü. Körpünün hündürlüyü: √(h/5) = 3 → h/5 = 9 → h = 45 m. Fizikadan tanıyırsan: h = gt²/2 = 10 · 9 / 2 = 45 m ✓
Tipik səhvlər
  • √(x − 4) = −2 → x − 4 = 4 → x = 8 yazmaq. Yoxla: √4 = 2 ≠ −2. Kök yoxdur!
  • √(3x + 1) + 2 = 6-da kökü tək saxlamadan kvadrata yüksəltmək: 3x + 1 + 4 = 36 — səhvdir.
  • Mənfi x-i "kökaltı mənfi olur" deyə atmaq. Kökaltını hesabla, x-ə baxma.
Yadda saxla
√ ≥ 0 həmişə. Kökü tək saxla → sağ tərəf mənfidirsə: kök yoxdur → deyilsə: kvadrata yüksəlt → həll et → yoxla.
Özünü yoxla: 3 sual
  1. √(x + 7) = 3. x = ? x + 7 = 9 → x = 2.
  2. √(4 − 3x) = 5. x = ? 4 − 3x = 25 → x = −7. Yoxla: √(4 + 21) = √25 = 5 ✓
  3. √(2x − 1) + 4 = 1. Neçə kök var? √(2x − 1) = −3 — mənfi. Kök yoxdur: 0.

Dərs 4. √f = g tipli tənliklər: yoxlama məcburidir

1 Niyə lazımdır

İndi sağ tərəfdə də x var: √(x + 5) = x − 1. Kvadrata yüksəldəndə kvadrat tənlik alınır, onun iki kökü olur. Amma çox vaxt onlardan biri saxtadır (kənar kökdür). İmtahan sualının tələsi məhz budur.

2 Kənar kök haradan çıxır

3 = 3 də, 3 = −3 də kvadrata yüksəldəndə 9 = 9 olur. Yəni kvadrata yüksəltmək √f = g ilə √f = −g-ni "qarışdırır". Mənfi g verən kök — o biri tənliyin köküdür, bizimki yox.

√f = g Şərt: g ≥ 0 f = g² → kökləri tap Hər kökü yoxla: g ≥ 0? yoxsa — at

3 Həll olunmuş nümunələr

Nümunə 1. √(x + 5) = x − 1 Şərt: x − 1 ≥ 0, yəni x ≥ 1 Kvadrata yüksəlt: x + 5 = (x − 1)² = x² − 2x + 1 x² − 3x − 4 = 0 → x = 4, x = −1 x = −1: sağ tərəf −2 < 0 → atılır. Yoxla x = 4: √9 = 3, 4 − 1 = 3 ✓ Cavab: x = 4
Nümunə 2. √(2x + 3) = x Şərt: x ≥ 0 2x + 3 = x² → x² − 2x − 3 = 0 → x = 3, x = −1 x = −1 < 0 → atılır. Yoxla: √9 = 3 ✓ Cavab: x = 3
Nümunə 3. √(5x − 4) = x 5x − 4 = x² → x² − 5x + 4 = 0 → x = 1, x = 4 İkisi də ≥ 0. Yoxla: √1 = 1 ✓, √16 = 4 ✓ Cavab: 1 və 4 (iki kök — həmişə biri atılmır!)
Nümunə 4. x − √x − 6 = 0 (əvəzləmə) t = √x, t ≥ 0, x = t²: t² − t − 6 = 0 → t = 3, t = −2 t = −2 < 0 → atılır. √x = 3 → x = 9 Yoxla: 9 − 3 − 6 = 0 ✓ Cavab: x = 9

4 Həyatdan

Nərdivan. 13 m-lik nərdivanın yuxarı ucu 12 m hündürlükdədir. Aşağı ucu divardan nə qədər aralıdır?

√(169 − x²) = 12 → 169 − x² = 144 → x² = 25 → x = ±5. Məsafə mənfi olmur: 5 m.

Həyatdan: ədəd tapmacası. "Ədəd öz kvadrat kökündən 30 vahid böyükdür." x − √x = 30, t = √x: t² − t − 30 = 0 → t = 6 (t = −5 atılır) → x = 36. Yoxla: 36 − 6 = 30 ✓
Tipik səhvlər
  • Yoxlamamaq və hər iki kökü yazmaq. Nümunə 1-də "4 və −1" səhv cavabdır.
  • (x − 1)² = x² − 1 yazmaq. Düzü: x² − 2x + 1 — ortadakı 2ab həddini unutma.
  • Həmişə bir kökün atılacağını düşünmək. Nümunə 3-də ikisi də yarayır — yoxlama qərar verir, vərdiş yox.
  • Əvəzləmədə t = √x-in mənfi qiymətini saxlamaq.
Yadda saxla
√f = g: g ≥ 0 şərti → f = g² → köklər → hər birini yoxla. Kvadrata yüksəltmək kənar kök yarada bilər. x + p√x + q = 0: t = √x ≥ 0.
Özünü yoxla: 3 sual
  1. √(x + 2) = x. Kökü tap. x² − x − 2 = 0 → x = 2, x = −1. x = −1 < 0 atılır. Cavab: 2.
  2. √(3x + 10) = x + 2. Kökü tap. Şərt x ≥ −2. 3x + 10 = x² + 4x + 4 → x² + x − 6 = 0 → x = 2, x = −3. −3 < −2 — atılır. Yoxla: √16 = 4 ✓. Cavab: 2.
  3. x − 3√x + 2 = 0. Köklərin cəmi? t = √x: t² − 3t + 2 = 0 → t = 1, t = 2 → x = 1, x = 4. Cəm: 5.
