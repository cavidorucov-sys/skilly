Koordinat sistemi, funksiya anlayışı

Nöqtənin yeri iki ədədlə verilir, funksiya isə bir ədədi başqa ədədə çevirən qaydadır. Bu mövzu bütün qrafik məsələlərinin əlifbasıdır: nöqtənin koordinatlarını, təyin oblastını və qiymətlər çoxluğunu tapmağı, qrafikdən sıfırları və artma-azalma aralıqlarını oxumağı öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Düzbucaqlı koordinat sistemi

1 Niyə lazımdır

Kinoteatrda bilet: "7-ci sıra, 12-ci yer". Şahmatda: "e4". Xəritədə: en və uzunluq. Hər dəfə yeri iki ədəd göstərir. Müstəvidə də belədir: hər nöqtənin iki koordinatı var.

2 Oxlar, koordinatlar, rüblər

İki perpendikulyar ədəd oxu: üfüqi — Ox (absislər oxu), şaquli — Oy (ordinatlar oxu). Kəsişmə nöqtəsi O — koordinat başlanğıcıdır.

A(x; y): x — absis, y — ordinat Əvvəl absis, sonra ordinat!

Oxlar müstəvini dörd rübə bölür (saat əqrəbinin əksinə nömrələnir):

I: x > 0, y > 0 · II: x < 0, y > 0
III: x < 0, y < 0 · IV: x > 0, y < 0

E(0; 3) heç bir rübdə deyil — Oy oxu üzərindədir.

3 Oxlar üzərində nöqtələr, məsafə

Ox üzərində: y = 0 (məs. (5; 0)) Oy üzərində: x = 0 (məs. (0; −2)) A(x; y)-dən Ox-a qədər məsafə = |y| A(x; y)-dən Oy-a qədər məsafə = |x| O-ya qədər məsafə = √(x² + y²)
Nümunə 1. A(2m − 8; 3) Oy oxu üzərindədir. m = ? Oy üzərində absis 0-dır: 2m − 8 = 0 → m = 4. Nümunə 2. A(−6; 8) nöqtəsindən: Ox-a qədər məsafə |8| = 8, Oy-a qədər |−6| = 6, O-ya qədər √(36 + 64) = √100 = 10.

4 Simmetrik nöqtələr

A(x; y) nöqtəsinə simmetrik nöqtə: Ox oxuna nəzərən: (x; −y) Oy oxuna nəzərən: (−x; y) O başlanğıcına nəzərən: (−x; −y)
A(3; −5): Ox-a nəzərən → (3; 5) (absis qalır) Oy-a nəzərən → (−3; −5) (ordinat qalır) O-ya nəzərən → (−3; 5) (ikisi də dəyişir)
Həyatdan. Şəhər xəritəsində məktəb O(0; 0), Fikrətin evi (3; 4)-dədir (1 vahid = 100 m). Düz xətt üzrə məktəbə qədər: √(9 + 16) = 5 vahid, yəni 500 m. Küçələrlə (əvvəl 3, sonra 4 vahid) — 700 m.
Tipik səhvlər
  • Koordinatların yerini dəyişmək: (3; −2) və (−2; 3) fərqli nöqtələrdir.
  • Ox oxu üzərində x = 0 yazmaq. Əksinə: Ox üzərində ordinat sıfırdır.
  • Ox-a qədər məsafəni absislə ölçmək. Ox-a qədər məsafə — |y|.
Yadda saxla
A(absis; ordinat). Rüblər: I (+;+), II (−;+), III (−;−), IV (+;−). Ox üzərində y = 0, Oy üzərində x = 0. Ox-a simmetriya: (x; −y). Oy-a: (−x; y). O-ya: (−x; −y).
Özünü yoxla: 3 sual
  1. M(−7; −2) neçənci rübdədir? Hər iki koordinat mənfidir — III rüb.
  2. A(4; −9)-a Oy oxuna nəzərən simmetrik nöqtə? (−4; −9): ordinat qalır, absisin işarəsi dəyişir.
  3. B(5; 3k + 6) Ox oxu üzərindədir. k = ? Ordinat 0: 3k + 6 = 0 → k = −2.

Dərs 2. Funksiya anlayışı, verilmə üsulları

1 Niyə lazımdır

Kvadratın tərəfi a olanda sahəsi a²-dır: tərəfi seçdin — sahə öz-özünə müəyyən olur. Taksi haqqı yolun uzunluğundan, temperatur saatdan asılıdır. Belə "bir şey digərini təyin edir" asılılığına funksiya deyilir.

2 Tərif

Təyin oblastındakı hər x-ə yalnız bir y uyğun gəlirsə, bu uyğunluq funksiyadır. x — arqument (sərbəst dəyişən), y — funksiya (asılı dəyişən).

y = f(x) f(a) — x = a olanda funksiyanın qiyməti

Burada funksiyanın üç əsas verilmə üsulunu öyrənirik: düsturla (y = 2x + 1), cədvəllə (x və y sütunları), qrafiklə. Qrafik — koordinatları (x; f(x)) olan bütün nöqtələrdir.

3 Qiymət hesablamaq, nöqtə qrafikə aiddirmi

Nümunə 1. f(x) = 2x² − 3x + 1. f(−2) = ? f(−2) = 2·(−2)² − 3·(−2) + 1 = 8 + 6 + 1 = 15 Nümunə 2. f(x) = (x + 4)/(x − 2). f(5) = ? f(5) = 9/3 = 3 Nümunə 3. A(3; m) nöqtəsi y = −2x + 7 qrafikinə aiddir. m = ? x = 3 yaz: m = −2·3 + 7 = 1 Nümunə 4. B(2; 5) nöqtəsi y = x² + 1 qrafikinə aiddirmi? 2² + 1 = 5 ✓ — aiddir. Nümunə 5. f(x) = 3x − 5. Hansı x-də f(x) = 13? 3x − 5 = 13 → 3x = 18 → x = 6

Mənfi ədədi qüvvətə yüksəldəndə mötərizə məcburidir: (−2)² = 4, amma −2² = −4.

4 Qrafik funksiyadırmı? Şaquli xətt yoxlaması

Çevrə funksiyanın qrafiki deyil: x = 1 xətti onu iki nöqtədə kəsir — bir x-ə iki y düşür.

Parabola funksiyanın qrafikidir: hər şaquli xətt onu ən çox bir nöqtədə kəsir. Qayda: hər şaquli xətt qrafiki ən çox bir dəfə kəsməlidir.

Həyatdan. Mobil tarif: ayda 5 manat + hər GB üçün 2 manat. y = 5 + 2x (x — GB). 7 GB işlətsən: 5 + 14 = 19 manat. 25 manat ödəmisənsə: 5 + 2x = 25 → x = 10 GB.
Tipik səhvlər
  • Mənfi ədədi mötərizəsiz yazmaq: f(−3) üçün x² = 9, "−9" yox.
  • f(a) ilə "f(x) = a"-nı qarışdırmaq. Birincidə x verilib, y-i tapırsan; ikincidə y verilib, x-i.
  • Nöqtənin koordinatlarını tərsinə yerinə qoymaq: A(3; m)-də x = 3, y = m.
Yadda saxla
Funksiya: hər x-ə yalnız bir y. f(a): x-in yerinə a (mötərizə ilə!). Nöqtə qrafikə aiddir ⇔ koordinatları düsturu ödəyir.
Özünü yoxla: 3 sual
  1. f(x) = x² − 4x. f(−1) = ? 1 + 4 = 5.
  2. A(−2; m) nöqtəsi y = 3x + 10 qrafikinə aiddir. m = ? m = −6 + 10 = 4.
  3. f(x) = 4x + 3. Hansı x-də f(x) = −9? 4x = −12 → x = −3.

Dərs 3. Təyin oblastı və qiymətlər çoxluğu

1 Niyə lazımdır

Lift 0-cı mərtəbədən 16-cıya qədər gedir: "−3-cü mərtəbə" və ya "2,5-ci mərtəbə" mənasızdır. Funksiyanın da "işlədiyi" x-lər və "ala bildiyi" y-lər var. İmtahanda bu ikisi demək olar ki, hər variantda soruşulur.

2 Təriflər

D(f) — təyin oblastı: x-in ala biləcəyi bütün qiymətlər E(f) — qiymətlər çoxluğu: y-in aldığı bütün qiymətlər

Düsturla verilən funksiyada D(f)-i iki qadağa məhdudlaşdırır:

məxrəc ≠ 0 kvadrat kök altı ≥ 0

Qadağa yoxdursa (məs. y = 3x² − x), D(f) — bütün ədədlərdir.

3 Düsturdan D(f)

Nümunə 1. y = √(2x − 5) 2x − 5 ≥ 0 → x ≥ 2,5. D(f) = [2,5; +∞) Ən kiçik tam ədəd: 3 Nümunə 2. y = √(4 − x) + √(x + 2) 4 − x ≥ 0 → x ≤ 4; x + 2 ≥ 0 → x ≥ −2 D(f) = [−2; 4] — tam ədədlər: −2, −1, 0, 1, 2, 3, 4 (7 ədəd) Nümunə 3. y = √(x − 1)/(x − 3) x − 1 ≥ 0 → x ≥ 1; x − 3 ≠ 0 → x ≠ 3 D(f) = [1; 3) ∪ (3; +∞)

Kvadrat mötərizə [ — uc daxildir, dəyirmi ( — daxil deyil. Sonsuzluğun yanında həmişə dəyirmi mötərizə.

4 Qrafikdən D(f) və E(f), düsturdan E(f)

Qrafiki Ox-a "proyeksiya et" (narıncı): D(f) = [−5; 4].

Oy-a proyeksiya et (yaşıl): ən aşağı nöqtə −2, ən yuxarı 3: E(f) = [−2; 3].

Düsturda E(f) üçün əsas fakt: x² ≥ 0, |x| ≥ 0, √x ≥ 0.

y = x² + 3: x² ≥ 0 → y ≥ 3. E(f) = [3; +∞) y = −(x − 1)² + 5: −(x − 1)² ≤ 0 → y ≤ 5. E(f) = (−∞; 5] y = |x + 2| − 4: |x + 2| ≥ 0 → y ≥ −4. E(f) = [−4; +∞)
Həyatdan. Bilet qiyməti: 1 nəfər 3 manat, maksimum 6 nəfərlik qrup. y = 3x, burada D = {1, 2, 3, 4, 5, 6}, E = {3, 6, 9, 12, 15, 18}. Funksiyanın düsturu eyni olsa da, həyatdakı şərt təyin oblastını kəsir.
Tipik səhvlər
  • x − 1 ≥ 0-dan "x > 1" yazmaq. Bərabərlik də olur: √0 = 0, ona görə 1 daxildir.
  • Məxrəcdə kök olanda (1/√(x − 2)) sıfırı unutmaq: burada x − 2 > 0, ciddi bərabərsizlik.
  • D və E-ni qarışdırmaq: D — Ox üzrə (x-lər), E — Oy üzrə (y-lər).
Yadda saxla
D(f): məxrəc ≠ 0, √ altı ≥ 0 (məxrəcdəki √ altı > 0). Qrafikdə: D — Ox-a kölgə, E — Oy-a kölgə. x² ≥ 0, |x| ≥ 0, √x ≥ 0 → E(f)-in sərhədi.
Özünü yoxla: 3 sual
  1. y = √(3x + 6) üçün D(f)? 3x + 6 ≥ 0 → x ≥ −2: [−2; +∞).
  2. y = 5/(x + 1) + √x üçün D(f)? x ≥ 0 və x ≠ −1. −1 onsuz da x ≥ 0-a daxil deyil: [0; +∞).
  3. y = 7 − x² funksiyasının ən böyük qiyməti? −x² ≤ 0, ona görə y ≤ 7. Ən böyük qiymət 7 (x = 0-da).

Dərs 4. Qrafiki oxumaq: sıfırlar, işarə, artma və azalma

1 Niyə lazımdır

İmtahanda tez-tez düstur verilmir — yalnız şəkil. Hava proqnozu, səhm qiyməti, sürət qrafiki — hamısını oxumaq eyni bacarıqdır: qrafikə soldan sağa bax və sualı onun dilinə çevir.

2 Nümunə qrafik

Funksiya [−6; 6] parçasında verilib. Sınma nöqtələri: (−6; −2), (−4; 2), (−1; −1), (3; 3), (6; 0).

Yaşıl nöqtələr — sıfırlar. Narıncı qırıq xətt — y = 1.

3 Sıfırlar və işarə

Funksiyanın sıfırı — f(x) = 0 olan x (qrafikin Ox oxu ilə ortaq nöqtəsinin absisi) f(x) > 0 — qrafik Ox-dan yuxarıda f(x) < 0 — qrafik Ox-dan aşağıda
Şəkildəki funksiya üçün: Sıfırlar: −5; −2; 0; 6 (4 sıfır, cəmi −1) f(x) > 0: (−5; −2) və (0; 6) f(x) < 0: [−6; −5) və (−2; 0)

4 Artma, azalma, ən böyük və ən kiçik qiymət

Soldan sağa: qrafik qalxır → funksiya artır qrafik enir → funksiya azalır
Artma aralıqları: [−6; −4] və [−1; 3] Azalma aralıqları: [−4; −1] və [3; 6] (uzunluqlar: 3 + 3 = 6) Ən böyük qiymət: 3 (x = 3-də). Ən kiçik qiymət: −2 (x = −6-da) E(f) = [−2; 3]

5 f(a) və f(x) = c qrafikdən

f(−4) = 2 (x = −4-dən qrafikə qədər qalx) f(x) = 1 tənliyi: y = 1 xəttini çək — qrafiki 4 nöqtədə kəsir, deməli 4 həll var. f(x) = 3 tənliyi: yalnız (3; 3) nöqtəsi → bir həll, x = 3.
Həyatdan. Səhər saat 0-da temperatur −2° idi, saat 6-ya qədər +4°-yə qalxdı, sonra saat 9-a qədər +1°-yə endi. Qrafikdə: [0; 6] — artma, [6; 9] — azalma. Temperatur sıfırı bir dəfə keçib — bu, funksiyanın sıfırıdır.
Tipik səhvlər
  • Sıfır kimi nöqtənin ordinatını yazmaq. Sıfır — absisdir (x), çünki y onsuz da 0-dır.
  • Artma aralığını Oy üzrə yazmaq. Aralıqlar həmişə x-lərlə yazılır.
  • f(x) = c tənliyində həllərin sayını sayarkən ucdakı və sınma nöqtələrini buraxmaq.
Yadda saxla
Sıfır: qrafik ∩ Ox, cavab — x. Qalxır — artır, enir — azalır (soldan sağa, aralıq x-lərlə). f(x) = c: y = c xətti, kəsişmələrin sayı = həllərin sayı.
Özünü yoxla: 3 sual (yuxarıdakı qrafik üzrə)
  1. f(3) − f(−1) = ? 3 − (−1) = 4.
  2. f(x) = −1 tənliyinin neçə həlli var? y = −1 xətti: birinci hissədə bir dəfə (x = −5,5), sonra (−1; −1) nöqtəsi — cəmi 2 həll. Son hissə 0-a qədər enir, −1-ə çatmır.
  3. Funksiyanın ən uzun artma aralığının uzunluğu? [−1; 3] — uzunluğu 4.
