Yüksəkdərəcəli tənliklər, rasional köklər

Kvadrat tənliyin düsturu var. Üçüncü və dördüncü dərəcəli tənliklərin də düsturu var, amma o qədər çətindir ki, olimpiadada heç kim işlətmir. Əvəzində ağıllı üsullar var: mümkün rasional kökləri siyahıya almaq, vuruqlara ayırmaq, qarşılıqlı tənliyi t = x + 1/x ilə kiçiltmək, düzgün əvəzləmə seçmək. Bu mövzuda məhz bunları öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Rasional köklər teoremi

1 Niyə lazımdır

2x³ − 3x² − 11x + 6 = 0 tənliyini necə həll edəsən? Kökləri təxmin etmək olar, amma təsadüfi sınamaq vaxt aparır. Əgər kökün yalnız bir neçə namizədi olduğunu bilsən, sınamaq 2–3 dəqiqəlik işdir. Rasional köklər teoremi bu namizədlərin siyahısını verir.

2 Əsas fikir

P(x) = aₙxⁿ + … + a₁x + a₀ — tam əmsallı çoxhədli p/q (azalmaz kəsr) P-nin kökü olarsa: p bölür a₀-ı (sərbəst həddi), q bölür aₙ-i (baş əmsalı).

İsbat. x = p/q qoyub qⁿ-ə vuraq:

aₙpⁿ + aₙ₋₁pⁿ⁻¹q + … + a₁pqⁿ⁻¹ + a₀qⁿ = 0

Sonuncu hədd istisna olmaqla hər həddin tərkibində p var. Deməli p bölür a₀qⁿ-i. p və q qarşılıqlı sadədir, ona görə p bölür a₀-ı. Eyni qayda ilə birinci həddi çıxanda q bölür aₙpⁿ-i, yəni aₙ-i. ∎

Xüsusi hal. Baş əmsal 1-dirsə (q = 1), bütün rasional köklər tam ədəddir və sərbəst həddi bölür.

3 Həll olunmuş nümunələr

1) x³ − 6x² + 11x − 6 = 0 Baş əmsal 1, sərbəst hədd −6. Namizədlər: ±1, ±2, ±3, ±6. P(1) = 1 − 6 + 11 − 6 = 0 ✓ → x = 1 kökdür. Horner (a = 1): 1, −5, 6 | 0 → x² − 5x + 6 = (x − 2)(x − 3) Cavab: 1, 2, 3 2) 2x³ − 3x² − 11x + 6 = 0 p bölür 6: ±1, ±2, ±3, ±6. q bölür 2: 1 və ya 2. Namizədlər: ±1, ±2, ±3, ±6, ±1/2, ±3/2. P(1) = 2 − 3 − 11 + 6 = −6, P(−1) = −2 − 3 + 11 + 6 = 12, P(2) = 16 − 12 − 22 + 6 = −12, P(−2) = −16 − 12 + 22 + 6 = 0 ✓ Horner (a = −2): 2, −7, 3 | 0 → 2x² − 7x + 3 = (2x − 1)(x − 3) Cavab: −2, 1/2, 3

Hər namizədi yoxlamaq lazım deyil. Kökü tapan kimi Horner ilə dərəcəni aşağı sal, qalanını kvadrat tənlik kimi həll et.

Həyatdan. Ölçüləri ardıcıl tam ədədlər olan qutunun həcmi 336 sm³-dir. Ölçülər x, x + 1, x + 2 olarsa, x³ + 3x² + 2x − 336 = 0. Baş əmsal 1 olduğundan müsbət kök 336-nın böləni olmalıdır: 6 yoxlanır — 216 + 108 + 12 − 336 = 0. Ölçülər 6, 7, 8 sm.

4 Olimpiada məsələsi: irrasionallıq

Məsələ. Sübut et ki, √2 + √3 ədədi irrasionaldır. Həll. x = √2 + √3 olsun. Kvadrata yüksəldək: x² = 2 + 3 + 2√6 = 5 + 2√6 → x² − 5 = 2√6. Yenə kvadrata: (x² − 5)² = 24 → x⁴ − 10x² + 1 = 0. Deməli x tam əmsallı, baş əmsalı 1 olan tənliyin köküdür. Rasional köklər yalnız ±1 ola bilər (1-in bölənləri): 1 − 10 + 1 = −8 ≠ 0, hər iki halda eyni (cüt dərəcələr). Heç bir rasional kök yoxdur, ona görə x rasional deyil. ∎

5 Özünü yoxla

Tipik səhvlər
  • Namizədləri yalnız tam ədədlər götürmək. Baş əmsal 1-dən fərqlidirsə, kəsr köklər də ola bilər: 2x² − 5x + 2 = 0-in kökləri 2 və 1/2.
  • p-ni baş əmsalın, q-nu sərbəst həddin böləni götürmək. Düzü: p — sərbəst həddin, q — baş əmsalın.
  • Mənfi namizədləri unutmaq. Hər p/q üçün −p/q də yoxlanmalıdır.
  • Teorem kökün olduğunu demir, yalnız ola biləcəyini deyir. Namizədi yerinə qoyub yoxlamaq şərtdir.
Yadda saxla
Tam əmsallı P, kök p/q (azalmaz): p | a₀, q | aₙ Baş əmsal 1 → rasional kök tamdır və a₀-ı bölür Kök tapıldı → Horner ilə dərəcəni aşağı sal Namizədlərdən heç biri uyğun deyil → rasional kök yoxdur
Özünü yoxla: 3 sual
  1. 3x² − 5x − 2 = 0 tənliyinin rasional köklərinin namizədləri hansılardır? Köklər? p | 2, q | 3: ±1, ±2, ±1/3, ±2/3. Köklər: 2 və −1/3, çünki 3x² − 5x − 2 = (3x + 1)(x − 2).
  2. x³ + x + 1 = 0 tənliyinin rasional kökü varmı? Namizədlər ±1. P(1) = 3, P(−1) = −1. Yoxdur.
  3. x³ − 2x² − x + 2 = 0 tənliyini həll et. P(1) = 1 − 2 − 1 + 2 = 0. Horner: 1, −1, −2 | 0 → x² − x − 2 = (x − 2)(x + 1). Köklər: 1, 2, −1.

Dərs 2. Vuruqlara ayırma: üçüncü və dördüncü dərəcə

1 Niyə lazımdır

Çoxhədli tənliyi həll etmək = onu vuruqlara ayırmaq: hasil sıfırdırsa, vuruqlardan biri sıfırdır. Rasional kök tapılmayanda da yollar var: qruplaşdırma, tam kvadrat, "əlavə et və çıx" hiyləsi. Dördüncü dərəcəli çoxhədlinin rasional kökü olmasa belə, o, iki kvadrat üçhədlinin hasili ola bilər.

2 Əsas fikir

1) Qruplaşdır: x³ − 2x² − 5x + 10 = x²(x − 2) − 5(x − 2) 2) Rasional kök tap, Horner ilə böl 3) Tam kvadrat yarat: a² − b² = (a − b)(a + b) 4) Quartic üçün: iki kvadrat üçhədlinin hasilini cəhd et

3 Həll olunmuş nümunələr

1) x³ − 2x² − 5x + 10 = 0 x²(x − 2) − 5(x − 2) = (x − 2)(x² − 5) = 0 Cavab: x = 2, x = √5, x = −√5 2) x⁴ − 5x³ + 5x² + 5x − 6 = 0 Namizədlər: ±1, ±2, ±3, ±6. P(1) = 1 − 5 + 5 + 5 − 6 = 0 ✓ Horner (a = 1): 1, −4, 1, 6 | 0 → x³ − 4x² + x + 6 P(−1) = −1 − 4 − 1 + 6 = 0 ✓ Horner (a = −1): 1, −5, 6 | 0 → x² − 5x + 6 = (x − 2)(x − 3) Cavab: 1, −1, 2, 3 3) x⁴ + x² + 1 — vuruqlara ayır. Rasional kök yoxdur (±1 uyğun deyil). Tam kvadrat yaradaq: x⁴ + x² + 1 = (x⁴ + 2x² + 1) − x² = (x² + 1)² − x² = (x² + x + 1)(x² − x + 1)

4 Olimpiada məsələsi: Sofi Jermen eyniliyi

Məsələ. Sübut et ki, n > 1 natural ədədi üçün n⁴ + 4 mürəkkəb ədəddir. Həll. Tam kvadrat yaradaq: n⁴ + 4 = (n⁴ + 4n² + 4) − 4n² = (n² + 2)² − (2n)² = (n² − 2n + 2)(n² + 2n + 2). Vuruqlardan birincisi (n − 1)² + 1 şəklindədir, n > 1 olduqda ≥ 2. İkincisi bundan da böyükdür. Hər iki vuruq 1-dən böyükdür → n⁴ + 4 mürəkkəbdir. (n = 2: 20 = 2 · 10; n = 3: 85 = 5 · 17. n = 1 üçün 5 sadədir: vuruqlardan biri 1.) ∎
Həyatdan. Kriptoqrafiyada böyük ədədi vuruqlara ayırmaq çox çətin məsələdir, şifrələrin təhlükəsizliyi buna söykənir. Ədədin xüsusi şəkli (məsələn, n⁴ + 4) isə onu dərhal açır.

5 Özünü yoxla

Tipik səhvlər
  • Kökü tapıb dayanmaq. x − 1 vuruğunu ayırandan sonra qalan çoxhədlini də həll etmək lazımdır.
  • Hornerdə buraxılmış dərəcəni 0 ilə yazmamaq.
  • x⁴ + x² + 1-in vuruqlara ayrılmayacağını güman etmək: kök olmaması çoxhədlinin "bölünməz" olması demək deyil.
  • Hasil sıfırdan fərqli ədədə bərabər olanda ("(x − 1)(x − 2) = 6") vuruqlardan birini 0-a bərabərləşdirmək. Bu yalnız hasil 0 olduqda olar.
Yadda saxla
Hasil = 0 ⇔ vuruqlardan biri 0 Qruplaşdır, kök tap + Horner, tam kvadrat yarat x⁴ + 4 = (x² − 2x + 2)(x² + 2x + 2) x⁴ + x² + 1 = (x² + x + 1)(x² − x + 1)
Özünü yoxla: 3 sual
  1. x³ − 7x + 6 = 0 tənliyini həll et. P(1) = 0. Horner: 1, 1, −6 | 0 → x² + x − 6 = (x + 3)(x − 2). Köklər: 1, 2, −3.
  2. x⁴ + x² + 1-i vuruqlara ayır. (x² + x + 1)(x² − x + 1).
  3. 3⁴ + 4 = 85 ədədini (n² − 2n + 2)(n² + 2n + 2) düsturu ilə vuruqlara ayır. n = 3: (9 − 6 + 2)(9 + 6 + 2) = 5 · 17 = 85.

Dərs 3. Qarşılıqlı tənliklər

1 Niyə lazımdır

6x⁴ − 35x³ + 62x² − 35x + 6 = 0 tənliyinə bax: əmsallar 6, −35, 62, −35, 6 — soldan da, sağdan da eynidir. Belə tənliklərə qarşılıqlı (simmetrik) deyilir. Onların bir xüsusiyyəti var: kökləri cüt-cüt gəlir, x və 1/x. Bu simmetriya dördüncü dərəcəni ikinci dərəcəyə endirir.

2 Əsas fikir

ax⁴ + bx³ + cx² + bx + a = 0 1) a ≠ 0 olduğundan x = 0 kök deyil → x²-na böl: a(x² + 1/x²) + b(x + 1/x) + c = 0 2) t = x + 1/x qoy. x² + 1/x² = t² − 2 3) at² + bt + (c − 2a) = 0 həll et, sonra hər t üçün x + 1/x = t.

Mühüm qayda: x + 1/x = t tənliyi x² − tx + 1 = 0 deməkdir. Onun həqiqi kökü olması üçün diskriminant t² − 4 ≥ 0, yəni |t| ≥ 2 lazımdır. |t| < 2 alınanda həqiqi kök yoxdur. (Səbəb: x > 0 üçün x + 1/x ≥ 2.)

Tək dərəcə. ax³ + bx² + bx + a = 0 kimi tənliyin kökü x = −1-dir, çünki x³ + 1 və x² + x hər ikisi x + 1-ə bölünür. Onu çıxarandan sonra qalan qarşılıqlı tənlik həll olunur.

3 Həll olunmuş nümunələr

1) 6x⁴ − 35x³ + 62x² − 35x + 6 = 0 x²-na bölək: 6(x² + 1/x²) − 35(x + 1/x) + 62 = 0 t = x + 1/x: 6(t² − 2) − 35t + 62 = 0 → 6t² − 35t + 50 = 0 D = 1225 − 1200 = 25, t = (35 ± 5)/12 → t = 10/3 və t = 5/2 t = 5/2: x + 1/x = 5/2 → 2x² − 5x + 2 = 0 → x = 2, x = 1/2 t = 10/3: 3x² − 10x + 3 = 0 → x = 3, x = 1/3 Cavab: 2, 1/2, 3, 1/3 2) 2x⁴ − 5x³ + 6x² − 5x + 2 = 0 2(t² − 2) − 5t + 6 = 0 → 2t² − 5t + 2 = 0 → t = 2 və t = 1/2 t = 2: x² − 2x + 1 = 0 → x = 1 t = 1/2: |t| < 2, həqiqi kök yoxdur. Cavab: yalnız x = 1 3) 2x³ + 3x² + 3x + 2 = 0 x = −1: −2 + 3 − 3 + 2 = 0 ✓. (x + 1)(2x² + x + 2) = 0 2x² + x + 2: D = 1 − 16 < 0. Cavab: x = −1

4 x + 1/x = t verildikdə

Olimpiadada tənliyi həll etmədən x² + 1/x², x³ + 1/x³ kimi ifadələr tələb olunur. Qayda: Sₙ = xⁿ + 1/xⁿ olarsa

S₁ = t, S₂ = t² − 2, Sₙ₊₁ = t · Sₙ − Sₙ₋₁

Bu belə çıxır: (x + 1/x)(xⁿ + 1/xⁿ) = xⁿ⁺¹ + 1/xⁿ⁺¹ + xⁿ⁻¹ + 1/xⁿ⁻¹.

Olimpiada məsələsi. x + 1/x = 3 olarsa, x⁵ + 1/x⁵ = ? Həll. S₁ = 3, S₂ = 3² − 2 = 7. S₃ = 3 · 7 − 3 = 18 S₄ = 3 · 18 − 7 = 47 S₅ = 3 · 47 − 18 = 123 Cavab: 123. Yoxlama: S₃ = t³ − 3t = 27 − 9 = 18 ✓.
Həyatdan. Simmetriya — olimpiadada ən güclü silahlardan biridir. Əmsallar güzgü kimi təkrarlanırsa, köklər də güzgü cütləri (x və 1/x) kimi gəlir. Bunu görən tənliyi yarı dərəcəyə endirir.

5 Özünü yoxla

Tipik səhvlər
  • x² + 1/x² = t² yazmaq. Düzü: t² − 2 (çünki (x + 1/x)² = x² + 2 + 1/x²).
  • Alınan t-nin həqiqi köklər verib-vermədiyini yoxlamamaq: |t| < 2 olarsa heç bir həqiqi x yoxdur.
  • Yalnız t-ləri tapıb dayanmaq. Sual x-i soruşur.
Yadda saxla
Əmsallar simmetrik → x²-na böl, t = x + 1/x x² + 1/x² = t² − 2, x³ + 1/x³ = t³ − 3t Həqiqi x üçün |t| ≥ 2 şərtdir Sₙ₊₁ = t·Sₙ − Sₙ₋₁
Özünü yoxla: 3 sual
  1. x⁴ + 3x³ − 4x² + 3x + 1 = 0 tənliyi t = x + 1/x əvəzləməsi ilə hansı tənliyə gəlir? (t² − 2) + 3t − 4 = 0, yəni t² + 3t − 6 = 0.
  2. x + 1/x = 2 olarsa, x² + 1/x² neçədir? 2² − 2 = 2. (Həqiqətən x = 1.)
  3. x + 1/x = 5 olarsa, x³ + 1/x³ neçədir? t³ − 3t = 125 − 15 = 110.

Dərs 4. Əvəzləmə üsulları

1 Niyə lazımdır

(x + 1)(x + 2)(x + 3)(x + 4) = 120 tənliyində mötərizələri açsan dördüncü dərəcəli çətin tənlik alarsan. Amma ona bir az diqqətlə baxsan, ikinci dərəcəli tənliyə gətirmək olar. Əvəzləmənin sirri: təkrarlanan ifadəni bir hərflə əvəz et.

2 Əsas fikir

1) Bikvadrat: ax⁴ + bx² + c = 0 → t = x² (t ≥ 0) 2) Təkrar ifadə: (x² + x)² − 8(x² + x) + 12 → t = x² + x 3) Ortaya gətir: (x − a)ᵏ + (x − b)ᵏ → y = x − (a + b)/2 4) Mötərizələrdən cütləri uyğunlaşdır: (x + 1)(x + 4) və (x + 2)(x + 3)

Hər əvəzləmədən sonra t üçün alınan qiymətlərdən x-i tapmağı unutma. t = x² üçün mənfi t yararsızdır.

3 Həll olunmuş nümunələr

1) x⁴ − 13x² + 36 = 0 t = x²: t² − 13t + 36 = 0 → t = 4, t = 9 Cavab: x = ±2, x = ±3 2) (x² + x)² − 8(x² + x) + 12 = 0 t = x² + x: t² − 8t + 12 = 0 → t = 2, t = 6 x² + x − 2 = 0 → x = 1, −2. x² + x − 6 = 0 → x = 2, −3. Cavab: 1, −2, 2, −3 3) (x + 1)(x + 2)(x + 3)(x + 4) = 120 Birinci ilə sonuncunu, ortadakıları cütləşdir: (x² + 5x + 4)(x² + 5x + 6) = 120 t = x² + 5x + 5: (t − 1)(t + 1) = 120 → t² = 121 → t = ±11 t = 11: x² + 5x − 6 = 0 → x = 1, x = −6 t = −11: x² + 5x + 16 = 0, D = 25 − 64 < 0 Cavab: 1, −6. Yoxla: x = 1: 2·3·4·5 = 120 ✓; x = −6: (−5)(−4)(−3)(−2) = 120 ✓ 4) (x − 1)⁴ + (x − 3)⁴ = 82 Orta: y = x − 2. (y + 1)⁴ + (y − 1)⁴ = 2y⁴ + 12y² + 2 = 82 y⁴ + 6y² − 40 = 0 → y² = 4 və ya y² = −10 (yararsız) y = ±2 → x = 4, x = 0 Yoxla: x = 0: 1 + 81 = 82 ✓

4 Olimpiada məsələsi: dörd ardıcıl vuruq

Məsələ. Sübut et ki, istənilən n natural ədədi üçün n(n + 1)(n + 2)(n + 3) + 1 tam kvadratdır. Həll. Birinci ilə sonuncunu, ikinci ilə üçüncünü cütləşdir: n(n + 3) = n² + 3n, (n + 1)(n + 2) = n² + 3n + 2. t = n² + 3n: t(t + 2) + 1 = t² + 2t + 1 = (t + 1)². Deməli n(n + 1)(n + 2)(n + 3) + 1 = (n² + 3n + 1)². ∎ Yoxla: n = 1: 1·2·3·4 + 1 = 25 = 5², n² + 3n + 1 = 5 ✓.
Həyatdan. Məsələn, 24 = 1·2·3·4 və 24 + 1 = 25 = 5². Eyni qayda 2·3·4·5 + 1 = 121 = 11², 3·4·5·6 + 1 = 361 = 19² üçün də işləyir. Əvəzləmə bu naxışı bir sətirdə sübut edir.

5 Özünü yoxla

Tipik səhvlər
  • t tapıb x-ə qayıtmamaq.
  • t = x² üçün mənfi t qiymətlərini yararlı saymaq.
  • Mötərizələri yanlış cütləşdirmək: (x + 1)(x + 2) və (x + 3)(x + 4) eyni t vermir; cütlərin cəmi eyni olmalıdır (1 + 4 = 2 + 3).
  • Ortaya gətirmədə y-in işarəsini səhv götürmək: y = x − 2 olduqda x = y + 2.
Yadda saxla
Təkrar ifadə varsa → əvəz et Cəmi eyni olan cüt vuruqları birləşdir (x − a)ᵏ + (x − b)ᵏ → y = x − (a+b)/2 Sonda x-ə qayıt; t = x² əvəzləməsində t ≥ 0, başqa əvəzləmələrdə həmin ifadənin qiymətlər çoxluğunu yoxla
Özünü yoxla: 3 sual
  1. x⁴ − 10x² + 9 = 0 tənliyini həll et. t = x²: t² − 10t + 9 = 0, t = 1, 9. x = ±1, ±3.
  2. (x² − 3x)² − 2(x² − 3x) − 8 = 0 tənliyini həll et. t = x² − 3x: t² − 2t − 8 = 0, t = 4, −2. x² − 3x − 4 = 0 → 4, −1. x² − 3x + 2 = 0 → 1, 2. Köklər: −1, 1, 2, 4.
  3. (x − 2)⁴ + (x − 4)⁴ = 2 tənliyi üçün hansı əvəzləmə yaxşıdır və cavab nədir? y = x − 3: (y + 1)⁴ + (y − 1)⁴ = 2y⁴ + 12y² + 2 = 2 → y²(y² + 6) = 0 → y = 0 → x = 3.
