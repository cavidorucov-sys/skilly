Eynilik çevirmələri, simmetrik çoxhədlilər

a + b = 5, ab = 3 verilib, a³ + b³ soruşulur. a və b-ni tapmaq çətindir (köklər irrasionaldır), amma lazım da deyil: cavab eyniliklərlə bir sətirdə çıxır. Bu mövzuda olimpiadanın sevimli "ağıllı hesablama" fəndlərini öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Simmetrik ifadələr: a + b və ab

1 Niyə lazımdır

Eynilik — dəyişənlərin bütün qiymətlərində doğru olan bərabərlikdir: (a + b)² = a² + 2ab + b². Eynilik çevirməsi — ifadəni ona eyni olan başqa şəklə salmaq. Olimpiadada ifadəni hesablamaq yox, onu düzgün şəklə salmaq vacibdir.

2 Simmetrik ifadə

a ilə b-nin yerini dəyişəndə dəyişməyən ifadə simmetrikdir: a² + b², a³b + ab³, 1/a + 1/b. a − b isə simmetrik deyil (işarəsi dəyişir).

Teorem (sübutsuz): hər simmetrik çoxhədli iki "əsas" ifadə ilə yazılır:

s = a + b, p = ab

Viyetlə əlaqə: a, b — x² − sx + p = 0 tənliyinin kökləridir. Ona görə "köklərin kvadratları cəmi" kimi suallar da buraya aiddir.

3 Əsas düsturlar

a² + b² = s² − 2p (a − b)² = s² − 4p a³ + b³ = s³ − 3ps a⁴ + b⁴ = (a² + b²)² − 2p² 1/a + 1/b = s/p a/b + b/a = (s² − 2p)/p

Haradan? (a + b)² = a² + b² + 2ab → birinci. (a + b)³ = a³ + b³ + 3a²b + 3ab² = a³ + b³ + 3ab(a + b) → üçüncü. Dördüncü: (a² + b²)² = a⁴ + b⁴ + 2a²b².

a − b verilsə: a² + b² = (a − b)² + 2ab, a³ − b³ = (a − b)³ + 3ab(a − b).

4 Həll olunmuş nümunələr

a + b = 5, ab = 3. a² + b² = 25 − 6 = 19 a³ + b³ = 125 − 3 · 3 · 5 = 125 − 45 = 80 a⁴ + b⁴ = 19² − 2 · 9 = 361 − 18 = 343 (a − b)² = 25 − 12 = 13 → |a − b| = √13 1/a + 1/b = 5/3
Olimpiada məsələsi. a + b = 1, ab = −1. a⁵ + b⁵ = ? Həll. Tₙ = aⁿ + bⁿ yaz. Eynilik: aⁿ + bⁿ = (a + b)(aⁿ⁻¹ + bⁿ⁻¹) − ab(aⁿ⁻² + bⁿ⁻²), yəni Tₙ = s · Tₙ₋₁ − p · Tₙ₋₂ = Tₙ₋₁ + Tₙ₋₂. T₀ = 2, T₁ = 1, T₂ = 1 + 2 = 3, T₃ = 3 + 1 = 4, T₄ = 4 + 3 = 7, T₅ = 7 + 4 = 11. Cavab: 11.
Həyatdan. Düzbucaqlı sahənin perimetri 34 m, sahəsi 60 m²-dir. Diaqonalın uzunluğu? Tərəfləri tapmağa ehtiyac yoxdur: a + b = 17, ab = 60, d² = a² + b² = 289 − 120 = 169, d = 13 m.
Tipik səhvlər
  • a² + b² = (a + b)² yazmaq. 2ab unudulub.
  • a³ + b³ = s³ − 3p yazmaq. Düzü: s³ − 3ps — 3ab(a + b).
  • ab mənfi olanda işarəni itirmək: s² − 2p, p = −5 → s² + 10.
Yadda saxla
s = a + b, p = ab a² + b² = s² − 2p; (a − b)² = s² − 4p a³ + b³ = s³ − 3ps aⁿ + bⁿ = s(aⁿ⁻¹ + bⁿ⁻¹) − p(aⁿ⁻² + bⁿ⁻²)
Özünü yoxla: 3 sual
  1. a + b = 4, ab = 1. a² + b² = ? 16 − 2 = 14.
  2. Eyni verilənlərlə a³ + b³ = ? 64 − 3 · 1 · 4 = 52.
  3. a + b = 3, ab = −2. 1/a + 1/b = ? 3/(−2) = −3/2.

Dərs 2. x + 1/x fəndləri

1 Niyə lazımdır

x və 1/x — xüsusi cütdür: hasilləri 1-dir. Deməli, Dərs 1-in bütün düsturları burada p = 1 ilə işləyir. Olimpiadada "x² − 7x + 1 = 0 isə, x⁴ + 1/x⁴ = ?" tipli məsələlər çox çıxır.

2 Düsturlar

x + 1/x = t: x² + 1/x² = t² − 2 x³ + 1/x³ = t³ − 3t x⁴ + 1/x⁴ = (t² − 2)² − 2 (x − 1/x)² = t² − 4 x − 1/x = u: x² + 1/x² = u² + 2 x³ − 1/x³ = u³ + 3u

Tənlikdən t-yə keçid. x² − 5x + 1 = 0. x = 0 kök deyil, ona görə x-ə bölmək olar: x − 5 + 1/x = 0 → x + 1/x = 5.

3 Həll olunmuş nümunələr

1) x² − 5x + 1 = 0. x + 1/x = 5. x² + 1/x² = 25 − 2 = 23 x⁴ + 1/x⁴ = 23² − 2 = 527 x³ + 1/x³ = 125 − 15 = 110 2) x > 0, x² + 1/x² = 7. x + 1/x = ? (x + 1/x)² = 7 + 2 = 9, x > 0 → x + 1/x = 3.

4 Qayıdış (simmetrik) tənliklər

Əmsalları iki ucdan eyni olan tənlik: x⁴ − 5x³ + 6x² − 5x + 1 = 0. x²-yə böl və t = x + 1/x qoy:

x² + 1/x² − 5(x + 1/x) + 6 = 0 (t² − 2) − 5t + 6 = 0 → t² − 5t + 4 = 0 → t = 1 və ya t = 4. t = 1: x + 1/x = 1 → x² − x + 1 = 0, D = −3 — həqiqi kök yoxdur. t = 4: x² − 4x + 1 = 0 → x = 2 ± √3. Həqiqi köklərin cəmi: 4.

5 Olimpiada məsələləri

Məsələ 1. x + 1/x = 3. x⁶ + 1/x⁶ = ? Həll. x³ + 1/x³ = 27 − 9 = 18. x⁶ + 1/x⁶ = (x³ + 1/x³)² − 2 = 324 − 2 = 322.
Məsələ 2. x/(x² + x + 1) = 1/4. x²/(x⁴ + x² + 1) = ? Həll. Tərsinə çevir: (x² + x + 1)/x = 4 → x + 1 + 1/x = 4 → x + 1/x = 3. İndi soruşulanın tərsi: (x⁴ + x² + 1)/x² = x² + 1 + 1/x² = (9 − 2) + 1 = 8. Cavab: 1/8.
Həyatdan. Bu fənd "ölçü vahidi dəyişməsi" kimidir: x və 1/x bir-birini tarazlayır (məsələn, şəkli x dəfə böyüdüb sonra x dəfə kiçiltmək). Hesabda isə qısaltma verir: dördüncü dərəcəli tənlik iki kvadrat tənliyə çevrilir.
Tipik səhvlər
  • x² + 1/x² = t² yazmaq. Kvadrata yüksəldəndə orta hədd 2 · x · 1/x = 2 çıxır.
  • x − 1/x halında −2 yazmaq. Burada orta hədd −2-dir, ona görə x² + 1/x² = u² + 2.
  • x + 1/x-i kökdən tapanda işarəni unutmaq: x > 0 verilməyibsə, ±3.
Yadda saxla
x + 1/x = t: x² + 1/x² = t² − 2; x³ + 1/x³ = t³ − 3t x − 1/x = u: x² + 1/x² = u² + 2 ax² + bx + a = 0 → x-ə böl qayıdış tənlik → x²-yə böl, t = x + 1/x
Özünü yoxla: 3 sual
  1. x + 1/x = 4. x² + 1/x² = ? 16 − 2 = 14.
  2. Eyni şərtlə x³ + 1/x³ = ? 64 − 12 = 52.
  3. x − 1/x = 2. x² + 1/x² = ? 4 + 2 = 6.

Dərs 3. Üç dəyişən və a³ + b³ + c³ − 3abc

1 Niyə lazımdır

Üç dəyişəndə də eyni fikir işləyir: simmetrik ifadəni üç "əsas" ifadə ilə yazırıq. Ən məşhur eynilik — a³ + b³ + c³ − 3abc-nin vuruqlara ayrılması — olimpiadada həm hesabda, həm sübutda çıxır.

2 Əsas simmetrik ifadələr

σ₁ = a + b + c σ₂ = ab + bc + ca σ₃ = abc a² + b² + c² = σ₁² − 2σ₂ 1/a + 1/b + 1/c = σ₂/σ₃

Birincisi (a + b + c)² = a² + b² + c² + 2(ab + bc + ca)-dan çıxır. İkincisi — ortaq məxrəc abc.

3 Məşhur eynilik

a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)

Sübutun eskizi. s = a + b yaz: a³ + b³ = s³ − 3abs. Onda sol tərəf = s³ + c³ − 3ab(s + c). s³ + c³ = (s + c)(s² − sc + c²), ona görə (s + c) mötərizə xaricinə çıxır: (s + c)(s² − sc + c² − 3ab). s = a + b-ni yerinə qoy və aç — ikinci mötərizə a² + b² + c² − ab − bc − ca olur.

a² + b² + c² − ab − bc − ca = ½((a − b)² + (b − c)² + (c − a)²) ≥ 0

İki mühüm nəticə:

1) a + b + c = 0 ⇒ a³ + b³ + c³ = 3abc. 2) a, b, c > 0 və a³ + b³ + c³ = 3abc ⇒ a = b = c (ikinci mötərizə 0 olmalıdır — kvadratlar cəmi 0). Ümumi şəkil: a³ + b³ + c³ = σ₁³ − 3σ₁σ₂ + 3σ₃.

4 Həll olunmuş nümunələr

a + b + c = 6, ab + bc + ca = 11, abc = 6. a² + b² + c² = 36 − 22 = 14 a³ + b³ + c³ = 216 − 3 · 6 · 11 + 3 · 6 = 216 − 198 + 18 = 36 1/a + 1/b + 1/c = 11/6 (Yoxla: bunlar 1, 2, 3 ədədləridir: 1 + 8 + 27 = 36 ✓)
Olimpiada məsələsi 1. 17³ − 12³ − 5³ = ? Həll. a = 17, b = −12, c = −5: a + b + c = 0. Deməli a³ + b³ + c³ = 3abc = 3 · 17 · (−12) · (−5) = 3060.
Olimpiada məsələsi 2. a + b + c = 0, abc ≠ 0. (a² + b² + c²)² / (a⁴ + b⁴ + c⁴) = ? Həll. σ₁ = 0 → a² + b² + c² = −2σ₂. a²b² + b²c² + c²a² = σ₂² − 2abc(a + b + c) = σ₂². a⁴ + b⁴ + c⁴ = (a² + b² + c²)² − 2(a²b² + b²c² + c²a²) = 4σ₂² − 2σ₂² = 2σ₂². Cavab: 4σ₂² / 2σ₂² = 2.
Həyatdan. Düzbucaqlı qutunun (paralelepipedin) bütün tillərinin cəmi 4(a + b + c), tam səthi 2(ab + bc + ca)-dır. Bu iki ölçüdən diaqonal çıxır: d² = a² + b² + c² = σ₁² − 2σ₂. Tillər 48 sm, səth 94 sm² olsa: σ₁ = 12, σ₂ = 47, d² = 144 − 94 = 50, d = 5√2 sm.
Tipik səhvlər
  • a³ + b³ + c³ = (a + b + c)³ yazmaq — çox sayda hədd unudulur.
  • a + b + c = 0 olanda a³ + b³ + c³ = 0 demək. Düzü: 3abc.
  • a² + b² + c² = σ₁² − σ₂ yazmaq: 2 vuruğu itir.
Yadda saxla
a² + b² + c² = σ₁² − 2σ₂; 1/a + 1/b + 1/c = σ₂/σ₃ a³ + b³ + c³ − 3abc = σ₁ · (a² + b² + c² − σ₂) a + b + c = 0 ⇒ a³ + b³ + c³ = 3abc a³ + b³ + c³ = σ₁³ − 3σ₁σ₂ + 3σ₃
Özünü yoxla: 3 sual
  1. a + b + c = 5, ab + bc + ca = 7. a² + b² + c² = ? 25 − 14 = 11.
  2. a + b + c = 0, abc = 4. a³ + b³ + c³ = ? 3 · 4 = 12.
  3. ab + bc + ca = 3, abc = −6. 1/a + 1/b + 1/c = ? 3/(−6) = −1/2.

Dərs 4. Ağıllı hesablamalar

1 Niyə lazımdır

Olimpiadada kalkulyator yoxdur, ədədlər isə qəsdən böyük seçilir: √(2024 · 2025 · 2026 · 2027 + 1). Birbaşa hesablamaq — tələdir. Eyniliyi görən bir dəqiqədə həll edir.

2 Kvadratlar fərqi və kublar

a² − b² = (a − b)(a + b) a³ + b³ = (a + b)(a² − ab + b²) a³ − b³ = (a − b)(a² + ab + b²)
2027² − 2023² = 4 · 4050 = 16200 1003 · 997 = (1000 + 3)(1000 − 3) = 1000000 − 9 = 999991 (37³ + 63³)/(37² − 37 · 63 + 63²) = 37 + 63 = 100

3 Zəncirlər və teleskop

1) (2 + 1)(2² + 1)(2⁴ + 1)(2⁸ + 1) = ? Əvvəlinə (2 − 1) = 1 vuruğunu yaz: (2 − 1)(2 + 1) = 2² − 1; (2² − 1)(2² + 1) = 2⁴ − 1; … Cavab: 2¹⁶ − 1 = 65535. 2) 1/(1 · 2) + 1/(2 · 3) + … + 1/(99 · 100) = ? 1/(k(k + 1)) = 1/k − 1/(k + 1) — qonşu hədlər silinir ("teleskop" kimi qatlanır): 1 − 1/2 + 1/2 − 1/3 + … − 1/100 = 1 − 1/100 = 99/100.

4 Olimpiada məsələləri

Məsələ 1. √(2024 · 2025 · 2026 · 2027 + 1) = ? Həll. n = 2024. Kənar və orta vuruqları cütlə: n(n + 3) = n² + 3n = m, (n + 1)(n + 2) = n² + 3n + 2 = m + 2. m(m + 2) + 1 = m² + 2m + 1 = (m + 1)². Kök = m + 1 = n² + 3n + 1 = 4096576 + 6072 + 1 = 4102649.
Məsələ 2. Sübut et ki, n > 1 olanda n⁴ + 4 mürəkkəb ədəddir. Həll (Sofi Jermen eyniliyi). Tam kvadrata tamamla: n⁴ + 4 = (n² + 2)² − 4n² = (n² − 2n + 2)(n² + 2n + 2). n > 1 olanda n² − 2n + 2 = (n − 1)² + 1 > 1, ikinci vuruq ondan da böyükdür — ədəd iki vuruğa ayrılır. Məs.: 5⁴ + 4 = 629 = 17 · 37.
Həyatdan. Ağızdan hesab: 48 · 52 = 50² − 2² = 2496, 99² = (100 − 1)² = 9801. Bazarda, imtahanda, olimpiadada eyni fənd işləyir — ədədi "yuvarlaq ədəd ± kiçik" şəklində gör.
Tipik səhvlər
  • Böyük ədədləri birbaşa vurmağa başlamaq. Əvvəl quruluşa bax: kvadratlar fərqi? Ardıcıl ədədlər? Kublar?
  • Teleskop cəmində son həddi səhv yazmaq: 1/(99 · 100) → son həd 1/100, cavab 99/100.
  • a³ + b³-də ikinci mötərizəni a² + ab + b² yazmaq. Cəm üçün ortada mənfi işarə: a² − ab + b².
Yadda saxla
a² − b² = (a − b)(a + b); (N + k)(N − k) = N² − k² n(n + 1)(n + 2)(n + 3) + 1 = (n² + 3n + 1)² (a − 1)(a + 1)(a² + 1)… → zəncir 1/(k(k + 1)) = 1/k − 1/(k + 1) n⁴ + 4 = (n² − 2n + 2)(n² + 2n + 2)
Özünü yoxla: 3 sual
  1. 101 · 99 = ? 100² − 1 = 9999.
  2. 2026² − 2025² = ? 1 · 4051 = 4051.
  3. 1/(1 · 3) + 1/(3 · 5) + … + 1/(9 · 11) = ? ½ · (1 − 1/11) = ½ · 10/11 = 5/11.
