Cəbri ifadələr, sadələşdirmə

Hərfli ifadələr — 3x² − 5x + 2, 4(3x − 2) − 6(2x − 1) — cəbrin əlifbasıdır. Burada ifadənin qiymətini tapmağı, oxşar hədləri birləşdirməyi və mötərizələri açmağı öyrənəcəksən. Sonra tənliklər, çoxhədlilər, düsturlar — hamısı bu bacarıqlar üzərində qurulur.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Dəyişəni olan ifadənin qiyməti

1 Niyə lazımdır

Taksi minmə üçün 2 manat, hər kilometr üçün 0,7 manat alır. x km yolun qiyməti: 2 + 0,7x. Bu bir ifadədir. 10 km getsən, x-in yerinə 10 qoyursan: 2 + 0,7·10 = 9 manat. Bir ifadə — istənilən məsafə üçün hazır cavab.

2 Əsas fikir

Dəyişəni olan ifadə — ədədlərdən, hərflərdən (dəyişənlərdən) və əməl işarələrindən düzəlir. Dəyişənin yerinə ədəd qoyub hesabladıqda alınan ədəd — ifadənin qiymətidir.

1. Dəyişənin yerinə ədədi qoy. Mənfi ədədi MÖTƏRİZƏYƏ al: x = −3 → (−3) 2. Əməllər sırası: mötərizə → qüvvət → vurma/bölmə → toplama/çıxma

Yadda saxla: (−3)² = 9, amma −3² = −9 (əvvəl qüvvət, sonra minus).

3 Həll olunmuş nümunələr

1) 3x² − 5x + 2, x = −2 3·(−2)² − 5·(−2) + 2 = 3·4 + 10 + 2 = 24 2) 2a² − 3ab + b, a = −1, b = 4 2·(−1)² − 3·(−1)·4 + 4 = 2 + 12 + 4 = 18 3) −x² + 4x, x = −3 −(−3)² + 4·(−3) = −9 − 12 = −21
Həyatdan. Hərarətin Selsidən Farengeytə çevrilməsi: F = 1,8C + 32. Bakıda C = 25: F = 1,8·25 + 32 = 77. Qışda C = −5: F = 1,8·(−5) + 32 = 23. Bir ifadə, iki qiymət.
Tipik səhvlər
  • Mənfi ədədi mötərizəsiz qoymaq: x = −3 olanda x² yerinə −3² yazmaq. Düzü: (−3)² = 9.
  • −x²-də minusu "udmaq": x = −3 olanda −x² = −9, 9 yox.
  • Əməllər sırasını pozmaq: 2 + 3·4 = 14, 20 yox.
Yadda saxla
Dəyişən → ədəd (mənfisi mötərizədə). Sıra: mötərizə, qüvvət, vurma/bölmə, toplama/çıxma. (−a)² = a², −a² = −(a²).
Özünü yoxla: 3 sual
  1. x² − 4x, x = −3. (−3)² − 4·(−3) = 9 + 12 = 21.
  2. −a², a = −5. −(−5)² = −25.
  3. 2(a − b)², a = 7, b = 4. 2·(7 − 4)² = 2·9 = 18.

Dərs 2. Birhədli və oxşar hədlər

1 Niyə lazımdır

Səbətdə 3 alma və 2 armud var, sonra 4 alma da qoydun. Neçə alma? 7. Bəs "9 meyvə-alma-armud"? Belə demirik: almalar almalarla, armudlar armudlarla toplanır. Cəbrdə də belədir: 3a + 2p + 4a = 7a + 2p.

2 Birhədli

Birhədli — ədədlərin, dəyişənlərin və onların (üstləri mənfi olmayan tam ədəd olan) qüvvətlərinin hasilidir: 5x², −3ab, 7, x. Standart şəkil: əvvəldə bir ədəd (əmsal), sonra hər dəyişən bir dəfə, öz üstü ilə.

3x²y · (−2xy³) = 3·(−2) · x²·x · y·y³ = −6x³y⁴ Əmsal: −6. Dərəcə: 3 + 4 = 7

Dərəcə — bütün dəyişənlərin üstlərinin cəmi. Vuranda əmsallar vurulur, üstlər toplanır. Qüvvətə yüksəldəndə əmsal qüvvətə yüksəlir, üstlər vurulur: (−2x³y)² = 4x⁶y².

3 Oxşar hədlər

Oxşar hədlər — hərf hissəsi tam eyni olan hədlər: 5x² və −x² oxşardır; x² və x oxşar deyil. Oxşar hədləri birləşdirmək (islah etmək) — əmsallarını toplamaq, hərf hissəsini saxlamaqdır.

5x − 3x + x = (5 − 3 + 1)x = 3x

4 Həll olunmuş nümunələr

1) 7a − 3b + 2a + 5b − a a-lar: 7a + 2a − a = 8a b-lər: −3b + 5b = 2b Cavab: 8a + 2b 2) 4x² − 3x + 5 − x² + 7x − 8 x²: 4x² − x² = 3x² x: −3x + 7x = 4x ədəd: 5 − 8 = −3 Cavab: 3x² + 4x − 3 3) (−3a²b)³ = (−3)³·a⁶b³ = −27a⁶b³ Dərəcə: 6 + 3 = 9
Həyatdan. Kassa hesabı: səhər 5 qələm və 3 dəftər satıldı, axşam 2 qələm və 4 dəftər. Qələm q, dəftər d manatdırsa, gəlir: 5q + 3d + 2q + 4d = 7q + 7d. Qələmlərin pulu dəftərlərin pulu ilə qarışmır.
Tipik səhvlər
  • Fərqli hədləri birləşdirmək: 3x + 2y ≠ 5xy, x² + x ≠ x³.
  • −x-in əmsalını 0 və ya 1 saymaq. Əmsal −1-dir.
  • Vurmada üstləri vurmaq: x²·x³ = x⁵, x⁶ yox.
  • Toplamada üstləri toplamaq: x² + x² = 2x², x⁴ yox.
Yadda saxla
Vurma: əmsallar vurulur, üstlər toplanır. Dərəcə = üstlərin cəmi. Oxşar hədlər: hərf hissəsi eyni → əmsallar toplanır.
Özünü yoxla: 3 sual
  1. 5ab − 2a + 3ab + a sadələşdir. 8ab − a.
  2. −4x³y² birhədlisinin dərəcəsi? 3 + 2 = 5.
  3. 2x · 3x = ? 6x² (6x yox).

Dərs 3. Mötərizələrin açılması və sadələşdirmə

1 Niyə lazımdır

4(3x − 2) − 6(2x − 1) ifadəsinin x = 1,37 olanda qiyməti nədir? Birbaşa hesablasan — uzun və səhvə açıq. Mötərizələri açsan — x tamamilə silinir və cavab bir sətirdə çıxır. Sadələşdirmə vaxt qazandırır.

2 Qaydalar

a(b + c) = ab + ac (paylama qanunu) +(a − b + c) = a − b + c (işarələr qalır) −(a − b + c) = −a + b − c (HƏR işarə dəyişir) −k(a − b) = −ka + kb

Mötərizənin qarşısındakı ədəd (işarəsi ilə birlikdə) hər həddə vurulur. Sonra oxşar hədləri birləşdir.

3 Həll olunmuş nümunələr

1) 3(2x − 5) − 4(x − 2) = 6x − 15 − 4x + 8 = 2x − 7 2) x(x + 3) − (x² − 2x + 5), x = 2026 = x² + 3x − x² + 2x − 5 = 5x − 5 x = 2026: 5·2026 − 5 = 10125 3) 4(3x − 2) − 6(2x − 1), x = 1,37 = 12x − 8 − 12x + 6 = −2 (x silindi — qiymət x-dən asılı deyil)
Həyatdan. Böyük bileti x manat, uşaq bileti ondan 2 manat ucuzdur. 2 böyük və 3 uşaq bileti: 2x + 3(x − 2) = 5x − 6. x = 8 olanda: 40 − 6 = 34 manat. Yoxla: 2·8 + 3·6 = 16 + 18 = 34 ✓.
Tipik səhvlər
  • −(x − 5) = −x − 5. Səhvdir! İkinci hədd də işarəsini dəyişir: −x + 5.
  • Ədədi yalnız birinci həddə vurmaq: 3(x + 4) = 3x + 4. Düzü: 3x + 12.
  • −2(3 − x)-də mənfi vurub mənfi almaq: düzü −6 + 2x.
Yadda saxla
Qarşıdakı ədəd hər həddə vurulur. "−" qarşısında: içindəki bütün işarələr dəyişir. Hesablamaq üçün əlverişsiz qiymət verilib? Əvvəl sadələşdir, sonra qoy.
Özünü yoxla: 3 sual
  1. −(2a − 7 + b) aç. −2a + 7 − b.
  2. 5(x − 1) − 2(2x − 3) sadələşdir. 5x − 5 − 4x + 6 = x + 1.
  3. 2(3a + b) − 3(2a − b), a = 99, b = 2. 6a + 2b − 6a + 3b = 5b = 10.

Dərs 4. Məsələdən ifadəyə

1 Niyə lazımdır

İmtahanda məsələ çox vaxt sözlə verilir: "uzunluğu enindən 5 sm çox", "atası ondan 3 dəfə böyük". Bunu hərfli ifadəyə çevirə bilsən, qalanı — Dərs 1–3-dəki texnikadır.

2 Sözdən işarəyə

"x-dən 5 çox" → x + 5 "x-dən 3 az" → x − 3 "x-dən 4 dəfə çox" → 4x "x-in yarısı" → x/2 "ardıcıl üç ədəd" → n, n + 1, n + 2

Plan: 1) naməlumu hərflə işarə et; 2) qalan kəmiyyətləri onunla ifadə et; 3) ifadəni qur və sadələşdir; 4) lazım olsa, ədədi qoy.

3 Həll olunmuş nümunələr

1) Düzbucaqlının tərəfləri (x + 5) sm və (2x − 3) sm. Perimetr, x = 7? P = 2((x + 5) + (2x − 3)) = 2(3x + 2) = 6x + 4 x = 7: 6·7 + 4 = 46 sm Yoxla: 12 + 11 = 23, 2·23 = 46 ✓ 2) Fikrət x yaşındadır, atası 3 dəfə böyükdür. 5 il sonra yaşlarının cəmi, x = 14? (x + 5) + (3x + 5) = 4x + 10 x = 14: 56 + 10 = 66 3) Ardıcıl üç natural ədədin cəmi: n + (n + 1) + (n + 2) = 3n + 3 = 3(n + 1) Deməli cəm həmişə 3-ə bölünür.

Perimetr — dörd tərəfin cəmi: iki dəfə x + 5, iki dəfə 2x − 3. Sadələşdir: 6x + 4.

Həyatdan. Telefon tarifi: ayda 5 manat abunə + hər GB internet 1,5 manat. x GB üçün: 5 + 1,5x. İki ay, birində x, digərində x + 2 GB: (5 + 1,5x) + (5 + 1,5(x + 2)) = 3x + 13. x = 4 olanda — 25 manat.
Tipik səhvlər
  • "Ondan 3 dəfə böyük" yerinə x + 3 yazmaq. "Dəfə" — vurmadır: 3x.
  • Perimetrdə yalnız iki tərəfi toplamaq. Düzbucaqlının dörd tərəfi var: 2(a + b).
  • "5 il sonra" yalnız birinin yaşına əlavə etmək. Hər kəs 5 il böyüyür.
Yadda saxla
Naməlum → hərf. Qalanlar → onunla ifadə. İfadəni qur → sadələşdir → ədədi qoy. Cavabı mətnlə yoxla.
Özünü yoxla: 3 sual
  1. Kvadratın tərəfi (x + 2) sm. Perimetri? 4(x + 2) = 4x + 8.
  2. Qələm x manat, dəftər ondan 1 manat bahadır. 3 qələm və 2 dəftər? 3x + 2(x + 1) = 5x + 2.
  3. Ardıcıl iki cüt ədədin cəmi, kiçiyi 2n? 2n + (2n + 2) = 4n + 2.
