Kvadrat kök, hesabi kökün xassələri

Kvadratın sahəsi 49 m²-dirsə, tərəfi 7 m-dir: √49 = 7. Bəs sahə 50 m² olsa? Cavab √50 = 5√2. Bu mövzuda kökləri hesablamağı, sadələşdirməyi, vuruğu kök altından çıxarmağı və məxrəci kökdən azad etməyi öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Kvadrat kök və hesabi kvadrat kök

1 Niyə lazımdır

Kvadrat formalı xalçanın sahəsi 9 m²-dir. Tərəfi? Elə ədəd lazımdır ki, öz-özünə vurulanda 9 versin: 3. Bu, kvadratlaşdırmanın tərs əməlidir — kvadrat kök.

2 Tərif

a-nın kvadrat kökü — kvadratı a olan ədəddir. 49-un iki kvadrat kökü var: 7 və −7, çünki 7² = (−7)² = 49.

Hesabi kvadrat kök √a — kvadratı a olan mənfi olmayan ədəddir. Yəni √49 = 7, −7 yox.

√a = b ⇔ b ≥ 0 və b² = a √a yalnız a ≥ 0 olanda var (√a)² = a

3 Ən vacib eynilik: √(a²) = |a|

√((−6)²) = √36 = 6, −6 yox. Kök altından həmişə mənfi olmayan ədəd çıxır. Ona görə:

√(a²) = |a| a ≥ 0 olanda: a; a < 0 olanda: −a
1) √0,49 = 0,7 (0,7² = 0,49) 2) √(1 9/16) = √(25/16) = 5/4 3) √((−6)²) = |−6| = 6 4) √((3 − √10)²) = |3 − √10| 3 = √9 < √10, deməli 3 − √10 mənfidir = √10 − 3 5) √(−9) — mənası yoxdur (kvadratı mənfi olan ədəd yoxdur)

Tərəf uzunluqdur, mənfi ola bilməz. Ona görə kvadratın tərəfi hesabi kökdür: a = √S.

Həyatdan. Daş h metr hündürlükdən düşəndə h = 5t² (g = 10 m/s²), yəni t = √(h/5). 45 m hündürlükdən: t = √9 = 3 s. 80 m-dən: √16 = 4 s.
Tipik səhvlər
  • √16 = ±4 yazmaq. Hesabi kök birdir: √16 = 4.
  • √((−5)²) = −5 yazmaq. Düzü: |−5| = 5.
  • √0,4 = 0,2 demək. Yoxla: 0,2² = 0,04. Düzü: √0,04 = 0,2.
Yadda saxla
√a ≥ 0, a ≥ 0, (√a)² = a √(a²) = |a| Yoxlama: cavabı kvadrata yüksəlt.
Özünü yoxla: 3 sual
  1. √0,09 = ? 0,3 (0,3² = 0,09).
  2. √((−11)²) = ? |−11| = 11.
  3. √((2 − √5)²) = ? 2 = √4 < √5, ona görə |2 − √5| = √5 − 2.

Dərs 2. Hesabi kvadrat kökün xassələri

1 Niyə lazımdır

√8 də, √18 də "pis" ədədlərdir. Amma √8·√18 = √144 = 12 — tam ədəd! Xassələr kökləri birləşdirib tam kvadrat yaratmağa imkan verir.

2 Xassələr

√(ab) = √a·√b (a ≥ 0, b ≥ 0) √(a/b) = √a/√b (a ≥ 0, b > 0) √(a²ⁿ) = |aⁿ|, məs. √(a⁴) = a²

Soldan sağa: hasilin kökü — köklərin hasili. Sağdan sola: köklərin hasili — hasilin kökü. Hər iki istiqamət lazımdır.

3 Həll olunmuş nümunələr

1) √(16·81) = √16·√81 = 4·9 = 36 2) √8·√18 = √(8·18) = √144 = 12 3) √75/√3 = √(75/3) = √25 = 5 4) √(2⁴·3²) = 2²·3 = 12 5) √(17² − 8²) = √((17 − 8)(17 + 8)) = √(9·25) = 3·5 = 15
Həyatdan. Televizor ekranının eni 48 sm, hündürlüyü 20 sm-dir. Diaqonal: √(48² + 20²) = √(2304 + 400) = √2704 = 52 sm. Böyük ədədləri hesablamamaq üçün: √(4²·(12² + 5²)) = 4·√169 = 4·13 = 52.
Tipik səhvlər
  • √(a + b) = √a + √b yazmaq. Yoxla: √(9 + 16) = √25 = 5, amma 3 + 4 = 7. Cəmin kökü belə açılmır!
  • √(17² − 8²) = 17 − 8 = 9 demək. Əvvəl hesabla: 289 − 64 = 225, kök 15.
  • Mənfi ədədlərlə √(ab) = √a·√b yazmaq: √((−4)(−9))-u √(−4)·√(−9) kimi yazmaq olmaz.
Yadda saxla
√(ab) = √a·√b, √(a/b) = √a/√b Hasil və nisbət — bəli. Cəm və fərq — YOX. √(c² − a²) = √((c − a)(c + a))
Özünü yoxla: 3 sual
  1. √(25·0,04) = ? 5·0,2 = 1.
  2. √2·√32 = ? √64 = 8.
  3. √(10² − 6²) = ? √(4·16) = √64 = 8.

Dərs 3. Vuruğun kök işarəsi altından çıxarılması və altına salınması

1 Niyə lazımdır

Testdə cavab variantları belə olur: 5√2, 6√2, 4√3. Sən isə √72 almısan. Hansıdır? Kök altındakı ədədi "sadələşdirməyi" bacarmasan, cavabı tanımayacaqsan.

2 Qayda

Çıxarmaq: √(a²b) = a√b (a ≥ 0, b ≥ 0) Salmaq: a√b = √(a²b) (a ≥ 0)

Çıxaranda: kök altındakı ədəddən ən böyük tam kvadratı ayır (4, 9, 16, 25, 36, 49, 64, 81, 100, …).

1) √72 = √(36·2) = 6√2 2) √300 = √(100·3) = 10√3 3) √48 = √(16·3) = 4√3 (√(4·12) = 2√12 — hələ bitməyib!) 4) 3√5 = √(9·5) = √45 5) −2√3 = −√12 (mənfi kök xaricində qalır)

3 Müqayisə və bənzər köklər

Müqayisə et: 3√5 və 4√3 3√5 = √45, 4√3 = √48 45 < 48 → 4√3 böyükdür
Bənzər köklər (eyni kök altı) toplanır, adi hədlər kimi: √50 + √18 − √8 = 5√2 + 3√2 − 2√2 = 6√2 2√3 + 3√2 — bənzər deyil, toplanmır

Sahəsi 50 m² olan kvadrat otağın tərəfi: √50 = 5√2 ≈ 5·1,414 ≈ 7,07 m.

Həyatdan. Kvadrat otağa döşəmə alırsan: sahə 50 m². Divar boyu plintus üçün tərəf lazımdır: 5√2 ≈ 7,07 m, perimetr 20√2 ≈ 28,3 m. √50-ni kalkulyatorsuz qiymətləndirmək üçün 5√2 forması daha rahatdır.
Tipik səhvlər
  • √72 = 36√2 yazmaq — 36-nın kökünü almağı unutmaq. Düzü: 6√2.
  • √2 + √3 = √5 yazmaq. Bənzər olmayan köklər toplanmır.
  • Ən böyük kvadratı ayırmamaq: √48 = 2√12 — hələ √12 = 2√3 qalıb.
Yadda saxla
√(a²b) = a√b — ən böyük tam kvadratı ayır. a√b = √(a²b) — müqayisə üçün kök altına sal. Yalnız bənzər köklər toplanır.
Özünü yoxla: 3 sual
  1. √48 sadələşdir. √(16·3) = 4√3.
  2. 5√2 ifadəsini kök altına sal. √(25·2) = √50.
  3. √12 + √27 = ? 2√3 + 3√3 = 5√3.

Dərs 4. Kvadrat köklər daxil olan ifadələrin çevrilməsi

1 Niyə lazımdır

Köklərlə də mötərizə açılır, müxtəsər vurma düsturları işləyir. Məqsəd adətən köklərdən qurtulmaq: (√7 − √2)(√7 + √2) = 5 — kök yox oldu. Bu hiylə ilə məxrəcdəki kökü də aradan qaldırırıq.

2 Düsturlar köklərlə

(√a)² = a (√a − √b)(√a + √b) = a − b (√a ± √b)² = a ± 2√(ab) + b
1) (√3 + √12)² = (√3 + 2√3)² = (3√3)² = 9·3 = 27 2) (√7 − √2)(√7 + √2) = 7 − 2 = 5 3) (3 − √2)² = 9 − 6√2 + 2 = 11 − 6√2 4) √3·(√12 + √27) = √36 + √81 = 6 + 9 = 15

3 Məxrəcin irrasionallıqdan azad edilməsi

Məxrəcdə kök varsa, kəsri elə ifadəyə vururuq ki, məxrəcdə kök itsin:

k/√a = k√a/a (a > 0) k/(√a − √b) = k(√a + √b)/(a − b) (a, b ≥ 0, a ≠ b) k/(√a + √b) = k(√a − √b)/(a − b) (a, b ≥ 0, a ≠ b)

√a + √b və √a − √b — qoşma ifadələrdir: hasilləri köksüzdür. Vurmazdan əvvəl yoxla: vurduğun ifadə sıfır deyil (a ≠ b). a = b > 0 olduqda ayrıca: k/(√a + √a) = k/(2√a).

5) 6/√3 = 6√3/(√3·√3) = 6√3/3 = 2√3 6) 8/(√7 − √3) = 8(√7 + √3)/(7 − 3) = 2(√7 + √3) = 2√7 + 2√3 7) 1/(√5 − 2) = (√5 + 2)/((√5)² − 2²) = (√5 + 2)/1 = √5 + 2
Həyatdan. Kalkulyatorsuz 1/√2 hesablamaq çətindir: 1-i 1,414-ə bölmək. Amma 1/√2 = √2/2 ≈ 1,414/2 = 0,707 — iki dəqiqəlik bölmə bir saniyəlik işə çevrildi. Mühəndislər də ona görə məxrəci kökdən azad edirlər.
Tipik səhvlər
  • √3·√3 = 9 yazmaq. Düzü: √3·√3 = 3, ona görə 6/√3 = 6√3/3.
  • (√a + √b)² = a + b yazmaq — orta həddi 2√(ab) unutmaq.
  • Qoşmanı səhv seçmək: √5 − 2 üçün qoşma √5 + 2-dir, və surət də vurulur.
Yadda saxla
(√a − √b)(√a + √b) = a − b k/√a (a > 0) → surət və məxrəci √a-ya vur k/(√a ± √b) → qoşmaya (√a ∓ √b) vur (a, b ≥ 0, a ≠ b)
