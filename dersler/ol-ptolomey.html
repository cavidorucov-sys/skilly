Çevrəyə daxil çəkilmiş dördbucaqlı, Ptolomey teoremi

Dörd nöqtə bir çevrə üzərində olanda onların arasında sərt əlaqələr yaranır: qarşı bucaqların cəmi 180°-dir, tərəflər və diaqonallar isə Ptolomey teoremi ilə bağlanır: AC · BD = AB · CD + BC · AD. Bu mövzuda həm bucaq əlamətlərini, həm teoremin sübutunu, həm də onun olimpiada tətbiqlərini öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Daxilə çəkilmiş dördbucaqlı: xassələr və əlamətlər

1 Niyə lazımdır

Dairəvi meydançanın kənarında dörd işarə var. Üçünün arasındakı bucaqları ölçüb dördüncüdəki bucağı hesablamaq, ya da dörd nöqtənin bir çevrə üzərində olduğunu bucaqlara baxaraq yoxlamaq lazımdır. Olimpiadada "dörd nöqtə bir çevrədədir" demək bir çox məsələni bir addıma gətirir.

2 Qarşı bucaqlar

Dördbucaqlının dörd təpəsi çevrə üzərindədir: ona çevrəyə daxil çəkilmiş dördbucaqlı deyirlər.

Qarşı bucaqlar A və C (həmçinin B və D) üçün cəm 180°-dir.

∠A + ∠C = 180°, ∠B + ∠D = 180°

Niyə? ∠A daxilə çəkilmiş bucaqdır, o BCD qövsünün yarısıdır. ∠C isə DAB qövsünün yarısıdır. Bu iki qövs birlikdə bütöv çevrədir, yəni 360°. Onda ∠A + ∠C = (360°) : 2 = 180°.

3 Xarici bucaq və eyni qövs

BC tərəfini C-dən o yana K nöqtəsinə qədər uzadaq. ∠BCD + ∠DCK = 180° (qonşu bucaqlar), ∠BCD + ∠A = 180° (qarşı bucaqlar). Deməli xarici bucaq daxili qarşı bucağa bərabərdir: ∠DCK = ∠A.

Eyni BC qövsünə söykənən daxilə çəkilmiş bucaqlar bərabərdir (təpələri qövsün eyni tərəfindədirsə): ∠BAC = ∠BDC. Başqa sözlə, A və D nöqtələrindən BC parçası eyni bucaq altında görünür.

4 Tərs teorem: çevrə çəkmək olar?

Bu xassələrin hər biri həm də əlamətdir. Aşağıdakılardan biri ödənərsə, dörd nöqtə bir çevrə üzərindədir:

1) ∠A + ∠C = 180° 2) A və D nöqtələri BC-nin eyni tərəfindədir və ∠BAC = ∠BDC 3) xarici bucaq daxili qarşı bucağa bərabərdir 4) diaqonallar E-də kəsişir və AE · EC = BE · ED

Niyə? (1) üçün ABD üçbucağının çevrəsini çək. C nöqtəsi çevrənin daxilində olsa, BD parçası C-dən daha böyük bucaq altında, xaricində olsa daha kiçik bucaq altında görünür. Yalnız C çevrənin üzərində olanda ∠C = 180° − ∠A alınır. (4) üçün: AE · EC = BE · ED bərabərliyindən AE / ED = BE / EC; AEB və DEC üçbucaqlarında E bucaqları qarşılıqlıdır, deməli onlar oxşardır, ∠BAC = ∠BDC — bu isə (2)-dir.

Xüsusi hallar: çevrəyə daxil çəkilmiş paraleloqram düzbucaqlıdır (∠A = ∠C və cəmləri 180°). Çevrəyə daxil çəkilmiş trapesiya bərabəryanlıdır.

5 Həll olunmuş nümunələr

Nümunə 1. ABCD çevrəyə daxil çəkilib, ∠A = (3x + 10)°, ∠C = (2x + 50)°. ∠A = ? ∠A + ∠C = 180: 3x + 10 + 2x + 50 = 180 → 5x = 120 → x = 24 ∠A = 3 · 24 + 10 = 82° (yoxla: ∠C = 98°, cəmi 180°)
Nümunə 2. Daxilə çəkilmiş ABCD-də ∠A : ∠B : ∠C = 2 : 3 : 4. ∠D = ? ∠A + ∠C = 180° → (2 + 4) = 6 hissə = 180°, bir hissə = 30° ∠B = 3 · 30° = 90° ∠D = 180° − ∠B = 90°
Nümunə 3. Çevrəyə daxil çəkilmiş paraleloqramın bucaqları? Paraleloqramda qarşı bucaqlar bərabərdir: ∠A = ∠C. Daxilə çəkilmişdə ∠A + ∠C = 180°. Onda 2∠A = 180°, ∠A = 90°. Paraleloqram düzbucaqlıdır.
Nümunə 4. ABCD çevrəyə daxil çəkilib, ∠BAC = 35°. ∠BDC = ? İkisi də eyni BC qövsünə söykənir, A və D qövsün eyni tərəfindədir: ∠BDC = 35°.
Həyatdan. Dörd ağac dairəvi bağın kənarında ardıcıl A, B, C, D nöqtələrindədir. A-dan B və D ağaclarına baxanda bucaq 72°-dirsə, qarşı C nöqtəsindən həmin iki ağaca baxanda bucaq 108°-dir.

6 Özünü yoxla

Tipik səhvlər
  • Qonşu bucaqların cəmini 180° saymaq. 180° yalnız qarşı bucaqlar üçündür.
  • Eyni qövsə söykənən bucaqları "bərabərdir" demək, amma təpələr qövsün əks tərəflərindədir: onda cəmləri 180°-dir.
  • Bütün dördbucaqlıya çevrə çəkmək olar sanmaq. Məsələn, bucaqları 60° və 120° olan rombun qarşı bucaqları bərabərdir (60° + 60° = 120° ≠ 180°), ona çevrə çəkmək olmur.
Yadda saxla
Daxilə çəkilmişdə: ∠A + ∠C = 180°, ∠B + ∠D = 180°. Xarici bucaq = daxili qarşı bucaq. Eyni qövsə söykənən bucaqlar bərabərdir. Bunların hər biri həm də əlamətdir.
Özünü yoxla: 3 sual
  1. Daxilə çəkilmiş ABCD-də ∠A = 95°, ∠B = 70°. ∠C və ∠D? ∠C = 180° − 95° = 85°, ∠D = 180° − 70° = 110°.
  2. ∠A = 80°, ∠B = 95°, ∠C = 100°, ∠D = 85°. Çevrə çəkmək olarmı? Bəli: 80° + 100° = 180° və 95° + 85° = 180°.
  3. Çevrəyə daxil çəkilmiş trapesiyanın (AD ∥ BC) ∠B = 65°. ∠D? B və D qarşı bucaqlardır: ∠D = 180° − 65° = 115°.

Dərs 2. Ptolomey teoremi

1 Niyə lazımdır

Dairəvi gölün sahilində dörd nöqtə var. Dörd tərəf və bir diaqonal ölçülüb, ikinci diaqonalı ölçmək üçün gölün üstündən keçmək lazımdır. Ptolomey teoremi onu hesablamağa imkan verir.

2 Teorem

Çevrəyə daxil çəkilmiş ABCD dördbucaqlısında (təpələr çevrə üzərində ardıcıl yerləşir) diaqonalların hasili qarşı tərəflərin hasillərinin cəminə bərabərdir.

AC · BD = AB · CD + BC · AD

3 Niyə belədir? (sübut)

AC diaqonalı üzərində elə K nöqtəsi götürək ki, ∠ABK = ∠DBC olsun. (∠DBC < ∠ABC, ona görə belə şüa ∠ABC-nin daxilindən keçir və AC-ni kəsir.)

1-ci cüt. △ABK və △DBC: ∠ABK = ∠DBC (seçdik), ∠BAK = ∠BAC = ∠BDC (eyni BC qövsünə söykənir). İki bucaq bərabərdir, üçbucaqlar oxşardır:

AK / DC = AB / DB → AK · DB = AB · DC

2-ci cüt. ∠KBC = ∠ABC − ∠ABK = ∠ABC − ∠DBC = ∠ABD. Və ∠BCK = ∠BCA = ∠BDA (eyni AB qövsünə söykənir). Deməli △KBC ∼ △ABD:

KC / AD = BC / BD → KC · BD = BC · AD

İki bərabərliyi toplayaq: (AK + KC) · BD = AB · DC + BC · AD. AK + KC = AC olduğundan teorem sübut olundu.

4 Xüsusi hallar

Düzbucaqlı. Diaqonallar bərabərdir (AC = BD = d), qarşı tərəflər bərabərdir: d² = a · a + b · b — Pifaqor teoremi. Beləliklə Ptolomey Pifaqorun ümumiləşməsidir.

Bərabəryanlı trapesiya. Əsasları a və b, yan tərəfi c olan daxilə çəkilmiş trapesiyada diaqonallar bərabərdir:

d² = a · b + c²

5 Həll olunmuş nümunələr

Nümunə 1. ABCD daxilə çəkilib: AB = 7, BC = 24, CD = 20, DA = 15, AC = 25. BD = ? AC · BD = AB · CD + BC · DA 25 · BD = 7 · 20 + 24 · 15 = 140 + 360 = 500 BD = 500 : 25 = 20
Nümunə 2. Eyni dördbucaqlıda AB = 7, BC = 24, CD = 20, AC = 25, BD = 20. DA = ? 25 · 20 = 7 · 20 + 24 · DA → 500 = 140 + 24 · DA 24 · DA = 360, DA = 15
Nümunə 3. Daxilə çəkilmiş trapesiyanın əsasları 7 və 25, yan tərəfi 15. Diaqonal = ? d² = a · b + c² = 7 · 25 + 15² = 175 + 225 = 400 d = 20
Həyatdan. Dairəvi gölün sahilində ardıcıl dörd A, B, C, D nöqtəsində: AB = 7 m, BC = 24 m, CD = 20 m, DA = 15 m və AC = 25 m. B ilə D arasındakı məsafəni gölün üstündən ölçmədən tapmaq olar: 20 m (Nümunə 1).

6 Özünü yoxla

Tipik səhvlər
  • Qonşu tərəflərin hasillərini götürmək: AB · BC + CD · DA. Teoremdə qarşı tərəflərdir: AB · CD və BC · DA.
  • Teoremi daxil çəkilməyən dördbucaqlıya tətbiq etmək. Təpələr çevrə üzərində olmalıdır, və ardıcıl yerləşməlidir (A, B, C, D çevrə boyu ardıcıl).
  • Cəmi tapıb dayanmaq. AB · CD + BC · AD diaqonalın özü deyil, diaqonalların hasilidir; onu məlum diaqonala bölmək lazımdır.
Yadda saxla
AC · BD = AB · CD + BC · AD (qarşı tərəflər). Sübut: AC üzərində K, ∠ABK = ∠DBC; iki cüt oxşar üçbucaq. Düzbucaqlı → Pifaqor. Bərabəryanlı trapesiya: d² = ab + c².
Özünü yoxla: 3 sual
  1. Düzbucaqlının tərəfləri 6 və 8. Diaqonal? d² = 6 · 6 + 8 · 8 = 100, d = 10.
  2. ABCD daxilə çəkilib: AB = 3, BC = 4, CD = 4, DA = 3, AC = 5. BD? 5 · BD = 3 · 4 + 4 · 3 = 24, BD = 24/5 = 4,8.
  3. Daxilə çəkilmiş trapesiyanın əsasları 9 və 16, diaqonalı 20. Yan tərəf? 400 = 9 · 16 + c² = 144 + c², c² = 256, c = 16.

Dərs 3. Ptolomey bərabərsizliyi və tətbiqlər

1 Niyə lazımdır

Ptolomey teoremi yalnız hesablamaq üçün deyil, həm də sübut üçün alətdir: "bir parça digər ikisinin cəmidir" kimi nəticələr dərhal alınır. Bərabərsizlik versiyası isə dördbucaqlının çevrəyə daxil çəkilib-çəkilməyəcəyini yoxlamağa imkan verir.

2 Ptolomey bərabərsizliyi

İstənilən dörd A, B, C, D nöqtəsi üçün:

AC · BD ≤ AB · CD + BC · AD

Bərabərlik dördbucaqlı çevrəyə daxil çəkiləndə olur (Dərs 2-dəki teorem və onun tərsi); dörd nöqtə bir düz xətt üzərində olduqda da bərabərlik mümkündür: ardıcıl 0, 1, 2, 3 üçün 2·2 = 1·1 + 1·3.

Niyə? K nöqtəsini elə qur ki, △ABK ∼ △ACD olsun (A ortaq təpə, B → C, K → D). Onda:

  • AB / AC = BK / CD, yəni BK = AB · CD / AC.
  • ∠BAK = ∠CAD, ona görə ∠BAC = ∠KAD və AB / AK = AC / AD. Deməli △ABC ∼ △AKD və KD = BC · AD / AC.

Üçbucaq bərabərsizliyi: BD ≤ BK + KD = (AB · CD + BC · AD) / AC. AC-yə vursaq, bərabərsizlik alınır.

Bərabərlik yalnız K nöqtəsi BD parçası üzərində olanda mümkündür. Nöqtələr bir düz xətt üzərində deyilsə, onda ∠ABD = ∠ABK = ∠ACD: B və C nöqtələrindən AD parçası eyni bucaq altında görünür, yəni A, B, C, D bir çevrə üzərindədir (Dərs 1, əlamət 2).

3 Bərabərtərəfli üçbucaq: PA = PB + PC

ABC bərabərtərəfli üçbucaqdır, P nöqtəsi onun xaricinə çəkilmiş çevrənin BC qövsü (A-nı saxlamayan) üzərindədir. ABPC çevrəyə daxil çəkilmiş dördbucaqlıdır, diaqonalları AP və BC.

Ptolomey: AP · BC = AB · PC + AC · PB AB = AC = BC = a: a · AP = a · PC + a · PB PA = PB + PC

Eyni dördbucaqlıdan başqa bir nəticə: ABPC daxilə çəkilmişdir, ona görə ∠BPC = 180° − ∠BAC = 120°.

4 Düzgün beşbucaqlı

Düzgün beşbucaqlının tərəfi a, bütün diaqonalları bərabərdir: d. ABCD dördbucaqlısına Ptolomey: AC · BD = AB · CD + BC · AD, yəni d · d = a · a + a · d.

d² = a² + a · d → d = a · (1 + √5) / 2

Kvadrat tənliyin d² − a·d − a² = 0 müsbət kökü: d = (a + √(a² + 4a²)) / 2 = a(1 + √5)/2. Bu — qızıl nisbətdir.

5 Diaqonalların nisbəti

Ptolomey diaqonalların hasilini verir. Onların nisbətini tapmaq üçün çevrənin radiusundan istifadə et: radiusu R olan çevrəyə daxil çəkilmiş üçbucağın sahəsi S = xyz / (4R)-dir (x, y, z — tərəfləri). Dördbucaqlının sahəsini iki yolla yaz:

S = S(ABD) + S(CBD) = BD · (AB · AD + CB · CD) / (4R) S = S(ABC) + S(ADC) = AC · (AB · BC + AD · DC) / (4R)

İkisini bərabərləşdirsək:

AC / BD = (AB · AD + CB · CD) / (AB · BC + AD · DC)

Hasil və nisbət birlikdə hər iki diaqonalı verir.

6 Həll olunmuş nümunələr

Nümunə 1. Bərabərtərəfli ABC, P — BC qövsündə, PB = 3, PC = 5. PA = ? PA = PB + PC = 3 + 5 = 8
Nümunə 2. Düzgün beşbucaqlının tərəfi 4. Diaqonal = ? d = a(1 + √5)/2 = 4(1 + √5)/2 = 2 + 2√5
Nümunə 3. Daxilə çəkilmiş ABCD-də AB = 7, BC = 24, CD = 15, DA = 20. AC / BD = ? AC / BD = (AB · AD + CB · CD) / (AB · BC + AD · DC) = (7 · 20 + 24 · 15) / (7 · 24 + 20 · 15) = (140 + 360) / (168 + 300) = 500 / 468 = 125 / 117
Həyatdan. Üçbucaq şəkilli bağın üç küncündə ağaclar var və bağın hər üç küncündən keçən dairəvi hasar çəkilib. Hasar üzərindəki quyunun B və C ağaclarından məsafələri 3 m və 5 m-dirsə, A ağacına olan məsafə birbaşa 8 m olur — ölçmə lazım deyil.

7 Özünü yoxla

Tipik səhvlər
  • PA = PB + PC düsturunu P çevrənin istənilən nöqtəsi üçün tətbiq etmək. Yalnız P A-nı saxlamayan BC qövsündə olanda doğrudur.
  • Beşbucaqlıda d = a · (1 + √5) yazmaq (2-yə bölməyi unutmaq).
  • Nisbət düsturunda surəti və məxrəci dəyişmək. Surətdə A-dan və C-dən çıxan tərəflərin hasilləri yazılır (AB · AD + CB · CD), məxrəcdə B-dən və D-dən çıxanlar (AB · BC + AD · DC).
Yadda saxla
AC · BD ≤ AB · CD + BC · AD, bərabərlik ⇔ çevrə. Bərabərtərəfli üçbucaq: PA = PB + PC. Beşbucaqlı: d = a(1 + √5)/2. AC / BD = (AB·AD + CB·CD) / (AB·BC + AD·DC).
Özünü yoxla: 3 sual
  1. Bərabərtərəfli ABC, P — BC qövsündə, PB = 6, PC = 7. PA? 6 + 7 = 13.
  2. Düzgün beşbucaqlının tərəfi 6. Diaqonal? 6 · (1 + √5)/2 = 3 + 3√5.
  3. Daxilə çəkilmiş ABCD: AB = 3, BC = 4, CD = 4, DA = 3. AC / BD? (3 · 3 + 4 · 4) / (3 · 4 + 3 · 4) = 25/24.

Dərs 4. Klassik olimpiada məsələləri

1 Necə yanaşmaq

Çevrə üzərində dörd nöqtə görəndə üç sual ver: (1) bucaqlar arasında əlaqə varmı (qarşı bucaqlar, eyni qövs)? (2) diaqonalların və tərəflərin uzunluqları arasında Ptolomey işə düşürmü? (3) üçbucaq çevrə üzərində nöqtə ilə tamamlanırmı? Aşağıdakı məsələlərdə bunların hamısı işləyir.

2 Məsələ 1. Bərabərtərəfli üçbucaq və çevrə nöqtəsi

ABC bərabərtərəfli üçbucaqdır, P nöqtəsi onun xaricinə çəkilmiş çevrənin BC qövsü (A-nı saxlamayan) üzərindədir, PB = 3, PC = 5. PA və BC-ni tap.

Həll. 1) PA. ABPC çevrəyə daxildir, Ptolomey: PA · BC = AB · PC + AC · PB. AB = AC = BC olduğundan PA = PC + PB = 5 + 3 = 8. 2) BC. ABPC daxilə çəkilmişdir, A və P qarşı təpələrdir: ∠BPC = 180° − ∠BAC = 180° − 60° = 120°. BPC üçbucağında kosinuslar teoremi: BC² = PB² + PC² − 2 · PB · PC · cos 120° = 9 + 25 − 2 · 3 · 5 · (−1/2) = 34 + 15 = 49. BC = 7. Cavab: PA = 8, BC = 7

3 Məsələ 2. Hər iki diaqonal

Çevrəyə daxil çəkilmiş ABCD dördbucaqlısında AB = 7, BC = 24, CD = 15, DA = 20. Diaqonalları AC və BD tap.

Həll. Ptolomey (hasil): AC · BD = AB · CD + BC · DA = 7 · 15 + 24 · 20 = 105 + 480 = 585. Nisbət (Dərs 3): AC / BD = (AB · AD + CB · CD) / (AB · BC + AD · DC) = (7 · 20 + 24 · 15) / (7 · 24 + 20 · 15) = 500 / 468 = 125 / 117. BD = (117/125) · AC. Hasilə qoy: AC · (117/125) · AC = 585 → AC² = 585 · 125 / 117 = 5 · 125 = 625. AC = 25. BD = 585 : 25 = 23,4 = 117/5. Yoxlama: 7² + 24² = 625 = 25², deməli ABC düz bucaqlıdır və AC — diametrdir (Dərs 1, diametrə söykənən bucaq). Cavab: AC = 25, BD = 117/5

4 Məsələ 3. Düzgün yeddibucaqlı

ABCDEFG — düzgün yeddibucaqlıdır. AB = a, AC = b, AD = c olsun. Sübut et: 1/a = 1/b + 1/c.

Həll. Düzgün çoxbucaqlıda bərabər qövsləri tutan vətərlər bərabərdir. Ona görə: BC = a (qonşu təpələr), CE = b (bir təpə atlayır, AC kimi), AE = c (E → F → G → A üç addımdır, AD kimi), BE = c (B → C → D → E də üç addımdır). ABCE dördbucaqlısı çevrəyə daxildir (təpələr çevrə üzərində ardıcıl: A, B, C, E). Ptolomey: AC · BE = AB · CE + BC · EA b · c = a · b + a · c Hər iki tərəfi a · b · c-yə böl: 1/a = 1/c + 1/b. Sübut tamamdır.
Həyatdan. Yeddi küncü dairəvi meydançanın kənarında olan yeddibucaqlı pavilyonda tərəfi və iki növ diaqonalı ölçən memar üçüncü ölçünü həmişə birinci ikisindən tapa bilər: c = ab / (b − a). Ptolomey şəkildən ölçməsiz əlaqə verir.

5 Özünü yoxla

Tipik səhvlər
  • Məsələ 1-də BC-ni "3 + 5 = 8" hesab etmək. PA = PB + PC — A-ya qədər olan məsafədir, BC tərəf deyil.
  • Məsələ 2-də yalnız nisbəti və ya yalnız hasili tapıb dayanmaq: ikisini birləşdirmək lazımdır.
  • Məsələ 3-də dördbucaqlıların təpələrinin ardıcıllığını qarışdırmaq: ABCE (A, B, C, E) çevrə boyu ardıcıldır, ABEC deyil.
Yadda saxla
Çevrə üzərində üçbucağa nöqtə əlavə et → ABPC daxilə çəkilmiş dördbucaqlı → Ptolomey + qarşı bucaqlar. Hasil (Ptolomey) + nisbət → hər iki diaqonal. Çoxbucaqlıda bərabər qövs = bərabər vətər.
