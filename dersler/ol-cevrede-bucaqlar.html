Çevrədə bucaqlar (mərkəzi, daxili): olimpiada səviyyəsi

Olimpiada həndəsəsinin ən çox işlənən üsulu bucaq ovlamaqdır: bir bucağı digərləri ilə əlaqələndirib çevrənin gizli xassələrini tapırsan. Bu mövzuda məktəbdəki mərkəzi və daxili bucaqları iki vətər və iki kəsən arasındakı bucaqlara qədər genişləndirəcəksən, çevrəyə daxil olan dördbucaqlıların əlamətlərini öyrənəcəksən, üçbucağın mühüm nöqtələrində bucaqları (I, O, H) və məşhur "daxili–xarici mərkəz lemması"nı sübut edəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Hər bucaq bir qövsdür

1 Niyə lazımdır

Çevrə həndəsəsində bucaqları ayrı-ayrı düsturlarla yadda saxlamaq çətindir. Daha yaxşı yol: hər bucağı qövslərlə ifadə et. Qövslər dərəcə ilə ölçülür (tam çevrə 360°). Sonra "bucaq ovlamaq" — qövsləri toplayıb çıxmaq — bütün bucaq məsələlərini bir üsula gətirir.

2 Əsas fikir: bucağın təpəsi harada olur?

təpə mərkəzdə: bucaq = qövs təpə çevrə üzərində: bucaq = qövs/2 (daxilə çəkilmiş; toxunan–vətər) təpə çevrənin daxilində: bucaq = (qövs₁ + qövs₂)/2 (iki vətər arasında) təpə çevrənin kənarında: bucaq = (uzaq qövs − yaxın qövs)/2 (iki kəsən, toxunan–kəsən, iki toxunan)

Daxilə çəkilmiş bucağın qövsün yarısı olduğunu bilirsən. Qalan halları ondan çıxaraq.

İki vətər arasındakı bucaq. AC və BD vətərləri E-də kəsişir.

φ = ∠AEB

φ = (AB qövsü + CD qövsü)/2

∠AEB, EBC üçbucağının xarici bucağıdır: ∠AEB = ∠ECB + ∠EBC = ∠ACB + ∠DBC = (AB qövsü)/2 + (CD qövsü)/2 ∠AEB = (AB qövsü + CD qövsü)/2. ∎

Çevrədən kənar nöqtə. P-dən iki kəsən: biri A, B-də, digəri C, D-də kəsir (A və C yaxındır).

φ = ∠APC

φ = (BD qövsü − AC qövsü)/2

∠BAD, APD üçbucağının xarici bucağıdır: ∠BAD = ∠APD + ∠ADP → ∠P = ∠BAD − ∠ADC = (BD qövsü)/2 − (AC qövsü)/2 ∠P = (uzaq BD − yaxın AC)/2. ∎

Xüsusi hallar. Kəsənlərdən biri toxunana çevriləndə C və D bir nöqtəyə (T) birləşir: ∠P = (TB − TA)/2. İki toxunanda ∠P = (böyük qövs − kiçik qövs)/2 = 180° − kiçik qövs (çünki iki qövsün cəmi 360°). Toxunan–vətər bucağı: ∠PAB = AB qövsü/2. Sübut: AD diametri çəkək; ∠PAB = 90° − ∠BAD, ∠BAD = 90° − ∠ADB (ABD düzbucaqlıdır), deməli ∠PAB = ∠ADB = AB/2.

AD — diametr. ∠PAB = ∠ADB = α = AB qövsü/2.

∠AOB = m (kiçik qövs), φ = ∠APB.

φ = 180° − m

3 Həll olunmuş nümunələr

Nümunə 1. Vətərlər E-də kəsişir. AB qövsü 70°, CD qövsü 50°. ∠AEB = ? ∠AEB = (70° + 50°)/2 = 60° Nümunə 2. P-dən iki kəsən. Yaxın qövs AC = 50°, uzaq qövs BD = 150°. ∠P = ? ∠P = (150° − 50°)/2 = 50° Nümunə 3. PT toxunan, PAB kəsən. TA = 40°, TB = 120°. ∠TPA = ? ∠P = (120° − 40°)/2 = 40° Nümunə 4. PA, PB toxunanlardır, ∠APB = 40°. Kiçik AB qövsü? ∠P = 180° − kiçik qövs → kiçik qövs = 180° − 40° = 140° Nümunə 5. Toxunan–vətər bucağı ∠PAB = 35°. AB qövsü? ∠AOB? AB qövsü = 2 · 35° = 70°, ∠AOB = 70°
Həyatdan: arena. Dairəvi arenanın kənarındakı A və B nöqtələrində kameralar var, ∠AOB = 80° (O — mərkəz). Böyük qövsdəki izləyici kameralara 80°/2 = 40° bucaq altında baxır. Kiçik qövsdəki izləyici üçün qövs 360° − 80° = 280°-dir, bucaq 280°/2 = 140°.

4 Klassik olimpiada məsələləri

Məsələ 1. Perpendikulyar vətərlər. Çevrənin AC və BD vətərləri perpendikulyardır. Sübut et: AB və CD qövslərinin cəmi 180°-dir.

Həll. ∠AEB = 90° = (AB qövsü + CD qövsü)/2. Deməli AB qövsü + CD qövsü = 180°. ∎ Eyni ilə BC qövsü + DA qövsü = 180°. Məsələn AB = 100° olarsa, CD = 80°.

Məsələ 2. Daxilə çəkilmiş çevrənin toxunma üçbucağı. ABC üçbucağının daxilinə çəkilmiş çevrə (mərkəz I) BC, CA, AB tərəflərinə D, E, F nöqtələrində toxunur. Sübut et: ∠EDF = 90° − ∠A/2.

φ = ∠EDF = 90° − A/2

Həll. 1) Toxunan radiusa perpendikulyardır: IE ⟂ AC, IF ⟂ AB. 2) AEIF dördbucaqlısında iki düz bucaq var: ∠EIF = 360° − 90° − 90° − ∠A = 180° − ∠A. 3) ∠EDF — daxilə çəkilmiş, ∠EIF — mərkəzi bucaqdır, ikisi də EF qövsünə söykənir: ∠EDF = ∠EIF/2 = (180° − ∠A)/2 = 90° − ∠A/2. ∎ Məsələn ∠A = 50° olanda ∠EDF = 65°.
Tipik səhvlər
  • Çevrədən kənar bucaqda qövsləri toplamaq (düzü: uzaq − yaxın). Çevrənin daxilində isə toplanır.
  • Uzaq və yaxın qövsü qarışdırmaq: yaxın qövs bucağın daxilində, uzaq qövs onun davamı tərəfdədir.
  • Daxilə çəkilmiş bucağı hansı qövsə söykəndiyini yoxlamamaq: bucaq təpəni saxlamayan qövsə söykənir. Təpə kiçik qövsdədirsə, bucaq 90°-dən böyükdür.
  • Toxunan–vətər bucağını tam qövs götürmək. Düzü: yarısı.
Yadda saxla
mərkəzi = qövs; daxili = qövs/2; toxunan–vətər = qövs/2 iki vətər (daxildə): (qövs₁ + qövs₂)/2 çevrədən kənar: (uzaq − yaxın)/2; iki toxunan: 180° − kiçik qövs toxunma üçbucağı: ∠EDF = 90° − ∠A/2
Özünü yoxla: 3 sual
  1. Vətərlər kəsişir, bucaq üzərinə söykəndiyi iki qövs 80° və 40°-dir. Bucaq? (80° + 40°)/2 = 60°.
  2. Kənar nöqtədən iki kəsən, qövslər: uzaq 160°, yaxın 40°. Bucaq? (160° − 40°)/2 = 60°.
  3. İki toxunan arasındakı bucaq 50°. Kiçik qövs? 180° − 50° = 130°.

Dərs 2. Çevrəyə daxil olan dördbucaqlı

1 Niyə lazımdır

Olimpiada məsələlərində çevrə çox vaxt şəkildə çəkilmir — onu sən "görməlisən". Dörd nöqtənin bir çevrədə olduğunu bilən adam bucaqları tez tapır və düz xətləri oxşar üçbucaqlara bağlayır. Bu dərsdə həm teorem, həm də tərsi öyrənilir.

2 Əsas fikir

Təpələri bir çevrə üzərində olan dördbucaqlıya çevrəyə daxil olan dördbucaqlı deyilir. ABCD belə olanda:

1) ∠A + ∠C = 180°, ∠B + ∠D = 180° (qarşı bucaqlar) 2) xarici bucaq = daxili qarşı bucaq: ∠DAM = ∠BCD (M ∈ BA davamı) 3) eyni tərəfə baxan bucaqlar bərabərdir: ∠ABD = ∠ACD, ∠BAC = ∠BDC

∠A + ∠C = 180°.

Xarici bucaq ∠DAM = ∠BCD = γ.

Sübut (1). ∠A daxilə çəkilmiş bucaqdır, o, BCD qövsünə söykənir: ∠A = (BCD qövsü)/2. ∠C isə BAD qövsünə söykənir: ∠C = (BAD qövsü)/2. İki qövsün cəmi tam çevrədir (360°): ∠A + ∠C = (360°)/2 = 180°. ∎ (2) ∠DAM = 180° − ∠BAD = ∠BCD. (3) eyni qövsə söykənən daxili bucaqlar.

Tərsi (dörd nöqtənin bir çevrədə olması əlaməti). Aşağıdakılardan biri doğrudursa, A, B, C, D bir çevrədədir:

a) qarşı bucaqların cəmi 180°-dir (∠A + ∠C = 180°); b) xarici bucaq daxili qarşı bucağa bərabərdir; c) B və C nöqtələri AD parçasına eyni tərəfdədir və ∠ABD = ∠ACD.

Niyə? A, B, C nöqtələrindən çevrə çəkək. D bu çevrənin daxilində olsa, ∠ADC böyük, kənarında olsa kiçik çıxar. Yalnız çevrə üzərində olanda cəm 180° (və ya bucaqlar bərabər) olur. Bu tərs teoremi sübutsuz qəbul edə bilərsən; olimpiadada o, "çevrə tapmağın" əsas yoludur.

3 Həll olunmuş nümunələr

Nümunə 1. ABCD daxil olan, ∠A = 75°. ∠C = 180° − 75° = 105°. Nümunə 2. ∠BCD = 110°, BA davamı M. ∠DAM = ∠BCD = 110°. Nümunə 3. Dördbucaqlıda ∠B = 95°, ∠D = 85°. B + D = 180° → daxil ola bilər. ∠A = 100° olarsa, ∠C = 80° olmalıdır. Nümunə 4. BC ∥ AD trapesiyası daxil olan, ∠B = 70°. ∠B + ∠A = 180° (birtərəfli) → ∠A = 110°; ∠A + ∠C = 180° (daxil olan) → ∠C = 70° = ∠B → bərabəryanlıdır, ∠D = 110°. Nümunə 5. Diaqonallar E-də kəsişir. ∠ABD = 30°, ∠BDC = 55°. ∠AEB = ? ∠BAC = ∠BDC = 55° (eyni BC qövsünə söykənir) ABE üçbucağında: ∠AEB = 180° − 30° − 55° = 95°
Həyatdan: park. Dairəvi parkın kənarında A və B səhnənin uclarıdır. C nöqtəsindən səhnə 40° bucaq altında görünür. Qarşı tərəfdəki D nöqtəsində ACBD daxil olan dördbucaqlıdır: ∠ADB = 180° − 40° = 140°. Eyni tərəfdəki nöqtədən isə yenə 40°.

4 Klassik olimpiada məsələləri

Məsələ 1. Paraleloqram və trapesiya. (a) Çevrəyə daxil olan paraleloqram düzbucaqlıdır. (b) Çevrəyə daxil olan trapesiya bərabəryanlıdır. Sübut et.

(a) Paraleloqramda ∠A = ∠C. Daxil olanda ∠A + ∠C = 180°. Deməli ∠A = ∠C = 90°. Paraleloqramın bir bucağı düzdürsə — düzbucaqlıdır. ∎ (b) BC ∥ AD. Birtərəfli bucaqlar: ∠A + ∠B = 180°. Daxil olan: ∠A + ∠C = 180°. Çıxsaq: ∠B = ∠C. Oturacaqdakı bucaqlar bərabərdir — trapesiya bərabəryanlıdır (AB = CD). ∎

Məsələ 2. Brahmaqupta. ABCD çevrəyə daxil olan dördbucaqlıdır və diaqonalları perpendikulyardır (E — kəsişmə). E-dən BC-yə çəkilmiş perpendikulyar AD-ni M nöqtəsində kəsir. Sübut et: M — AD-nin orta nöqtəsidir.

AC ⟂ BD, EH ⟂ BC.

MA = MD

Həll. H — E-dən BC-yə perpendikulyarın ayağıdır. 1) EHC düzbucaqlıdır: ∠CEH = 90° − ∠ECB = 90° − ∠ACB. 2) ∠MEA = ∠CEH (şaquli bucaqlar), deməli ∠MEA = 90° − ∠ACB. 3) Daxil olan dördbucaqlıda ∠ACB = ∠ADB (eyni AB qövsü): ∠MEA = 90° − ∠ADB. 4) AED düzbucaqlıdır (AC ⟂ BD): ∠EAD = 90° − ∠ADE = 90° − ∠ADB. 5) ∠MEA = ∠MAE → MAE bərabəryanlıdır: MA = ME. Eyni mühakimə ilə ∠MED = ∠MDE → ME = MD. Deməli MA = MD, M — AD-nin orta nöqtəsidir. ∎
Tipik səhvlər
  • Qarşı olmayan bucaqların cəmini 180° götürmək: ∠A + ∠B = 180° daxil olan dördbucaqlıda doğru deyil (qonşu bucaqlar üçün yalnız paralel olanda).
  • Eyni qövsə söykənən bucaqların təpələrinin qövsün eyni tərəfində olmalı olduğunu unutmaq. Əks tərəfdə bucaqlar 180°-ə tamamlanır.
  • Xarici bucağı yanındakı daxili bucaqla bərabər sanmaq. Düzü: qarşı daxili bucaqla.
  • Tərs teoremi yoxlamadan "daxil olandır" demək: ən azı bir əlamət ödənməlidir.
Yadda saxla
daxil olan dördbucaqlı: ∠A + ∠C = 180°, ∠B + ∠D = 180° xarici bucaq = daxili qarşı bucaq eyni qövsə söykənən (eyni tərəfdən) bucaqlar bərabərdir tərs: bu şərtlərdən biri → 4 nöqtə bir çevrədə daxil olan trapesiya bərabəryanlı, paraleloqram düzbucaqlıdır
Özünü yoxla: 3 sual
  1. Daxil olan ABCD-də ∠BAD = 100°. ∠BCD? 80°.
  2. BC ∥ AD daxil olan trapesiyada ∠ABC = 65°. ∠BAD? ∠BAD = 180° − 65° = 115°.
  3. Diaqonallar E-də kəsişir. ∠ABD = 40°, ∠BDC = 25°. ∠AEB? ∠BAC = ∠BDC = 25°; ∠AEB = 180° − 40° − 25° = 115°.

Dərs 3. Üçbucağın mühüm nöqtələrində bucaqlar

1 Niyə lazımdır

Olimpiada məsələlərində üçbucağın xaricinə və daxilinə çəkilmiş çevrələrin mərkəzləri, hündürlüklərin kəsişməsi tez-tez görünür. Onların təpələrdən "görünmə bucağını" əzbər bilsən, çox məsələ bir addımda həll olunur. Hər düstur öz sübutu ilə birlikdə verilir.

2 Əsas fikir

ABC üçbucağının bucaqları A, B, C olsun. I — tənbölənlərin kəsişməsi, O — xaricə çəkilmiş çevrənin mərkəzi, H — hündürlüklərin kəsişməsi, J — A qarşısındakı xaric mərkəz (kəskinbucaqlı halda).

∠BIC = 90° + A/2 (I — daxili mərkəz) ∠BJC = 90° − A/2 (J — xaric mərkəz) ∠BOC = 2A (O — xarici çevrənin mərkəzi) ∠BHC = 180° − A (H — hündürlüklərin kəsişməsi)

φ = ∠BIC = 90° + A/2

I: BI və CI tənbölənlərdir: ∠IBC + ∠ICB = (B + C)/2 = (180° − A)/2 = 90° − A/2 ∠BIC = 180° − (90° − A/2) = 90° + A/2. ∎ J: BJ və CJ xarici bucaqların tənbölənləridir: ∠JBC + ∠JCB = (180° − B)/2 + (180° − C)/2 = 180° − (B + C)/2 = 90° + A/2 ∠BJC = 180° − (90° + A/2) = 90° − A/2. ∎ O: ∠A daxilə çəkilmiş, ∠BOC eyni BC qövsünə söykənən mərkəzi bucaqdır: ∠BOC = 2A. ∎ H: BE ⟂ AC, CF ⟂ AB (E, F — ayaqlar). AEHF dördbucaqlısında ∠EHF = 360° − 90° − 90° − A = 180° − A, ∠BHC = ∠EHF (şaquli). ∎

Qeyd. Bu düsturlarda A yerinə B və ya C qoysan, digər təpələr üçün düsturlar alınır. Məsələn ∠AIC = 90° + B/2.

3 Həll olunmuş nümunələr

Nümunə 1. ∠A = 50°. ∠BIC = 90° + 25° = 115° ∠BJC = 90° − 25° = 65° ∠BOC = 2 · 50° = 100° ∠BHC = 180° − 50° = 130° Nümunə 2. ∠BIC = 128°. ∠A = ? 90° + A/2 = 128° → A = 76° Nümunə 3. ∠A = 60° olanda ∠BIC = ∠BOC = ∠BHC = 120°: bu üç nöqtə (I, O, H) B və C ilə eyni çevrə üzərindədir.
Həyatdan: üçbucaq bağ. Üçbucaq formalı bağın künclərindəki bucaqlar 50°, 60°, 70°-dir. A (50°) küncünün qarşısındakı BC divarından daxili tənbölənlərin kəsişdiyi nöqtədə ağac əkilib. Divarın uclarından ağaca baxış bucağı 90° + 50°/2 = 115°-dir.

4 Klassik olimpiada məsələləri

Məsələ 1. H-ın simmetriki çevrənin üzərindədir. Kəskinbucaqlı ABC-də H — hündürlüklərin kəsişməsidir. H nöqtəsinin BC düz xəttinə nəzərən simmetriki H' nöqtəsi ABC-nin xaricinə çəkilmiş çevrə üzərindədir. Sübut et.

H' — H-ın BC-yə nəzərən simmetrikidir.

∠BH'C = ∠BHC = 180° − A

Həll. Simmetriyada bucaqlar qorunur: ∠BH'C = ∠BHC = 180° − A. H' nöqtəsi A-nın əks tərəfindədir (H üçbucağın daxilindədir). Deməli ∠BAC + ∠BH'C = A + (180° − A) = 180°: ABH'C dördbucaqlısında qarşı bucaqların cəmi 180°-dir — tərs teoremə görə ABH'C daxil olan dördbucaqlıdır, H' çevrədədir. ∎

Məsələ 2. Hündürlük və radius arasındakı bucaq. AK — BC-yə hündürlük, O — xarici çevrənin mərkəzidir. Sübut et: ∠KAO = |B − C|.

Həll. ABK düzbucaqlıdır: ∠BAK = 90° − B. AOB bərabəryanlıdır (OA = OB), ∠AOB = 2C (mərkəzi bucaq): ∠OAB = (180° − 2C)/2 = 90° − C. AK və AO şüaları A bucağının daxilindədir, AB-dən ölçülərək: ∠KAO = |∠BAK − ∠OAB| = |(90° − B) − (90° − C)| = |B − C|. ∎ Məsələn B = 70°, C = 60° olanda ∠KAO = 10°.

Məsələ 3. Hündürlüklərin ayaqlarından üçbucaq. Kəskinbucaqlı ABC-də AD, BE, CF hündürlükləri H-da kəsişir. Sübut et: H nöqtəsi DEF üçbucağının daxilə çəkilmiş çevrəsinin mərkəzidir və ∠EDF = 180° − 2A.

H — DEF-in daxili mərkəzidir.

φ = ∠EDF = 180° − 2A

Həll. 1) BDHF dördbucaqlısında ∠BDH = ∠BFH = 90°, cəmi 180°: daxil olan dördbucaqlıdır. Eyni BH qövsünə söykənən bucaqlar: ∠FDH = ∠FBH = 90° − A (ABE düzbucaqlıdır, ∠ABE = 90° − A). 2) CDHE də daxil olandır (∠CDH = ∠CEH = 90°): ∠EDH = ∠ECH = 90° − A (ACF düzbucaqlı). 3) ∠FDH = ∠HDE → DH bucağın tənböləndir. Eyni ilə EH və FH də DEF-in tənbölənləridir. Deməli H — DEF-in daxili mərkəzidir. 4) ∠EDF = ∠FDH + ∠HDE = 2 · (90° − A) = 180° − 2A. ∎ Məsələn A = 68° olanda ∠EDF = 44°.
Tipik səhvlər
  • ∠BIC = 90° − A/2 yazmaq (bu, xaric mərkəzin bucağıdır). Daxili mərkəz üçün plus.
  • ∠BOC = A götürmək. Mərkəzi bucaq daxilə çəkilmişin iki mislidir.
  • Düstur küt bucaqlı üçbucaqda dəyişir: ∠BOC = 2A yalnız A < 90° olanda; H üçbucağın xaricində olur. Burada kəskinbucaqlı üçbucaqla işləyirik.
  • Orta üçbucağın və toxunma üçbucağının bucaqlarını qarışdırmaq: toxunma (daxili çevrə) üçün 90° − A/2, ayaqlar (hündürlüklər) üçün 180° − 2A.
Yadda saxla
∠BIC = 90° + A/2; ∠BJC = 90° − A/2 ∠BOC = 2A; ∠BHC = 180° − A ∠KAO = |B − C| (hündürlük və xarici radius) toxunma üçbucağı: 90° − A/2; ayaqlar üçbucağı: 180° − 2A (H — daxili mərkəz)
Özünü yoxla: 3 sual

Dərs 4. Daxili–xarici mərkəz lemması

1 Niyə lazımdır

Bu, olimpiada həndəsəsinin ən məşhur faktlarından biridir və bir çox çətin məsələ onun bir sətirlik tətbiqidir. Xarici çevrə üzərində elə bir nöqtə var ki, o, həm B, C-dən, həm də daxili mərkəz I-dən eyni məsafədədir. Yəni B, C, I nöqtələri həmin nöqtə mərkəz olan bir çevrə üzərindədir.

2 Əsas fikir

ABC üçbucağında I — daxili mərkəz, AI şüası xarici çevrəni W nöqtəsində kəsir. Onda W — BC qövsünün orta nöqtəsidir (A-nı saxlamayan).

WB = WC = WI

W — BC qövsünün ortasıdır.

WB = WC = WI

Sübut. 1) ∠BAW = ∠WAC (AW tənböləndir) → bərabər bucaqlar bərabər vətərləri kəsir: WB = WC. 2) ∠WBI = ∠WBC + ∠CBI. ∠WBC = ∠WAC = A/2 (eyni WC qövsünə söykənir) ∠CBI = B/2 (BI tənböləndir) ∠WBI = A/2 + B/2. 3) ∠WIB, ABI üçbucağının xarici bucağıdır: ∠WIB = ∠IAB + ∠IBA = A/2 + B/2. 4) WBI üçbucağında ∠WBI = ∠WIB → WB = WI. ∎

Nəticələr. (1) ∠BWI = 180° − (A + B) = C. (2) AW ilə BC kəsişmə nöqtəsi D olarsa, WB² = WD · WA: WBD və WAB oxşardır (∠BWD ümumi, ∠WBD = ∠WBC = ∠WAC = ∠WAB), deməli WB/WA = WD/WB. (3) A qarşısındakı xaric mərkəz J da AI şüası üzərindədir və W — IJ-nin orta nöqtəsidir (Məsələ 1).

Nümunə 1. ∠A = 40°, ∠B = 70°. ∠WBI = ? ∠WBI = (A + B)/2 = 55°, ∠C = 70°, ∠BWI = C = 70° (WBI üçbucağı: 55° + 55° + 70° = 180° ✓) Nümunə 2. WB = 7. WC = ? WI = ? WB + WC + WI = ? Həyatdan: dairəvi meydan. Dairəvi meydanın kənarında B və C girişləri var, W isə aralarındakı qövsün ortasıdır. W-dən hər iki girişə məsafə 12 m-dirsə, girişləri və tənbölənlərin kəsişdiyi I nöqtəsini əhatə edən çevrənin mərkəzi W-dir: I də W-dən 12 m aralıdadır.

4 Klassik olimpiada məsələləri

Məsələ 1. Mərkəzlərin orta nöqtəsi. Sübut et: W nöqtəsi I və J (A qarşısındakı xaric mərkəz) nöqtələrinin orta nöqtəsidir.

Həll. BI və BJ — B təpəsindəki daxili və xarici bucaqların tənbölənləridir, qonşu bucaqların tənbölənləri perpendikulyardır: ∠IBJ = 90°. Eyni ilə ∠ICJ = 90°. B və C nöqtələri IJ diametrli çevrə üzərindədir; bu çevrənin mərkəzi IJ-nin orta nöqtəsi M-dir. Lemmadan WB = WC = WI. W nöqtəsi I, B, C üçün bərabər məsafəli nöqtədir (IBC üçbucağının xaricinə çəkilmiş çevrənin mərkəzi), M də eyni üç nöqtədən bərabər məsafədədir. Üç nöqtənin (I, B, C) xaricinə çəkilmiş çevrənin mərkəzi yeganədir: W = M, yəni W — IJ-nin orta nöqtəsidir. ∎ Nəticə: IJ = 2 · WI = 2 · WB.

Məsələ 2. WB² = WD · WA. Yuxarıdakı nəticəni nümunə ilə yoxla: WB = 6, WA = 9 olarsa, WD = 36/9 = 4, deməli AD = AW − WD = 5. Burada D — tənbölənin BC ilə kəsişməsidir; AD · DW = BD · DC (vətərlər) olduğundan BD · DC = 5 · 4 = 20.

Məsələ 3. İki çevrə və sabit bucaq. İki çevrə A və B nöqtələrində kəsişir. A-dan keçən düz xətt birinci çevrəni C, ikincini D nöqtəsində kəsir (A nöqtəsi C və D arasındadır). Sübut et: ∠CBD düz xəttin seçimindən asılı deyil.

α = ∠ACB, β = ∠ADB — sabitdir.

φ = ∠CBD = 180° − α − β

Həll. ∠ACB — birinci çevrədə AB qövsünə söykənən daxilə çəkilmiş bucaqdır, ∠ADB — ikinci çevrədə AB qövsünə. AB sabit parçadır, buna görə ∠ACB = α və ∠ADB = β düz xətt dəyişəndə dəyişmir (A nöqtəsi C və D arasında qaldıqca C həmişə birinci çevrənin eyni qövsündə, D isə ikinci çevrənin eyni qövsündə yerləşir). BCD üçbucağında ∠CBD = 180° − α − β — sabitdir. ∎ Məsələn α = 50°, β = 60° olanda ∠CBD = 70°.
Tipik səhvlər
  • WB = WC deyib WI-ni unutmaq: lemmanın əsas gücü WB = WC = WI bərabərliyindədir.
  • W nöqtəsini A-nın tərəfindəki qövsdə axtarmaq: W BC qövsünün A-nı saxlamayan orta nöqtəsidir.
  • WB² = WD · WA yerinə WB² = WD · WI yazmaq.
  • Xaric mərkəzlə daxili mərkəzi qarışdırmaq: IJ = 2 · WI, yəni W mərkəzdir, I isə uc.
