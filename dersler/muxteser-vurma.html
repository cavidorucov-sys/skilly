Müxtəsər vurma düsturları

Bəzi hasillər o qədər tez-tez çıxır ki, onları hər dəfə açmaq əvəzinə hazır düsturla yazırıq: (a + b)², a² − b², kublar. Bu düsturlar həm ifadələri sadələşdirir, həm də 101², 49·51 kimi hesabları başda, kalkulyatorsuz etməyə imkan verir.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Cəmin və fərqin kvadratı

1 Niyə lazımdır

Tərəfi 10 m olan kvadrat bağçanın tərəfini 2 m uzatdılar. Sahə nə qədər artdı? Çoxları "4 m²" deyir. Əslində 12² − 10² = 44 m². Niyə belə çox? Cavab — (a + b)² düsturundakı ortadakı həddədir.

2 Düsturlar

(a + b)² = a² + 2ab + b² (a − b)² = a² − 2ab + b²

Sözlə: birincinin kvadratı, üstəgəl (çıx) ikiqat hasil, üstəgəl ikincinin kvadratı. Şəkildə tərəfi a + b olan kvadrat dörd hissəyə bölünür: a², b² və iki eyni düzbucaqlı ab.

Bütün kvadrat: (a + b)² = a² + ab + ab + b² = a² + 2ab + b². İki ədəd ab düzbucaqlısı — "ikiqat hasil".

3 Həll olunmuş nümunələr

1) (x + 5)² = x² + 2·x·5 + 5² = x² + 10x + 25 2) (3x − 2y)² = (3x)² − 2·3x·2y + (2y)² = 9x² − 12xy + 4y² 3) Tərsinə: x² − 14x + 49 49 = 7², 14x = 2·x·7 = (x − 7)² 4) x² + 6x + c tam kvadrat olsun: 6x = 2·x·3 → c = 3² = 9
Həyatdan. Bağçanın nümunəsi: (10 + 2)² = 100 + 2·10·2 + 4 = 144. Artım: 2·10·2 + 2² = 40 + 4 = 44 m². İki uzun zolaq (hər biri 10 × 2) və küncdə kiçik kvadrat (2 × 2).
Tipik səhvlər
  • (a + b)² = a² + b² — ən məşhur səhv. Ortadakı 2ab itib.
  • (3x)²-ni 3x² yazmaq. Düzü: 9x² — əmsal da kvadrata yüksəlir.
  • (a − b)²-də b²-ni mənfi yazmaq. Kvadrat həmişə müsbətdir: +b².
Yadda saxla
(a ± b)² = a² ± 2ab + b² Üç hədd: kvadrat, ikiqat hasil, kvadrat. Tam kvadrat: c = (x-in əmsalının yarısı)².
Özünü yoxla: 3 sual
  1. (x − 6)² aç. x² − 12x + 36.
  2. (2a + 3)² aç. 4a² + 12a + 9.
  3. x² + 8x + c tam kvadratdır. c = ? 8x = 2·x·4 → c = 16.

Dərs 2. Kvadratlar fərqi

1 Niyə lazımdır

49·51 neçədir? Başda vurmaq çətindir. Amma 49 = 50 − 1, 51 = 50 + 1, və (50 − 1)(50 + 1) = 2500 − 1 = 2499. Bir saniyə! Bu — kvadratlar fərqi düsturudur.

2 Düstur

(a − b)(a + b) = a² − b² a² − b² = (a − b)(a + b)

Mötərizələr yalnız ortadakı işarə ilə fərqlənirsə, hasil — kvadratlar fərqidir, orta hədd yoxdur: −ab + ab = 0. Tərsinə oxusan, a² − b²-ni vuruqlara ayırırsan.

3 Həll olunmuş nümunələr

1) (x − 7)(x + 7) = x² − 49 2) (2x + 3y)(2x − 3y) = 4x² − 9y² 3) 25x² − 16 = (5x)² − 4² = (5x − 4)(5x + 4) 4) x − y = 3, x² − y² = 39. x + y = ? (x − y)(x + y) = 39 → 3(x + y) = 39 → x + y = 13 5) (x − 2)(x + 2)(x² + 4) = (x² − 4)(x² + 4) = x⁴ − 16
Həyatdan. Kvadrat kafelin tərəfi 30 sm-dir, ortasından tərəfi 10 sm olan kvadrat deşik kəsilir. Qalan sahə: 30² − 10² = (30 − 10)(30 + 10) = 20·40 = 800 sm².
Tipik səhvlər
  • a² − b²-ni (a − b)² ilə qarışdırmaq. (a − b)² = a² − 2ab + b² — başqa şeydir.
  • a² + b²-ni də belə ayırmağa çalışmaq. Kvadratların cəmi bu düsturla vuruqlara ayrılmır.
  • (3x)² = 3x² yazmaq: (3x − 1)(3x + 1) = 9x² − 1.
Yadda saxla
(a − b)(a + b) = a² − b² (orta hədd yoxdur) x² − y² = (x − y)(x + y): iki ədəd bilinirsə, üçüncüsü tapılır.
Özünü yoxla: 3 sual
  1. (a − 9)(a + 9). a² − 81.
  2. 49 − x² vuruqlara ayır. (7 − x)(7 + x).
  3. x + y = 10, x − y = 4. x² − y² = ? 4·10 = 40.

Dərs 3. Cəmin və fərqin kubu, kubların cəmi və fərqi

1 Niyə lazımdır

Tərəfi x sm olan kub şəklində qutunun hər tərəfini 1 sm böyütsək, həcm (x + 1)³ olur. Onu açmaq üçün iki dəfə vurmaq lazımdır — düstur bunu bir addımda edir.

2 Düsturlar

(a + b)³ = a³ + 3a²b + 3ab² + b³ (a − b)³ = a³ − 3a²b + 3ab² − b³ a³ + b³ = (a + b)(a² − ab + b²) a³ − b³ = (a − b)(a² + ab + b²)

Kubda əmsallar 1, 3, 3, 1-dir. Fərqin kubunda işarələr növbələşir: + − + −. Kubların cəmi/fərqində ikinci mötərizə natamam kvadratdır: ortada ab, 2ab yox.

3 Həll olunmuş nümunələr

1) (x + 2)³ = x³ + 3·x²·2 + 3·x·4 + 8 = x³ + 6x² + 12x + 8 2) (x − 3)³ = x³ − 9x² + 27x − 27 3) x³ − 8 = x³ − 2³ = (x − 2)(x² + 2x + 4) 4) x³ + 27 = (x + 3)(x² − 3x + 9) 5) a + b = 5, ab = 6. a³ + b³ = ? a³ + b³ = (a + b)³ − 3ab(a + b) = 125 − 3·6·5 = 125 − 90 = 35 Yoxla: a = 2, b = 3 → 8 + 27 = 35 ✓
Həyatdan. Tərəfi 10 sm olan kub qutunu hər istiqamətdə 1 sm böyütdülər. Həcm: 11³ = (10 + 1)³ = 1000 + 300 + 30 + 1 = 1331 sm³. Artım 331 sm³ — "1 sm" az görünür, amma həcm üçüncü dərəcə ilə böyüyür.
Tipik səhvlər
  • (a + b)³ = a³ + b³. Ortadakı 3a²b + 3ab² itib.
  • a³ + b³ = (a + b)(a² − 2ab + b²) yazmaq. Ortada −ab-dir.
  • Fərqin kubunda sonuncu hədd: (x − 3)³-də −27, +27 yox.
Yadda saxla
Kub: əmsallar 1, 3, 3, 1. a³ ± b³ = (a ± b)(a² ∓ ab + b²). a³ + b³ = (a + b)³ − 3ab(a + b).
Özünü yoxla: 3 sual
  1. (x + 1)³ aç. x³ + 3x² + 3x + 1.
  2. x³ − 1 vuruqlara ayır. (x − 1)(x² + x + 1).
  3. (x − 2)³-da x-in əmsalı? 3·x·2² = 12x, əmsal 12.

Dərs 4. Düsturlarla tez hesablama və hiylələr

1 Niyə lazımdır

DİM-də kalkulyator yoxdur, vaxt isə azdır. 998·1002, 67² − 33², "a + b = 7, ab = 10, a² + b² = ?" — belə suallar düsturu bilənə bir dəqiqə, bilməyənə beş dəqiqə aparır.

2 Fənd: dəyirmi ədəd ± kiçik ədəd

101² = (100 + 1)² = 10000 + 200 + 1 = 10201 99² = (100 − 1)² = 10000 − 200 + 1 = 9801 49·51 = (50 − 1)(50 + 1) = 2500 − 1 = 2499 53² − 47² = (53 − 47)(53 + 47) = 6·100 = 600

3 Fənd: a + b və ab-dən istifadə

a² + b² = (a + b)² − 2ab a² + b² = (a − b)² + 2ab (a − b)² = (a + b)² − 4ab
a + b = 7, ab = 10: a² + b² = 49 − 20 = 29 (a − b)² = 49 − 40 = 9 Yoxla: a = 5, b = 2 → 25 + 4 = 29 ✓, (5 − 2)² = 9 ✓

4 Fənd: tam kvadratı tanı və ayır

1) x² − 2xy + y², x = 57, y = 47 = (x − y)² = 10² = 100 2) x² + 10x + 25, x = 995 = (x + 5)² = 1000² = 1000000 3) x² − 6x + 14 — ən kiçik qiyməti? = x² − 6x + 9 + 5 = (x − 3)² + 5 (x − 3)² ≥ 0, ən kiçiyi 0 (x = 3) Ən kiçik qiymət: 5
Həyatdan. Bir dəftər 95 qəpikdir, məktəb 105 dəftər alır. Kassir kalkulyator axtarır, sən isə deyirsən: 95·105 = 100² − 5² = 10000 − 25 = 9975 qəpik, yəni 99 manat 75 qəpik.
Tipik səhvlər
  • 99² = 10000 − 1 yazmaq. Bu a² − b² deyil, (a − b)²-dir: 10000 − 200 + 1 = 9801.
  • a² + b² = (a + b)² + 2ab — işarə səhvi. 2ab çıxılır.
  • Ən kiçik qiymətdə x-i cavab yazmaq. Soruşulan ifadənin qiymətidir (5), x = 3 yox.
Yadda saxla
Ədədi "dəyirmi ± kiçik" yaz. İki ədədin hasili, ortası dəyirmidirsə: a² − b². a² + b² = (a + b)² − 2ab. (x − m)² + q-nun ən kiçik qiyməti q-dur.
Özünü yoxla: 3 sual
  1. 102². 10000 + 400 + 4 = 10404.
  2. 38·42. 40² − 2² = 1600 − 4 = 1596.
  3. 67² − 33². (67 − 33)(67 + 33) = 34·100 = 3400.
