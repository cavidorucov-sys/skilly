Sürtünmə, maili müstəvi

Sürtünmə olmasa, yerdə yeriyə bilməzdin, avtomobil əyləc edə bilməzdi. Maili müstəvi isə sürtünməni və ağırlığın toplananlarını bir yerə yığır. Sən bu həftələrdə FRİTL-də mg·sin α, mg·cos α və μ = tg α düsturlarını keçmisən. Bu səhifə onların haradan gəldiyini və hansı hallarda işlədiyini sadə dillə yığır.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq. Hər yerdə g = 10 m/s². Bucaqlar üçün hazır qiymətlər: sin 37° = 0,6; cos 37° = 0,8; sin 53° = 0,8; cos 53° = 0,6; sin 30° = 0,5.

Dərs 1. Sürtünmə qüvvəsi: sükunət və sürüşmə

1 Niyə lazımdır

Tatamidə corabla sürüşürsən, ayaqyalın isə sürüşmürsən. Qışda yollara qum səpilir. Buzda avtomobil əyləc etsə də dayanmır. Bunların hamısında iki səthin təması sürtünmə qüvvəsi yaradır. Sürtünmə həmişə hərəkətə mane olur və səth boyu yönəlir.

2 İki növ sürtünmə

  • Sükunət sürtünməsi — cisim tərpənmir, amma tərpətməyə çalışırlar. Sürtünmə itələyən qüvvəni tam tarazlayır və onunla birlikdə artır, lakin müəyyən həddə qədər: f ≤ f_max = μ_s·N.
  • Sürüşmə sürtünməsi — cisim sürüşür. Sabit qiymətdir: f = μ_k·N (adətən μ_k bir az μ_s-dən kiçikdir).

İtələyən qüvvə F artdıqca sürtünmə də ona bərabər artır (cisim durur). f_max-a çatanda cisim qopur və sürtünmə μ_k N-ə düşür, sonra sabit qalır. Ona görə ağır qutunu tərpətmək tərpətdikdən sonra sürüşdürməkdən çətindir.

3 f = μN: N həmişə mg deyil

f = μ · N

μ — sürtünmə əmsalı (vahidsiz), iki səthdən asılıdır: buz üstündə polad ≈ 0,02; buz üstündə rezin ≈ 0,1–0,2; quru asfaltda rezin ≈ 0,7–0,8. N — səthin cismə perpendikulyar təsir qüvvəsi. Üfüqi səthdə və yalnız şaquli qüvvə mg olanda N = mg; maili müstəvidə və ya bucaq altında dartanda — yox!

Həyatdan. Tatamidə: ayaqyalın μ böyükdür, corabla kiçikdir. Kitabı divara sıxırsan ki, düşməsin: sürtünmə kitabın ağırlığını tarazlayır: saxlanma şərti μ_sF ≥ mg, minimal sıxma qüvvəsi isə F = mg/μ_s (bərabərlik məhz bu halda). Divar hamar (μ kiçik) olarsa, daha bərk sıxmaq lazımdır.

4 Həll olunmuş nümunələr

Nümunə 1. 10 kq qutu, μ_s = 0,5, μ_k = 0,4. Üfüqi səth. f_max = 0,5·100 = 50 N F = 30 N: 30 < 50 → qutu durur, f = 30 N (itələyən qüvvəyə bərabər, μN yox!) F = 60 N: 60 > 50 → sürüşür, f = 0,4·100 = 40 N Nümunə 2. 2 kq kitab şaquli divara sıxılıb, μ = 0,4. mg = 20 N = μF → F = 20/0,4 = 50 N Nümunə 3 (bucaq altında dartma). 5 kq cisim, F = 25 N üfüqlə 37° yuxarı, μ = 0,2. N + F·sin 37° = mg → N = 50 − 25·0,6 = 35 N (qüvvə cismi yüngülləşdirdi) f = 0,2·35 = 7 N (mg ilə hesablasaydıq 10 N olardı — səhv)

5 Özünü yoxla

Tipik səhvlər
  • Cisim durursa, sürtünməni yenə μN götürmək. Durursa, sürtünmə tam lazım olan qədərdir; μN yalnız onun ən böyük qiymətidir.
  • Hər yerdə N = mg yazmaq. Bucaq altında dartanda və ya maili müstəvidə N ayrıca qüvvə tənliyindən tapılır.
  • Sürtünmənin sürüşmə sürətindən və ya təmas sahəsindən asılı olduğunu düşünmək — təxminən asılı deyil.
  • Sürtünmənin istiqamətini hərəkətlə eyni götürmək: sürtünmə əksinədir (nisbi hərəkətin əksinə).
Yadda saxla
Sükunət: f = tətbiq olunan qüvvə, f ≤ μ_s·N Sürüşmə: f = μ_k·N N — səthə perpendikulyar qüvvə (həmişə mg deyil) Divara sıxılma: μ_sF ≥ mg (minimal F üçün μ_sF = mg)
Özünü yoxla: 3 sual
  1. 8 kq cisim üfüqi səthdə sürüşür, μ = 0,25. Sürtünmə qüvvəsi? f = 0,25·80 = 20 N.
  2. 10 kq cisim, μ_s = 0,5, μ_k = 0,4. İtələyən qüvvə 30 N, sonra 60 N olanda sürtünmə? 30 N-da durur: f = 30 N. 60 N-da sürüşür: f = 0,4·100 = 40 N.
  3. 2 kq kitab divara sıxılıb, μ = 0,4. Ən az hansı qüvvə lazımdır? F = mg/μ = 20/0,4 = 50 N.

Dərs 2. Üfüqi səthdə sürtünmə ilə hərəkət

1 Niyə lazımdır

Qutunu döşəmədə sürüşdürürsən, avtomobil əyləc edir, şayba buzda yavaş-yavaş dayanır. Hamısı eyni sxemdir: hərəkət istiqamətində bir qüvvə (dartıcı), əks istiqamətdə sürtünmə.

2 Dartılan qutu

Şaquli: N = mg (cisim batmır, qalxmır). Üfüqi: F − f = ma, f = μN = μmg.

a = (F − μmg) / m
Nümunə. 4 kq qutu, F = 20 N, μ = 0,25. f = 0,25·40 = 10 N a = (20 − 10)/4 = 2,5 m/s² Əgər F = 8 N olsaydı (f_max = 10 N-dan kiçik) və cisim əvvəlcə sükunətdə olsaydı (μ statik əmsal kimi götürülür): cisim tərpənməzdi, a = 0, f = 8 N.

3 Əyləc: yalnız sürtünmə yavaşıdır

Cisimə ilkin sürət verilib, dartan qüvvə yoxdur. Yalnız sürtünmə yavaşıdır: ma = μmg → a = μg. Kütlə ixtisar olunur. Dayanana qədər yol və vaxt (sabit yavaşıma):

a = μ·g s = v₀² / (2μg) t = v₀ / (μg)
72 km/saat = 20 m/s sürətlə gedən avtomobil təkərləri bloklaşdırıb sürüşür. Quru asfalt μ = 0,5: a = 5, s = 400/10 = 40 m Yaş yol μ = 0,25: a = 2,5, s = 400/5 = 80 m Buz μ = 0,1: a = 1, s = 400/2 = 200 m
Həyatdan. Yaş yolda əyləc yolu 2 dəfə, buzda 5 dəfə uzanır. Üstəlik, s ~ v²: sürət 2 dəfə artarsa yol 4 dəfə artır. Ona görə yağışda sürəti azaltmaq lazımdır. Yük maşınında qutu platformada sürüşməməsi üçün maşının maksimal yavaşıması qutunun μg-sindən böyük olmamalıdır.

4 İplə bağlı cisimlər + sürtünmə

Nyuton dərsindəki qayda eynidir, sadəcə hər cismə sürtünmə əlavə olunur. Hamısını bir cisim kimi götür:

a = F / (m₁ + m₂) − μg T = m₁ · (a + μg)
m₁ = 2 kq (arxada), m₂ = 3 kq, F = 30 N, μ = 0,2 (hər ikisi üçün). a = 30/5 − 0,2·10 = 6 − 2 = 4 m/s² m₁ üçün: T − μm₁g = m₁a → T = 2·(4 + 2) = 12 N Yoxla m₂: F − T − μm₂g = 30 − 12 − 6 = 12 = 3·4 ✓

5 Bucaq altında dartma

Qutunu yuxarı-irəli (üfüqlə α bucağı altında) dartanda qüvvənin şaquli toplananı cismi qismən qaldırır, N azalır, sürtünmə də azalır. Üfüqi toplanan isə F cos α-dır:

N = mg − F·sin α a = (F·cos α − μN) / m
5 kq, F = 25 N, α = 37° (sin 0,6; cos 0,8), μ = 0,2. N = 50 − 15 = 35 N, f = 0,2·35 = 7 N F cos α = 20 N → a = (20 − 7)/5 = 2,6 m/s² Aşağı itələsən (α bucağı ilə aşağı): N = mg + F sin α — sürtünmə artır.

6 Özünü yoxla

Tipik səhvlər
  • f = μ·m yazmaq (g unudulur) və ya f = μ·m·g-ni vahidsiz buraxmaq.
  • Sürtünməni F-ə əlavə etmək: a = (F + f)/m. Sürtünmə hərəkətin əksinədir, çıxılır.
  • Bucaq altında dartanda hələ də N = mg götürmək.
  • Əyləc yolunda kütləni düstura salmaq — s = v²/(2μg) kütlədən asılı deyil.
Yadda saxla
a = (F − μmg)/m (F tətbiq olunan, f = μmg) Əyləc: a = μg, s = v₀²/(2μg), t = v₀/(μg) Bağlı cisimlər: a = F/(m₁+m₂) − μg, T = m_arxa(a + μg) Bucaq altında: N = mg − F sin α
Özünü yoxla: 3 sual
  1. 5 kq cismi F = 25 N ilə dartırlar, μ = 0,2. a = ? a = (25 − 10)/5 = 3 m/s².
  2. 10 m/s sürətlə sürüşən şayba μ = 0,25 olan buzda neçə metr gedər? a = 2,5; s = 100/5 = 20 m.
  3. 2 kq və 4 kq iplə bağlı, 4 kq-lıq F = 24 N ilə dartılır, μ = 0,1. a və T? a = 24/6 − 1 = 3 m/s²; T = 2·(3 + 1) = 8 N.

Dərs 3. Sürtünməsiz maili müstəvi

1 Niyə lazımdır

Uşaq parkındakı sürüşmə, dağ yolu, xizək yamacı, yük maşınına qutu qaldırmaq üçün qoyulan taxta — hamısı maili müstəvidir. Üfüqlə bucaq altında duran düz səth. Burada qüvvələr müxtəlif istiqamətə baxır: ağırlıq düz aşağı, dayaq reaksiyası səthə perpendikulyar. Çətinlik də budur. Həll yolu: ağırlığı iki hissəyə bölmək.

2 Ağırlığı iki hissəyə bölək

Qara ox — mg. Qırmızı: müstəvi boyu aşağı çəkən hissə mg·sin α. Yaşıl: müstəviyə basan hissə mg·cos α. Üçü düzbucaqlı üçbucaq yaradır: mg — hipotenuz, iki hissə — katetlər. Mavi: N.

müstəvi boyu aşağı: mg · sin α müstəviyə perpendikulyar: mg · cos α N = mg · cos α

Yoxlama ən sadə hallarda: α = 0° (düz yer) → sin 0° = 0: sürüşdürən hissə sıfırdır ✓; cos 0° = 1: bütün ağırlıq yerə basır ✓. α = 90° (divar) → sin 90° = 1: bütün ağırlıq "boyu" — sərbəst düşmə ✓; cos 90° = 0: divara basmır ✓. Sin ilə cos-u qarışdırsan, bu yoxlama dərhal bildirər.

α30°37°45°53°60°
sin α0,50,60,710,80,87
cos α0,870,80,710,60,5

3 Sürtünmə yoxdursa: a = g·sin α

Sürtünmə yoxdursa, müstəvi boyu yalnız mg·sin α qalır. Perpendikulyar istiqamətdə cisim hərəkət etmir — N ilə mg·cos α bir-birini tarazlayır. Nyutonun II qanunu:

m · a = m · g · sin α Hər iki tərəfi m-ə bölək: a = g · sin α

Kütlə yoxdur! Yüngül və ağır cisim hamar müstəvidə eyni təcillə sürüşür. Sərbəst düşmədə də belə idi — maili müstəvi "yavaşladılmış düşmədir". Qalileo düşməni öyrənmək üçün məhz maili müstəvidən istifadə edib: cisim yavaş hərəkət etdiyi üçün vaxtı ölçmək asan olurdu.

g = 10: α = 30°: a = 10·0,5 = 5 m/s² α = 37°: a = 10·0,6 = 6 m/s² α = 53°: a = 10·0,8 = 8 m/s² α = 90°: a = 10 m/s² ← sərbəst düşmə N = mg·cos α: 2 kq cisim, 37°: N = 20·0,8 = 16 N (mg = 20 N-dan kiçik!)

4 Kinematika ilə birləşdirmək

Təcili tapdıqdan sonra kinematika düsturları işləyir.

Hamar müstəvi 30°, uzunluğu 10 m. Cisim yuxarıdan sükunətdən buraxılır. a = 10·0,5 = 5 m/s² v² = 2aL = 2·5·10 = 100 → v = 10 m/s Vaxt: L = at²/2 → t² = 2·10/5 = 4 → t = 2 s Yuxarı atılma. 37° hamar müstəvi boyu yuxarı 6 m/s başlanğıc sürət verilib. Yavaşıma da a = g·sin 37° = 6 m/s² (təcil aşağı yönəlib) L = v₀²/(2a) = 36/12 = 3 m yuxarı qalxar
Həyatdan: buzlu yamac. Qışda buz bağlamış 37° yamacda ayağın sürüşsə, təcilin 6 m/s² olar — 2 saniyədən sonra sürətin 12 m/s (43 km/saat). Ona görə buzlu yamac təhlükəlidir: sürtünmə yox olanda cisim demək olar ki, sərbəst düşür.

5 Özünü yoxla

Tipik səhvlər
  • Maili müstəvidə N = mg yazmaq. Düzü: N = mg·cos α, mg-dən kiçikdir.
  • Sin ilə cos-u qarışdırmaq: yoxla α = 0° və α = 90° üçün.
  • a = g·cos α yazmaq. Sürüşdürən hissə sin-lidir (α qarşı katetdir).
  • Kütləni cavabda saxlamaq: sürtünməsiz təcil kütlədən asılı deyil.
Yadda saxla
Ağırlığın hissələri: mg·sin α (boyu aşağı), mg·cos α (basır) N = mg·cos α Hamar müstəvi: a = g·sin α (aşağı hər iki istiqamətdə) Yoxlama: α = 0° → a = 0; α = 90° → a = g
Özünü yoxla: 3 sual
  1. Hamar 37° müstəvidə cismin təcili və 2 s-dən sonra sürəti? a = 6 m/s²; v = 12 m/s.
  2. 53°-li hamar müstəvidə 5 kq cisim üçün N və a? N = 50·0,6 = 30 N; a = 10·0,8 = 8 m/s².
  3. 30° hamar müstəvi boyu yuxarı 10 m/s ilə atılan cisim neçə metr qalxar? a = 5; L = 100/10 = 10 m.

Dərs 4. Sürtünmə ilə maili müstəvi

1 Sürtünmə nə qədərdir

Maili müstəvidə N = mg·cos α, deməli sürtünmənin ən böyük qiyməti:

f_max = μ · m · g · cos α

Bu qüvvə müstəvi boyu, cismin hərəkət etdiyi (və ya etmək istədiyi) istiqamətin əksinə yönəlir: aşağı sürüşən cismə yuxarı, yuxarı gedənə aşağı.

2 Üç hal: durur, bərabər sürüşür, sürətlənir

İki qüvvəni müqayisə et: aşağı çəkən mg·sin α və saxlayan sürtünmə μ·mg·cos α. Hər ikisində mg var — ixtisar et, cos α-ya böl (sin ÷ cos = tg):

müqayisənə baş verir
tg α ≤ μ_scisim durur — sürtünmə saxlaya bilir
tg α = μitələsən, sabit sürətlə sürüşür (F_əv = 0)
tg α > μcisim sürətlənərək sürüşür

Cisim durursa, sürtünmə tam lazım olan qədərdir: f = mg·sin α (ağırlığın boyu toplananı), μN deyil.

5 kq cisim 37° müstəvidə, μ_s = 0,9. tg 37° = 0,75 < 0,9 → durur. f = mg·sin α = 50·0,6 = 30 N (ən böyük mümkün: 0,9·50·0,8 = 36 N — hamısını işlətmir)

3 Aşağı sürüşəndə təcil

m·a = (aşağı çəkən) − (sürtünmə) m·a = mg·sin α − μ·mg·cos α | m-ə böl a = g·sin α − μ·g·cos α
a = g · (sin α − μ · cos α)

Yoxlama: μ = 0 → a = g·sin α, əvvəlki dərsdəki kimi ✓. Kütlə yenə yoxdur.

37°, μ = 0,25: a = 10·(0,6 − 0,25·0,8) = 10·0,4 = 4 m/s² 37°, μ = 0,75: a = 10·(0,6 − 0,6) = 0 — sərhəd (tg 37° = μ) 53°, μ = 0,5: a = 10·(0,8 − 0,5·0,6) = 5 m/s²

Cisim aşağı sürüşür. mg aşağı, N müstəviyə perpendikulyar, f = μN müstəvi boyu yuxarı (hərəkətin əksinə). mg iki hissəyə bölünür: boyu mg·sin α — aşağı çəkir, mg·cos α — N-i tarazlayır.

4 Yuxarı hərəkət

Cismi müstəvi boyu yuxarı itələdin və buraxdın. İndi sürtünmə aşağı yönəlib, ağırlığın hissəsi də aşağı. İki qüvvə eyni tərəfə baxır — toplanır:

a = g · (sin α + μ · cos α) (yavaşıma, yuxarı gedəndə)

Qayda: sürtünmə həmişə hərəkətə mane olur. Aşağı gedəndə təcili azaldır, yuxarı gedəndə yavaşımanı artırır.

Məsələ 1. 37°, μ = 0,25. Cismə yuxarı 8 m/s verildi. Nə qədər qalxar? a = 10·(0,6 + 0,25·0,8) = 8 m/s² (yavaşıma) L = v₀²/(2a) = 64/16 = 4 m Məsələ 2. 20 kq yükü 37° müstəvi boyu yuxarı SABİT sürətlə dartmaq üçün qüvvə? F = mg·sin α + μ·mg·cos α = 200·(0,6 + 0,25·0,8) = 200·0,8 = 160 N (Sürtünməsiz olsaydı 120 N. Pandus qüvvədən qazandırır, amma yol uzanır.)
Həyatdan: niyə pandus "qüvvə qənaət edir". 50 kq qutunu 1 m hündürlüyə birbaşa qaldırmaq üçün 500 N lazımdır. 30°-li hamar taxta ilə dartsan: 500·0,5 = 250 N — iki dəfə az. Amma yol iki dəfə uzundur (1 m əvəzinə 2 m). Qüvvədən qazanırsan, yoldan itirirsən — bu, mexanikanın "qızıl qaydası"dır.

5 Evdə təcrübə və həyat

μ-ni ölç. Kitabı masaya qoy, üstünə sikkə qoy. Kitabın bir ucunu yavaş-yavaş qaldır. Sikkə sürüşməyə başladığı anda dayan və bucağı telefonun Measure → Level funksiyası ilə ölç. Sürüşmə həddində tg α = μ_s. Məsələn, 17°-də sürüşdüsə: μ_s = tg 17° ≈ 0,31. Bir ölçmə ilə sürtünmə əmsalını tapdın. Bucaq əvəzinə hündürlüyü də ölçə bilərsən: tg α = h/b (h — qaldırılmış ucun hündürlüyü, b — kitabın masadakı izinin uzunluğu).
Niyə maşın yamacda durur. Yaş asfaltda μ ≈ 0,5 → maşın tg α ≤ 0,5, yəni təxminən 27°-yə qədər yamacda əyləclə dura bilər. Buzda μ ≈ 0,1 → yalnız ~6°-yə qədər. Ona görə qışda kiçik yamacda da maşınlar sürüşür.

6 Özünü yoxla

Tipik səhvlər
  • Maili müstəvidə N = mg yazmaq. Düzü: N = mg·cos α.
  • Sürtünməni μ·mg·sin α yazmaq. Sürtünmə N-dən asılıdır → cos.
  • Sin ilə cos-u qarışdırmaq — yoxla: α = 0°-də aşağı çəkən qüvvə 0 olmalıdır.
  • Cisim durursa, sürtünməni yenə μN götürmək. Durursa, sürtünmə mg·sin α-dır.
  • Yuxarı gedəndə sürtünməni də aşağı çəkən qüvvənin əksinə yazmaq: yuxarı gedəndə o, aşağıdır.
Yadda saxla — bütün mövzu
Ağırlığın hissələri: boyu mg·sin α, basır mg·cos α; N = mg·cos α Sürtünmə (max): μ·mg·cos α Durur: tg α ≤ μ_s (f = mg·sin α) Sabit sürətlə sürüşür: tg α = μ Aşağı sürüşür: a = g(sin α − μ cos α) Yuxarı gedir: a = g(sin α + μ cos α) (yavaşıma) Sabit sürətlə yuxarı dartma: F = mg(sin α + μ cos α) Yoxlama: α = 0° → çəkən 0; α = 90° → sərbəst düşmə
Özünü yoxla: 3 sual
