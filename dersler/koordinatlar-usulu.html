Koordinatlar üsulu: məsafə, orta nöqtə, düz xətt və çevrə tənliyi

Nöqtəni iki ədədlə — koordinatları ilə — yazanda həndəsə hesaba çevrilir. Məsafəni xətkeşsiz, orta nöqtəni pərgarsız tapırsan; düz xətt və çevrə isə tənliyə çevrilir. Bu dörd düstur imtahanda hər il çıxır.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. İki nöqtə arasındakı məsafə

1 Niyə lazımdır

Xəritə tətbiqi iki ünvan arasındakı "quş uçuşu" məsafəni dərhal göstərir. O, heç nə ölçmür — sadəcə iki nöqtənin koordinatlarını bir düsturda yerinə qoyur. Bu düsturu indi öyrənəcəksən.

2 Əsas fikir

Nöqtə A(x; y) kimi yazılır: birinci ədəd — absis (x), ikinci — ordinat (y). A və B nöqtələrini birləşdir, sonra A-dan üfüqi, B-dən şaquli xətt çək. Düzbucaqlı üçbucaq alınır: katetləri koordinatların fərqləridir, hipotenuzu isə AB-dir. Pifaqor teoremi qalanını edir.

A(x₁; y₁), B(x₂; y₂): AB = √((x₂ − x₁)² + (y₂ − y₁)²) O(0; 0)-dan A(x; y)-ə qədər: OA = √(x² + y²)

A(1; 2), B(4; 6): üfüqi katet 4 − 1 = 3, şaquli katet 6 − 2 = 4. AB = √(9 + 16) = 5.

3 Həll olunmuş nümunələr

1) A(1; 2), B(4; 6) x₂ − x₁ = 3, y₂ − y₁ = 4 AB = √(9 + 16) = √25 = 5 2) A(−2; 3), B(4; −1) x₂ − x₁ = 4 − (−2) = 6, y₂ − y₁ = −1 − 3 = −4 AB = √(36 + 16) = √52 = √(4 · 13) = 2√13 3) O(0; 0) və A(5; −12) OA = √(25 + 144) = √169 = 13
Həyatdan. Şəhər xəritəsində hər vahid 100 m-dir. Ev E(1; 1), məktəb M(7; 9) nöqtəsindədir. Düz xətt boyunca məsafə: √(6² + 8²) = 10 vahid, yəni 1000 m. Küçələrlə yol bundan uzun olacaq, amma dron məhz 1 km uçacaq.
Tipik səhvlər
  • Mənfi ədədi çıxanda işarəni itirmək: 4 − (−2) = 6, 2 yox.
  • Fərqləri toplayıb sonra kvadrata yüksəltmək: (6 + (−4))² = 4 — səhvdir. Hər fərq ayrıca kvadrata yüksəlir.
  • Kökü almağı unutmaq: AB² = 25 → AB = 5, 25 yox. Kökü sadələşdir: √52 = 2√13.
Yadda saxla
AB = √((x₂ − x₁)² + (y₂ − y₁)²) Fərqlərin sırası nəticəni dəyişmir, çünki kvadrata yüksəldilir, amma fərqi düz hesabla.
Özünü yoxla: 3 sual
  1. O(0; 0) və A(6; 8) arasındakı məsafə? √(36 + 64) = 10.
  2. A(−1; 2), B(2; −2). AB = ? √(3² + (−4)²) = √25 = 5.
  3. A(1; 1), B(3; 5). AB = ? √(4 + 16) = √20 = 2√5.

Dərs 2. Parçanın orta nöqtəsinin koordinatları

1 Niyə lazımdır

İki dost iki fərqli yerdən çıxıb yolun tən ortasında görüşmək istəyir. Görüş nöqtəsi harada olacaq? Cavab sadədir — koordinatların ədədi ortası.

2 Düstur

A(x₁; y₁), B(x₂; y₂), M — AB-nin ortası: x = (x₁ + x₂)/2, y = (y₁ + y₂)/2

Tərsinə: ortası M(x; y) və bir ucu A(x₁; y₁) məlumdursa, o biri uc:

x₂ = 2x − x₁, y₂ = 2y − y₁

3 Həll olunmuş nümunələr

1) A(−3; 5), B(7; 1) x = (−3 + 7)/2 = 2, y = (5 + 1)/2 = 3 → M(2; 3) 2) A(2; −1), ortası M(5; 3). B = ? x₂ = 2 · 5 − 2 = 8, y₂ = 2 · 3 − (−1) = 7 → B(8; 7) 3) ABCD paraleloqramı: A(1; 1), B(5; 2), C(6; 6). D = ? Paraleloqramın diaqonalları kəsişmə nöqtəsində yarıya bölünür: AC-nin ortası = BD-nin ortası. AC-nin ortası: (3,5; 3,5) D: x = 2 · 3,5 − 5 = 2, y = 2 · 3,5 − 2 = 5 → D(2; 5)
Həyatdan. Elvin A(−2; 4), dostu B(6; −2) nöqtəsindədir (1 vahid = 100 m). Görüş yeri: ((−2 + 6)/2; (4 + (−2))/2) = (2; 1). Hər biri √(4² + 3²) = 5 vahid, yəni 500 m yol gedəcək.
Tipik səhvlər
  • Koordinatları toplamaq əvəzinə çıxmaq: orta nöqtədə cəm, məsafədə fərq var.
  • 2-yə bölməyi unutmaq.
  • Ucu taparkən sadəcə x − x₁ yazmaq. Düzü: 2x − x₁.
Yadda saxla
Orta nöqtə = koordinatların ədədi ortası M = ((x₁ + x₂)/2; (y₁ + y₂)/2) Uc: B = (2x − x₁; 2y − y₁)
Özünü yoxla: 3 sual
  1. A(4; −2), B(−2; 6). Orta nöqtə? ((4 − 2)/2; (−2 + 6)/2) = (1; 2).
  2. A(0; 3), ortası M(2; 0). B = ? (2 · 2 − 0; 2 · 0 − 3) = (4; −3).
  3. A(1; 2), B(4; 7). Orta nöqtənin absisi? (1 + 4)/2 = 2,5.

Dərs 3. İki nöqtədən keçən düz xəttin tənliyi

1 Niyə lazımdır

Taksi 2 km üçün 3 manat, 6 km üçün 5 manat alır. Qiymət məsafədən xətti asılıdırsa, iki məlumatdan bütün qiymət cədvəlini qurmaq olar: iki nöqtə bir düz xətti tam təyin edir.

2 Bucaq əmsalı və tənlik

Şaquli olmayan hər düz xəttin tənliyi y = kx + b şəklindədir. k — bucaq əmsalıdır: x 1 vahid artanda y nə qədər dəyişir. b — düz xəttin Oy oxunu kəsdiyi nöqtənin ordinatıdır.

A(x₁; y₁), B(x₂; y₂), x₁ ≠ x₂: k = (y₂ − y₁)/(x₂ − x₁) b = y₁ − k·x₁

Əgər A ≠ B və x₁ = x₂-dirsə, düz xətt şaquli olur: x = x₁ (eyni iki nöqtə düz xətti müəyyən etmir).

3 Həll olunmuş nümunələr

1) A(1; 3), B(3; 7) k = (7 − 3)/(3 − 1) = 4/2 = 2 b = 3 − 2 · 1 = 1 → y = 2x + 1 Yoxla B ilə: 2 · 3 + 1 = 7 ✓ 2) A(−2; 5), B(4; 2) k = (2 − 5)/(4 − (−2)) = −3/6 = −1/2 b = 5 − (−1/2) · (−2) = 5 − 1 = 4 → y = −(1/2)x + 4 Yoxla B ilə: −2 + 4 = 2 ✓

4 Paralel və perpendikulyar düz xətlər

y = k₁x + b₁ və y = k₂x + b₂: paraleldir ⇔ k₁ = k₂ (b₁ ≠ b₂) perpendikulyardır ⇔ k₁ · k₂ = −1 (üfüqi xəttə (k = 0) perpendikulyar xətt şaquli olur: x = const)
P(2; 1) nöqtəsindən keçən və y = 2x + 3-ə perpendikulyar düz xətt: k₂ = −1/2 (çünki 2 · (−1/2) = −1) 1 = −1/2 · 2 + b → b = 2 Cavab: y = −(1/2)x + 2 P(2; 1)-dən keçən və y = 2x + 3-ə paralel düz xətt: k = 2, 1 = 2 · 2 + b → b = −3 Cavab: y = 2x − 3
Həyatdan. Taksi: (2; 3) və (6; 5) nöqtələri. k = (5 − 3)/(6 − 2) = 0,5 manat hər km üçün, b = 3 − 0,5 · 2 = 2 manat — minimum ödəniş. Tənlik y = 0,5x + 2: 10 km üçün 7 manat.
Tipik səhvlər
  • k-nı tərsinə yazmaq: (x₂ − x₁)/(y₂ − y₁). Surətdə həmişə y-lərin fərqi durur.
  • Surətdə və məxrəcdə nöqtələrin sırasını qarışdırmaq: yuxarıda y₂ − y₁-dirsə, aşağıda da x₂ − x₁ olmalıdır.
  • Perpendikulyarda yalnız işarəni dəyişmək: 2-yə perpendikulyar −2 deyil, −1/2-dir.
Yadda saxla
k = (y₂ − y₁)/(x₂ − x₁), b = y₁ − k·x₁ Paralel: k eyni. Perpendikulyar: k₂ = −1/k₁ (k₁ ≠ 0).
Özünü yoxla: 3 sual
  1. A(0; −1), B(2; 5) nöqtələrindən keçən düz xəttin tənliyi? k = 6/2 = 3, b = −1 → y = 3x − 1.
  2. (1; 1)-dən keçən və y = 4x − 2-yə paralel düz xəttin b-si? 1 = 4 · 1 + b → b = −3.
  3. y = −3x + 1-ə perpendikulyar düz xəttin bucaq əmsalı? −1/(−3) = 1/3.

Dərs 4. Çevrənin tənliyi

1 Niyə lazımdır

Wi-Fi ötürücüsü 10 m radiusda işləyir. Sənin stulun siqnal zonasındadırmı? Zonanın sərhədi çevrədir, sual isə "nöqtədən mərkəzə qədər məsafə R-dən kiçikdirmi?" sualıdır.

2 Tənlik

Çevrə — mərkəzdən eyni R məsafədə olan nöqtələrdir. Mərkəz (a; b), nöqtə (x; y): məsafə düsturunu kvadrata yüksəlt.

(x − a)² + (y − b)² = R² mərkəz (a; b), radius R, R > 0

Mərkəz O(0; 0)-dadırsa: x² + y² = R². Diqqət: mötərizədə x + 3 yazılıbsa, a = −3-dür.

Mərkəz (1; 2), A(4; 6): R = √(3² + 4²) = 5. Tənlik: (x − 1)² + (y − 2)² = 25.

3 Həll olunmuş nümunələr

1) Mərkəz (2; −1), R = 3: (x − 2)² + (y + 1)² = 9 2) (x + 3)² + (y − 4)² = 25: mərkəz (−3; 4), R = 5 3) Mərkəz (1; 2), çevrə A(4; 6)-dan keçir: R = √((4 − 1)² + (6 − 2)²) = 5 (x − 1)² + (y − 2)² = 25 4) x² + y² − 4x + 6y − 12 = 0 x² − 4x = (x − 2)² − 4, y² + 6y = (y + 3)² − 9 (x − 2)² − 4 + (y + 3)² − 9 − 12 = 0 (x − 2)² + (y + 3)² = 25 → mərkəz (2; −3), R = 5
Həyatdan. Ötürücü O(0; 0)-da, radius 10 m. Stul (6; 7)-dədir: 6² + 7² = 85 < 100 — zonadasan. Masa (8; 7)-dədir: 64 + 49 = 113 > 100 — siqnal yoxdur. Kök almağa ehtiyac yoxdur: R² ilə müqayisə et.
Tipik səhvlər
  • Sağ tərəfi radius saymaq: … = 25-də R = 5-dir, 25 yox.
  • Mərkəzin işarəsini səhv götürmək: (x + 3)² → a = −3.
  • Tam kvadrat ayıranda çıxılan ədədi unutmaq: x² − 4x = (x − 2)² − 4.
Yadda saxla
(x − a)² + (y − b)² = R² → mərkəz (a; b), radius R Mötərizədəki işarəni tərsinə çevir. Sağ tərəfdən kök al.
Özünü yoxla: 3 sual
  1. (x − 5)² + (y + 2)² = 49. Mərkəz və radius? Mərkəz (5; −2), R = 7.
  2. Mərkəzi O(0; 0), A(−3; 4)-dən keçən çevrənin tənliyi? R = 5: x² + y² = 25.
  3. x² + y² + 2x − 8 = 0. Radius? (x + 1)² − 1 + y² − 8 = 0 → (x + 1)² + y² = 9 → R = 3.
