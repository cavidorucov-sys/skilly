Riyaziyyat · Buraxılış · DİM: Rasional ifadələr

Rasional ifadələrin çevrilməsi, DMQ

Hərfli kəsrlər: (x² − 9)/(x + 3), 1/x + 2/(x − 1). Onlarla adi kəsrlər kimi işləyirik — ixtisar edirik, toplayırıq, vururuq, bölürük. Fərq ikidir: əvvəl hər şeyi vuruqlara ayırmaq lazımdır və məxrəci sıfır edən qiymətləri (DMQ) yadda saxlamaq lazımdır.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Rasional ifadə, DMQ və kəsrin ixtisarı

1 Niyə lazımdır

24/36 kəsrini 2/3 kimi yazırsan — ixtisar edirsən. Hərfli kəsrlərdə də eyni iş görülür, sadəcə ortaq vuruğu görmək üçün əvvəl surəti və məxrəci vuruqlara ayırmaq lazımdır. İmtahanda "sadələşdirin" sualları məhz budur.

2 Rasional ifadə və DMQ

Rasional ifadə — ədədlərdən və dəyişənlərdən toplama, çıxma, vurma, bölmə və natural üstlü qüvvət ilə qurulan ifadədir. Dəyişənə bölmə varsa, bu, kəsr ifadədir: 5/(x − 2).

DMQ (dəyişənin mümkün qiymətləri) — ifadənin mənası olan bütün qiymətlər. Qayda bir dənədir: məxrəc sıfır ola bilməz.

x/(x² − 4) + 3/x x² − 4 = 0 → x = ±2; x = 0 DMQ: x ≠ −2; 0; 2

3 Kəsrin əsas xassəsi və ixtisar

A/B = (A·C)/(B·C), C ≠ 0 İxtisar: surəti və məxrəci vuruqlara ayır, ortaq VURUĞU ixtisar et.
1) (x² − 9)/(x² + 3x) = (x − 3)(x + 3)/(x(x + 3)) = (x − 3)/x DMQ: x ≠ 0, x ≠ −3 2) (x² − 5x + 6)/(2x − 6) = (x − 2)(x − 3)/(2(x − 3)) = (x − 2)/2 DMQ: x ≠ 3 3) (a² − 2ab + b²)/(b − a) = (a − b)²/(−(a − b)) ← b − a = −(a − b) = −(a − b) = b − a
Həyatdan. Ekskursiya üçün 120 manat x şagird arasında bölünür — hərəyə 120/x manat. Bu, kəsr ifadədir və onun DMQ-su x ≠ 0-dır: şagird yoxdursa, bölmək mənasızdır.
Tipik səhvlər
  • Toplananı ixtisar etmək: (x + 3)/x ≠ 3. Yalnız vuruq ixtisar olunur — əvvəl vuruqlara ayır.
  • DMQ-nu ixtisardan sonra yazmaq. (x² − 9)/(x² + 3x)-də x = −3 ixtisardan sonra görünmür, amma yenə qadağandır.
  • b − a ilə a − b-ni eyni saymaq. Onlar əks ədədlərdir: b − a = −(a − b).
Yadda saxla
DMQ: hər məxrəc ≠ 0 (ixtisardan ƏVVƏL). İxtisar: vuruqlara ayır → ortaq vuruğu at. Toplananı yox, vuruğu ixtisar et.
Özünü yoxla: 3 sual
  1. (x² − 16)/(x + 4) kəsrini ixtisar et. (x − 4)(x + 4)/(x + 4) = x − 4, x ≠ −4.
  2. (5x − 10)/(x² − 4) kəsrini ixtisar et. 5(x − 2)/((x − 2)(x + 2)) = 5/(x + 2), x ≠ ±2.
  3. 7/(x² − 3x) ifadəsinin DMQ-su nədir? x(x − 3) ≠ 0 → x ≠ 0, x ≠ 3.

Dərs 2. Rasional ifadələrin toplanması və çıxılması

1 Niyə lazımdır

Birgə iş, orta sürət, borular — bu məsələlərdə hər dəfə 1/x + 1/y kimi kəsrləri toplamaq lazım gəlir. Qayda adi kəsrlərdəki kimidir: ortaq məxrəc.

2 Qayda

A/C ± B/C = (A ± B)/C A/B ± C/D = (A·D ± B·C)/(B·D)

Ən kiçik ortaq məxrəci tapmaq üçün məxrəcləri vuruqlara ayır — ƏKOB kimi: hər vuruq bir dəfə, ən böyük qüvvəti ilə.

3 Həll olunmuş nümunələr

1) x²/(x − 3) − 9/(x − 3) = (x² − 9)/(x − 3) = (x − 3)(x + 3)/(x − 3) = x + 3 2) 1/(x − 2) + 1/(x + 2) = ((x + 2) + (x − 2))/((x − 2)(x + 2)) = 2x/(x² − 4) 3) 2/(x − 3) − 12/(x² − 9) Ortaq məxrəc: x² − 9 = (x − 3)(x + 3) = (2(x + 3) − 12)/(x² − 9) = (2x − 6)/(x² − 9) = 2(x − 3)/((x − 3)(x + 3)) = 2/(x + 3) 4) a/(a − b) + b/(b − a) = a/(a − b) − b/(a − b) = (a − b)/(a − b) = 1
Həyatdan. Bir boru hovuzu x saata, ikincisi x + 2 saata doldurur. Bir saatda birlikdə: 1/x + 1/(x + 2) = (2x + 2)/(x(x + 2)) hissə. x = 4 olsa: 10/24 = 5/12 hissə saatda.
Tipik səhvlər
  • Surətləri və məxrəcləri ayrıca toplamaq: 1/x + 1/y ≠ 2/(x + y).
  • Surəti əlavə vuruğa vurmağı unutmaq: 2/(x − 3) − 12/(x² − 9)-də 2-ni (x + 3)-ə vurmaq lazımdır.
  • Kəsrin qarşısındakı mənfini bütün surətə tətbiq etməmək: − (x − 3)/x = (−x + 3)/x.
Yadda saxla
Məxrəcləri vuruqlara ayır → ortaq məxrəc Hər surəti çatışmayan vuruğa vur → topla Sonda yenə ixtisar etməyə çalış.
Özünü yoxla: 3 sual
  1. x/(x − 1) − 1/(x − 1) = ? (x − 1)/(x − 1) = 1 (x ≠ 1).
  2. 1/x − 1/(x + 1) = ? (x + 1 − x)/(x(x + 1)) = 1/(x(x + 1)).
  3. 3/(x + 2) + 6/(x² − 4) sadələşdir. (3(x − 2) + 6)/(x² − 4) = 3x/(x² − 4).

Dərs 3. Vurma, bölmə və qüvvətə yüksəltmə

1 Niyə lazımdır

Vurma və bölmə toplamadan asandır — ortaq məxrəc lazım deyil. Amma bir şərt var: vurmazdan əvvəl hər şeyi vuruqlara ayır, yoxsa ixtisar olunan vuruqları görməyəcəksən və nəhəng ifadə alınacaq.

2 Qaydalar

A/B · C/D = (A·C)/(B·D) A/B : C/D = A/B · D/C (C ≠ 0!) (A/B)ⁿ = Aⁿ/Bⁿ

Bölmədə ikinci kəsri çevirib vururuq. Diqqət: bölən kəsrin surəti də sıfır ola bilməz — DMQ-ya bir qadağan qiymət də əlavə olunur.

3 Həll olunmuş nümunələr

1) (x² − 4)/(3x) · 6x²/(x + 2) = (x − 2)(x + 2)·6x² / (3x·(x + 2)) = 2x(x − 2)
2) (x² − 9)/(x² + 3x) : (x − 3)/(5x) = (x − 3)(x + 3)/(x(x + 3)) · 5x/(x − 3) = 5 DMQ: x ≠ 0, x ≠ −3 (məxrəclər), x ≠ 3 (bölən sıfır olmasın)
3) (x² − 5x + 6)/(x² − 16) : (x − 2)/(x + 4) = (x − 2)(x − 3)/((x − 4)(x + 4)) · (x + 4)/(x − 2) = (x − 3)/(x − 4) 4) (2a/b²)³ = 8a³/b⁶
Həyatdan. Sürət = yol : vaxt. Maşın (x² − 1) km yolu (x − 1) saata gedirsə, sürəti (x² − 1)/(x − 1) = x + 1 km/saat. x = 61 olsa — 3720 km 60 saata, sürət 62 km/saat.
Tipik səhvlər
  • Bölmədə ikinci kəsri çevirməmək: A/B : C/D ≠ (A·C)/(B·D).
  • Bölən kəsrin surətini DMQ-da unutmaq (nümunə 2-də x ≠ 3).
  • Qüvvətdə yalnız surəti yüksəltmək: (3x/y)² = 9x²/y², 9x²/y yox.
Yadda saxla
Vurma: surət·surət, məxrəc·məxrəc. Bölmə: ikincini çevir və vur. Əvvəl vuruqlara ayır, sonra ixtisar et, sonra vur.
Özünü yoxla: 3 sual
  1. x/y · y²/x² = ? y/x.
  2. (a² − 1)/a : (a − 1)/a² = ? (a − 1)(a + 1)/a · a²/(a − 1) = a(a + 1).
  3. (3x/y)² = ? 9x²/y².

Dərs 4. Eynilik çevrilmələri: sadələşdir, sonra hesabla

1 Niyə lazımdır

"İfadənin x = 98 olduqda qiymətini tapın." Ədədi birbaşa qoysan, böyük kəsrlərlə əziyyət çəkəcəksən. Əvvəl sadələşdirsən, çox vaxt cavab bir addımda çıxır. DİM məhz bunu yoxlayır.

2 Plan

1. DMQ-nu yaz. 2. Mötərizələrin içini sadələşdir. 3. Vur / böl, vuruqlara ayır, ixtisar et. 4. Qiyməti yerinə qoy (DMQ-dadırmı?).

3 Həll olunmuş nümunələr

1) (x/(x − 2) − 1) : 2/(x² − 4), x = 98 x/(x − 2) − 1 = (x − x + 2)/(x − 2) = 2/(x − 2) 2/(x − 2) · (x − 2)(x + 2)/2 = x + 2 x = 98: 100
2) x/y = 3 olarsa, (2x + y)/(x − y) = ? Surəti və məxrəci y-ə böl: (2·x/y + 1)/(x/y − 1) = (2·3 + 1)/(3 − 1) = 7/2
3) a + 1/a = 5 olarsa, a² + 1/a² = ? (a + 1/a)² = a² + 2·a·(1/a) + 1/a² = a² + 2 + 1/a² a² + 1/a² = 25 − 2 = 23

4 Tələ: DMQ-dan kənar qiymət

(x² − 1)/(x − 1), x = 1 olduqda? Sadələşdirsən: x + 1 → "2"? Yox! x = 1 olanda məxrəc sıfırdır. İfadənin bu nöqtədə qiyməti YOXDUR.
Həyatdan: orta sürət. Maşın şəhərə 40 km/saat, geri 60 km/saat sürətlə gedir. Orta sürət 50 deyil! Yol s olsun: vaxt s/40 + s/60 = 5s/120 = s/24. Orta sürət = 2s : (s/24) = 48 km/saat. Ümumi düstur: 2uv/(u + v) — sadələşdirilmiş rasional ifadə.
Tipik səhvlər
  • Sadələşdirmədən ədədi qoyub hesabda səhv etmək. Əvvəl sadələşdir.
  • (a + 1/a)²-da orta həddi unutmaq: 2·a·(1/a) = 2.
  • Verilən qiymətin DMQ-da olduğunu yoxlamamaq.
Yadda saxla
Əvvəl sadələşdir, sonra yerinə qoy. x/y verilibsə — surəti və məxrəci y-ə böl. a² + 1/a² = (a + 1/a)² − 2 = (a − 1/a)² + 2
Özünü yoxla: 3 sual
  1. a + 1/a = 3. a² + 1/a² = ? 9 − 2 = 7.
  2. x/y = 2. (x + y)/(x − y) = ? (2 + 1)/(2 − 1) = 3.
  3. (1/(x − 1) − 1/(x + 1)) · (x² − 1) = ? 2/(x² − 1) · (x² − 1) = 2 (x ≠ ±1).
