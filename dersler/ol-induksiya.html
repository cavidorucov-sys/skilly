Riyazi induksiya

Fərz et ki, sonsuz sayda domino ardıcıl düzülüb. Birinci domino yıxılır və hər yıxılan domino növbətini yıxır — onda hamısı yıxılacaq. Riyazi induksiya məhz bu fikirdir: sonsuz sayda iddianı bir-bir yoxlamadan sübut edirsən. Düsturları "təxmin edib sübut etmək" olimpiadanın ən güclü alətlərindən biridir.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Metodun mahiyyəti və cəm düsturları

1 Niyə lazımdır

1 + 3 + 5 + 7 = 16 = 4², 1 + 3 + 5 + 7 + 9 = 25 = 5². Görünür ki, ilk n tək ədədin cəmi n²-dir. Amma bu 100 halda doğrudur deyə, 101-ci halda da doğrudur demək olarmı? Riyaziyyatda "bir neçə halda yoxladım" sübut deyil. İnduksiya bütün natural n üçün sübutu verir.

2 Üç hissə

P(n) — n-dən asılı bir iddiadır. Onu bütün natural n üçün sübut etmək üçün:

1) Baza: P(1) doğrudur (və ya ilk n₀ üçün P(n₀)). 2) Addım: P(k) doğrudur (induksiya fərziyyəsi) ⟹ P(k + 1) doğrudur. 3) Nəticə: P(n) bütün n ≥ 1 (n ≥ n₀) üçün doğrudur.

Domino bənzətməsi: baza — ilk domino yıxılır; addım — hər k-cı domino (k + 1)-ciyə toxunur. İkisindən biri çatışmasa, sübut qüvvədən düşür.

3 Həll olunmuş nümunələr

1) Sübut: 1 + 3 + 5 + … + (2n − 1) = n². Baza. n = 1: sol 1, sağ 1² = 1 ✓. Addım. 1 + 3 + … + (2k − 1) = k² fərz edək. (k + 1)-ci hədd 2(k + 1) − 1 = 2k + 1. k² + (2k + 1) = (k + 1)² — bu, P(k + 1)-dir. Nəticə. P(n) bütün n üçün doğrudur. ∎ 2) Sübut: 1 + 2 + … + n = n(n + 1)/2. Baza. n = 1: 1 = 1·2/2 ✓. Addım. k(k + 1)/2 + (k + 1) = (k + 1)(k/2 + 1) = (k + 1)(k + 2)/2 ✓ ∎ 3) Sübut: 1·1! + 2·2! + … + n·n! = (n + 1)! − 1. Baza. n = 1: 1 = 2! − 1 ✓. Addım. (k + 1)! − 1 + (k + 1)·(k + 1)! = (k + 1)!·(1 + k + 1) − 1 = (k + 2)! − 1 ✓ ∎
Həyatdan. Pilləkən: birinci pilləyə çıxa bilirsənsə və hər pillədən növbətiyə çıxa bilirsənsə, istənilən pilləyə çıxa bilərsən. Zəncirvari məktub, dominoların yıxılması, "bir addım irəli" — hamısı induksiyadır. Yalnız bir şərt: baza (başlanğıc pillə) mütləq olmalıdır.

4 İnduksiya addımını necə quraq

Cəm düsturlarında addımın texnikası eynidir: sol tərəfdə yeni hədd əlavə et, sağ tərəfin k-lı formasını k + 1-li formaya gətir. Məqsədi əvvəlcədən yaz: P(k + 1) nə olmalıdır (n əvəzinə k + 1 qoy). Sonra tərəfləri o ifadəyə çevir.

5 Olimpiada məsələləri

Məsələ 1. Sübut et: 1² + 2² + … + n² = n(n + 1)(2n + 1)/6. Baza. n = 1: 1 = 1·2·3/6 ✓. Addım. k(k + 1)(2k + 1)/6 + (k + 1)² = (k + 1)[k(2k + 1) + 6(k + 1)]/6 = (k + 1)(2k² + 7k + 6)/6 = (k + 1)(k + 2)(2k + 3)/6. Bu, n = k + 1 üçün n(n + 1)(2n + 1)/6-dir. ∎ Məsələ 2. Sübut et: 1/(1·2) + 1/(2·3) + … + 1/(n(n + 1)) = n/(n + 1). Baza. 1/2 = 1/2 ✓. Addım. k/(k + 1) + 1/((k + 1)(k + 2)) = (k(k + 2) + 1)/((k + 1)(k + 2)) = (k + 1)²/((k + 1)(k + 2)) = (k + 1)/(k + 2) ✓ ∎ Məsələ 3. Sübut et: 1·2⁰ + 2·2¹ + … + n·2ⁿ⁻¹ = (n − 1)·2ⁿ + 1. Baza. n = 1: 1 = 0·2 + 1 ✓. Addım. (k − 1)·2ᵏ + 1 + (k + 1)·2ᵏ = 2ᵏ·2k + 1 = k·2ᵏ⁺¹ + 1 = ((k + 1) − 1)·2ᵏ⁺¹ + 1 ✓ ∎
Tipik səhvlər
  • Bazanı yoxlamamaq. Misal: "n = n + 1" yanlış iddiasında addım "doğru" çıxır (P(k)-nın hər iki tərəfinə 1 əlavə et), amma baza ödənmir. Deməli, addım tək başına heç nə sübut etmir.
  • İnduksiya addımında P(k + 1)-i doğru qəbul etmək. Fərz olunan yalnız P(k)-dır.
  • Yeni həddi səhv yazmaq: n-ci hədd 2n − 1 isə, (k + 1)-ci hədd 2k + 1-dir, 2k − 1 yox.
  • Nəticədə yalnız bir-iki halı yoxlayıb "deməli, hər n üçün" demək.
Yadda saxla
Baza + addım (P(k) ⟹ P(k + 1)) + nəticə Addım: sol tərəfə yeni hədd əlavə et, nəticəni P(k + 1)-ə gətir P(k + 1)-i əvvəlcədən yaz: n əvəzinə k + 1
Özünü yoxla: 3 sual
  1. Induksiya sübutunun iki ayağı hansılardır? Baza (ilk halın doğruluğu) və addım (P(k) ⟹ P(k + 1)).
  2. 1 + 2 + … + n = n(n + 1)/2 üçün P(k + 1) necə yazılır? 1 + 2 + … + (k + 1) = (k + 1)(k + 2)/2.
  3. n = 10 üçün 1² + … + 10² = ? 10·11·21/6 = 385.

Dərs 2. Bölünmə məsələləri

1 Niyə lazımdır

"7ⁿ − 1 ifadəsi 6 ədədinə bölünür" iddiasını 6 halda yoxlamaq olar, amma hər n üçün? Bölünmə məsələləri induksiyanın ən çox işləyən sahəsidir: ifadədən bölünən hissə ayırırsan, qalanı fərziyyəyə gətirirsən.

2 Əsas fikir

Bölünməni induksiya ilə sübut edəndə f(k + 1)-i belə yaz:

f(k + 1) = c·f(k) + (bölünən ifadə) — və ya — f(k + 1) = f(k) + (bölünən ifadə)

f(k) fərziyyəyə görə m ədədinə bölünür, ikinci toplanan da bölünürsə, cəm də bölünür. "Bölünən ifadə"ni tapmaq üçün f(k + 1)-də f(k)-nın üstündəki hissəni ayır.

3 Həll olunmuş nümunələr

1) 7ⁿ − 1 ifadəsi 6 ədədinə bölünür. Baza. n = 1: 7 − 1 = 6 ✓. Addım. 7ᵏ⁺¹ − 1 = 7·(7ᵏ − 1) + 7 − 1 = 7·(7ᵏ − 1) + 6. Birinci toplanan fərziyyəyə görə 6-ya bölünür, ikincisi 6-dır ✓ ∎ 2) n³ + 5n ifadəsi 6 ədədinə bölünür. Baza. n = 1: 6 ✓. Addım. (k + 1)³ + 5(k + 1) = k³ + 5k + (3k² + 3k + 6) = f(k) + 3k(k + 1) + 6. k(k + 1) cütdür → 3k(k + 1) 6-ya bölünür ✓ ∎ 3) "Ən böyük bölən" tapmaq: f(n) = n(n + 1)(n + 2). f(1) = 6, f(2) = 24, f(3) = 60 → EBOB = 6. Cavab 6-dan böyük ola bilməz. Sübut: f(k + 1) − f(k) = 3(k + 1)(k + 2), (k + 1)(k + 2) cütdür → fərq 6 ədədinə bölünür; baza f(1) = 6 ✓.
Həyatdan. Kassada yalnız 6 manatlıq əskinas olsa, ümumi məbləğ həmişə 6-ya bölünəcək. Hər dəfə əlavə etdiyin məbləğ də 6-ya bölünürsə, bölünmə "ötürülür" — induksiya addımı məhz budur.

4 "Ən böyük bölən" üçün plan

1) f(1), f(2), f(3)-ü hesabla. 2) Onların EBOB-u cavabın yuxarı həddidir. 3) Bu EBOB-un bütün n üçün bölündüyünü induksiya ilə sübut et. Bölünmənin bir neçə n-dən sonra pozulması mümkün deyil — sübut bunu təmin edir.

5 Olimpiada məsələləri

Məsələ 1. Sübut et: 4ⁿ + 15n − 1 ifadəsi 9 ədədinə bölünür. Baza. n = 1: 4 + 15 − 1 = 18 ✓. Addım. f(k + 1) = 4ᵏ⁺¹ + 15k + 14 = 4(4ᵏ + 15k − 1) − 60k + 4 + 15k + 14 = 4f(k) − 45k + 18 = 4f(k) − 9(5k − 2). Hər iki toplanan 9-a bölünür ✓ ∎ Məsələ 2. Sübut et: 11ⁿ⁺¹ + 12²ⁿ⁻¹ ifadəsi 133 ədədinə bölünür. Baza. n = 1: 121 + 12 = 133 ✓. Addım. f(k + 1) = 11ᵏ⁺² + 12²ᵏ⁺¹ = 11·11ᵏ⁺¹ + 144·12²ᵏ⁻¹ = 11(11ᵏ⁺¹ + 12²ᵏ⁻¹) + 133·12²ᵏ⁻¹ = 11f(k) + 133·12²ᵏ⁻¹ ✓ ∎ Məsələ 3. 3^(2n+1) + 2^(n+2) ifadəsi bütün natural n üçün hansı ən böyük ədədə bölünür? Həll. f(1) = 27 + 8 = 35, f(2) = 243 + 16 = 259 = 7·37. EBOB(35, 259) = 7. Sübut. f(k + 1) = 9·3²ᵏ⁺¹ + 2·2ᵏ⁺² = 9f(k) − 7·2ᵏ⁺² ✓. Cavab: 7.
Tipik səhvlər
  • f(k + 1)-də f(k)-nı çıxarmaq üçün qüvvəti səhv bölmək. İlk addım: 7ᵏ⁺¹ = 7·7ᵏ.
  • "Bölünən ifadə"yə fərziyyənin tətbiqini unutmaq: yalnız f(k) bölünür, ikinci toplanan ayrıca yoxlanır.
  • Fərqin işarəsini səhv yazmaq: f(k + 1) − f(k) yazanda f(k)-nın üstündən çıx.
  • "Ən böyük bölən"də yalnız EBOB hesablayıb sübutu atmaq. EBOB yuxarı sərhəddir, bölünmə isə sübut olunmalıdır.
Yadda saxla
f(k + 1) = c·f(k) + (bölünən ifadə) Ən böyük bölən: EBOB(f(1), f(2), …) + induksiya ilə sübut 7ⁿ − 1: 6; aⁿ − 1: a − 1; aⁿ − (a − 1)n − 1: (a − 1)²
Özünü yoxla: 3 sual
  1. 5ⁿ − 1 ifadəsi hansı ədədə bölünür? 4-ə: 5ᵏ⁺¹ − 1 = 5(5ᵏ − 1) + 4.
  2. n³ + 5n üçün f(1), f(2)? f(1) = 6, f(2) = 18, EBOB = 6.
  3. 9ⁿ − 8n − 1 ifadəsinin bölündüyü ən böyük ədəd? f(2) = 81 − 17 = 64, f(3) = 729 − 25 = 704 = 64·11 → 64.

Dərs 3. Bərabərsizliklər və baza n₀

1 Niyə lazımdır

2ⁿ > n² iddiasına bax: n = 1 üçün 2 > 1 ✓, n = 2: 4 > 4 ✗, n = 3: 8 > 9 ✗, n = 4: 16 > 16 ✗, n = 5: 32 > 25 ✓. Bərabərsizlik n ≥ 5 üçün həmişə doğrudur; n = 1 üçün də doğrudur, n = 2, 3, 4 üçün yanlışdır. Belə iddialarda baza n₀ məsələnin əsas hissəsidir.

2 Əsas fikir

Baza: ilk n₀ üçün yoxla (əl ilə, kiçik n-ləri sına) Addım: k ≥ n₀ üçün P(k) ⟹ P(k + 1) Nəticə: P(n) bütün n ≥ n₀ üçün

Bərabərsizliyin addımında adətən "sol tərəf 2 dəfə (və ya (k + 1) dəfə) artır, sağ tərəf daha az artır" ideyası işləyir. Addımın doğru olması üçün k-nın şərti (məs. k ≥ 5) lazım ola bilər — məhz buna görə baza kiçik n-lərdən başlamır.

3 Həll olunmuş nümunələr

1) 2ⁿ > n² bütün n ≥ 5 üçün. Baza. n = 5: 32 > 25 ✓. Addım. k ≥ 5, 2ᵏ > k² fərz edək. 2ᵏ⁺¹ = 2·2ᵏ > 2k². 2k² ≥ (k + 1)² ⟺ k² − 2k − 1 ≥ 0, bu k ≥ 3 üçün doğrudur (k = 5: 14 ≥ 0). Deməli 2ᵏ⁺¹ > (k + 1)² ✓ ∎ 2) n! > 2ⁿ bütün n ≥ 4 üçün. Baza. n = 4: 24 > 16 ✓ (n = 3: 6 > 8 ✗). Addım. (k + 1)! = (k + 1)·k! > (k + 1)·2ᵏ ≥ 2·2ᵏ = 2ᵏ⁺¹ (k + 1 ≥ 2) ✓ ∎ 3) Bernulli: x ≥ −1 olduqda (1 + x)ⁿ ≥ 1 + nx. Baza. n = 1: 1 + x ≥ 1 + x ✓. Addım. (1 + x)ᵏ⁺¹ = (1 + x)ᵏ·(1 + x) ≥ (1 + kx)(1 + x) = 1 + (k + 1)x + kx² ≥ 1 + (k + 1)x. (1 + x ≥ 0 olduğuna görə bərabərsizliyi 1 + x-ə vurmaq olar.) ∎
Həyatdan. İki bakteriya kolonisi: biri hər saat 2 dəfə, digəri hər saat sabit 100 ədəd artır. Əvvəlcə ikincisi çox ola bilər, amma müəyyən saatdan sonra birincisi həmişə qabaqda olacaq. "Hansı saatdan sonra" sualı məhz n₀-dır.

4 n₀-ı necə tapmaq olar

1) n = 1, 2, 3, … üçün hər iki tərəfi hesabla və pozulan ən böyük n-i tap. 2) Ondan sonrakı n₀ baza olur. 3) Addımın k ≥ n₀ üçün işlədiyini göstər. Misal: 2ⁿ > 20n. n = 6: 64 < 120 ✗; n = 7: 128 < 140 ✗; n = 8: 256 > 160 ✓; n = 9: 512 > 180 ✓. Pozulan ən böyük n = 7-dir, deməli n₀ = 8.

5 Olimpiada məsələləri

Məsələ 1. Sübut et: 1/1² + 1/2² + … + 1/n² < 2 (hər n üçün). Həll. Bu iddianı birbaşa induksiya ilə sübut etmək çətindir: addımda 1/(k + 1)² əlavə olunur, amma "< 2" yetərli deyil. Güclü iddia sübut edək: P(n): 1/1² + 1/2² + … + 1/n² ≤ 2 − 1/n. Baza. n = 1: 1 ≤ 2 − 1 = 1 ✓. Addım. 1/1² + … + 1/(k + 1)² ≤ 2 − 1/k + 1/(k + 1)². Göstərək ki, bu ≤ 2 − 1/(k + 1): 1/(k + 1)² ≤ 1/k − 1/(k + 1) = 1/(k(k + 1)) ⟺ k(k + 1) ≤ (k + 1)² ✓. Deməli cəm ≤ 2 − 1/n < 2. ∎ (Güclü iddia induksiyanı "qüvvətləndirir".) Məsələ 2. 2ⁿ > n³ bərabərsizliyi hansı n-lərdə doğrudur? Ən kiçik n₀ ki, n ≥ n₀ üçün doğrudur? Həll. n = 9: 512 < 729 ✗. n = 10: 1024 > 1000 ✓. n = 11: 2048 > 1331 ✓. Addım: k ≥ 10: 2ᵏ⁺¹ > 2k³ ≥ (k + 1)³ ⟺ (1 + 1/k)³ ≤ 2, bu k ≥ 4 üçün doğrudur. n₀ = 10. Tam cavab: n = 1 (2 > 1) və bütün n ≥ 10 (n = 2, …, 9 üçün yanlışdır). Məsələ 3. Sübut et: 1·2 + 2·3 + … + n(n + 1) = n(n + 1)(n + 2)/3. Baza. n = 1: 2 = 1·2·3/3 ✓. Addım. k(k + 1)(k + 2)/3 + (k + 1)(k + 2) = (k + 1)(k + 2)(k + 3)/3 ✓ ∎
Tipik səhvlər
  • Bazanı n = 1 götürmək, halbuki iddia n = 1-də doğru ola bilər, amma n = 2, 3, 4-də yox: 2ⁿ > n².
  • Addımda k ≥ n₀ şərtini istifadə etməyi unutmaq: k² − 2k − 1 ≥ 0 hər k üçün doğru deyil.
  • Bərabərsizliyi mənfi ədədə vuranda istiqaməti dəyişməmək.
  • Güclü iddia seçəndə baza halını yoxlamamaq.
Yadda saxla
Baza = ilk n₀ (kiçik n-ləri əl ilə sına) Addım yalnız k ≥ n₀ üçün Çətin iddia → daha güclü iddia (məs. ≤ 2 − 1/n) 2ⁿ > n²: n = 1 və n ≥ 5; n! > 2ⁿ: n ≥ 4; 2ⁿ > n³: n = 1 və n ≥ 10
Özünü yoxla: 3 sual
  1. 2ⁿ > 3n bərabərsizliyi üçün ən kiçik n₀? n = 1: 2 < 3; n = 2: 4 < 6; n = 3: 8 < 9; n = 4: 16 > 12 ✓; n₀ = 4.
  2. n! > 3ⁿ üçün n₀? n = 6: 720 < 729; n = 7: 5040 > 2187 ✓ → n₀ = 7.
  3. Niyə 2ⁿ > n² iddiasının bazası n = 1 deyil? n = 2, 3, 4-də bərabərsizlik pozulur; addım k ≥ 5 üçün işləyir, ona görə baza n = 5.

Dərs 4. Düstur təxmini, güclü induksiya, səhv sübutlar

1 Niyə lazımdır

Çox vaxt düstur verilmir — onu özün tapırsan: ilk hədləri hesablayırsan, qanunu təxmin edirsən, sonra induksiya ilə sübut edirsən. Bundan əlavə, bəzən P(k)-dan P(k + 1) almaq üçün tək P(k) yetərli olmur — bütün əvvəlki hallar lazım olur (güclü induksiya).

2 Təxmin et və sübut et

a₁ = 1, aₙ₊₁ = 2aₙ + 1: 1; 3; 7; 15; 31; … təxmin: aₙ = 2ⁿ − 1 Baza. a₁ = 2¹ − 1 = 1 ✓. Addım. aₖ = 2ᵏ − 1 ⟹ aₖ₊₁ = 2(2ᵏ − 1) + 1 = 2ᵏ⁺¹ − 1 ✓

Başqa misal: a₁ = 1, aₙ₊₁ = aₙ + 2n + 1 → 1; 4; 9; 16 → aₙ = n². aₙ₊₁ = (n + 1)aₙ, a₁ = 1 → aₙ = n!.

Xətti rekurrent. aₙ₊₁ = 2aₙ + d üçün: aₙ₊₁ + d = 2(aₙ + d), yəni aₙ + d = (a₁ + d)·2ⁿ⁻¹. Məsələn a₁ = 2, aₙ₊₁ = 2aₙ − 1 → aₙ − 1 = 2ⁿ⁻¹ → aₙ = 2ⁿ⁻¹ + 1: 2, 3, 5, 9, 17 ✓.

3 Güclü induksiya

Addımda yalnız P(k) deyil, P(n₀), P(n₀ + 1), …, P(k) hamısını fərz etmək olar. Bu, iki əvvəlki həddən asılı ardıcıllıqlarda (aₙ₊₂ = 3aₙ₊₁ − 2aₙ) və bölməyə əsaslanan məsələlərdə lazımdır. İki əvvəlki hədd lazımdırsa, iki baza yoxlanmalıdır.

a₁ = 1, a₂ = 3, aₙ₊₂ = 3aₙ₊₁ − 2aₙ. Sübut: aₙ = 2ⁿ − 1. Baza. a₁ = 1, a₂ = 3 ✓ (2¹ − 1, 2² − 1). Addım. aₖ = 2ᵏ − 1 və aₖ₊₁ = 2ᵏ⁺¹ − 1 fərz edək: aₖ₊₂ = 3(2ᵏ⁺¹ − 1) − 2(2ᵏ − 1) = 6·2ᵏ − 3 − 2·2ᵏ + 2 = 4·2ᵏ − 1 = 2ᵏ⁺² − 1 ✓

4 Həll olunmuş nümunələr

1) Şokolad plitəsi: n parçadan ibarət plitəni (hər dəfə bir parçanı düz xətt boyunca sındırmaqla) n ayrı kvadrata ayırmaq üçün tam n − 1 sındırma lazımdır. Baza. n = 1: 0 sındırma ✓. Addım (güclü). n = k + 1 parçanı ilk sındırma a və b parçaya ayırır (a + b = k + 1). Güclü fərziyyə: a parçanı ayırmaq a − 1, b parçanı ayırmaq b − 1 sındırma tələb edir (a ≤ k və b ≤ k). Cəmi 1 + (a − 1) + (b − 1) = a + b − 1 = k ✓. 2) Turnir: n oyunçu, hər oyunda bir nəfər kənarlaşır → qalibi təyin etmək üçün n − 1 oyun. 3) Əskinaslar 3 və 5 manat: 8-dən böyük və ya bərabər hər məbləği vermək olar. Baza. 8 = 3 + 5, 9 = 3 + 3 + 3, 10 = 5 + 5. Addım (güclü). n ≥ 11 üçün n − 3 ≥ 8 məbləği verilir (fərziyyə) → üzərinə 3 əlavə et ✓. 7 verilə bilməz: 3x + 5y = 7 tənliyinin natural-sıfır həlli yoxdur (y = 0: 7/3; y = 1: 2/3). Deməli ən böyük verilməyən məbləğ 7 = 3·5 − 3 − 5.
Həyatdan. Hanoy qülləsi: n diski köçürmək üçün minimum Hₙ gediş; Hₙ = 2Hₙ₋₁ + 1, H₁ = 1. İlk hədlər 1, 3, 7, 15 → Hₙ = 2ⁿ − 1, induksiya ilə sübut: yuxarıdakı birinci nümunə ilə eyni. 64 disk üçün 2⁶⁴ − 1 gediş lazımdır: saniyədə bir gedişlə yüz milyardlarla il çəkər.

5 Olimpiada məsələləri və səhv sübutlar

Məsələ 1. Əskinaslar a və b manatdır (a, b qarşılıqlı sadə). Ən böyük verilməyən məbləğ ab − a − b (3 və 5 üçün 7). 4 və 7 üçün ən böyük verilməyən məbləği tap. Həll. 4·7 − 4 − 7 = 17. Yoxla: 18 = 4 + 7 + 7, 19 = 4 + 4 + 4 + 7, 20 = 4·5, 21 = 7·3; 17 isə 4x + 7y = 17 tənliyinin natural-sıfır həllinə malik deyil (y = 0: 17/4; y = 1: 10/4; y = 2: 3/4). Məsələ 2 ("Bütün atlar eyni rəngdədir" paradoksu). "Sübut": n at üçün induksiya. Baza n = 1 ✓. Addım: k + 1 at olsun. Birinci k atı bir qrup, sonuncu k atı başqa qrup say. Hər qrup fərziyyəyə görə eyni rəngdədir, ortaq atlar var (k − 1 at) → hamısı eyni rəngdədir. Səhv hardadır? Cavab. Addım k = 1 (yəni k + 1 = 2 at) üçün işləmir: qrupların ortaq atı yoxdur (k − 1 = 0), bir-birinə bağlanmırlar. Beləliklə P(1) ⟹ P(2) addımı yanlışdır və zəncir qırılır. Dərs: addım bütün k ≥ n₀ üçün işləməlidir. Məsələ 3. a₁ = 3, aₙ₊₁ = 2aₙ − 1. a₁₀ = ? Həll. 3; 5; 9; 17 → aₙ = 2ⁿ + 1. İnduksiya: 2(2ᵏ + 1) − 1 = 2ᵏ⁺¹ + 1 ✓. a₁₀ = 1024 + 1 = 1025.
Tipik səhvlər
  • Təxmin etdiyin düsturu sübutsuz qəbul etmək. İlk 5 halda doğru olan qanun sonra pozula bilər (misal: n² + n + 41 ilk 39 natural ədəddə sadə ədəd verir, amma n = 40-da yox).
  • İki əvvəlki həddən asılı rekurrentdə bir baza ilə kifayətlənmək.
  • Güclü induksiyada fərziyyəni lazım olan k-lar üçün göstərməmək.
  • Addımda ayrıca halı (kiçik k) unutmaq: paradoksdakı kimi.
Yadda saxla
Qanunu təxmin et (ilk 4–5 hədd) → induksiya ilə sübut et İki əvvəlki hədd → iki baza Güclü induksiya: P(n₀), …, P(k) ⟹ P(k + 1) Addım bütün k ≥ n₀ üçün işləməlidir
Özünü yoxla: 3 sual
  1. a₁ = 2, aₙ₊₁ = aₙ + 2n: ilk hədlər və düstur? 2; 4; 8; 14 → aₙ = n² − n + 2 (yoxla: aₖ₊₁ = k² − k + 2 + 2k = (k + 1)² − (k + 1) + 2).
  2. 6×4 şokolad plitəsini 24 kvadrata ayırmaq üçün neçə sındırma? 24 − 1 = 23.
  3. 3 və 7 manatlıq əskinaslarla ən böyük verilməyən məbləğ? 3·7 − 3 − 7 = 11.
