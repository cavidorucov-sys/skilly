Riyaziyyat olimpiadası · RFO: Çoxhədlilər — qalıqlı bölmə, Bezu teoremi

Çoxhədlilərin bölünməsi, Bezu teoremi, qeyri-müəyyən əmsallar

x¹⁰⁰ − 3x⁵¹ + 2x + 7 çoxhədlisini x + 1-ə bölmək üçün 100 addımlı bölmə lazım deyil — qalıq bir sətirdə tapılır. Bu mövzuda çoxhədliləri ədədlər kimi qalıqla bölməyi, Bezu teoremini və qeyri-müəyyən əmsallar üsulunu öyrənəcəksən. Olimpiadada "qalığı tap", "bölünürsə parametri tap", "vuruqlara ayır" məsələləri bunlarla həll olunur.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Qalıqlı bölmə: bucaqlı bölmə və Horner sxemi

1 Niyə lazımdır

Ədədləri qalıqla bölməyi bilirsən: 17 = 5 · 3 + 2. Çoxhədlilərdə də eynidir: bir çoxhədlini digərinə bölürük, qismət və qalıq alırıq. Olimpiadanın "qalığı tap", "bölünürsə a-nı tap" məsələlərinin hamısı bu bərabərliyə söykənir.

2 Əsas fikir

P(x) = S(x) · Q(x) + R(x) P — bölünən, S — bölən, Q — qismət, R — qalıq Şərt: R-in dərəcəsi S-in dərəcəsindən kiçikdir.

Bölən birinci dərəcəlidirsə (x − a), qalıq sadəcə ədəddir. Bölən ikinci dərəcəlidirsə, qalıq px + q şəklindədir.

3 Bucaqlı bölmə

Ədədlərdəki "künclə bölmə" kimi: hər dəfə bölünənin baş həddini bölənin baş həddinə bölür, vurur, çıxırıq.

(2x³ − 3x² + 4x − 5) : (x − 2) 2x³ : x = 2x² → 2x²(x − 2) = 2x³ − 4x² çıxırıq: (2x³ − 3x²) − (2x³ − 4x²) = x² → x² + 4x − 5 x² : x = x → x(x − 2) = x² − 2x çıxırıq: x² + 4x − 5 − (x² − 2x) = 6x − 5 6x : x = 6 → 6(x − 2) = 6x − 12 çıxırıq: 6x − 5 − (6x − 12) = 7 Qismət: 2x² + x + 6, qalıq: 7 Yoxla: (x − 2)(2x² + x + 6) + 7 = 2x³ − 3x² + 4x − 5 ✓
(x⁴ + 2x³ − x + 3) : (x² + x − 1) x⁴ : x² = x² → x⁴ + x³ − x²; qalır: x³ + x² − x + 3 x³ : x² = x → x³ + x² − x; qalır: 3 Qismət: x² + x, qalıq: 3

4 Horner sxemi — x − a-ya bölmənin qısa yolu

Yuxarıdakı birinci bölmədə yalnız əmsallar işləyir. Onları cədvəldə yazırıq: birinci əmsalı aşağı endiririk, sonra hər dəfə "aşağıdakı ədəd · a + növbəti əmsal". Son ədəd — qalıq, qalanları — qismətin əmsalları.

a = 2 │ 2 −3 4 −5 │ 2 1 6 │ 7 2 · 2 + (−3) = 1, 1 · 2 + 4 = 6, 6 · 2 + (−5) = 7 Qismət 2x² + x + 6, qalıq 7

Diqqət: buraxılmış dərəcələrin yerinə 0 yaz. x³ − 5x + 3 üçün əmsallar: 1, 0, −5, 3. x + 2-yə bölmədə a = −2.

Həyatdan. 2357 ədədi əslində çoxhədlidir: 2·10³ + 3·10² + 5·10 + 7, yəni P(10). Kompüterlər çoxhədlinin qiymətini məhz Horner üsulu ilə hesablayır: ((2·10 + 3)·10 + 5)·10 + 7. Bu yol ən az vurma əməli tələb edir.

5 Olimpiada məsələsi

Məsələ. p və q-nun hansı qiymətlərində x³ + px + q çoxhədlisi x² + x + 1-ə qalıqsız bölünür? Həll. Bucaqlı bölmə aparaq: x³ : x² = x → x(x² + x + 1) = x³ + x² + x qalır: −x² + (p − 1)x + q −x² : x² = −1 → −(x² + x + 1) = −x² − x − 1 qalır: (p − 1 + 1)x + (q + 1) = px + (q + 1) Qalıq px + (q + 1) sıfır çoxhədli olmalıdır: p = 0, q + 1 = 0 → q = −1. Cavab: p = 0, q = −1. Doğrudan da, x³ − 1 = (x − 1)(x² + x + 1). ∎
Tipik səhvlər
  • Buraxılmış dərəcəni 0 ilə yazmamaq: x³ − 5x + 3 üçün "1, −5, 3" yazmaq. Düzü: 1, 0, −5, 3.
  • x + 2-yə bölmədə Hornerdə a = 2 götürmək. x + 2 = x − (−2), yəni a = −2.
  • Bucaqlı bölmədə çıxanda işarəni unutmaq: (4x − 5) − (−2x) = 6x − 5, 2x − 5 yox.
Yadda saxla
P = S · Q + R, dərəcə R < dərəcə S x − a-ya bölmə: qalıq ədəddir; Horner: endir, a-ya vur, topla İkinci dərəcəli bölən: qalıq px + q
Özünü yoxla: 3 sual
  1. (x³ − 5x + 3) : (x − 1) — qismət və qalıq? Horner (a = 1): 1, 1, −4, −1. Qismət x² + x − 4, qalıq −1.
  2. (x³ + 2x² − 3) : (x + 2) — qalıq? a = −2: 1; 1·(−2) + 2 = 0; 0·(−2) + 0 = 0; 0·(−2) − 3 = −3. Qismət x², qalıq −3.
  3. Çoxhədlini x² + 1-ə böldükdə qalığın dərəcəsi ən çox neçə ola bilər? 1 (qalıq px + q şəklindədir).

Dərs 2. Bezu teoremi

1 Niyə lazımdır

x¹⁰⁰ − 3x⁵¹ + 2x + 7 çoxhədlisini x + 1-ə böləndə Horner cədvəli 101 xanalı olardı. Bezu teoremi deyir: qalığı tapmaq üçün bircə ədəd yerinə qoymaq kifayətdir.

2 Teorem və isbatı

Bezu teoremi P(x)-i x − a-ya böldükdə qalıq P(a)-ya bərabərdir.

İsbat. Bölən birinci dərəcəlidir, ona görə qalıq ədəddir: P(x) = (x − a) · Q(x) + r. Bu bərabərlik bütün x-lər üçün doğrudur. x = a qoyaq: P(a) = 0 · Q(a) + r = r. ∎

Nəticələr 1) a ədədi P-nin köküdür ⇔ P(x) bölünür x − a-ya 2) kx + m-ə bölmədə qalıq = P(−m/k) (k ≠ 0) 3) P tam əmsallıdırsa, P(m) − P(n) bölünür m − n-ə

3-cü nəticənin səbəbi: mᵏ − nᵏ həmişə m − n-ə bölünür (növbəti mövzuda isbat edəcəyik), P(m) − P(n) isə belə fərqlərin tam əmsallarla cəmidir.

3 Həll olunmuş nümunələr

1) (x¹⁰⁰ − 3x⁵¹ + 2x + 7) : (x + 1), qalıq? a = −1: (−1)¹⁰⁰ = 1, (−1)⁵¹ = −1 P(−1) = 1 + 3 − 2 + 7 = 9. Cavab: 9 2) a-nın hansı qiymətində x³ − ax² + 5x − 6 bölünür x − 2-yə? P(2) = 8 − 4a + 10 − 6 = 12 − 4a = 0 → a = 3 3) (2x³ − x + 4) : (2x − 1), qalıq? 2x − 1 = 0 → x = 1/2 P(1/2) = 2 · 1/8 − 1/2 + 4 = 1/4 − 1/2 + 4 = 15/4

4 İki parametr — iki tənlik

x³ + ax² + bx − 6 çoxhədlisi həm x − 1-ə, həm x + 2-yə bölünür. a, b? P(1) = 1 + a + b − 6 = 0 → a + b = 5 P(−2) = −8 + 4a − 2b − 6 = 0 → 2a − b = 7 Toplasaq: 3a = 12 → a = 4, b = 1 Yoxla: x³ + 4x² + x − 6 = (x − 1)(x + 2)(x + 3) ✓
Həyatdan. 9-a bölünmə əlaməti Bezudan çıxır! Ədəd N = P(10), rəqəmləri isə P-nin əmsallarıdır. P(10) − P(1) fərqi 10 − 1 = 9-a bölünür, P(1) isə rəqəmlər cəmidir. 11 üçün: P(10) − P(−1) bölünür 11-ə, P(−1) — rəqəmlərin növbəli cəmi. Məsələn, 2357: 7 − 5 + 3 − 2 = 3, və doğrudan da 2357 = 11 · 214 + 3.

5 Olimpiada məsələsi

Məsələ. Tam əmsallı P(x) çoxhədlisi üçün P(2) = 5 və P(7) = 13 ola bilərmi? Həll. 3-cü nəticəyə görə P(7) − P(2) ədədi 7 − 2 = 5-ə bölünməlidir. Amma P(7) − P(2) = 13 − 5 = 8, 5-ə bölünmür. Cavab: ola bilməz. ∎
Tipik səhvlər
  • x + a-ya bölmədə P(a) hesablamaq. Düzü: P(−a).
  • 2x − 1-ə bölmədə P(1) yazmaq. Bölənin kökü x = 1/2-dir.
  • (−1)-in tək qüvvətini 1 götürmək: (−1)⁵¹ = −1.
Yadda saxla
P(x) : (x − a) → qalıq P(a) P(a) = 0 ⇔ x − a bölür P(x) Bölünmə şərti → P(a) = 0 → parametr üçün tənlik
Özünü yoxla: 3 sual
  1. (x⁵⁰ + x²⁵ + 1) : (x − 1) — qalıq? P(1) = 3.
  2. k-nın hansı qiymətində x³ + kx + 4 bölünür x + 2-yə? P(−2) = −8 − 2k + 4 = 0 → k = −2.
  3. (x³ + 1) : (3x − 1) — qalıq? P(1/3) = 1/27 + 1 = 28/27.

Dərs 3. (x − a)(x − b)-yə bölmədə qalıq

1 Niyə lazımdır

Olimpiadanın sevimli sualı: "P(x)-i x − 1-ə böldükdə qalıq 3, x − 2-yə böldükdə 5-dir. (x − 1)(x − 2)-yə böldükdə qalıq nədir?" P(x)-in özü məlum deyil — amma cavab tapılır.

2 Əsas fikir

Bölən ikinci dərəcəlidir, deməli qalıq birinci dərəcəlidir: R(x) = px + q.

P(x) = (x − a)(x − b) · Q(x) + px + q x = a: P(a) = pa + q x = b: P(b) = pb + q İki tənlikdən p və q tapılır.

3 Həll olunmuş nümunələr

1) P(1) = 3, P(2) = 5. (x − 1)(x − 2)-yə bölmədə qalıq? p + q = 3, 2p + q = 5 → p = 2, q = 1 Cavab: R(x) = 2x + 1 2) x¹⁰⁰ : (x² − 1) = x¹⁰⁰ : ((x − 1)(x + 1)) P(1) = 1: p + q = 1 P(−1) = 1: −p + q = 1 → p = 0, q = 1 Cavab: R(x) = 1 3) x¹⁰⁰ : (x² − 3x + 2) = x¹⁰⁰ : ((x − 1)(x − 2)) P(1) = 1: p + q = 1 P(2) = 2¹⁰⁰: 2p + q = 2¹⁰⁰ → p = 2¹⁰⁰ − 1, q = 2 − 2¹⁰⁰ Cavab: R(x) = (2¹⁰⁰ − 1)x + 2 − 2¹⁰⁰
Həyatdan. R(x) = px + q qalığının qrafiki (a; P(a)) və (b; P(b)) nöqtələrindən keçən düz xəttdir. Kompüter oyunlarında personajın iki mövqe arasındakı hərəkəti də belə hesablanır: iki məlum nöqtədən düz xətt keçirilir (buna interpolyasiya deyilir).

4 Bir neçə kök — bir neçə vuruq

a ≠ b və P(a) = P(b) = 0 → P(x) bölünür (x − a)(x − b)-yə

Niyə? P(a) = 0, deməli P(x) = (x − a)·Q(x). x = b qoyaq: 0 = (b − a)·Q(b), b − a ≠ 0, onda Q(b) = 0 və Q(x) də x − b-yə bölünür. Üç və daha çox fərqli kök üçün eyni mühakimə.

Olimpiada məsələsi. Sübut et ki, istənilən natural n üçün (x + 1)²ⁿ − x²ⁿ − 2x − 1 çoxhədlisi x(x + 1)(2x + 1)-ə bölünür. Həll. P(x) = (x + 1)²ⁿ − x²ⁿ − 2x − 1. Bölənin kökləri: 0, −1, −1/2. P(0) = 1 − 0 − 0 − 1 = 0 P(−1) = 0 − 1 + 2 − 1 = 0 ((−1)²ⁿ = 1) P(−1/2) = (1/2)²ⁿ − (1/2)²ⁿ + 1 − 1 = 0 ((−1/2)²ⁿ = (1/2)²ⁿ) Üç fərqli kök → P bölünür x(x + 1)(x + 1/2)-yə, deməli 2x + 1 = 2(x + 1/2) olduğundan x(x + 1)(2x + 1)-ə də. ∎
Tipik səhvlər
  • İkinci dərəcəli bölənə bölmədə qalığı ədəd hesab etmək. Qalıq px + q-dur; p = 0 ola bilər, amma bunu hesablamaqla tapırsan.
  • (x + 1) vuruğu üçün x = 1 qoymaq. Düzü: x = −1.
  • Bölənin vuruqlara ayrılmasında səhv: x² − 3x + 2 = (x − 1)(x − 2), (x + 1)(x + 2) yox.
Yadda saxla
(x − a)(x − b)-yə bölmə: R(x) = px + q pa + q = P(a), pb + q = P(b) Fərqli köklər → bölən onların hasilidir
Özünü yoxla: 3 sual
  1. P(x)-i x + 1-ə böldükdə qalıq 4, x − 3-ə böldükdə 8-dir. (x + 1)(x − 3)-ə böldükdə? −p + q = 4, 3p + q = 8 → p = 1, q = 5: R(x) = x + 5.
  2. x⁵¹ : (x² − 1) — qalıq? p + q = 1, −p + q = −1 → p = 1, q = 0: R(x) = x.
  3. x⁷ : (x² − x) — qalıq? x² − x = x(x − 1): P(0) = 0 → q = 0; P(1) = 1 → p = 1. R(x) = x.

Dərs 4. Qeyri-müəyyən əmsallar üsulu

1 Niyə lazımdır

Bəzən cavabın şəklini bilirik, amma əmsallarını yox: "x⁴ + 4-ü iki kvadrat üçhədlinin hasili kimi yaz", "(x − 1)²-ə bölünən x³ + ax + b-ni tap". Onda əmsalları hərflərlə yazır və tapırıq.

2 Əsas fikir

İki çoxhədli eynidir ⇔ eyni dərəcəli hədlərin əmsalları bərabərdir 1) Naməlum əmsallı şəkil yaz 2) Mötərizələri aç 3) x³, x², x, sərbəst hədd üzrə bərabərlik yaz və həll et

3 Həll olunmuş nümunələr

1) x³ − 6x² + 11x − 6 = (x − 1)(x² + mx + n). m, n? Sağ tərəf: x³ + (m − 1)x² + (n − m)x − n x²: m − 1 = −6 → m = −5 sərbəst: −n = −6 → n = 6 yoxla x: n − m = 6 + 5 = 11 ✓ Deməli x³ − 6x² + 11x − 6 = (x − 1)(x² − 5x + 6) = (x − 1)(x − 2)(x − 3) 2) x⁴ + 4 = (x² + ax + 2)(x² − ax + 2). a? Sağ tərəf: (x² + 2)² − a²x² = x⁴ + (4 − a²)x² + 4 x²: 4 − a² = 0 → a = ±2 (a = −2 eyni iki vuruğun yerini dəyişir) x⁴ + 4 = (x² + 2x + 2)(x² − 2x + 2) (Sofi Jermen eyniliyi) 3) P(x) — kvadrat üçhədli, P(x + 1) − P(x) = 2x + 3, P(0) = 1. P(5)? P(x) = ax² + bx + c: P(x + 1) − P(x) = 2ax + (a + b) 2a = 2 → a = 1; a + b = 3 → b = 2; c = P(0) = 1 P(x) = x² + 2x + 1, P(5) = 36
Həyatdan. Kimyada reaksiya tənliyini tarazlaşdırmaq — eyni üsuldur. a H₂ + b O₂ → c H₂O: hidrogen üçün 2a = 2c, oksigen üçün 2b = c. Ən kiçik tam həll a = 2, b = 1, c = 2: 2H₂ + O₂ → 2H₂O. Hər element bir "dərəcə" kimidir — sol və sağ tərəfdə sayı eyni olmalıdır.

4 Olimpiada məsələləri

Məsələ 1. a və b-nin hansı qiymətlərində x³ + ax + b çoxhədlisi (x − 1)²-ə bölünür? Həll. Qismət birinci dərəcəlidir: x³ + ax + b = (x − 1)²(x + c). Sağ tərəf: (x² − 2x + 1)(x + c) = x³ + (c − 2)x² + (1 − 2c)x + c x²: c − 2 = 0 → c = 2; x: a = 1 − 4 = −3; sərbəst: b = 2. Cavab: a = −3, b = 2 (x³ − 3x + 2 = (x − 1)²(x + 2)). ∎
Məsələ 2. n-in hansı natural qiymətlərində n⁴ + 4 sadə ədəddir? Həll. Nümunə 2-yə görə n⁴ + 4 = (n² + 2n + 2)(n² − 2n + 2). İkinci vuruq: n² − 2n + 2 = (n − 1)² + 1. n ≥ 2 olduqda o ≥ 2-dir, birinci vuruq isə ondan böyükdür — ədəd iki vuruğa ayrılır, mürəkkəbdir. n = 1: 1 + 4 = 5 — sadədir. Cavab: yalnız n = 1. ∎
Tipik səhvlər
  • Şəkli səhv seçmək: üçüncü dərəcəli çoxhədlini (x − 1)²-ə bölsək, qismət birinci dərəcəlidir (x + c), ikinci yox.
  • Mötərizə açanda hədd itirmək. Açdıqdan sonra bütün dərəcələri yoxla — bir tənlik "yoxlama" kimi artıq qalır.
  • Olmayan həddin əmsalını unutmaq: x³ + ax + b-də x²-nın əmsalı 0-dır və bu da tənlikdir.
Yadda saxla
Şəkli yaz → aç → əmsalları bərabərləşdir (x² + mx + n)² = x⁴ + 2mx³ + (m² + 2n)x² + 2mnx + n² x⁴ + 4 = (x² + 2x + 2)(x² − 2x + 2)
Özünü yoxla: 3 sual
  1. x² + 5x + 6 = (x + 2)(x + m). m = ? Sərbəst hədd: 2m = 6 → m = 3.
  2. x⁴ + 2x³ + 3x² + ax + b = (x² + x + n)². a, b = ? x²: 1 + 2n = 3 → n = 1; a = 2n = 2, b = n² = 1.
  3. x³ + ax + b çoxhədlisi (x + 1)²-ə bölünür. a, b = ? (x + 1)²(x − 2) = x³ − 3x − 2: a = −3, b = −2.
