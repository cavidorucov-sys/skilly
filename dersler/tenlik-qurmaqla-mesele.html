Tənlik qurmaqla məsələ həlli

Mətnli məsələni tənliyə çevirmək — buraxılışda ən çox xal gətirən bacarıqlardan biridir. Burada ədəd, yaş, rəqəm, hərəkət, iş və qarışıq məsələlərini bir plana salacağıq. Xüsusi diqqət — orta sürət tələsinə: orada çoxları səhv edir.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Tənlik qurmağın planı. Ədəd və yaş məsələləri

1 Niyə lazımdır

"Ata oğlundan 3 dəfə böyükdür, 12 ildən sonra 2 dəfə böyük olacaq..." Belə məsələni təxminlə həll etmək çətindir. Tənlik isə onu 3 sətirdə bitirir. Bütün sirr — sözləri riyazi dilə düzgün tərcümə etməkdir.

2 Plan

1. x — nədir? (adətən soruşulan kəmiyyət) 2. Qalan kəmiyyətləri x ilə yaz. 3. Şərtdə "bərabərdir" yerini tap → tənlik. 4. Tənliyi həll et. 5. Yoxla və soruşulanı yaz (x həmişə cavab deyil!).

Tərcümə lüğəti: "a-dan 5 çox" → a + 5; "3 dəfə böyük" → 3a; "ardıcıl ədədlər" → x, x + 1, x + 2; "ardıcıl cüt (tək) ədədlər" → x, x + 2, x + 4.

3 Ədəd məsələləri

Nümunə 1. Üç ardıcıl natural ədədin cəmi 87-dir. Ən böyüyü? x — ən kiçik ədəd. Ədədlər: x, x + 1, x + 2. x + x + 1 + x + 2 = 87 → 3x + 3 = 87 → 3x = 84 → x = 28 Ədədlər: 28, 29, 30. Yoxla: 28 + 29 + 30 = 87 ✓ Cavab: 30 (x yox, soruşulan!)
Nümunə 2. İki ədədin cəmi 64-dür, biri digərindən 3 dəfə böyükdür. Kiçik x, böyük 3x. x + 3x = 64 → 4x = 64 → x = 16 Cavab: 16 və 48. Yoxla: 16 + 48 = 64, 48 = 3·16 ✓

4 Yaş məsələləri

İki qızıl qayda: hər il hamı 1 yaş böyüyür və yaş fərqi heç vaxt dəyişmir.

Nümunə 3. Ata 40, oğlu 12 yaşındadır. Neçə ildən sonra ata oğlundan 2 dəfə böyük olacaq? x ildən sonra: ata 40 + x, oğlu 12 + x. 40 + x = 2(12 + x) → 40 + x = 24 + 2x → x = 16 Yoxla: 16 ildən sonra ata 56, oğlu 28; 56 = 2·28 ✓ Cavab: 16 ildən sonra
Nümunə 4. Ana qızından 24 yaş böyükdür. 4 il əvvəl ana qızından 5 dəfə böyük idi. Qız indi neçə yaşındadır? x — qızın indiki yaşı, ana x + 24. 4 il əvvəl: qız x − 4, ana x + 20. x + 20 = 5(x − 4) → x + 20 = 5x − 20 → 40 = 4x → x = 10 Yoxla: 4 il əvvəl qız 6, ana 30; 30 = 5·6 ✓ Cavab: 10 yaş
Həyatdan. Sən 15 yaşındasan, qardaşın 9. Fərq 6 ildir — 10 ildən sonra da, 50 ildən sonra da 6 il olacaq. Amma "neçə dəfə böyük" nisbəti hər il dəyişir: indi 15/9, 10 ildən sonra 25/19. Ona görə yaş məsələsində "dəfə" həmişə konkret bir anda verilir.
Tipik səhvlər
  • "x ildən sonra" yalnız bir adama əlavə etmək. İkisi də x il böyüyür.
  • "Ata oğlundan 2 dəfə böyükdür" yazanda vuruğu səhv yerə qoymaq: ata = 2·oğul, "2·ata = oğul" yox.
  • Cavab kimi x-i yazmaq, halbuki ən böyük ədəd və ya başqa kəmiyyət soruşulub.
Yadda saxla
x → qalanlar x ilə → tənlik → həll → yoxla → soruşulanı yaz. Ardıcıl: x, x + 1, x + 2; ardıcıl cüt/tək: x, x + 2, x + 4. Yaş: hamı eyni sayda il böyüyür; fərq sabitdir.
Özünü yoxla: 3 sual
  1. Dörd ardıcıl cüt ədədin cəmi 100-dür. Ən kiçiyi? x + x + 2 + x + 4 + x + 6 = 100 → 4x + 12 = 100 → x = 22. Yoxla: 22 + 24 + 26 + 28 = 100 ✓
  2. Qardaş 7, bacı 15 yaşındadır. Neçə il əvvəl bacı qardaşdan 3 dəfə böyük idi? 15 − x = 3(7 − x) → 15 − x = 21 − 3x → 2x = 6 → x = 3. Yoxla: 12 = 3·4 ✓
  3. Bir ədəd digərindən 12 çoxdur, cəmləri 50-dir. Kiçik ədəd? x + x + 12 = 50 → 2x = 38 → x = 19 (böyüyü 31).

Dərs 2. Rəqəmlərlə bağlı məsələlər

1 Niyə lazımdır

"Rəqəmlərin yerini dəyişsək, ədəd 27 artar" — DİM-in sevimli sual tipidir. Burada ədədin özünü yox, onun rəqəmlərini naməlum götürürük.

2 Əsas fikir: mərtəbə yazılışı

47 ədədi "4 onluq və 7 təklik"dir: 47 = 10·4 + 7. Ümumi halda onluq rəqəmi a, təklik rəqəmi b olan ədəd:

ab = 10a + b (a·b deyil!) yeri dəyişən: ba = 10b + a fərq: ba − ab = 9(b − a) cəm: ab + ba = 11(a + b) sağına c yazmaq: 10x + c

Şərt: a — 1-dən 9-a qədər (ədəd 0 ilə başlamır), b — 0-dan 9-a qədər.

3 Həll olunmuş nümunələr

Nümunə 1. İkirəqəmli ədədin rəqəmləri cəmi 11-dir. Rəqəmlərin yerini dəyişsək, ədəd 27 artar. Ədədi tap. Onluq rəqəmi x, təklik 11 − x. Ədəd: 10x + (11 − x) = 9x + 11 Yeri dəyişən: 10(11 − x) + x = 110 − 9x 110 − 9x − (9x + 11) = 27 → 99 − 18x = 27 → 18x = 72 → x = 4 Ədəd: 47. Yoxla: 74 − 47 = 27 ✓ (Qısa yol: 9(b − a) = 27 → b − a = 3, a + b = 11 → a = 4, b = 7.)
Nümunə 2. Onluq rəqəmi təklik rəqəmindən 2 dəfə böyükdür. Ədəd öz rəqəmlərinin cəmindən 54 çoxdur. Təklik x, onluq 2x. Ədəd: 20x + x = 21x, cəm: 3x. 21x − 3x = 54 → 18x = 54 → x = 3 Ədəd: 63. Yoxla: 63 − (6 + 3) = 54 ✓
Nümunə 3. İkirəqəmli ədədin sağına 5 yazdıq, ədəd 482 artdı. x — ədəd. Sağına 5 yazmaq: 10x + 5 (53 → 535 = 530 + 5) 10x + 5 − x = 482 → 9x = 477 → x = 53 Yoxla: 535 − 53 = 482 ✓
Həyatdan. Hiylə: istənilən ikirəqəmli ədəddən onun tərsini çıx — cavab həmişə 9-a bölünür (9(a − b)). Dostuna de: "Ədəd fikirləş, tərsini çıx, nəticəni de" — rəqəmlər fərqini dərhal tapacaqsan: nəticə ÷ 9.
Tipik səhvlər
  • ab-ni hasil kimi yazmaq. İkirəqəmli ədəd 10a + b-dir.
  • Sağına rəqəm yazmağı "+ c" kimi yazmaq. Ədəd 10 dəfə böyüyür: 10x + c.
  • Rəqəm üçün 9-dan böyük və ya kəsr cavabı qəbul etmək. Rəqəm 0…9 tam ədəddir — belə kök çıxırsa, tənlikdə səhv var.
Yadda saxla
ab = 10a + b, ba = 10b + a ba − ab = 9(b − a), ab + ba = 11(a + b) ədəd − rəqəmlər cəmi = 9a sağına c yazmaq: 10x + c
Özünü yoxla: 3 sual
  1. Rəqəmləri cəmi 9 olan ikirəqəmli ədəd rəqəmlərin yeri dəyişəndə 45 azalır. Ədəd? 9(a − b) = 45 → a − b = 5; a + b = 9 → a = 7, b = 2 → 72. Yoxla: 72 − 27 = 45 ✓
  2. İkirəqəmli ədədlə onun tərsinin cəmi həmişə hansı ədədə bölünür? 11-ə: 10a + b + 10b + a = 11(a + b).
  3. Təklik rəqəmi onluq rəqəmindən 4 çoxdur, ədəd rəqəmlər cəmindən 4 dəfə böyükdür. Ədəd? Onluq x, təklik x + 4: 11x + 4 = 4(2x + 4) → 3x = 12 → x = 4 → 48. Yoxla: 4·12 = 48 ✓

Dərs 3. Hərəkət məsələləri və orta sürət

1 Niyə lazımdır

Avtobus, qatar, velosiped — hamısı bir düsturla işləyir: s = v·t. Çətinlik düsturda deyil, vəziyyəti düzgün təsəvvür etməkdədir: kim haradan, nə vaxt, hansı istiqamətdə çıxıb.

2 Qarşı-qarşıya və ardınca

s = v·t, t = s/v, v = s/t Qarşı-qarşıya: yaxınlaşma sürəti v₁ + v₂ Ardınca (eyni istiqamət): v₂ − v₁

Yuxarıda: aradakı məsafə saatda v₁ + v₂ azalır. Aşağıda: arxadakı daha sürətlidir, məsafə saatda v₂ − v₁ azalır.

Nümunə 1. İki şəhər arası 260 km. Eyni anda qarşı-qarşıya iki maşın çıxdı və 2 saat sonra görüşdü. Birincinin sürəti ikincininkindən 10 km/saat çoxdur. Sürətlər? x — ikincinin sürəti, birincinin x + 10. 2x + 2(x + 10) = 260 → 4x + 20 = 260 → x = 60 Cavab: 70 və 60 km/saat. Yoxla: 140 + 120 = 260 ✓
Nümunə 2. Piyada 5 km/saat ilə çıxdı. 2 saat sonra eyni yerdən velosipedçi 15 km/saat ilə onun ardınca çıxdı. Neçə saata çatar? t — velosipedçinin vaxtı; piyada isə t + 2 saat yoldadır. 15t = 5(t + 2) → 10t = 10 → t = 1 Yoxla: velosipedçi 15 km; piyada 3 saatda 15 km ✓

3 Orta sürət tələsi

Maşın A-dan B-yə 60 km/saat, geri 40 km/saat sürətlə getdi. Orta sürət neçədir? Əksəriyyət "50" deyir. Səhvdir!

Orta sürət = ÜMUMİ YOL ÷ ÜMUMİ VAXT
A ilə B arası 120 km olsun (60 və 40-a bölünən rahat ədəd). Gediş: 120/60 = 2 saat. Qayıdış: 120/40 = 3 saat. Ümumi yol 240 km, ümumi vaxt 5 saat. Orta sürət = 240/5 = 48 km/saat (50 yox!)

Niyə 50 deyil? Maşın yavaş hissədə daha çox vaxt keçirir, ona görə orta sürət kiçik sürətə yaxındır. Bərabər iki yol üçün hazır düstur:

v_orta = 2·v₁·v₂/(v₁ + v₂) (yolun yarıları bərabərdirsə) 2·60·40/100 = 48 ✓

Ədədi orta (v₁ + v₂)/2 yalnız vaxtlar bərabər olanda doğrudur.

Nümunə 3. 2 saat 60 km/saat, sonra 3 saat 80 km/saat. Yol: 120 + 240 = 360 km, vaxt: 5 saat → 360/5 = 72 km/saat (70 yox) Nümunə 4. Yolun yarısını 30 km/saat getdi. Qalanını hansı sürətlə getməlidir ki, orta sürət 40 km/saat olsun? 2·30·x/(30 + x) = 40 → 60x = 1200 + 40x → 20x = 1200 → x = 60 Yoxla (yarı yol 60 km): 2 saat + 1 saat = 3 saat, 120/3 = 40 ✓
Həyatdan. Naviqator "orta sürət 48 km/saat" göstərirsə, o, sürətlərin ortasını yox, getdiyin yolu keçən vaxta bölüb. Tıxacda keçən 10 dəqiqə orta sürəti çox aşağı salır — çünki həmin vaxt da hesaba düşür.
Tipik səhvlər
  • Orta sürəti (v₁ + v₂)/2 kimi hesablamaq. Düzü: ümumi yol ÷ ümumi vaxt.
  • Ardınca çıxanda başlanğıc fərqi unutmaq: əvvəl çıxanın vaxtı t + t₀-dır.
  • Vahidləri qarışdırmaq: 30 dəqiqə = 0,5 saat, 30 yox.
Yadda saxla
s = v·t qarşı-qarşıya: v₁ + v₂; ardınca: v₂ − v₁ v_orta = ümumi yol / ümumi vaxt bərabər yarılar: 2v₁v₂/(v₁ + v₂)
Özünü yoxla: 3 sual
  1. Getmə 80, qayıtma 120 km/saat. Orta sürət? 2·80·120/200 = 96 km/saat (100 yox). Yoxla: 240 km → 3 + 2 = 5 saat, 480/5 = 96 ✓
  2. 1 saat 50 km/saat, 2 saat 80 km/saat. Orta sürət? (50 + 160)/3 = 70 km/saat.
  3. 450 km aralı iki şəhərdən eyni anda qarşı-qarşıya 40 və 50 km/saat sürətlə iki maşın çıxdı. Neçə saata görüşərlər? 40t + 50t = 450 → t = 5 saat.

Dərs 4. İş və qarışıq məsələləri

1 Niyə lazımdır

İş məsələsi hərəkət məsələsi ilə eyni quruluşa malikdir: yol əvəzinə görülən iş, sürət əvəzinə məhsuldarlıq. Qarışıq məsələsində isə əsas sual birdir: təmiz maddə nə qədərdir?

2 İş məsələləri

İş = məhsuldarlıq · vaxt Bütün iş = 1 → 1 gündə görülən hissə = 1/vaxt Birlikdə: hissələr toplanır, vaxtlar yox
Nümunə 1. Usta saatda şagirddən 4 detal çox hazırlayır. Usta 6 saat, şagird 5 saat işlədi, birlikdə 167 detal. Hər biri saatda neçə? x — şagird, x + 4 — usta. 6(x + 4) + 5x = 167 → 11x + 24 = 167 → 11x = 143 → x = 13 Cavab: şagird 13, usta 17. Yoxla: 102 + 65 = 167 ✓
Nümunə 2. Birinci işi 6 günə, ikinci 12 günə görür. Birlikdə? 1 gündə: 1/6 və 1/12 hissə. x gündə bütün iş (1): x/6 + x/12 = 1 → 12-yə vur: 2x + x = 12 → x = 4 Cavab: 4 gün (6 + 12 = 18 yox — birlikdə daha TEZ!)

3 Qarışıq və məhlul

təmiz maddə = məhlulun kütləsi · faiz/100 Su əlavə edəndə (buxarlananda) duz dəyişmir. Qarışdıranda duzlar toplanır.
Nümunə 3. 200 q 30%-li duz məhluluna neçə qram su əlavə edək ki, məhlul 20%-li olsun? Duz: 200·0,3 = 60 q (dəyişmir) 60 = 0,2·(200 + x) → 300 = 200 + x → x = 100 Yoxla: 60/300 = 0,2 = 20% ✓
Nümunə 4. 10%-li və 30%-li məhlullardan 400 q 25%-li məhlul almaq lazımdır. Hər birindən nə qədər? x — 10%-li, 400 − x — 30%-li. 0,1x + 0,3(400 − x) = 0,25·400 0,1x + 120 − 0,3x = 100 → 0,2x = 20 → x = 100 Cavab: 100 q 10%-li, 300 q 30%-li. Yoxla: 10 + 90 = 100 q duz ✓
Həyatdan. Çay çox şirindir? Su əlavə edirsən — şəkər eyni qalır, amma faizi düşür. Ümumi kütləsi 200 q olan şirin çayda 10 q şəkər var — 5%. 100 q su əlavə et (300 q) — şəkər yenə 10 q, indi 10/300 ≈ 3,33%.
Tipik səhvlər
  • Birgə işdə vaxtları toplamaq. Toplanan — 1 gündə görülən hissələrdir: 1/a + 1/b.
  • Faizləri toplamaq: 10%-li + 30%-li ≠ 40%-li. Qarışığın faizi həmişə ikisinin arasında olur.
  • Su əlavə edəndə duzu da dəyişmək. Dəyişən yalnız ümumi kütlədir.
Yadda saxla
iş = məhsuldarlıq · vaxt; birgə: x/a + x/b = 1 duz = kütlə · p/100 su əlavə et / buxarlandır → duz sabit qarışdır → duzlar toplanır
Özünü yoxla: 3 sual
  1. 500 q 12%-li məhlulda neçə qram duz var? 500·0,12 = 60 q.
  2. 40%-li 50 q məhlula 50 q su əlavə etdik. Yeni faiz? Duz 20 q, kütlə 100 q → 20%.
  3. Bir boru hovuzu 10 saata, digəri 15 saata doldurur. Birlikdə? x/10 + x/15 = 1 → 3x + 2x = 30 → x = 6 saat.
