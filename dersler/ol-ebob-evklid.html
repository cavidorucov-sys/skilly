ƏBOB/ƏKOB, Evklid alqoritmi

ƏBOB və ƏKOB-u sadə vuruqlarla tapmağı Natural ədədlər mövzusunda öyrənmisən. Olimpiadada isə ədədlər böyük olur, ya da ümumiyyətlə ədəd deyil, ifadə olur: ƏBOB(n + 3; 2n + 1). Belə yerdə vuruqlara ayırmaq işləmir — Evklid alqoritmi işləyir. Burada onu, ƏBOB · ƏKOB = a · b düsturunun olimpiada tətbiqlərini və ax + by = ƏBOB bərabərliyini (Bezu) öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Evklid alqoritmi

1 Niyə lazımdır

ƏBOB(1071; 462) tap. Vuruqlara ayırmaq olar, amma 1071-in böləni 17 olduğunu tapmaq vaxt aparır. Ədəd 6 rəqəmli olsa, iş daha da uzanır. Evklid (təxminən 2300 il əvvəl) elə bir yol tapıb ki, heç bir vuruq axtarmadan, yalnız qalıqlı bölmə ilə ƏBOB tapılır. Kompüterlər bu gün də məhz belə hesablayır.

2 Əsas fikir

Tutaq ki, a = b · q + r (qalıqlı bölmə, 0 ≤ r < b). Onda

ƏBOB(a; b) = ƏBOB(b; r) xüsusi halda: ƏBOB(a; b) = ƏBOB(a − b; b)

Niyə (isbatın ideyası). d həm a-nı, həm b-ni bölürsə, r = a − bq fərqini də bölür. Tərsinə: d həm b-ni, həm r-i bölürsə, a = bq + r cəmini də bölür. Deməli (a; b) və (b; r) cütlərinin ortaq bölənləri eyni çoxluqdur — ən böyükləri də eynidir.

Alqoritm: böyüyü kiçiyə qalıqla böl; sonra böləni qalığa böl; sonra yenə böləni qalığa… Qalıqlar hər dəfə kiçilir, nə vaxtsa 0 olur. Son sıfırdan fərqli qalıq — ƏBOB-dur.

3 Həll olunmuş nümunələr

Nümunə 1. ƏBOB(1071; 462) 1071 = 2 · 462 + 147 462 = 3 · 147 + 21 147 = 7 · 21 + 0 Son sıfırdan fərqli qalıq 21. Cavab: 21 Yoxlama: 1071 = 3² · 7 · 17, 462 = 2 · 3 · 7 · 11 → ortaq 3 · 7 = 21 ✓ Nümunə 2. ƏBOB(3587; 2743) 3587 = 1 · 2743 + 844 2743 = 3 · 844 + 211 844 = 4 · 211 + 0 Cavab: 211 (3587 = 17 · 211, 2743 = 13 · 211)

ƏBOB(8; 3) şəkildə: 8 × 3 düzbucaqlıdan ən böyük kvadratları kəsirik. 8 = 2 · 3 + 2 — iki 3×3; 3 = 1 · 2 + 1 — bir 2×2; 2 = 2 · 1 + 0 — iki 1×1. Ən kiçik kvadratın tərəfi 1 = ƏBOB. Qismətlərin cəmi (2 + 1 + 2 = 5) — kvadratların sayıdır.

4 Olimpiada məsələsi

Məsələ. A = 111…1 (12 dənə 1), B = 111…1 (8 dənə 1). ƏBOB(A; B) = ? Həll. Belə ədədi Rₖ ilə işarə edək (k dənə 1). R₁₂ = R₈ · 10⁴ + R₄ (8 vahidin arxasına 4 sıfır, üstəgəl 1111) R₈ = R₄ · 10⁴ + R₄ = R₄ · 10001 → qalıq 0 Evklid: ƏBOB(R₁₂; R₈) = ƏBOB(R₈; R₄) = R₄ = 1111. Cavab: 1111. Ümumi qayda: ƏBOB(Rₘ; Rₙ) = R_ƏBOB(m; n).
Həyatdan. Usta 1071 × 462 sm döşəməni eyni ölçülü kvadrat plitələrlə kəsmədən örtmək istəyir, plitələr mümkün qədər böyük olsun. Plitənin tərəfi = ƏBOB(1071; 462) = 21 sm. Usta Evklidin addımlarını faktiki olaraq lentlə edir: böyük kvadratları kəsib qalan zolağa baxır.
Tipik səhvlər
  • Cavab kimi 0-ı və ya son qisməti yazmaq. ƏBOB — son sıfırdan fərqli qalıqdır (son bölmədəki bölən).
  • İkinci addımda yenə ilk ədədi bölmək. Hər addımda: bölən → bölünən, qalıq → bölən.
  • Qalığı böləndən böyük yazmaq (qisməti az götürmək). Həmişə 0 ≤ r < b.
Yadda saxla
a = b·q + r → ƏBOB(a; b) = ƏBOB(b; r) Qalıq 0 olana qədər davam et; son sıfırdan fərqli qalıq — ƏBOB ƏBOB(a; b) = ƏBOB(a − b; b) — fərqə keçmək olar
Özünü yoxla: 3 sual
  1. ƏBOB(391; 299) = ? 23. 391 = 1 · 299 + 92; 299 = 3 · 92 + 23; 92 = 4 · 23 + 0.
  2. ƏBOB(1001; 455) = ? 91. 1001 = 2 · 455 + 91; 455 = 5 · 91 + 0.
  3. Niyə ƏBOB(n; n + 1) = 1 istənilən natural n üçün? ƏBOB(n + 1; n) = ƏBOB(n; 1) = 1 — fərq 1-dir, ortaq bölən 1-i bölməlidir.

Dərs 2. ƏBOB · ƏKOB = a · b və cütləri saymaq

1 Niyə lazımdır

Olimpiadada tez-tez ədədlərin özü verilmir, yalnız ƏBOB-u, ƏKOB-u, cəmi və ya hasili verilir: "ƏBOB 12, ƏKOB 360 olan neçə cüt var?" Bunu yoxlama ilə yox, bir fikirlə həll edirik.

2 Əsas fikir: ƏBOB-u "çıxarmaq"

d = ƏBOB(a; b) olsun. Onda a = d·x, b = d·y, burada x və y qarşılıqlı sadədir (ortaq vuruq qalsaydı, ƏBOB daha böyük olardı).

a = d·x, b = d·y, ƏBOB(x; y) = 1 ƏKOB(a; b) = d·x·y ƏBOB · ƏKOB = d · dxy = a · b

Bu yazılış olimpiadanın əsas açarıdır: məsələ x, y üçün sadə şərtə çevrilir.

3 Cütləri saymaq

ƏBOB və ƏKOB verilib. x · y = ƏKOB : ƏBOB = m, ƏBOB(x; y) = 1. m-in hər sadə vuruğu öz qüvvəti ilə bütövlükdə ya x-ə, ya y-ə gedir (bölünsə, ortaq vuruq yaranar). m-də k müxtəlif sadə vuruq varsa:

sıralı cütlər: 2ᵏ, a < b olan cütlər: 2ᵏ⁻¹
Nümunə 1. ƏBOB(a; b) = 12, ƏKOB(a; b) = 360. Neçə cüt (a < b)? m = 360 : 12 = 30 = 2 · 3 · 5 → k = 3 → 2² = 4 cüt x · y = 30: (1; 30), (2; 15), (3; 10), (5; 6) (a; b) = (12; 360), (24; 180), (36; 120), (60; 72) Nümunə 2. a + b = 168, ƏBOB(a; b) = 24. Neçə cüt (a < b)? x + y = 168 : 24 = 7, ƏBOB(x; y) = 1, x < y (1; 6), (2; 5), (3; 4) — hamısı qarşılıqlı sadədir (a; b) = (24; 144), (48; 120), (72; 96). Cavab: 3

4 Olimpiada məsələsi

Məsələ. ƏBOB(a; b) + ƏKOB(a; b) = a + b. İsbat et ki, ədədlərdən biri digərinin bölənidir. Həll. a = dx, b = dy, ƏKOB = dxy: d + dxy = dx + dy | : d 1 + xy = x + y xy − x − y + 1 = 0 (x − 1)(y − 1) = 0 → x = 1 və ya y = 1 x = 1 olsa, a = d — a ədədi b-ni bölür. y = 1 olsa, əksinə. ∎
Həyatdan. İki mayak: biri hər 12 saniyədən, digəri hər 18 saniyədən bir yanır. Hər ƏKOB(12; 18) = 36 saniyədən bir birlikdə yanırlar. Düstura görə yoxla: ƏBOB · ƏKOB = 6 · 36 = 216 = 12 · 18 ✓. Əgər ƏBOB məlumdursa, ƏKOB-u bir bölmə ilə tapırsan.
Tipik səhvlər
  • x və y-nin qarşılıqlı sadə olmasını unutmaq. x + y = 8-də (2; 6) cütü yaramır: ƏBOB(2; 6) = 2, ƏBOB böyüyər.
  • Sadə vuruğun qüvvətini bölmək: m = 2² · 3-də x = 2, y = 6 olmaz — 2² bütövlükdə bir tərəfə gedir.
  • Sıralı və sırasız cütləri qarışdırmaq: 2ᵏ — sıralı, a < b üçün yarısı.
Yadda saxla
a = dx, b = dy, ƏBOB(x; y) = 1, ƏKOB = dxy ƏBOB · ƏKOB = a · b ƏKOB : ƏBOB-da k sadə vuruq → 2ᵏ⁻¹ cüt (a < b)
Özünü yoxla: 3 sual
  1. a = 36, ƏBOB(a; b) = 12, ƏKOB(a; b) = 180. b = ? 60. b = 12 · 180 : 36 = 60.
  2. ƏBOB 6, ƏKOB 210 olan neçə cüt var (a < b)? 2. m = 210 : 6 = 35 = 5 · 7 → k = 2 → 2¹ = 2 cüt: (6; 210), (30; 42).
  3. a + b = 60, ƏBOB(a; b) = 12. Neçə cüt (a < b)? 2. x + y = 5: (1; 4), (2; 3) → (12; 48), (24; 36).

Dərs 3. İfadələrin ƏBOB-u, ixtisar olunan kəsrlər

1 Niyə lazımdır

Olimpiadanın klassik sualı: "(n + 3)/(2n + 1) kəsri hansı n-lərdə ixtisar olunur?" Burada n məlum deyil, vuruqlara ayırmaq mümkün deyil. Amma Evklidin fikri — birindən o birinin mislini çıx — ifadələrlə də işləyir.

2 Əsas fikir: n-i yox et

ƏBOB(A; B) = ƏBOB(A; B − k·A) (k — istənilən tam) k-nı elə seç ki, n yox olsun
ƏBOB(n + 3; 2n + 1) = ƏBOB(n + 3; 2n + 1 − 2(n + 3)) = ƏBOB(n + 3; −5) = ƏBOB(n + 3; 5) Deməli ƏBOB ya 1, ya 5-dir. 5 olur ⇔ n + 3 ədədi 5-ə bölünür ⇔ n = 2, 7, 12, … 1-dən 100-ə qədər belə n: 2, 7, …, 97 — 20 dənə. Yoxla: n = 2 → 5/5; n = 7 → 10/15 ✓

3 Olimpiada məsələləri

Məsələ 1 (Beynəlxalq olimpiada, 1959). İsbat et ki, (21n + 4)/(14n + 3) kəsri heç bir natural n üçün ixtisar olunmur. Həll. ƏBOB(21n + 4; 14n + 3) = ƏBOB(14n + 3; 7n + 1) (21n + 4 − (14n + 3)) = ƏBOB(7n + 1; 1) (14n + 3 − 2(7n + 1)) = 1. ∎ Məsələ 2. ƏBOB(2¹² − 1; 2¹⁸ − 1) = ? Həll. Fikir: 2ᵐ − 1 − 2ᵐ⁻ⁿ(2ⁿ − 1) = 2ᵐ⁻ⁿ − 1. Yəni ƏBOB(2ᵐ − 1; 2ⁿ − 1) = ƏBOB(2ᵐ⁻ⁿ − 1; 2ⁿ − 1) — üstlərdə Evklid alqoritmi gedir! Nəticə: ƏBOB(2ᵐ − 1; 2ⁿ − 1) = 2ᵈ − 1, d = ƏBOB(m; n) ƏBOB(12; 18) = 6 → 2⁶ − 1 = 63. Cavab: 63 Məsələ 3. ƏBOB(n² + 1; n + 1) hansı qiymətləri ala bilər? Həll. n² + 1 = (n + 1)(n − 1) + 2 → ƏBOB = ƏBOB(n + 1; 2). n tək olanda 2, cüt olanda 1.
Həyatdan. Dişli çarxlarda 21 və 14 diş olsa, eyni dişlər tez-tez rastlaşır və tez yeyilir. Ona görə mühəndislər diş saylarını qarşılıqlı sadə seçir (məs. 21 və 13). Yoxlamaq üçün vuruqlara ayırmağa ehtiyac yoxdur: 21 − 13 = 8, ƏBOB(13; 8) = ƏBOB(8; 5) = … = 1.
Tipik səhvlər
  • Mənfi ədəddə ilişib qalmaq: ƏBOB(n + 3; −5) = ƏBOB(n + 3; 5) — işarə ƏBOB-a təsir etmir.
  • "ƏBOB 5-dir" demək. ƏBOB 5-in bölənidir: bəzən 1, bəzən 5. Hansı n-də 5 olduğunu ayrıca tapmaq lazımdır.
  • Saymada başlanğıcı səhv tapmaq: n + 3 = 5k → ilk natural n = 2 (n = −3 yox).
Yadda saxla
ƏBOB(A; B) = ƏBOB(A; B − kA) — n-i yox et, sabit ədəd qalsın ƏBOB həmin sabitin bölənidir ƏBOB(2ᵐ − 1; 2ⁿ − 1) = 2^ƏBOB(m; n) − 1
Özünü yoxla: 3 sual
  1. ƏBOB(n + 5; 3n + 4) hansı qiymətləri ala bilər? 1 və 11. 3n + 4 − 3(n + 5) = −11; 11 olur, məs. n = 6: 11 və 22.
  2. ƏBOB(2¹² − 1; 2¹⁸ − 1) neçədir? 63 = 2⁶ − 1, çünki ƏBOB(12; 18) = 6.
  3. (n² + 2)/(n + 1) hansı natural n-də natural ədəddir? n = 2. n² + 2 = (n + 1)(n − 1) + 3 → n + 1 ədədi 3-ü bölməlidir → n + 1 = 3. Yoxla: 6/3 = 2.

Dərs 4. Bezu bərabərliyi: ax + by = ƏBOB(a; b)

1 Niyə lazımdır

9 litrlik və 4 litrlik qabla düz 1 litr su ölçmək olarmı? Olar: 9-luğu doldur, ondan 4-lüyü iki dəfə doldurub boşalt — 9-luqda 9 − 2 · 4 = 1 litr qalır. Ümumi sual: a və b-ni toplayıb-çıxmaqla hansı ədədləri almaq olar? Cavab: ƏBOB-un bütün misllərini, başqa heç nə.

2 Əsas fikir

Bezu teoremi: elə tam x, y var ki, a·x + b·y = ƏBOB(a; b) Nəticə: ax + by = c tam həlli var ⇔ ƏBOB(a; b) ədədi c-ni bölür

Niyə. Evklid alqoritminin hər qalığı a və b-nin "tam kombinasiyasıdır": r₁ = a − q₁b, r₂ = b − q₂r₁ və s. Son qalıq — ƏBOB — da belədir. Tərsinə: ax + by həmişə ƏBOB-a bölünür, çünki hər iki toplanan bölünür.

3 Evklidi geriyə açmaq

Nümunə 1. 37x + 11y = 1 üçün tam x, y tap. İrəli: 37 = 3 · 11 + 4 11 = 2 · 4 + 3 4 = 1 · 3 + 1 Geri (hər qalığı yuxarıdakı bərabərlikdən əvəz et): 1 = 4 − 3 = 4 − (11 − 2 · 4) = 3 · 4 − 11 = 3 · (37 − 3 · 11) − 11 = 3 · 37 − 10 · 11 x = 3, y = −10. Yoxla: 111 − 110 = 1 ✓ Nümunə 2. 1071x + 462y = 21 (Dərs 1-in addımları) 21 = 462 − 3 · 147 = 462 − 3(1071 − 2 · 462) = 7 · 462 − 3 · 1071 x = −3, y = 7. Yoxla: −3213 + 3234 = 21 ✓

Bir həll tapılandan sonra başqaları da var: x-ə b/d əlavə edib y-dən a/d çıxsan, cəm dəyişmir (d = ƏBOB). Məsələn, 37x + 11y = 1: (3; −10), (14; −47), (−8; 27), …

4 Olimpiada məsələləri

Məsələ 1. Kalkulyatorda iki düymə var: "+7" və "−11". Ekranda 0 var. Ən azı neçə basma ilə 1 almaq olar? Həll. 7x − 11y = 1, x, y ≥ 0 — basmaların sayı. 7 · 8 = 56 = 55 + 1 → x = 8, y = 5. Bütün həllər: x = 8 + 11t, y = 5 + 7t; t < 0 olsa y < 0. Ən kiçik x + y = 13. Cavab: 13. Məsələ 2 (Evklid lemması). ƏBOB(a; b) = 1 və a ədədi bc-ni bölür. İsbat et ki, a ədədi c-ni bölür. Həll. Bezu: ax + by = 1. Hər tərəfi c-yə vur: acx + bcy = c. acx a-ya bölünür, bcy də (bc bölünür) → cəm c də a-ya bölünür. ∎ (Bundan çıxır: sadə p ədədi hasili bölürsə, vuruqlardan birini bölür.)
Həyatdan. 5 və 3 litrlik qabla 4 litr: 2 · 5 − 2 · 3 = 4. 5-liyi doldur, 3-lüyə tök (5-likdə 2 qalır); 3-lüyü boşalt, 2 litri ora tök; 5-liyi yenə doldur, 3-lüyə 1 litr tök — 5-likdə düz 4 litr qalır.
Tipik səhvlər
  • Geri açanda qalığı səhv bərabərlikdən götürmək. Hər addımda ən son qalığı əvəz et, işarələrə diqqət.
  • Tək həll olduğunu düşünmək: həllər sonsuzdur, addım b/d və a/d.
  • 6x + 15y = 7 kimi tənlikdə həll axtarmaq: ƏBOB = 3, 7-ni bölmür — tam həll yoxdur.
Yadda saxla
Elə tam x, y var ki, ax + by = ƏBOB(a; b) Tapmaq: Evklidi geriyə aç ax + by = c həll olunur ⇔ ƏBOB(a; b) | c
Özünü yoxla: 3 sual
  1. 13x + 8y = 1 üçün tam x, y tap. x = −3, y = 5 (−39 + 40 = 1). Başqa həllər də var: x = 5, y = −8 və s.
  2. 6x + 15y = 7 tənliyinin tam həlli varmı? Yox. ƏBOB(6; 15) = 3, 7 isə 3-ə bölünmür.
  3. 5 və 3 litrlik qabla 4 litr ölçmək olarmı? Olar: ƏBOB(5; 3) = 1, 4 = 2 · 5 − 2 · 3 (yuxarıdakı "Həyatdan" üsulu).
