Kvadrat tənlik, diskriminant

ax² + bx + c = 0 — DİM-də ən çox rast gəlinən tənlik. Natamam kvadrat tənlikləri, diskriminantı, köklərin sayını, köklər düsturunu və cüt əmsal üçün qısa düsturu öyrənəcəksən. Sonda — kvadrat tənliyə gələn məsələlər.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Kvadrat tənlik. Natamam kvadrat tənliklər

1 Niyə lazımdır

Kvadrat formalı otağın sahəsi 36 m² olarsa, tərəfi nə qədərdir? x² = 36. Bu artıq xətti tənlik deyil — x kvadratdadır. Sahə, sürət, düşən cisim, faiz artımı — hamısı kvadrat tənliyə gətirir.

2 Kvadrat tənlik nədir

ax² + bx + c = 0, a ≠ 0 a — birinci əmsal, b — ikinci əmsal, c — sərbəst hədd

Məsələn, 2x² − 3x − 5 = 0: a = 2, b = −3, c = −5. Əmsalları işarəsi ilə götür. a = 1 olanda tənliyə gətirilmiş kvadrat tənlik deyilir: x² + px + q = 0.

Əgər b və ya c sıfırdırsa, tənlik natamamdır. Onu düstursuz, tez həll edirik.

3 Natamam tənliklərin üç növü

ax² = 0 → x = 0 (bir kök) ax² + c = 0 → x² = −c/a −c/a > 0: x = ±√(−c/a) −c/a < 0: kök yoxdur ax² + bx = 0 → x(ax + b) = 0 x = 0 və x = −b/a

Son halda hasil sıfırdır qaydasını işlədirik: A·B = 0 ⇔ A = 0 və ya B = 0.

4 Həll olunmuş nümunələr

1) 3x² − 27 = 0 → 3x² = 27 → x² = 9 → x = 3, x = −3 2) 2x² + 8 = 0 → x² = −4 → kvadrat mənfi olmur — kök yoxdur 3) 5x² − 15x = 0 → 5x(x − 3) = 0 → x = 0, x = 3 4) x² − 12 = 0 → x² = 12 → x = ±√12 = ±2√3 5) 4x² = 0 → x = 0
Həyatdan. Otaq məsələsi: x² = 36 → x = 6 və x = −6. Uzunluq mənfi olmur — tərəf 6 m. Riyazi kökü həmişə şərtlə yoxla.
Tipik səhvlər
  • x² = 9-dan yalnız x = 3 yazmaq. İki kök var: ±3.
  • 5x² = 15x-i x-ə bölüb x = 3 yazmaq — x = 0 kökü itir. Bölmə yox, mötərizə xaricinə çıxar.
  • x² = −4 → "x = ±2". Yoxla: 2² = 4, −4 deyil. Kök yoxdur.
Yadda saxla
c yoxdursa: x-i mötərizə xaricinə çıxar → bir kök 0. b yoxdursa: x² = ədəd → ±√ və ya kök yoxdur. Heç vaxt x-ə bölmə.
Özünü yoxla: 3 sual
  1. 2x² − 50 = 0. Köklər? x² = 25 → x = 5, x = −5.
  2. x² + 7x = 0. Köklər? x(x + 7) = 0 → x = 0, x = −7.
  3. 3x² + 12 = 0. Neçə kök? x² = −4 — kök yoxdur (0).

Dərs 2. Diskriminant və köklərin sayı

1 Niyə lazımdır

Tam kvadrat tənliyi həll etməzdən əvvəl bir ədəd hesablayıb bilmək olar: kök neçədir — iki, bir, yoxsa heç biri. Bu ədəd diskriminantdır (latınca "ayıran"). DİM-də "neçə kökü var?", "hansı qiymətdə bir kökü var?" sualları məhz onunla həll olunur.

2 Düstur və üç hal

D = b² − 4ac D > 0 → iki müxtəlif kök D = 0 → bir kök (iki bərabər kök) D < 0 → kök yoxdur

Haradan gəlir? Tam kvadrat ayıranda tənlik bu şəklə düşür:

(x + b/(2a))² = D/(4a²)

Sol tərəf kvadratdır, mənfi ola bilməz. D < 0 olanda sağ tərəf mənfidir — kök yoxdur. D = 0 olanda x = −b/(2a) — tək kök. D > 0 olanda kvadratın kökü iki işarəlidir — iki kök.

y = ax² + bx + c parabolasının x oxu ilə kəsişmə nöqtələri — tənliyin kökləridir.

3 Həll olunmuş nümunələr

1) 2x² − 3x − 5 = 0 D = (−3)² − 4·2·(−5) = 9 + 40 = 49 > 0 → iki kök 2) x² − 6x + 9 = 0 D = (−6)² − 4·1·9 = 36 − 36 = 0 → bir kök (x = 3) 3) 3x² + 2x + 1 = 0 D = 2² − 4·3·1 = 4 − 12 = −8 < 0 → kök yoxdur

Faydalı fənd: a və c müxtəlif işarəlidirsə, −4ac > 0, deməli D > 0 — həmişə iki kök var. Məsələn, x² + 100x − 1 = 0.

4 Parametrli suallar

c-nin hansı qiymətində x² − 6x + c = 0 tənliyinin bir kökü var? D = 0: 36 − 4c = 0 → c = 9. (Onda (x − 3)² = 0.) İki müxtəlif kök üçün: 36 − 4c > 0 → c < 9. Belə c-lərin ən böyük tamı: 8. Kök olmaması üçün: c > 9.
Həyatdan. Top 20 m/s sürətlə yuxarı atılıb, hündürlüyü h = 20t − 5t². 25 metrə çatacaqmı? 20t − 5t² = 25 → t² − 4t + 5 = 0 → D = 16 − 20 = −4 < 0. Kök yoxdur — top 25 metrə çatmır. (Ən yüksək nöqtəsi 20 m-dir: orada D = 0.)
Tipik səhvlər
  • (−3)² yerinə −9 yazmaq. Mənfi ədədin kvadratı müsbətdir: 9.
  • Mənfi c-də işarə səhvi: −4·2·(−5) = +40. Mənfiləri mötərizədə yaz.
  • D = 0 görüb "kök yoxdur" demək. D = 0 — bir kök deməkdir.
Yadda saxla
D = b² − 4ac D > 0 — 2 kök; D = 0 — 1 kök; D < 0 — kök yoxdur. "Bir kökü var" sualı → D = 0 tənliyini həll et.
Özünü yoxla: 3 sual
  1. x² + 4x + 5 = 0. Neçə kök? D = 16 − 20 = −4 < 0. Kök yoxdur (0).
  2. 4x² − 4x + 1 = 0. Neçə kök? D = 16 − 16 = 0. Bir kök: x = 1/2.
  3. b-nin hansı müsbət qiymətində x² + bx + 16 = 0 tənliyinin bir kökü var? b² − 64 = 0 → b = 8 (b = −8 mənfidir).

Dərs 3. Kvadrat tənliyin kökləri düsturu

1 Niyə lazımdır

Diskriminant köklərin sayını deyir. İndi kökləri özlərini tapırıq — istənilən kvadrat tənlik üçün işləyən bir düsturla.

2 Köklər düsturu

x₁,₂ = (−b ± √D) / (2a), D = b² − 4ac ≥ 0

Ardıcıllıq: a, b, c-ni işarəsi ilə yaz → D → √D → iki kök ayrı-ayrı: biri "+" ilə, biri "−" ilə. 2a bütün surətin məxrəcidir.

Nümunə 1. 2x² − 3x − 5 = 0 a = 2, b = −3, c = −5 D = 9 + 40 = 49, √D = 7 x = (3 ± 7)/4 → x₁ = 10/4 = 5/2, x₂ = −4/4 = −1 Yoxla x = −1: 2 + 3 − 5 = 0 ✓
Nümunə 2. x² − 4x − 1 = 0 D = 16 + 4 = 20, √20 = 2√5 x = (4 ± 2√5)/2 = 2 ± √5 Böyük kök: 2 + √5, kiçik kök: 2 − √5
Nümunə 3. −x² + 2x + 8 = 0 a mənfidir — əvvəl hər iki tərəfi −1-ə vur: x² − 2x − 8 = 0 D = 4 + 32 = 36, √D = 6 x = (2 ± 6)/2 → x₁ = 4, x₂ = −2

3 Cüt ikinci əmsal: b = 2k

b cüt olanda k = b/2 götür. Düstur sadələşir, ədədlər kiçik qalır:

D₁ = k² − ac (D₁ = D/4) x₁,₂ = (−k ± √D₁) / a

Köklərin sayı üçün D₁-in işarəsi də kifayətdir: D₁ və D eyni işarəlidir.

Nümunə 4. 3x² − 8x + 4 = 0 b = −8 = 2·(−4) → k = −4 D₁ = (−4)² − 3·4 = 16 − 12 = 4, √D₁ = 2 x = (4 ± 2)/3 → x₁ = 2, x₂ = 2/3 Yoxla x = 2: 12 − 16 + 4 = 0 ✓
Nümunə 5. x² + 6x − 2 = 0 k = 3, D₁ = 9 + 2 = 11 x = −3 ± √11
Nümunə 2 yenidən (k = −2): D₁ = 4 + 1 = 5, x = 2 ± √5 — iki addımda.

4 Həyatdan

Həyatdan. D tam kvadratdırsa (1, 4, 9, 25, 49 …), köklər rasional ədədlərdir; deyilsə, cavabda √ qalır. İmtahanda D "pis" çıxırsa, əvvəl hesabı yoxla — çox vaxt səhv işarədədir.
Tipik səhvlər
  • Yalnız √D-ni 2a-ya bölmək: −b ± √D/(2a) səhvdir. Bütün surət bölünür.
  • b mənfi olanda −b-ni mənfi yazmaq: b = −3 → −b = 3.
  • Cüt əmsal düsturunda məxrəci 2a yazmaq. Orada məxrəc a-dır.
Yadda saxla
x = (−b ± √D)/(2a) b = 2k: D₁ = k² − ac, x = (−k ± √D₁)/a a < 0 olanda əvvəl −1-ə vur.
Özünü yoxla: 3 sual
  1. x² − 7x + 10 = 0. Köklər? D = 49 − 40 = 9 → x = (7 ± 3)/2 → 5 və 2.
  2. 5x² + 2x − 3 = 0. Köklər? k = 1, D₁ = 1 + 15 = 16 → x = (−1 ± 4)/5 → 3/5 və −1.
  3. x² + 2x − 4 = 0. Böyük kök? k = 1, D₁ = 1 + 4 = 5 → x = −1 ± √5. Böyüyü −1 + √5.

Dərs 4. Kvadrat tənliklərin tətbiqi ilə məsələ həlli

1 Niyə lazımdır

Sahə, ardıcıl ədədlərin hasili, atılan cisim, "hər kəs hər kəslə" — bu məsələlərdə naməlum özü-özünə vurulur və kvadrat tənlik alınır. Tənliyin iki kökü olur, amma məsələnin cavabı çox vaxt birdir: mənasız kökü atırıq.

2 Alqoritm

1. x — naməlum; qalanları x ilə yaz. 2. Tənlik qur, ax² + bx + c = 0 şəklinə gətir. 3. D və köklər. 4. Hər kökü şərtlə yoxla: mənfi uzunluq / vaxt / say — atılır.

3 Həll olunmuş nümunələr

Nümunə 1. Düzbucaqlının uzunluğu enindən 3 m çoxdur, sahəsi 40 m². En x, uzunluq x + 3: x(x + 3) = 40 → x² + 3x − 40 = 0 D = 9 + 160 = 169, √D = 13 x = (−3 ± 13)/2 → x = 5, x = −8 (atılır) Cavab: en 5 m, uzunluq 8 m (yoxla: 5·8 = 40 ✓)
Nümunə 2. Ardıcıl iki natural ədədin hasili 156-dır. x(x + 1) = 156 → x² + x − 156 = 0 D = 1 + 624 = 625, √D = 25 x = (−1 ± 25)/2 → x = 12, x = −13 (natural deyil) Cavab: 12 və 13
Nümunə 3. Görüşdə hər kəs hər kəslə bir dəfə əl sıxdı — 45 əl sıxma. Neçə nəfər var idi? x nəfərin hər biri x − 1 nəfərlə; hər əl sıxma iki dəfə sayılıb: x(x − 1)/2 = 45 → x² − x − 90 = 0 D = 1 + 360 = 361, √D = 19 x = (1 + 19)/2 = 10 (x = −9 atılır) Cavab: 10 nəfər

4 Həyatdan: iki kök də doğrudur

Həyatdan. Top 20 m/s sürətlə yuxarı atılıb: h = 20t − 5t². Top nə vaxt 15 m hündürlükdə olur? 5t² − 20t + 15 = 0 → t² − 4t + 3 = 0 → t = 1 və t = 3. İkisi də doğrudur: 1-ci saniyədə qalxarkən, 3-cü saniyədə enərkən. Kökü atmaq yalnız şərt qadağan edəndə lazımdır.
Tipik səhvlər
  • Mənfi kökü cavab kimi saxlamaq (mənfi en, mənfi say).
  • Hər iki müsbət kökü "biri artıqdır" deyə atmaq. Topun nümunəsində ikisi də mənalıdır — suala bax: "ilk dəfə" yoxsa "ikinci dəfə".
  • Əl sıxma məsələsində 2-yə bölməyi unutmaq: A ilə B-nin əl sıxması B ilə A-nınki ilə eynidir.
Yadda saxla
Tənlik qur → ax² + bx + c = 0 → D → köklər → şərtlə süz. Cavab sualın soruşduğu kəmiyyətdir.
Özünü yoxla: 3 sual
  1. Kvadratın tərəfini 3 sm artırsaq, sahəsi 64 sm² olar. Tərəf nə qədərdir? (x + 3)² = 64 → x + 3 = 8 (−8 mənasızdır) → x = 5 sm.
  2. Natural ədədin kvadratı özündən 30 çoxdur. Ədəd? x² − x − 30 = 0 → D = 1 + 120 = 121 → x = (1 + 11)/2 = 6 (x = −5 natural deyil).
  3. Düzbucaqlının perimetri 20 m, sahəsi 24 m². Böyük tərəf? Tərəflərin cəmi 10: x(10 − x) = 24 → x² − 10x + 24 = 0 → x = 4, x = 6. Böyük tərəf 6 m.
