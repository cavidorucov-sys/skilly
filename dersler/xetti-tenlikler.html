Riyaziyyat · Buraxılış · DİM: Birdəyişənli tənliklər

Xətti tənliklər

ax = b şəklinə gətirilən tənliklər — bütün cəbrin təməlidir. Burada mötərizəli və kəsr əmsallı tənlikləri həll etməyi, tənliyin neçə kökü olduğunu (bir, heç biri, sonsuz sayda) və parametrli tənlikləri öyrənəcəksən. Sonda — mətnli məsələlər.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Birdəyişənli xətti tənlik və onun həlli

1 Niyə lazımdır

Taksidə minmək 1 manat, hər kilometr isə 0,5 manatdır. Sən 6 manat ödədin. Neçə kilometr getdin? Yolu x ilə işarə edək:

1 + 0,5x = 6

Bu, xətti tənlikdir: x yalnız birinci dərəcədə var (x² yoxdur, məxrəcdə x yoxdur). Həlli: 0,5x = 5 → x = 10 km.

2 Əsas fikir

Tənliyin kökü — tənliyi doğru bərabərliyə çevirən ədəddir. Tənliyi həll etmək — bütün köklərini tapmaq (və ya kökü olmadığını göstərmək).

Tənliyi addım-addım sadələşdiririk, kökləri isə dəyişmir. Belə tənliklərə eynigüclü tənliklər deyilir. İki qayda kifayətdir:

1) Həddi bir tərəfdən o biri tərəfə əks işarə ilə keçirmək olar: 5x − 7 = 2x + 8 → 5x − 2x = 8 + 7 2) Hər iki tərəfi sıfırdan fərqli eyni ədədə vurmaq və ya bölmək olar: 3x = 15 → x = 5

Birdəyişənli xətti tənlik — ax = b şəklində tənlikdir. a ≠ 0 olanda yeganə kökü var:

ax = b, a ≠ 0 → x = b/a

Tənlik — taraz tərəzidir. Hər iki gözə eyni şeyi əlavə etsən, eyni şeyi götürsən və ya hər ikisini eyni dəfə artırsan — tarazlıq pozulmur.

3 Həll olunmuş nümunələr

Nümunə 1. 5x − 7 = 2x + 8 x-li hədlər sola, ədədlər sağa: 5x − 2x = 8 + 7 3x = 15 → x = 5 Yoxla: 5·5 − 7 = 18, 2·5 + 8 = 18 ✓ Cavab: x = 5
Nümunə 2. 3(x − 4) − 2(x + 1) = 5 − x Mötərizələri aç: 3x − 12 − 2x − 2 = 5 − x Oxşar hədlər: x − 14 = 5 − x x + x = 5 + 14 → 2x = 19 → x = 9,5 Yoxla: 3·5,5 − 2·10,5 = 16,5 − 21 = −4,5; 5 − 9,5 = −4,5 ✓ Cavab: x = 9,5
Nümunə 3. 4 − 2(x − 3) = 3x Mənfi əmsalı mötərizədəki hər həddə vur: −2(x − 3) = −2x + 6 4 − 2x + 6 = 3x → 10 = 5x → x = 2 Yoxla: 4 − 2·(−1) = 6, 3·2 = 6 ✓ Cavab: x = 2
Həyatdan. Telefon tarifi: ayda 5 manat abunə haqqı və hər dəqiqə 0,1 manat. Ay sonunda hesab 12 manat gəldi. Neçə dəqiqə danışmısan? 5 + 0,1x = 12 → 0,1x = 7 → x = 70 dəqiqə.
Tipik səhvlər
  • Həddi o biri tərəfə keçirəndə işarəni dəyişməmək: 5x − 7 = 8 → 5x = 8 − 7 səhvdir, düzü 5x = 8 + 7.
  • Mənfi mötərizədə yalnız birinci həddin işarəsini dəyişmək: −2(x − 3) = −2x + 6, "−2x − 6" yox.
  • Tərsinə bölmək: 3x = 15 → x = 15/3 = 5, "3/15" yox.
Yadda saxla
Mötərizələri aç → x-li hədlər bir tərəfə, ədədlər o biri tərəfə (keçəndə işarə dəyişir) → ax = b → x = b/a. Kökü tənliyə qoyub yoxla.
Özünü yoxla: 3 sual
  1. 7x + 3 = 4x − 9. x = ? 3x = −12 → x = −4. Yoxla: −28 + 3 = −25, −16 − 9 = −25 ✓
  2. 2(x + 5) = 3x − 1. x = ? 2x + 10 = 3x − 1 → x = 11. Yoxla: 2·16 = 32, 33 − 1 = 32 ✓
  3. 5 − (x − 2) = 2x + 1. x = ? 5 − x + 2 = 2x + 1 → 6 = 3x → x = 2. Yoxla: 5 − 0 = 5, 4 + 1 = 5 ✓

Dərs 2. Kəsr əmsallı xətti tənliklər

1 Niyə lazımdır

Kitabın birinci gün 1/3 hissəsini, ikinci gün 1/4 hissəsini oxudun — cəmi 70 səhifə. Kitab neçə səhifədir? Tənlik: x/3 + x/4 = 70. Kəsrlərlə hesablamaq yorucudur. Bir hərəkətlə onlardan qurtulmaq olar.

2 Əsas fikir: ortaq məxrəcə vur

Bütün məxrəclərin ən kiçik ortaq bölünənini tap və tənliyin hər həddini ona vur. Kəsrlər yox olur, adi xətti tənlik qalır.

x/3 + x/4 = 70 | ortaq məxrəc 12 12·x/3 + 12·x/4 = 12·70 4x + 3x = 840 → 7x = 840 → x = 120

İki vacib qayda:

1) Kəsr olmayan hədd də vurulur: x/2 − 3 → ×6 → 3x − 18 2) Surəti mötərizəyə al: −(x − 3)/2 → ×10 → −5(x − 3) = −5x + 15

Onluq kəsrlər üçün də eyni fikir: hər iki tərəfi 10-a (və ya 100-ə) vur.

3 Həll olunmuş nümunələr

Nümunə 1. (x − 1)/3 + (x + 2)/4 = 6 Ortaq məxrəc 12. Hər həddi 12-yə vur: 4(x − 1) + 3(x + 2) = 72 4x − 4 + 3x + 6 = 72 → 7x + 2 = 72 → 7x = 70 → x = 10 Yoxla: 9/3 + 12/4 = 3 + 3 = 6 ✓ Cavab: x = 10
Nümunə 2. (2x + 1)/5 − (x − 3)/2 = 1 Ortaq məxrəc 10: 2(2x + 1) − 5(x − 3) = 10 4x + 2 − 5x + 15 = 10 → −x + 17 = 10 → x = 7 Yoxla: 15/5 − 4/2 = 3 − 2 = 1 ✓ Cavab: x = 7
Nümunə 3. x/2 − 3 = (x + 4)/6 Ortaq məxrəc 6 (3 də vurulur!): 3x − 18 = x + 4 → 2x = 22 → x = 11 Yoxla: 5,5 − 3 = 2,5; 15/6 = 2,5 ✓ Cavab: x = 11
Nümunə 4. 0,3x + 1,2 = 0,5x − 0,4 Hər iki tərəfi 10-a vur: 3x + 12 = 5x − 4 16 = 2x → x = 8 Yoxla: 2,4 + 1,2 = 3,6; 4 − 0,4 = 3,6 ✓ Cavab: x = 8
Həyatdan. Kitab məsələsi: x/3 + x/4 = 70 → x = 120 səhifə. Yoxla: 120-nin 1/3-i 40 səhifə, 1/4-i 30 səhifə, cəmi 70 ✓
Tipik səhvlər
  • Kəsrsiz həddi vurmağı unutmaq: x/2 − 3 = … → "3x − 3" yox, 3x − 18.
  • Surəti mötərizəsiz vurmaq: 2·(2x + 1) = 4x + 2, "4x + 1" yox.
  • Kəsr qarşısındakı mənfini yalnız birinci həddə aid etmək: −5(x − 3) = −5x + 15.
Yadda saxla
Ortaq məxrəcə vur — HƏR həddi, kəsrsizləri də. Surəti mötərizəyə al, sonra aç. Sonra Dərs 1-dəki kimi: ax = b.
Özünü yoxla: 3 sual
  1. x/3 + x/6 = 5. x = ? 6-ya vur: 2x + x = 30 → x = 10. Yoxla: 10/3 + 10/6 = 20/6 + 10/6 = 5 ✓
  2. (x + 3)/2 = (x − 1)/3. x = ? Çarpaz vur: 3(x + 3) = 2(x − 1) → 3x + 9 = 2x − 2 → x = −11. Yoxla: −8/2 = −4, −12/3 = −4 ✓
  3. (x − 2)/4 − 1 = x/6. x = ? 12-yə vur: 3(x − 2) − 12 = 2x → 3x − 18 = 2x → x = 18. Yoxla: 16/4 − 1 = 3, 18/6 = 3 ✓

Dərs 3. Tənliyin neçə kökü var? Parametrli tənliklər

1 Niyə lazımdır

İki taksi şirkəti: birində minmək 2 manat, o birində 1 manat; hər ikisində kilometr 0,5 manatdır. Hansı məsafədə qiymətlər bərabər olar? 2 + 0,5x = 1 + 0,5x → 0·x = −1. Heç vaxt! Tənliyin kökü yoxdur.

Hər xətti tənliyin bir kökü olmur. DİM-də bunu soruşurlar — xüsusən parametrli tənliklərdə.

2 Üç hal

Tənliyi sadələşdirib ax = b şəklinə gətir və x-in əmsalına bax:

ax = b a ≠ 0 → bir kök: x = b/a a = 0, b ≠ 0 → kök yoxdur (0·x = b) a = 0, b = 0 → sonsuz sayda kök (0·x = 0)
Nümunə 1. 3(x − 2) + 1 = 3x − 4 3x − 6 + 1 = 3x − 4 → 3x − 5 = 3x − 4 3x − 3x = −4 + 5 → 0·x = 1 0·x həmişə 0-a bərabərdir, 1 ola bilməz. Cavab: kök yoxdur
Nümunə 2. 4(x + 1) − x = 3x + 4 4x + 4 − x = 3x + 4 → 3x + 4 = 3x + 4 0·x = 0 — istənilən x yarayır. Cavab: sonsuz sayda kök (hər ədəd kökdür)

3 Parametr nədir

Parametr — tənlikdə x-dən başqa hərflə yazılmış ədəddir (adətən a). Onun qiyməti dəyişdikcə tənlik də dəyişir. Sual: "a-nın hansı qiymətində tənliyin kökü yoxdur / sonsuz sayda kökü var / kökü filan ədəddir?"

1. Tənliyi (…)·x = (…) şəklinə gətir. 2. x-in əmsalını sıfıra bərabər et → a-nı tap. 3. Həmin a-nı sağ tərəfə qoy: sağ tərəf ≠ 0 → kök yoxdur sağ tərəf = 0 → sonsuz sayda kök

4 Parametrli nümunələr

Nümunə 3. (a² − 4)x = a − 2 Əmsal: a² − 4 = 0 → a = 2 və ya a = −2 a = 2: 0·x = 0 → sonsuz sayda kök a = −2: 0·x = −4 → kök yoxdur Başqa a-larda bir kök: x = (a − 2)/(a² − 4) = 1/(a + 2) Cavab: kök yoxdur — a = −2; sonsuz sayda kök — a = 2
Nümunə 4. a(x − 1) = 2x + 3a. Kök yoxdur — a = ? Aç: ax − a = 2x + 3a → ax − 2x = 3a + a → (a − 2)x = 4a Əmsal sıfır: a = 2. Onda sağ tərəf 4·2 = 8 ≠ 0 → 0·x = 8 Cavab: a = 2
Nümunə 5. a-nın hansı qiymətində x = 3 ədədi ax + 4 = 2x + a tənliyinin köküdür? x = 3 yaz: 3a + 4 = 6 + a → 2a = 2 → a = 1 Yoxla: a = 1 → x + 4 = 2x + 1 → x = 3 ✓ Cavab: a = 1
Həyatdan. Taksi şirkətlərinin hər ikisində minmək 1 manat, kilometr 0,5 manat olsaydı: 1 + 0,5x = 1 + 0,5x → 0·x = 0. Hər məsafədə qiymət eynidir — sonsuz sayda "kök". Xətti tənliyin üç halı həyatda belə görünür: bir an bərabərləşmək, heç vaxt bərabərləşməmək, həmişə bərabər olmaq.
Tipik səhvlər
  • a² − 4 = 0-dan yalnız a = 2 yazmaq. Mənfi kök də var: a = −2.
  • Əmsal sıfır olan kimi "kök yoxdur" demək. Əvvəl sağ tərəfə bax: 0·x = 0 — sonsuz sayda kök.
  • 0·x = 5 görüb "x = 0" yazmaq. 0·0 = 0, 5 deyil — kök yoxdur.
Yadda saxla
ax = b: a ≠ 0 → bir kök; a = 0, b ≠ 0 → kök yoxdur; a = 0, b = 0 → sonsuz sayda kök. Parametrdə: əmsalı sıfırla, sonra sağ tərəfi yoxla.
Özünü yoxla: 3 sual
  1. 5(x − 1) = 5x − 5. Neçə kök? 5x − 5 = 5x − 5 → 0·x = 0. Sonsuz sayda kök.
  2. 2x − 7 = 2(x − 3). Neçə kök? 2x − 7 = 2x − 6 → 0·x = 1. Kök yoxdur.
  3. a-nın hansı qiymətində (a + 5)x = 3 tənliyinin kökü yoxdur? a + 5 = 0 → a = −5. Onda 0·x = 3 — kök yoxdur.

Dərs 4. Xətti tənliklərin tətbiqi ilə məsələ həlli

1 Niyə lazımdır

Tənlik tərəzi kimidir: iki gözdə eyni çəki olmalıdır. Hər iki gözdən eyni şeyi götürsən, tarazlıq pozulmur — xətti tənliyi də belə həll edirik.

DİM-in mətnli məsələlərinin çoxu xətti tənliyə gəlir: yaş, ardıcıl ədədlər, alış-veriş, hərəkət. Çətin olan həll deyil — tənliyi qurmaqdır. Bunu alqoritmlə edirik.

2 Alqoritm

1. Naməlumu x ilə işarə et (adətən soruşulanı). 2. Qalan kəmiyyətləri x ilə ifadə et. 3. Şərtdəki bərabərliyi tənlik kimi yaz. 4. Həll et. 5. Yoxla və SUALIN cavabını yaz.

Faydalı "tərcümələr": "a çox" → + a; "k dəfə çox" → ·k; ardıcıl ədədlər → x, x + 1, x + 2; ardıcıl cüt (tək) ədədlər → x, x + 2, x + 4; yol = sürət · vaxt.

3 Həll olunmuş nümunələr

Nümunə 1. Ardıcıl üç natural ədədin cəmi 87-dir. Bu ədədlər hansılardır? Kiçiyi x: x + (x + 1) + (x + 2) = 87 3x + 3 = 87 → 3x = 84 → x = 28 Cavab: 28, 29, 30 (yoxla: 28 + 29 + 30 = 87 ✓)
Nümunə 2. Ata oğlundan 4 dəfə böyükdür. 5 il sonra ata oğlundan 3 dəfə böyük olacaq. Oğul neçə yaşındadır? Oğul x, ata 4x. 5 il sonra: x + 5 və 4x + 5 4x + 5 = 3(x + 5) → 4x + 5 = 3x + 15 → x = 10 Yoxla: ata 40; 5 il sonra 45 və 15, 45 = 3·15 ✓ Cavab: oğul 10 yaşındadır
Nümunə 3. Aralarında 360 km olan iki şəhərdən eyni vaxtda bir-birinə doğru iki maşın çıxdı və 3 saat sonra görüşdü. Biri o birindən 20 km/saat sürətlidir. Sürətləri nədir? Yavaşın sürəti x, sürətlinin x + 20. 3 saatda birlikdə 360 km: 3(x + x + 20) = 360 2x + 20 = 120 → 2x = 100 → x = 50 Cavab: 50 km/saat və 70 km/saat (yoxla: 3·50 + 3·70 = 150 + 210 = 360 ✓)

4 Həyatdan

Həyatdan: endirim. Qulaqlığın qiyməti 20% endirimdən sonra 48 manat oldu. Əvvəl neçə idi? Endirimdən sonra qiymətin 80%-i qalır: 0,8x = 48 → x = 60 manat. Yoxla: 60-ın 20%-i 12 manat, 60 − 12 = 48 ✓
Tipik səhvlər
  • Soruşulmayanı cavab yazmaq: oğulun yaşını tapıb atanın yaşını soruşublarsa, 4x-i hesablamağı unutmaq.
  • "3 dəfə çox" ilə "3 çox"u qarışdırmaq: 3x ≠ x + 3.
  • Yaş məsələsində "illər sonra" yalnız bir nəfərə əlavə etmək. Hər kəs eyni sayda il böyüyür.
Yadda saxla
x — naməlum → qalanları x ilə yaz → tənlik → həll → yoxla. Cavab sualın dediyi kəmiyyətdir.
Özünü yoxla: 3 sual
  1. İki ədədin cəmi 50-dir, biri o birindən 8 çoxdur. Kiçik ədəd? x + (x + 8) = 50 → 2x = 42 → x = 21. Ədədlər 21 və 29.
  2. Qələm 2 manat, dəftər 3 manatdır. Cəmi 10 əşya alındı, 24 manat ödənildi. Neçə qələm alınıb? Qələm x, dəftər 10 − x: 2x + 3(10 − x) = 24 → 30 − x = 24 → x = 6. Yoxla: 12 + 12 = 24 ✓
  3. Ardıcıl dörd cüt ədədin cəmi 76-dır. Ən kiçiyi? x + (x + 2) + (x + 4) + (x + 6) = 76 → 4x + 12 = 76 → x = 16. Ədədlər 16, 18, 20, 22.
