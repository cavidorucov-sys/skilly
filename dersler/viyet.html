Viyet teoremi

Kvadrat tənliyin köklərinin cəmi və hasili əmsallarla birbaşa bağlıdır. Bu bağlılıq — Viyet teoremi — kökləri şifahi tapmağa, köklərdən tənlik qurmağa və tənliyi həll etmədən x₁² + x₂² kimi ifadələri hesablamağa imkan verir. DİM-in parametrli sualları da əsasən buna söykənir.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Viyet teoremi

1 Niyə lazımdır

x² − 5x + 6 = 0. Diskriminantla həll etmək bir dəqiqə çəkir. Amma diqqətlə bax: kökləri 2 və 3-dür, 2 + 3 = 5, 2·3 = 6 — tənlikdəki ədədlər! Bu təsadüf deyil. Bunu bilən adam çox tənliyi 5 saniyəyə həll edir və hər cavabı bir baxışla yoxlayır.

2 Teorem

Gətirilmiş tənlik: x² + px + q = 0 x₁ + x₂ = −p x₁ · x₂ = q Ümumi tənlik: ax² + bx + c = 0 x₁ + x₂ = −b/a x₁ · x₂ = c/a

Niyə doğrudur? Köklər düsturundan:

x₁ + x₂ = (−b + √D)/(2a) + (−b − √D)/(2a) = −2b/(2a) = −b/a x₁ · x₂ = (b² − D)/(4a²) = (b² − b² + 4ac)/(4a²) = c/a

Şərt: teorem yalnız köklər varsa işləyir, yəni D ≥ 0. x² + 2x + 5 = 0 üçün D = 4 − 20 < 0 — kök yoxdur, "köklərin cəmi −2" yazmaq səhvdir.

3 Həll olunmuş nümunələr

Nümunə 1. x² − 7x + 10 = 0 D = 49 − 40 = 9 > 0 x₁ + x₂ = 7, x₁·x₂ = 10 (köklər 2 və 5)
Nümunə 2. 3x² + 5x − 2 = 0 D = 25 + 24 = 49 > 0 x₁ + x₂ = −5/3, x₁·x₂ = −2/3 (Köklər 1/3 və −2: 1/3 − 2 = −5/3 ✓, 1/3·(−2) = −2/3 ✓)
Nümunə 3. Köklərin işarələri (həll etmədən): x² − 3x − 10 = 0: hasil −10 < 0 → köklər müxtəlif işarəlidir x² + 8x + 15 = 0: hasil 15 > 0, cəm −8 < 0 → ikisi də mənfidir (D = 64 − 60 = 4 > 0, köklər var)
Həyatdan: cavabı yoxla. İmtahanda 2x² − 3x − 5 = 0-ı həll edib 5/2 və −1 aldın. Yoxla: cəm 3/2 = −b/a ✓, hasil −5/2 = c/a ✓. On saniyə — və cavabına əminsən.
Tipik səhvlər
  • Cəmin işarəsini dəyişməmək: x² − 7x + 10-da cəm +7-dir, −7 yox. Cəm — −p, hasil — q.
  • a ≠ 1 olanda a-ya bölməyi unutmaq: 3x² + 5x − 2 üçün cəm −5 yox, −5/3 olur.
  • D < 0 olan tənliyə Viyeti tətbiq etmək. Əvvəl köklərin olduğunu yoxla.
Yadda saxla
x₁ + x₂ = −b/a, x₁·x₂ = c/a (D ≥ 0 olanda) Cəmdə işarə dəyişir, hasildə dəyişmir.
Özünü yoxla: 3 sual
  1. x² + 4x − 21 = 0: cəm və hasil? D = 16 + 84 = 100 > 0. Cəm −4, hasil −21 (köklər 3 və −7).
  2. 2x² − 9x + 4 = 0: cəm və hasil? D = 81 − 32 = 49 > 0. Cəm 9/2, hasil 4/2 = 2 (köklər 4 və 1/2).
  3. x² + x + 3 = 0 köklərinin cəmi −1-dir? Yox. D = 1 − 12 < 0 — kök yoxdur, Viyet tətbiq olunmur.

Dərs 2. Tərs teorem: kökləri seçmək, tənlik qurmaq

1 Niyə lazımdır

Teoremi tərsinə də işlətmək olar: cəmi və hasili bilinən iki ədəd həmişə müəyyən kvadrat tənliyin kökləridir. Bu, "iki ədədin cəmi 20, hasili 96" kimi məsələləri və kökləri şifahi tapmağı mümkün edir.

2 Tərs teorem

Əgər m + n = −p və m·n = q, onda m və n ədədləri x² + px + q = 0 tənliyinin kökləridir. Köklərdən tənlik: x² − (x₁ + x₂)x + x₁x₂ = 0

Kökləri seçmək (gətirilmiş tənlikdə): hasili q olan cütləri sına, cəmi −p olanı götür.

q > 0 → köklər eyni işarəli (işarəsi −p-nin işarəsidir) q < 0 → köklər müxtəlif işarəli

3 Həll olunmuş nümunələr

Kökləri seç: x² − 9x + 20 = 0 hasil 20, cəm 9 → 4 və 5 x² + 2x − 15 = 0 hasil −15, cəm −2 → −5 və 3 x² + 11x + 24 = 0 hasil 24, cəm −11 → −3 və −8
Tənlik qur: Köklər 3 və −7: cəm −4, hasil −21 x² − (−4)x + (−21) = 0 → x² + 4x − 21 = 0 Köklər 1/2 və 3: cəm 7/2, hasil 3/2 x² − (7/2)x + 3/2 = 0 → (×2) 2x² − 7x + 3 = 0

4 Vuruqlara ayırma və iki fənd

Köklər məlumdursa, kvadrat üçhədli vuruqlara ayrılır:

ax² + bx + c = a(x − x₁)(x − x₂) x² − 5x + 6 = (x − 2)(x − 3) 2x² − 7x + 3 = 2(x − 1/2)(x − 3) = (2x − 1)(x − 3)

İki tez fənd (Viyetdən çıxır):

a + b + c = 0 → x₁ = 1, x₂ = c/a a − b + c = 0 → x₁ = −1, x₂ = −c/a
5x² − 8x + 3 = 0: 5 − 8 + 3 = 0 → x₁ = 1, x₂ = 3/5 Yoxla: cəm 1 + 3/5 = 8/5 = −b/a ✓ 2x² + 5x + 3 = 0: 2 − 5 + 3 = 0 → x₁ = −1, x₂ = −3/2
Həyatdan. İki ədədin cəmi 20, hasili 96. Hansılardır? Onlar x² − 20x + 96 = 0 tənliyinin kökləridir. Hasili 96, cəmi 20: 8 və 12. Yoxla: 8 + 12 = 20, 8·12 = 96 ✓
Tipik səhvlər
  • Tənlik qurarkən işarəni çaşmaq: kökləri 3 və −7 olan tənlik x² + 4x − 21 = 0-dır, "x² − 4x − 21" yox. Ortadakı hədd — mənfi cəmdir.
  • Vuruqlara ayıranda a-nı unutmaq: 2x² − 7x + 3 ≠ (x − 1/2)(x − 3).
  • Ağılda seçəndə yalnız hasilə baxmaq: x² − 7x + 12 üçün 2 və 6-nın hasili də 12-dir, amma cəmi 8-dir. Düzü 3 və 4.
Yadda saxla
Köklər x₁, x₂ → x² − (x₁ + x₂)x + x₁x₂ = 0 ax² + bx + c = a(x − x₁)(x − x₂) a + b + c = 0 → kök 1; a − b + c = 0 → kök −1.
Özünü yoxla: 3 sual
  1. x² − 10x + 21 = 0: kökləri seç. Hasil 21, cəm 10 → 3 və 7.
  2. Kökləri −2 və 5 olan gətirilmiş kvadrat tənliyi yaz. Cəm 3, hasil −10 → x² − 3x − 10 = 0.
  3. 7x² + 2x − 9 = 0: kökləri tap. 7 + 2 − 9 = 0 → x₁ = 1, x₂ = c/a = −9/7.

Dərs 3. Köklərin simmetrik ifadələri

1 Niyə lazımdır

DİM sualı: "x² − 5x + 3 = 0 tənliyinin kökləri x₁ və x₂-dir. x₁² + x₂² ifadəsini tap." Köklər burada (5 ± √13)/2 — onları kvadrata yüksəltmək uzun və səhvlidir. Əvəzində ifadəni cəm və hasil ilə yazırıq.

2 Düsturlar

Qısa yazaq: s = x₁ + x₂, p = x₁·x₂.

x₁² + x₂² = s² − 2p 1/x₁ + 1/x₂ = s/p (p ≠ 0) (x₁ − x₂)² = s² − 4p x₁/x₂ + x₂/x₁ = (s² − 2p)/p (p ≠ 0) x₁²x₂ + x₁x₂² = p·s x₁³ + x₂³ = s³ − 3ps

Hamısı bir fikirdən çıxır: (x₁ + x₂)² = x₁² + 2x₁x₂ + x₂², yəni x₁² + x₂² = s² − 2p. Qalanlarını da ortaq məxrəc və mötərizə xaricinə çıxarma ilə alırsan.

3 Həll olunmuş nümunələr

Nümunə 1. x² − 5x + 3 = 0 D = 25 − 12 = 13 > 0, köklər var. s = 5, p = 3 x₁² + x₂² = 25 − 6 = 19 1/x₁ + 1/x₂ = 5/3 (x₁ − x₂)² = 25 − 12 = 13 x₁/x₂ + x₂/x₁ = 19/3 x₁³ + x₂³ = 125 − 3·3·5 = 125 − 45 = 80
Nümunə 2. 2x² − 6x − 1 = 0 D = 36 + 8 = 44 > 0. s = 6/2 = 3, p = −1/2 x₁² + x₂² = 9 − 2·(−1/2) = 9 + 1 = 10 1/x₁ + 1/x₂ = 3 : (−1/2) = −6
Həyatdan: düsturu özün yoxla. Düsturu unutdunsa, sadə tənlikdə sına. x² − 5x + 6 = 0: köklər 2 və 3, 4 + 9 = 13. Düstur: s² − 2p = 25 − 12 = 13 ✓. Belə yoxlama imtahanda 20 saniyə çəkir.
Tipik səhvlər
  • x₁² + x₂² = (x₁ + x₂)² yazmaq. 2x₁x₂ çıxılmalıdır.
  • Mənfi hasildə işarə: p = −2 olanda −2p = +4.
  • 1/x₁ + 1/x₂-ni p/s yazmaq. Cəm surətdədir: (x₂ + x₁)/(x₁x₂).
Yadda saxla
Kökləri tapma — s və p ilə yaz. x₁² + x₂² = s² − 2p, 1/x₁ + 1/x₂ = s/p, (x₁ − x₂)² = s² − 4p. Əvvəl D ≥ 0 olduğunu yoxla; məxrəc varsa p ≠ 0.
Özünü yoxla: 3 sual
  1. x² + 3x − 4 = 0: x₁² + x₂² = ? s = −3, p = −4: 9 + 8 = 17. (Köklər 1 və −4: 1 + 16 = 17 ✓)
  2. x² − 6x + 4 = 0: 1/x₁ + 1/x₂ = ? D = 36 − 16 = 20 > 0. s/p = 6/4 = 3/2.
  3. x² − 7x + 2 = 0: (x₁ − x₂)² = ? 49 − 8 = 41.

Dərs 4. Parametrli məsələlər

1 Niyə lazımdır

Şəkildəki sıçrayışın yolu iki daşda başlayıb bitir — tənliyin iki kökü kimi. Viyet teoremi kökləri tapmadan onların cəmini və hasilini verir.

Tənlikdə naməlum əmsal (parametr) var, köklər haqqında isə bir şərt verilib: "bir kökü 3-dür", "köklərin fərqi 2-dir", "kvadratları cəmi 20-dir". Bu şərti Viyetlə tənliyə çeviririk.

2 Alqoritm

1. Viyet: x₁ + x₂ = …, x₁·x₂ = … (parametrlə) 2. Şərti də tənlik kimi yaz. 3. Sistemi həll et → parametr. 4. YOXLA: tapılan parametrdə D ≥ 0 olmalıdır.

3 Həll olunmuş nümunələr

Nümunə 1. x² + bx − 12 = 0 tənliyinin bir kökü 3-dür. b = ? İkinci kök? Hasil: 3·x₂ = −12 → x₂ = −4 Cəm: 3 + (−4) = −1 = −b → b = 1 Yoxla: 9 + 3 − 12 = 0 ✓
Nümunə 2. x² − 8x + q = 0, x₁ − x₂ = 2. q = ? x₁ + x₂ = 8, x₁ − x₂ = 2 → x₁ = 5, x₂ = 3 q = x₁·x₂ = 15
Nümunə 3. x² − 9x + q = 0, x₁ = 2x₂. q = ? 2x₂ + x₂ = 9 → x₂ = 3, x₁ = 6 q = 18

4 D yoxlaması niyə vacibdir

Nümunə 4. x² + px + 8 = 0, x₁² + x₂² = 20. p = ? x₁ + x₂ = −p, x₁x₂ = 8: (−p)² − 2·8 = 20 → p² = 36 → p = ±6 D = 36 − 32 = 4 ≥ 0 ✓ Cavab: p = 6 və ya p = −6
Nümunə 5 (tələ). x² + px + 10 = 0, x₁² + x₂² = 16. p = ? p² − 20 = 16 → p² = 36 → p = ±6 D = 36 − 40 = −4 < 0 — bu p-lərdə kök YOXDUR! Cavab: belə p yoxdur
Nümunə 6. a-nın hansı qiymətində x² + (a − 3)x − 5 = 0 tənliyinin kökləri qarşılıqlı əks ədədlərdir (x₁ = −x₂)? x₁ + x₂ = 0 → −(a − 3) = 0 → a = 3 Onda x² − 5 = 0, x = ±√5 ✓ (D = 20 > 0)
Həyatdan. Düzbucaqlı hasarın perimetri 26 m, sahəsi isə 40 m². Tərəflərin cəmi 13, hasili 40 — onlar x² − 13x + 40 = 0-ın kökləridir: 5 m və 8 m. Viyet olmasaydı, iki naməlumlu sistem həll etməli idin.
Tipik səhvlər
  • Parametri tapıb D-ni yoxlamamaq (Nümunə 5). Kök olmayan tənliyin "köklərinin kvadratları cəmi" olmur.
  • p² = 36-dan yalnız p = 6 yazmaq. Sual "müsbət qiymət" demirsə, ikisi də cavabdır.
  • Bir kök məlum olanda onu tənliyə qoymağı unutmaq: əvəz etmək də işləyir: 9 + 3b − 12 = 0 → b = 1.
Yadda saxla
Şərt + Viyet → parametr üçün tənlik. Sonda: D ≥ 0? Deyilsə, o qiymət atılır.
Özünü yoxla: 3 sual
  1. x² + bx + 15 = 0, bir kök −3. b = ? x₂ = 15 : (−3) = −5. Cəm −8 = −b → b = 8.
  2. x² − 10x + q = 0, x₁ = 4x₂. q = ? 5x₂ = 10 → x₂ = 2, x₁ = 8 → q = 16.
  3. x² − 2x + q = 0, x₁² + x₂² = 10. q = ? 4 − 2q = 10 → q = −3. D = 4 + 12 = 16 ≥ 0 ✓
