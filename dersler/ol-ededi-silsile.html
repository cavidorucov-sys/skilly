Riyaziyyat olimpiadası · RFO: Ardıcıllıqlar — ədədi silsilə

Ədədi silsilə

Pilləkənin pillələri, amfiteatrın sıraları, hər gün bir az çox yığılan pul — hamısında hər addımda eyni ədəd qədər artım var. Belə ardıcıllığa ədədi silsilə deyilir. Bu mövzu məktəb proqramında ancaq 10-cu sinifdə gəlir, amma RFO-da 9-cu sinifdən çıxır. Burada sıfırdan başlayıb rayon və yarımfinal səviyyəsinə qədər qalxacağıq.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Fərq d və n-ci hədd

1 Niyə lazımdır

Taksi: oturanda 3 manat, hər kilometrə 2 manat. 1 km — 5 manat, 2 km — 7, 3 km — 9, … Ardıcıl qiymətlər 5; 7; 9; 11; … hər dəfə eyni ədəd qədər artır. Soruşsalar ki, 40 km nə qədərdir, 39 dəfə toplamaq lazım deyil — düstur var.

2 Əsas fikir

Ardıcıllıqda ədədlərə hədd deyilir: a₁ — birinci, a₂ — ikinci, aₙ — n-ci hədd. Hər həddi əvvəlkindən eyni d ədədi qədər fərqlənirsə, bu ədədi silsilədir, d isə onun fərqidir:

aₙ₊₁ = aₙ + d, d = a₂ − a₁ = a₃ − a₂ = … d > 0 — silsilə artır; d < 0 — azalır; d = 0 — hamısı eynidir

Birinci hədd a₁, ikinci a₁ + d, üçüncü a₁ + 2d… n-ci hədd üçün d cəmi n − 1 dəfə əlavə olunub:

aₙ = a₁ + (n − 1)·d İki hədd verilibsə: aₘ − aₖ = (m − k)·d

Sonuncu düstur çox işə yarayır: hədlər arasında m − k addım var, hər addım d-dir. Əvvəl d-ni tap, sonra istənilən həddə get.

3 Həll olunmuş nümunələr

1) 5; 8; 11; 14; … silsiləsinin 30-cu həddi d = 8 − 5 = 3. a₃₀ = 5 + 29·3 = 92 2) a₄ = 17, a₁₀ = 41. a₂₅ = ? a₁₀ − a₄ = 6d → 41 − 17 = 24 = 6d → d = 4 a₂₅ = a₁₀ + 15·4 = 41 + 60 = 101 3) 100 ədədi 4; 11; 18; … silsiləsinin həddidirmi? d = 7. 4 + (n − 1)·7 = 100 → (n − 1)·7 = 96 → n − 1 = 96/7 — tam deyil. Deməli, 100 bu silsilənin həddi deyil. 102 üçün: (102 − 4)/7 = 14 → n = 15, yəni 102 — 15-ci həddir. Nömrə tam və müsbət olmalıdır!
Həyatdan. Pilləkəndə pillənin hündürlüyü hər dəfə eynidir: 1-ci pillə 18 sm, 2-ci 36 sm, 3-cü 54 sm. 25-ci pillənin yerdən hündürlüyü a₂₅ = 18 + 24·18 = 450 sm. Qatarın stansiyalararası vaxtı, aylıq maaş artımı — hamısı belə qurulur.

4 Hədlərin sayı və təkrar nömrələr

Sonlu silsilədə neçə hədd olduğunu tapmaq: ilk və son hədd məlumdursa,

hədlərin sayı = (son − ilk) / d + 1 (d ≠ 0)

Niyə "+ 1"? Çünki fərqlər sayını tapırıq, hədlər onlardan bir çoxdur (dirək-hasar məsələsi: 10 dirək arasında 9 aralıq var).

Mənfi və müsbət hədlər. Azalan silsilədə ilk mənfi həddi tapmaq üçün aₙ < 0 bərabərsizliyini həll et. Məsələn, 47; 41; 35; … üçün 47 − 6(n − 1) < 0 → n − 1 > 7,83 → n ≥ 9. İlk mənfi hədd 9-cudur (a₈ = 5 > 0, a₉ = −1). Müsbət hədlərin sayı — 8.

5 Olimpiada məsələsi

Məsələ. 100-dən 999-a qədər üçrəqəmli ədədlərdən 7-yə bölünənlərin sayını və cəmini tap. Həll. 7-yə bölünən üçrəqəmli ədədlər ədədi silsilədir (d = 7). İlk: 100 = 7·14 + 2, deməli ilk 7·15 = 105. Son: 999 = 7·142 + 5, deməli son 7·142 = 994. Say: (994 − 105)/7 + 1 = 127 + 1 = 128. Cəm: (105 + 994)·128/2 = 1099·64 = 70 336. Cavab: 128 ədəd, cəmi 70 336. Qısa yol: ilk və son qatın nömrəsi 15 və 142-dir → 142 − 15 + 1 = 128.
Məsələ. Ədədi silsilənin 3-cü həddi 7, 8-ci həddi 27-dir. Hədlərdən biri 2027-dir. Doğrudurmu? Həll. 5d = 27 − 7 = 20 → d = 4, a₁ = 7 − 8 = −1. aₙ = −1 + 4(n − 1) = 4n − 5. 4n − 5 = 2027 → 4n = 2032 → n = 508. Bəli, 2027 silsilənin 508-ci həddidir. Ümumi qayda: hədlərin hamısı 4-ə bölünəndə 3 qalıq verir (4n − 5 = 4(n − 2) + 3). 2027 = 4·506 + 3 ✓.
Tipik səhvlər
  • aₙ = a₁ + n·d yazmaq. Düz: (n − 1)·d. Yoxla: n = 1 üçün a₁ alınmalıdır.
  • Hədlərin sayında "+ 1"-i unutmaq: 5-dən 50-yə qədər d = 5 ilə (50 − 5)/5 = 9 yox, 10 hədd.
  • Nömrə kəsr çıxanda cavab vermək. Nömrə həmişə natural olmalıdır — yoxsa ədəd silsilənin həddi deyil.
  • d-ni mənfi silsilədə işarəsiz götürmək: 20; 17; 14 üçün d = −3.
Yadda saxla
aₙ = a₁ + (n − 1)d aₘ − aₖ = (m − k)d hədlərin sayı = (son − ilk)/d + 1 (d ≠ 0)
Özünü yoxla: 3 sual
  1. −7; −3; 1; … silsiləsində a₂₀ = ? d = 4, a₂₀ = −7 + 19·4 = 69.
  2. 3-cü hədd 10, 7-ci hədd 26. d = ? 4d = 16, d = 4.
  3. 12-dən 300-ə qədər 6-ya bölünən ədədlərin sayı? 12, 18, …, 300: (300 − 12)/6 + 1 = 49.

Dərs 2. Xarakteristik xassə

1 Niyə lazımdır

Olimpiada məsələsində çox vaxt a₁ və d ayrıca verilmir, yalnız bir neçə hədd və ya onların cəmi verilir. Hər ikisini tapmadan cavab almaq üçün silsilənin gözəl xassəsi lazımdır: mərkəzə görə simmetriya.

2 Əsas fikir

Hər hədd özündən sağda və solda eyni məsafədə duran iki həddin ədədi ortasıdır, çünki aₙ − d və aₙ + d-nin cəmində d ixtisar olur:

aₙ = (aₙ₋₁ + aₙ₊₁)/2 (hətta aₙ = (aₙ₋ⱼ + aₙ₊ⱼ)/2) m + n = k + l ⟹ aₘ + aₙ = aₖ + aₗ

İkinci düstur: nömrələrin cəmi eynidirsə, hədlərin cəmi də eynidir. Sübut: aₘ + aₙ = 2a₁ + (m + n − 2)d — yalnız m + n-dən asılıdır. Xüsusi hal: a₁ + aₙ = a₂ + aₙ₋₁ = …

3 Həll olunmuş nümunələr

1) a₄ + a₁₂ = 50. a₈ = ? 4 + 12 = 8 + 8 → a₄ + a₁₂ = 2a₈ → a₈ = 25 2) a₃ + a₁₀ = 31. a₅ + a₈ = ? 3 + 10 = 5 + 8 = 13 → a₅ + a₈ = 31 3) x; 2x + 1; 5x − 3 ardıcıl üç həddir. x = ? Orta hədd qonşuların ortasıdır: 2(2x + 1) = x + (5x − 3) 4x + 2 = 6x − 3 → 2x = 5 → x = 5/2
Həyatdan. Pilləkənin pillələri 18, 36, 54, 72, 90 sm yüksəklikdədir. İki uc pillənin cəmi 18 + 90 = 108, ikinci ilə dördüncünün cəmi 36 + 72 = 108 — eynidir, ortadakı pillənin iki mislidir (2·54).

4 Üç hədd üçün "orta" təyin etmək

Cəmi və ya hasili verilmiş ardıcıl hədlər üçün əlverişli yazılış:

3 hədd: m − d, m, m + d (cəm = 3m) 4 hədd: m − 3d, m − d, m + d, m + 3d (fərq 2d) 5 hədd: m − 2d, m − d, m, m + d, m + 2d

Cəm bir dəyişənə düşür, qalan tənlik d²-də olur.

5 Olimpiada məsələləri

Məsələ 1. Üç ədəd artan ədədi silsilə təşkil edir. Cəmləri 27, kvadratlarının cəmi 275-dir. Ədədləri tap. Həll. Ədədlər: m − d, m, m + d. Cəm: 3m = 27 → m = 9. Kvadratların cəmi: (9 − d)² + 81 + (9 + d)² = 243 + 2d² = 275 → d² = 16. Artan olduğundan d = 4. Ədədlər: 5, 9, 13. Yoxla: 25 + 81 + 169 = 275 ✓. Məsələ 2. Ədədi silsilənin 7-ci həddi 20-dir. İlk 13 həddin cəmini tap. Həll. Sₙ cəmini sonra öyrənəcəyik, amma burada xassə kifayətdir: a₁ + a₁₃ = a₂ + a₁₂ = … = a₆ + a₈ = 2a₇ = 40. 13 hədd 6 cüt (hər biri 40) və tək qalan orta a₇ = 20 verir: 6·40 + 20 = 260. Cavab: 13·a₇ = 260.
Tipik səhvlər
  • aₘ + aₙ = aₘ₊ₙ yazmaq. Bu yanlışdır: a₂ + a₃ ≠ a₅ (məs. 3; 5; 7; 9; 11-də 5 + 7 = 12 ≠ 11).
  • Nömrələrin cəmini yoxlamamaq: a₂ + a₉ = a₄ + a₆ səhvdir (11 ≠ 10).
  • Üç ədədi m, m + d, m + 2d götürüb hasil məsələsini çətinləşdirmək: simmetrik yazılış (m − d, m, m + d) daha qısadır.
Yadda saxla
aₙ = (aₙ₋₁ + aₙ₊₁)/2 m + n = k + l ⟹ aₘ + aₙ = aₖ + aₗ 3 hədd: m − d, m, m + d
Özünü yoxla: 3 sual
  1. a₂ + a₁₀ = 28. a₆ = ? 2 + 10 = 6 + 6, a₆ = 14.
  2. a₅ + a₉ = 40. a₆ + a₈ = ? 5 + 9 = 14 = 6 + 8, cavab 40.
  3. Üç artan hədd, cəm 21, hasil 231 (m = 7). Ən böyüyü? 7·(49 − d²) = 231 → d² = 16, d = 4; hədlər 3, 7, 11; ən böyüyü 11.

Dərs 3. İlk n həddin cəmi

1 Niyə lazımdır

Amfiteatrda 1-ci sırada 20 yer, hər növbəti sırada 2 yer çox, 30 sıra. Cəmi neçə yer var? 30 ədədi toplamaq olar, amma düstur bir sətirlikdir. Rəvayətə görə, 9 yaşlı Qauss müəllimin tapşırığını — 1-dən 100-ə qədər ədədlərin cəmini — saniyələrlə tapıb.

2 Qauss fəndi

İlk n həddin cəmi Sₙ. Onu iki dəfə yaz: bir dəfə soldan sağa, bir dəfə sağdan sola, sütunları topla:

Sₙ = a₁ + a₂ + … + aₙ Sₙ = aₙ + aₙ₋₁ + … + a₁ 2Sₙ = (a₁ + aₙ) + (a₂ + aₙ₋₁) + … = n·(a₁ + aₙ)

Hər sütunun cəmi eynidir (Dərs 2 xassəsi!) və n sütun var:

Sₙ = (a₁ + aₙ)·n/2 = (2a₁ + (n − 1)d)·n/2 Hissə cəmi: aₖ + … + aₘ = (aₖ + aₘ)·(m − k + 1)/2 1 + 2 + … + n = n(n + 1)/2

3 Həll olunmuş nümunələr

1) 1 + 2 + … + 100 = 100·101/2 = 5050 2) 4; 7; 10; … ilk 20 həddin cəmi a₂₀ = 4 + 19·3 = 61. S₂₀ = (4 + 61)·20/2 = 650 3) a₅ + a₆ + … + a₁₄ (a₁ = 2, d = 3) a₅ = 14, a₁₄ = 41, say = 14 − 5 + 1 = 10 Cəm = (14 + 41)·10/2 = 275 4) Amfiteatr: a₁ = 20, d = 2, n = 30 S₃₀ = (2·20 + 29·2)·30/2 = 98·15 = 1470 yer
Həyatdan. Kötüklər qalaq şəklində yığılıb: altda 12, yuxarı doğru hər sırada bir az, ən üstdə 3 kötük. Sıraların sayı 10, kötüklərin sayı (12 + 3)·10/2 = 75. Boru qalaqları, konserv piramidaları eyni qaydadır.

4 Tərs məsələ: n-i tapmaq

Cəm verilib, hədlərin sayı soruşulur. Düsturdan kvadrat tənlik alınır, mənfi və kəsr kök atılır.

a₁ = 5, d = 4, Sₙ = 275. n = ? (2·5 + (n − 1)·4)·n/2 = 275 → (3 + 2n)·n = 275 → 2n² + 3n − 275 = 0 D = 9 + 2200 = 2209 = 47² → n = (−3 + 47)/4 = 11 (digər kök mənfidir). Yoxla: a₁₁ = 45, (5 + 45)·11/2 = 275 ✓

5 Olimpiada məsələləri

Məsələ 1. Sübut et ki, ilk n tək ədədin cəmi n²-dir: 1 + 3 + 5 + … + (2n − 1) = n². Həll. a₁ = 1, d = 2, aₙ = 2n − 1. Sₙ = (1 + 2n − 1)·n/2 = n·n = n². ∎ (Şəkil: n×n kvadrat, "Γ" şəklində qatlarla: 1, 3, 5, …) Məsələ 2. 1-dən 200-ə qədər 3-ə və ya 5-ə bölünən ədədlərin cəmini tap. Həll. Daxilolma-xaricolma: S(3) + S(5) − S(15). 3-ə bölünənlər: 3, …, 198 — 66 ədəd, cəm (3 + 198)·66/2 = 6633. 5-ə bölünənlər: 5, …, 200 — 40 ədəd, cəm (5 + 200)·40/2 = 4100. 15-ə bölünənlər (hər ikisinə): 15, …, 195 — 13 ədəd, cəm (15 + 195)·13/2 = 1365. Cavab: 6633 + 4100 − 1365 = 9368.
Tipik səhvlər
  • Yarıya bölməyi unutmaq: Sₙ = (a₁ + aₙ)·n/2, "·n/2" yox, "·n" yox.
  • Hissə cəmində hədlərin sayını m − k götürmək. Düz: m − k + 1.
  • Kvadrat tənliyin ikinci kökünü (mənfi və ya kəsr) cavab kimi yazmaq.
  • Daxilolma-xaricolmada ortaq hissəni (15-ə bölünənləri) bir dəfə çıxmamaq: onlar iki dəfə sayılıb.
Yadda saxla
Sₙ = (a₁ + aₙ)·n/2 = (2a₁ + (n − 1)d)·n/2 1 + 2 + … + n = n(n + 1)/2; 1 + 3 + … + (2n − 1) = n² n-i tapanda: kvadrat tənlik, natural kök
Özünü yoxla: 3 sual
  1. 2 + 4 + … + 50 = ? 25 hədd, (2 + 50)·25/2 = 650.
  2. a₁ = −3, d = 2. S₁₀ = ? a₁₀ = 15, (−3 + 15)·10/2 = 60.
  3. 1 + 3 + 5 + … + 99 = ? 50 hədd, 50² = 2500.

Dərs 4. Sₙ-dən geri qayıtmaq (yarımfinal səviyyəsi)

1 Niyə lazımdır

Bəzən silsilənin özü verilmir, yalnız "ilk n həddin cəmi belədir" deyilir. Hədləri və fərqi bundan tapmaq olimpiadada tez-tez rast gəlinən fəndir.

2 Əsas fikir: aₙ = Sₙ − Sₙ₋₁

İlk n həddin cəmindən ilk n − 1 həddin cəmini çıxsaq, yalnız n-ci hədd qalır:

aₙ = Sₙ − Sₙ₋₁ (n ≥ 2), a₁ = S₁ Sₙ = p·n² + q·n ⟹ silsilə ədədidir, d = 2p, a₁ = p + q

Niyə d = 2p? Çünki Sₙ = (d/2)n² + (a₁ − d/2)n. Cəmin düsturunda n²-nin əmsalı d-nin yarısıdır, sərbəst hədd isə yoxdur (S₀ = 0).

3 Həll olunmuş nümunələr

1) Sₙ = 3n² + 2n. a₁₀ = ? S₁₀ = 300 + 20 = 320, S₉ = 243 + 18 = 261. a₁₀ = 59 Ümumi: aₙ = 3(n² − (n−1)²) + 2 = 3(2n − 1) + 2 = 6n − 1. a₁₀ = 59 ✓, d = 6 = 2·3 ✓ 2) Sₙ = n² − 4n. a₁ = ? d = ? a₁ = S₁ = −3. d = 2·1 = 2. Silsilə: −3; −1; 1; … 3) Sₙ = 2n² + 5n + 1 üçün silsilə ədədi deyil: sərbəst hədd 1 ≠ 0. a₁ = S₁ = 8, a₂ = S₂ − S₁ = 19 − 8 = 11, a₃ = S₃ − S₂ = 34 − 19 = 15 Fərqlər 3 və 4 — eyni deyil.
Həyatdan. Bank hesabına hər ay əvvəlkindən 2 manat artıq yatırırsan. İlk n ayda yığılan məbləğin düsturunu bilirsənsə, n-ci ayda nə qədər yatırdığını Sₙ − Sₙ₋₁ verir.

4 Eyni cəmlər

Əgər Sₘ = Sₙ (m ≠ n) isə, aₘ₊₁ + … + aₙ = 0 olur. Bundan a₁ + aₘ₊ₙ = 0 və Sₘ₊ₙ = 0 çıxır.

S₁₀ = S₃₀. S₄₀ = ? S₃₀ − S₁₀ = a₁₁ + … + a₃₀ = 0. Bu 20 hədd, cəmi 10·(a₁₁ + a₃₀) = 0 → a₁₁ + a₃₀ = 0. 11 + 30 = 1 + 40 → a₁ + a₄₀ = 0 → S₄₀ = (a₁ + a₄₀)·40/2 = 0.

5 Olimpiada məsələləri

Məsələ 1. Ədədi silsilədə a₁ = −33 və S₁₂ = S₂₂. d = ? Həll. S₂₂ − S₁₂ = 0 → a₁₃ + … + a₂₂ = 0 (10 hədd) → a₁₃ + a₂₂ = 0. 13 + 22 = 1 + 34 = 35 → a₁ + a₃₄ = 0 → 2a₁ + 33d = 0 → −66 + 33d = 0 → d = 2. Başqa üsul: S₁₂ = S₂₂ → 12(2a₁ + 11d) = 22(2a₁ + 21d) → 24a₁ + 132d = 44a₁ + 462d → −20a₁ = 330d → d = −2a₁/33 = 66/33 = 2 ✓. Məsələ 2. Sübut et ki, ardıcıllıq üçün Sₙ = n² + 2n-dirsə, silsilə ədədidir və aₙ = 2n + 1. Həll. a₁ = S₁ = 3. n ≥ 2 üçün aₙ = n² + 2n − (n − 1)² − 2(n − 1) = 2n − 1 + 2 = 2n + 1. n = 1 üçün də 2·1 + 1 = 3 uyğundur. aₙ₊₁ − aₙ = 2 sabit → ədədi silsilə. ∎
Tipik səhvlər
  • a₁ = S₁ halını ayrıca yoxlamamaq (Sₙ − Sₙ₋₁ düsturu n ≥ 2 üçündür).
  • d = p yazmaq (düz: d = 2p).
  • Sərbəst həddi olan Sₙ-i ədədi silsilə sanmaq.
  • Sₘ = Sₙ verilibsə, aₘ = aₙ sanmaq. Düz: aₘ₊₁ + … + aₙ = 0.
Yadda saxla
aₙ = Sₙ − Sₙ₋₁; a₁ = S₁ Sₙ = pn² + qn ⟹ d = 2p Sₘ = Sₙ ⟹ Sₘ₊ₙ = 0
Özünü yoxla: 3 sual
  1. Sₙ = 2n² + n. a₅ = ? S₅ = 55, S₄ = 36, a₅ = 19.
  2. Sₙ = 4n² − 3n üçün d = ? d = 2·4 = 8.
  3. S₆ = S₁₄ olarsa, S₂₀ = ? 0 (Sₘ = Sₙ ⟹ Sₘ₊ₙ = 0).
