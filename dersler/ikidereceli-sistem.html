Riyaziyyat · Buraxılış · DİM: Tənliklər sistemi və tənliklər sisteminin tətbiqi ilə məsələ həlli

İkidərəcəli tənliklər sistemi, sistemlə məsələ həlli

Sistemdə x², xy, y² görünəndə həll kvadrat tənliyə gəlib çıxır. Burada yerinə qoymanı, Viyet fəndini (x + y və xy), simmetrik ifadələri və düzbucaqlı, ikirəqəmli ədəd kimi məsələləri öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Biri xətti, digəri ikidərəcəli olan sistem

1 Niyə lazımdır

Düzbucaqlının perimetri 14, sahəsi 12-dir. Tərəflər? x + y = 7 (xətti) və xy = 12 (ikidərəcəli). Belə sistemlər həndəsədə, fizikada və DİM testlərində çox çıxır.

2 Yerinə qoyma üsulu

1. Xətti tənlikdən bir dəyişəni ifadə et. 2. Onu ikidərəcəli tənlikdə yerinə qoy. 3. Kvadrat tənliyi həll et. 4. HƏR kök üçün ikinci dəyişəni XƏTTİ tənlikdən tap. 5. Cavab — cütlər: (x₁; y₁), (x₂; y₂).
Nümunə 1. ⎧ x − y = 2 ⎩ x² + y² = 34 x = y + 2 → (y + 2)² + y² = 34 y² + 4y + 4 + y² = 34 → 2y² + 4y − 30 = 0 → y² + 2y − 15 = 0 y = 3 və y = −5 x = y + 2: x = 5 və x = −3 Cavab: (5; 3), (−3; −5). Yoxla: 25 + 9 = 34 ✓; 9 + 25 = 34 ✓

3 Qrafik məna və həllərin sayı

Nümunə 2. ⎧ y = x + 1 ⎩ x² + y = 7 y-i qoy: x² + x + 1 = 7 → x² + x − 6 = 0 → x = 2, x = −3 y = x + 1: y = 3, y = −2 Cavab: (2; 3), (−3; −2)

İkinci tənlik y = 7 − x² — parabola, birinci — düz xətt. Sistemin həlləri onların kəsişmə nöqtələridir.

Xətt ilə parabolanın 2, 1 və ya 0 ortaq nöqtəsi ola bilər. Bunu kvadrat tənliyin diskriminantı deyir:

D > 0 → 2 həll (xətt parabolanı kəsir) D = 0 → 1 həll (xətt parabolaya toxunur) D < 0 → həll yoxdur
⎧ y = x², ⎩ y = 2x − 1: x² − 2x + 1 = 0, D = 0 → x = 1, y = 1 — bir həll ⎧ y = x², ⎩ y = x − 1: x² − x + 1 = 0, D = −3 → həll yoxdur
Həyatdan. Körpünün tağı parabola, altından keçən yol isə düz xəttdir. Yolun tağa hansı nöqtələrdə dəydiyini tapmaq — elə bu sistemi həll etməkdir. D < 0 alınsa, yol tağa heç yerdə toxunmur.
Tipik səhvlər
  • İkinci dəyişəni ikidərəcəli tənlikdən tapmaq: y² = 9 → y = ±3 — artıq "saxta" cütlər çıxır. İkinci dəyişəni həmişə xətti tənlikdən tap.
  • (y + 2)² = y² + 4 yazmaq. Düzü: y² + 4y + 4.
  • Cavabda yalnız x-ləri yazmaq. Həll — cütdür; iki kök — iki cüt.
Yadda saxla
Xəttidən ifadə et → ikidərəcəliyə qoy → kvadrat tənlik. Hər kök üçün digər dəyişən — xətti tənlikdən. Həllərin sayı: D > 0 → 2, D = 0 → 1, D < 0 → 0.
Özünü yoxla: 3 sual
  1. ⎧ y = 2x, ⎩ x² + y² = 20. Həllər? x² + 4x² = 20 → x² = 4 → x = ±2. Həllər: (2; 4), (−2; −4).
  2. ⎧ y = x + 3, ⎩ y = x² + 1. Neçə həll? x² − x − 2 = 0, D = 9 > 0 → 2 həll: (2; 5), (−1; 2).
  3. ⎧ x + y = 1, ⎩ x² + y² = 25. Həllər? y = 1 − x → 2x² − 2x − 24 = 0 → x² − x − 12 = 0 → x = 4, x = −3. Həllər: (4; −3), (−3; 4).

Dərs 2. x + y və xy verilən sistemlər. Simmetrik ifadələr

1 Niyə lazımdır

⎧ x + y = 7, ⎩ xy = 12 sistemini yerinə qoyma ilə də həll etmək olar, amma Viyet teoremi ilə — bir sətirdə. Bundan başqa, DİM tez-tez x² + y²-ni sistemi həll etmədən tapmağı istəyir.

2 Viyet fəndi

Viyet teoremi: t² − st + p = 0 tənliyinin köklərinin cəmi s, hasili p-dir. Tərsinə: cəmi s, hasili p olan iki ədəd həmin tənliyin kökləridir.

⎧ x + y = s ⎩ xy = p → x, y — t² − st + p = 0 tənliyinin kökləri Həllər: (t₁; t₂) və (t₂; t₁)
Nümunə 1. ⎧ x + y = 7, ⎩ xy = 12 t² − 7t + 12 = 0 → t = 3, t = 4 Cavab: (3; 4) və (4; 3) — İKİ həll, x və y yer dəyişə bilər!
Nümunə 2. ⎧ x + y = 1, ⎩ xy = −6 t² − t − 6 = 0 → t = 3, t = −2 Cavab: (3; −2) və (−2; 3)
Nümunə 3. ⎧ x + y = 2, ⎩ xy = 5 t² − 2t + 5 = 0, D = 4 − 20 < 0 → həll yoxdur

3 Simmetrik ifadələr — həll etmədən

x² + y² = (x + y)² − 2xy (x − y)² = (x + y)² − 4xy x³ + y³ = (x + y)³ − 3xy(x + y) 1/x + 1/y = (x + y)/(xy) (xy ≠ 0)
Nümunə 4. x + y = 5, xy = 4. x² + y² = 25 − 8 = 17 (x − y)² = 25 − 16 = 9 x³ + y³ = 125 − 3·4·5 = 65 1/x + 1/y = 5/4 Yoxlama: x, y = 1 və 4 → 1 + 16 = 17 ✓, 1 + 64 = 65 ✓
Həyatdan. Düzbucaqlı otağın yarımperimetri 9 m, sahəsi 20 m²-dir. Diaqonal boyunca kabel çəkmək lazımdır: d² = x² + y² = 9² − 2·20 = 41 → d = √41 ≈ 6,4 m. Tərəfləri (4 m və 5 m) tapmağa ehtiyac olmadı.
Tipik səhvlər
  • (x + y)² = x² + y² yazmaq. Ortada 2xy həddi var!
  • Viyet tənliyini t² + st + p = 0 yazmaq. Orta həddin işarəsi mənfidir: t² − st + p.
  • Yalnız bir həll yazmaq: (3; 4) ilə yanaşı (4; 3) də həldir.
Yadda saxla
x + y = s, xy = p → t² − st + p = 0 x² + y² = s² − 2p (x − y)² = s² − 4p x³ + y³ = s³ − 3ps
Özünü yoxla: 3 sual
  1. ⎧ x + y = 5, ⎩ xy = 6. Həllər? t² − 5t + 6 = 0 → 2 və 3. Həllər: (2; 3), (3; 2).
  2. x + y = 6, xy = 8. x² + y² = ? 36 − 16 = 20 (yoxla: 2 və 4 → 4 + 16 = 20 ✓).
  3. x + y = 4, xy = 1. 1/x + 1/y = ? (x + y)/(xy) = 4/1 = 4.

Dərs 3. Hər iki tənliyi ikidərəcəli olan sistem

1 Niyə lazımdır

Hər iki tənlikdə kvadratlar varsa, adi yerinə qoyma 4-cü dərəcəli tənliyə apara bilər. Amma DİM sistemləri adətən "fəndlə" qurulur: üç fənd əksər halları bağlayır.

2 Fənd 1: x² və y² — yeni naməlumlar

⎧ x² + y² = 26 ⎩ x² − y² = 24 Topla: 2x² = 50 → x² = 25 → x = ±5 Çıx: 2y² = 2 → y² = 1 → y = ±1 Hər x hər y ilə: (5; 1), (5; −1), (−5; 1), (−5; −1) — 4 həll

Diqqət: y² = −3 kimi nəticə çıxsa — həll yoxdur; y² = 0 olsa — y = 0; x² > 0 olduqda həllər iki dənədir, x² = 0 da alınsa, yalnız bir həll (0; 0) var.

3 Fənd 2: kvadratlar fərqi

x² − y² = (x − y)(x + y)
⎧ x² − y² = 24 ⎩ x − y = 4 4·(x + y) = 24 → x + y = 6 Xətti sistem: x − y = 4, x + y = 6 → x = 5, y = 1 Yoxla: 25 − 1 = 24 ✓

4 Fənd 3: x² + y² və xy

⎧ x² + y² = 25 ⎩ xy = 12 (x + y)² = 25 + 24 = 49 → x + y = ±7 (x − y)² = 25 − 24 = 1 → x − y = ±1 x + y = 7: (3; 4), (4; 3) x + y = −7: (−3; −4), (−4; −3) Cavab: 4 həll
Həyatdan. Kvadrat bağçanın sahəsini bilsən, tərəfi √S-dir — mənfi kök atılır. Amma "tənliyin həlli" soruşulanda x² = 25-in iki kökü var: ±5. Məsələdə mənfini sonradan atırıq, tənlikdə isə saxlayırıq.
Tipik səhvlər
  • x² = 25 → yalnız x = 5. ± itəndə həllərin yarısı itir.
  • x² + y² = 25, xy = 12 üçün yalnız x + y = 7 götürmək. −7 də olar.
  • x² − y²-ni (x − y)² ilə qarışdırmaq.
Yadda saxla
x², y² — naməlum kimi topla/çıx. x² − y² = (x − y)(x + y). (x ± y)² = x² + y² ± 2xy; u² = A > 0 tənliyindən u = ±√A alınır.
Özünü yoxla: 3 sual
  1. ⎧ x² + y² = 13, ⎩ x² − y² = 5. Neçə həll? x² = 9, y² = 4 → x = ±3, y = ±2 → 4 həll.
  2. ⎧ x² − y² = 21, ⎩ x + y = 7. Həll? 7(x − y) = 21 → x − y = 3 → x = 5, y = 2. Yoxla: 25 − 4 = 21 ✓
  3. ⎧ x² + y² = 10, ⎩ xy = 3. Həllər? x + y = ±4, x − y = ±2 → (3; 1), (1; 3), (−3; −1), (−1; −3).

Dərs 4. Tənliklər sisteminin tətbiqi ilə məsələ həlli

1 Niyə lazımdır

Sahə, diaqonal, Pifaqor teoremi, ikirəqəmli ədəd — bunların hamısı hasil və kvadrat verir. İki naməlum, bir şərt xətti, digəri ikidərəcəli — tam bu mövzunun sistemi.

2 Düzbucaqlı

tərəflər x, y: perimetr P → x + y = P/2 sahə S → xy = S diaqonal d → x² + y² = d²
Nümunə 1. Perimetr 34 sm, sahə 60 sm². Tərəflər? x + y = 17, xy = 60 → t² − 17t + 60 = 0 D = 289 − 240 = 49 → t = 12, t = 5 Tərəflər 12 sm və 5 sm. (Diaqonal: √(144 + 25) = 13 sm.)
Nümunə 2. Diaqonal 10 sm, perimetr 28 sm. Sahə? x + y = 14, x² + y² = 100 2xy = (x + y)² − (x² + y²) = 196 − 100 = 96 → xy = 48 Sahə 48 sm² (tərəflər 6 və 8 — tapmaq belə lazım deyil)

3 İkirəqəmli ədəd

Nümunə 3. İkirəqəmli ədəd rəqəmləri cəmindən 4 dəfə böyükdür, rəqəmlərinin hasili 8-dir. 10a + b = 4(a + b) → 6a = 3b → b = 2a ab = 8 → 2a² = 8 → a = 2 (rəqəm mənfi olmur), b = 4 Ədəd: 24. Yoxla: 24 = 4·6 ✓, 2·4 = 8 ✓
Nümunə 4. Rəqəmlərin yeri dəyişəndə ədəd 36 azalır, rəqəmlərin kvadratları cəmi 40-dır. 9(a − b) = 36 → a = b + 4 (b + 4)² + b² = 40 → 2b² + 8b − 24 = 0 → b² + 4b − 12 = 0 b = 2 (b = −6 rəqəm deyil), a = 6 Ədəd: 62. Yoxla: 62 − 26 = 36 ✓, 36 + 4 = 40 ✓
Həyatdan. Divara bitişik düzbucaqlı bağçanı üç tərəfdən 40 m hasarla əhatə etmək, sahəni 192 m² etmək istəyirik. Divara perpendikulyar tərəflər x, paralel tərəf y: 2x + y = 40, xy = 192 → x(40 − 2x) = 192 → x² − 20x + 96 = 0 → x = 8 (y = 24) və ya x = 12 (y = 16). İki cavab da doğrudur — məsələ hansını seçməyi demirsə, ikisini də yaz.
Tipik səhvlər
  • x + y = P yazmaq. Perimetr iki uzunluq + iki en-dir: x + y = P/2.
  • Mənfi və ya rəqəm olmayan kökü cavab yazmaq. Uzunluq müsbətdir, rəqəm 0…9 tamdır.
  • Vahidləri qarışdırmaq: sahə sm², tərəf sm.
Yadda saxla
Düzbucaqlı: x + y = P/2, xy = S, x² + y² = d² 2xy = (x + y)² − (x² + y²) İkirəqəmli ədəd: 10a + b; yerdəyişmə fərqi 9(a − b) Mənasız kökü at, mənalı iki cavabı saxla.
Özünü yoxla: 3 sual
  1. Perimetri 20 sm, sahəsi 24 sm² olan düzbucaqlının tərəfləri? x + y = 10, xy = 24 → 6 sm və 4 sm.
  2. İki ədədin cəmi 11, hasili 28-dir. Ədədlər? t² − 11t + 28 = 0 → 4 və 7.
  3. Düzbucaqlı üçbucağın katetləri cəmi 17 sm, hipotenuzu 13 sm. Sahəsi? 2xy = 17² − 13² = 289 − 169 = 120 → xy = 60 → sahə xy/2 = 30 sm² (katetlər 5 və 12).
