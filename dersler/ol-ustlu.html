Riyaziyyat olimpiadası · RFO: Üstlü ifadələr, üstlü tənliklər və sistemlər

Üstlü ifadələr, sadə üstlü tənliklər və sistemlər

2³⁰⁰ və 3²⁰⁰ ədədlərindən hansı böyükdür? Kalkulyator bunları göstərə bilmir, amma bir fikir bunu bir sətirdə həll edir: qüvvətləri eyni üstə gətirmək. Bu mövzuda qüvvət qaydalarını, aˣ = aʸ tipli tənlikləri, t = 2ˣ əvəzləməsini, sistemləri və böyük qüvvətlərin müqayisəsini öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Qüvvət qaydaları və sadələşdirmə

1 Niyə lazımdır

Olimpiadada tez-tez 2²⁰²⁴ − 2²⁰²² kimi nəhəng ədədlər görürsən. Onları hesablamaq lazım deyil — ortaq vuruğu mötərizə xaricinə çıxarmaq kifayətdir. Bunun üçün qüvvət qaydalarını yaxşı bilmək lazımdır.

2 Əsas fikir

aᵐ · aⁿ = aᵐ⁺ⁿ aᵐ : aⁿ = aᵐ⁻ⁿ (aᵐ)ⁿ = aᵐⁿ (ab)ⁿ = aⁿ · bⁿ a⁰ = 1 (a ≠ 0) a⁻ⁿ = 1/aⁿ (a ≠ 0) a^(m/n) = ⁿ√(aᵐ) (a > 0)

Əsas strategiya: bütün əsasları sadə vuruqlara ayır (4 = 2², 9 = 3², 6 = 2·3, 12 = 2²·3) və hər sadə ədədin üstlərini ayrıca topla. Qalan iş sadə hesabdır.

3 Həll olunmuş nümunələr

1) (4¹⁵ · 9¹⁰) : 6²⁰ 4¹⁵ = (2²)¹⁵ = 2³⁰, 9¹⁰ = (3²)¹⁰ = 3²⁰, 6²⁰ = 2²⁰ · 3²⁰ (2³⁰ · 3²⁰) : (2²⁰ · 3²⁰) = 2³⁰⁻²⁰ = 2¹⁰ = 1024 2) (3²⁰²⁶ − 3²⁰²⁴) : 3²⁰²³ Ortaq vuruq 3²⁰²⁴: 3²⁰²⁴ · (3² − 1) = 3²⁰²⁴ · 8 3²⁰²⁴ · 8 : 3²⁰²³ = 3 · 8 = 24 3) √2 · ∛2 · ⁶√2 = 2^(1/2) · 2^(1/3) · 2^(1/6) = 2^(1/2 + 1/3 + 1/6) = 2¹ = 2

4 Olimpiada məsələləri

Məsələ 1. Hesabla: (2²⁰²⁴ − 2²⁰²²) : (3 · 2²⁰²¹) Həll. Surətdə ortaq vuruq 2²⁰²²: 2²⁰²² · (2² − 1) = 2²⁰²² · 3. Kəsr: (2²⁰²² · 3) : (3 · 2²⁰²¹) = 2²⁰²²⁻²⁰²¹ = 2. Cavab: 2. Məsələ 2. 7²⁰²⁶ ədədinin son rəqəmini tap. Həll. 7-nin qüvvətlərinin son rəqəmləri: 7¹ → 7, 7² = 49 → 9, 7³ → 3, 7⁴ → 1, 7⁵ → 7 … Dövr 4-dür (7, 9, 3, 1). Üstü 4-ə bölək: 2026 = 4 · 506 + 2. Deməli 7²⁰²⁶ də 7²-nin son rəqəmi ilə bitir: 9. Cavab: 9.
Həyatdan. Kompüter yaddaşı 2-nin qüvvətləri ilə ölçülür: 1 KiB = 2¹⁰ = 1024 bayt, 1 MiB = 2²⁰ bayt. Beləliklə 1 MiB-da neçə KiB var? 2²⁰ : 2¹⁰ = 2¹⁰ = 1024.

5 Özünü yoxla

Tipik səhvlər
  • aᵐ + aⁿ = aᵐ⁺ⁿ yazmaq. Düzü: toplananda üstlər toplanmır; ortaq vuruğu çıxar: 2⁵ + 2³ = 2³(4 + 1).
  • (aᵐ)ⁿ ilə a^(mⁿ)-i qarışdırmaq. (2³)² = 2⁶, amma 2^(3²) = 2⁹.
  • Əsasları fərqli olan qüvvətlərin üstlərini toplamaq: 2³ · 3² ≠ 6⁵.
  • (−2)⁴ ilə −2⁴-ü eyni saymaq: birincisi 16, ikincisi −16.
Yadda saxla
Əsasları sadə vuruqlara ayır, üstləri ayrı-ayrı topla Toplama/çıxmada ortaq vuruğu mötərizə xaricinə çıxar Son rəqəm: qüvvətlərin dövrünü tap a^(m/n) = ⁿ√(aᵐ)
Özünü yoxla: 3 sual
  1. 2⁵ · 4³ = 2ᵏ olarsa, k nədir? 4³ = 2⁶, onda 2⁵ · 2⁶ = 2¹¹. k = 11.
  2. 27^(2/3) neçədir? 27 = 3³, (3³)^(2/3) = 3² = 9.
  3. 5⁻² neçədir? 1/5² = 1/25.

Dərs 2. Sadə üstlü tənliklər: aˣ = aʸ

1 Niyə lazımdır

Bakteriyalar hər saat iki dəfə artır: neçə saatdan sonra 1 000 000 olarlar? Naməlum üstdə dayanır — bu üstlü tənlikdir. İlk addım həmişə eynidir: iki tərəfi eyni əsaslı qüvvət şəklinə gətir.

2 Əsas fikir

a > 0, a ≠ 1 olduqda: aˣ = aʸ ⇔ x = y Həmişə: aˣ > 0 (üstlü ifadə heç vaxt mənfi və ya sıfır deyil)

Niyə? a > 1 olduqda aˣ həmişə artır, 0 < a < 1 olduqda həmişə azalır. Monoton funksiya hər qiyməti yalnız bir dəfə alır, ona görə bərabər qüvvətlərdə üstlər də bərabərdir.

Plan: (1) hər iki tərəfi eyni əsasa gətir; (2) üstləri bərabərləşdir; (3) alınan xətti (və ya kvadrat) tənliyi həll et. Toplananlar varsa, ortaq vuruğu çıxar.

3 Həll olunmuş nümunələr

1) 4ˣ = 32 (2²)ˣ = 2⁵ → 2²ˣ = 2⁵ → 2x = 5 → x = 5/2 2) (1/3)ˣ = 27 3⁻ˣ = 3³ → −x = 3 → x = −3 3) 9^(x−1) = 27^(2x) 3^(2x−2) = 3^(6x) → 2x − 2 = 6x → x = −1/2 4) 2^(x+3) + 2ˣ = 72 2ˣ · 2³ + 2ˣ = 2ˣ · (8 + 1) = 9 · 2ˣ = 72 → 2ˣ = 8 → x = 3 5) 2ˣ · 3ˣ = 36 (2 · 3)ˣ = 6ˣ = 6² → x = 2 6) 2ˣ = −4 → heç vaxt: 2ˣ > 0. Kök yoxdur.

4 Olimpiada məsələsi: monotonluq

Məsələ. 2ˣ + 3ˣ = 5ˣ tənliyini həll et. Həll. Hər tərəfi 5ˣ-ə bölək (5ˣ > 0): (2/5)ˣ + (3/5)ˣ = 1. 2/5 və 3/5 hər ikisi 1-dən kiçikdir, ona görə (2/5)ˣ və (3/5)ˣ azalan funksiyalardır. Sol tərəf azalandır, deməli 1 qiymətini ən çox bir dəfə alır — yəni tənliyin ən çox bir kökü var. x = 1 yoxlayaq: 2/5 + 3/5 = 1 ✓. Cavab: x = 1 (yeganə kök). ∎
Həyatdan. Bank əmanəti hər il 10% artırsa, məbləğ 1,1ⁿ dəfə böyüyür. "Neçə ildən sonra iki dəfə olar" sualı 1,1ⁿ = 2 tənliyidir. Eyni əsasa gətirmək həmişə mümkün deyil, belə hallarda loqarifm lazımdır (10–11-ci sinifdə öyrənəcəksən), amma tam üstlü nümunələrdə bu dərsin üsulu kifayətdir.

5 Özünü yoxla

Tipik səhvlər
  • Əsasları eyni etmədən üstləri bərabərləşdirmək: 4ˣ = 2⁵ üçün x = 5 yazmaq. Düzü: 2²ˣ = 2⁵, x = 5/2.
  • 2^(x+3) + 2ˣ-i 2^(2x+3) kimi toplamaq. Ortaq vuruğu çıxarmaq lazımdır.
  • (1/3)ˣ = 3⁻ˣ işarəsini unutmaq.
  • Mənfi və ya sıfır qiymətə bərabər qüvvəti həll etməyə çalışmaq: aˣ = 0 və aˣ = −4 kök vermir.
Yadda saxla
Eyni əsas → üstləri bərabərləşdir aˣ > 0 həmişə Cəm olarsa, ortaq vuruğu çıxar Fərqli əsaslar: sadə vuruqlara ayır və ya bölüb monotonluqdan istifadə et
Özünü yoxla: 3 sual
  1. 8ˣ = 1/4 tənliyini həll et. 2³ˣ = 2⁻², 3x = −2, x = −2/3.
  2. 5^(x+1) + 5ˣ = 150 tənliyini həll et. 5ˣ · 6 = 150, 5ˣ = 25, x = 2.
  3. 2ˣ = −4 tənliyinin kökü varmı? Yoxdur, çünki 2ˣ həmişə müsbətdir.

Dərs 3. t = 2ˣ əvəzləməsi

1 Niyə lazımdır

4ˣ − 5 · 2ˣ + 4 = 0 tənliyində iki fərqli qüvvət var, amma onlar bir-birinə bağlıdır: 4ˣ = (2ˣ)². Ona görə 2ˣ-i yeni bir hərflə əvəz etsək, adi kvadrat tənlik alırıq.

2 Əsas fikir

t = aˣ qoy. Onda a²ˣ = t², a^(x+k) = aᵏ · t, a⁻ˣ = 1/t Əsas şərt: t > 0 t üçün tənliyi həll et, mənfi və sıfır kökləri at, qalanlar üçün aˣ = t tənliyini həll et.

Ən vacib yoxlama: t üçün alınan kök mənfi və ya 0 olarsa, atılır — çünki aˣ mənfi ola bilməz.

3 Həll olunmuş nümunələr

1) 4ˣ − 5 · 2ˣ + 4 = 0 t = 2ˣ: t² − 5t + 4 = 0 → t = 1, t = 4 (hər ikisi > 0) 2ˣ = 1 → x = 0. 2ˣ = 4 → x = 2. Cavab: 0 və 2 2) 9ˣ − 4 · 3ˣ − 45 = 0 t = 3ˣ: t² − 4t − 45 = 0 → t = 9 və t = −5 t = −5 < 0 yararsızdır. 3ˣ = 9 → x = 2. Cavab: 2 3) 2^(2x+1) − 5 · 2ˣ + 2 = 0 2^(2x+1) = 2 · (2ˣ)² = 2t². 2t² − 5t + 2 = 0 → t = 2, t = 1/2 2ˣ = 2 → x = 1. 2ˣ = 1/2 → x = −1. Cavab: 1 və −1 4) 2ˣ + 2⁻ˣ = 5/2 t + 1/t = 5/2 → 2t² − 5t + 2 = 0 → t = 2, t = 1/2 Cavab: x = 1 və x = −1

4 Olimpiada məsələləri

Məsələ 1. (2 + √3)ˣ + (2 − √3)ˣ = 4 tənliyini həll et. Həll. (2 + √3)(2 − √3) = 4 − 3 = 1. Deməli (2 − √3) = 1/(2 + √3). t = (2 + √3)ˣ qoyaq, onda (2 − √3)ˣ = 1/t. t + 1/t = 4 → t² − 4t + 1 = 0 → t = 2 ± √3. t = 2 + √3: (2 + √3)ˣ = (2 + √3)¹ → x = 1. t = 2 − √3 = (2 + √3)⁻¹: x = −1. Cavab: x = 1 və x = −1. Məsələ 2. 2ˣ + 2⁻ˣ = 2 tənliyini həll et. Həll. t + 1/t = 2 → t² − 2t + 1 = 0 → (t − 1)² = 0 → t = 1 → x = 0. Qeyd: t > 0 üçün həmişə t + 1/t ≥ 2 (orta qiymətlər mövzusunda sübut edəcəyik), bərabərlik yalnız t = 1-də. Ona görə sol tərəf heç vaxt 2-dən kiçik deyil.
Həyatdan. Radioaktiv maddənin kütləsi hər yarımparçalanma dövründə 2 dəfə azalır: m = m₀ · 2^(−t/T). Bu kimi düsturlar üstlü tənliyə gətirir, əvəzləmə üsulu isə mürəkkəb halları da həll edir.

5 Özünü yoxla

Tipik səhvlər
  • Mənfi t kökünü atmamaq və aˣ = −5 həll etməyə çalışmaq.
  • t tapıb dayanmaq. Sual x-i soruşur: aˣ = t həll etmək lazımdır.
  • 4ˣ-i 2ˣ-in iki mislidir hesab etmək. Düzü: 4ˣ = (2ˣ)².
  • 2^(x+1) = 2t əvəzinə t + 1 yazmaq.
Yadda saxla
t = aˣ, t > 0 a²ˣ = t², a^(x+k) = aᵏ·t, a⁻ˣ = 1/t Mənfi t atılır; qalan t üçün aˣ = t tənliyini həll et
Özünü yoxla: 3 sual
  1. 4ˣ − 6 · 2ˣ + 8 = 0 tənliyini həll et. t² − 6t + 8 = 0, t = 2, 4. x = 1 və x = 2.
  2. 3ˣ + 3^(1−x) = 4 tənliyini həll et. 3^(1−x) = 3/t. t + 3/t = 4 → t² − 4t + 3 = 0 → t = 1, 3. x = 0 və x = 1.
  3. 9ˣ + 9 = 10 · 3ˣ tənliyini həll et. t² − 10t + 9 = 0, t = 1, 9. x = 0 və x = 2.

Dərs 4. Üstlü sistemlər və böyük qüvvətlərin müqayisəsi

1 Niyə lazımdır

Olimpiadada iki cür üstlü məsələ çox rast gəlinir: (1) bir neçə naməlum üstdə olan sistemlər; (2) hansı ədəd böyükdür sualı. Birincidə eyni əsasa gətirib xətti sistemə çevirirsən, ikincidə qüvvətləri eyni üstə gətirirsən.

2 Əsas fikir

Sistem: əsasları eyni et → üstlərdən xətti sistem qur Vurma / bölmə ilə bir tənlik alırsan: 2ˣ·3ʸ = A, 2ʸ·3ˣ = B → vur: 6^(x+y) = A·B; böl: (2/3)^(x−y) = A/B Müqayisə: aᵖᵏ və bᵠᵏ → (aᵖ)ᵏ və (bᵠ)ᵏ, sonra aᵖ ilə bᵠ-ni müqayisə et

Müqayisə qaydası: k > 0 və u, v > 0 üçün uᵏ > vᵏ ⇔ u > v. Ona görə üstləri bərabərləşdirmək kifayətdir.

3 Həll olunmuş nümunələr

1) 2³⁰⁰ və 3²⁰⁰ — hansı böyükdür? 2³⁰⁰ = (2³)¹⁰⁰ = 8¹⁰⁰, 3²⁰⁰ = (3²)¹⁰⁰ = 9¹⁰⁰ 8 < 9 → 8¹⁰⁰ < 9¹⁰⁰. Cavab: 3²⁰⁰ daha böyükdür. 2) 2¹⁰⁰ və 10³⁰ 2¹⁰⁰ = (2¹⁰)¹⁰ = 1024¹⁰, 10³⁰ = (10³)¹⁰ = 1000¹⁰ 1024 > 1000 → 2¹⁰⁰ > 10³⁰. 3) 3⁴⁰ və 4³⁰ 3⁴⁰ = (3⁴)¹⁰ = 81¹⁰, 4³⁰ = (4³)¹⁰ = 64¹⁰ → 3⁴⁰ > 4³⁰ 4) 2ˣ · 4ʸ = 32, 3^(x−y) = 9 x + 2y = 5 (32 = 2⁵), x − y = 2 Çıxsaq: 3y = 3 → y = 1, x = 3. Yoxla: 8 · 4 = 32 ✓, 3² = 9 ✓

4 Olimpiada məsələsi: simmetrik sistem

Məsələ. 2ˣ · 3ʸ = 24, 2ʸ · 3ˣ = 54 sistemini həll et. Həll. Tənlikləri vuraq: 2ˣ⁺ʸ · 3ˣ⁺ʸ = 6ˣ⁺ʸ = 24 · 54 = 1296 = 6⁴ → x + y = 4. Tənlikləri bölək: (2ˣ·3ʸ) : (2ʸ·3ˣ) = 2^(x−y) · 3^(y−x) = (2/3)^(x−y) = 24/54 = 4/9 = (2/3)² → x − y = 2. Toplasaq: 2x = 6, x = 3, y = 1. Yoxlama: 2³ · 3 = 24 ✓, 2 · 3³ = 54 ✓. Cavab: x = 3, y = 1.
Həyatdan. İki şəhərin əhalisi müxtəlif tempdə artarsa (biri hər il 2 dəfə, digəri 3 dəfə), "nə vaxt eyni olarlar?" sualı eyni əsasa gətirmə və ya müqayisə tələb edir. Böyük qüvvətləri hesablamadan müqayisə etmək riyaziyyatçının əsas bacarığıdır.

5 Özünü yoxla

Tipik səhvlər
  • Müqayisədə üstləri deyil, əsasları bir-biri ilə müqayisə etmək: 2³⁰⁰ və 3²⁰⁰ üçün "3 > 2, deməli 3²⁰⁰ böyükdür" — bu üstlərin fərqini nəzərə almır.
  • Ortaq üstü düzgün tapmamaq. 300 və 200-ün ortaq böləni 100-dür, bu üstlərin ən böyük ortaq böləni (ƏBOB) götürülür.
  • Sistemdə üstləri bərabərləşdirəndə bir tənliyin sağ tərəfini səhv vuruqlara ayırmaq.
  • Vurma / bölmə ilə alınan tənliyin yoxlamasını unutmaq: iki tənlik ilə həll olunur, amma ilkin sistemə qoyub yoxla.
Yadda saxla
Sistem: eyni əsas → xətti sistem; vur və böl Müqayisə: üstləri bərabərləşdir (ƏBOB) uᵏ > vᵏ ⇔ u > v (k > 0, u, v > 0) 2¹⁰ = 1024 > 10³
Özünü yoxla: 3 sual
  1. 2⁵⁰ və 5²⁰ — hansı böyükdür? 2⁵⁰ = 32¹⁰, 5²⁰ = 25¹⁰. 2⁵⁰ böyükdür.
  2. 2ˣ · 2ʸ = 16, 3ˣ : 3ʸ = 9 sistemini həll et. x + y = 4, x − y = 2 → x = 3, y = 1.
  3. 3¹⁰⁰ və 2¹⁵⁰ — hansı böyükdür? 3¹⁰⁰ = 9⁵⁰, 2¹⁵⁰ = 8⁵⁰. 3¹⁰⁰ böyükdür.
