Binom açılışı, aⁿ ± bⁿ və bölünmə

(a + b)² düsturunu bilirsən. Bəs (a + b)¹⁰? Paskal üçbucağı istənilən qüvvəti açmağa imkan verir. Həmin açılış və aⁿ − bⁿ düsturu olimpiadanın iki güclü alətidir: "7¹⁰⁰ ədədini 48-ə böldükdə qalıq", "sübut et ki, bölünür" kimi məsələlər bir-iki sətirdə həll olunur.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Paskal üçbucağı və (a + b)ⁿ

1 Niyə lazımdır

(a + b)² = a² + 2ab + b², (a + b)³ = a³ + 3a²b + 3ab² + b³. Bu əmsallar — 1, 2, 1 və 1, 3, 3, 1 — təsadüfi deyil. Onları bir cədvəldən oxumaq olur və bu cədvəl ehtimal, kombinatorika, qalıq məsələlərində də çıxır.

2 Paskal üçbucağı

n = 0: 1 n = 1: 1 1 n = 2: 1 2 1 n = 3: 1 3 3 1 n = 4: 1 4 6 4 1 n = 5: 1 5 10 10 5 1 n = 6: 1 6 15 20 15 6 1

Qayda: kənarlarda 1, qalan hər ədəd üstündəki iki ədədin cəmidir (məsələn, 10 = 4 + 6). n-ci sətir (a + b)ⁿ açılışının əmsallarıdır:

(a + b)⁴ = a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴ (a − b)⁴ = a⁴ − 4a³b + 6a²b² − 4ab³ + b⁴

3 Niyə belədir: C(n, k)

(a + b)ⁿ = (a + b)(a + b)…(a + b) — n mötərizə. Mötərizələri açanda hər mötərizədən ya a, ya b götürürük. aⁿ⁻ᵏbᵏ həddi o vaxt alınır ki, n mötərizədən düz k dənəsində b seçək. Belə seçimlərin sayı C(n, k)-dır (dərsliklərdə Cₙᵏ də yazılır):

C(n, k) = n! / (k!·(n − k)!) = n·(n − 1)·…·(n − k + 1) / (1·2·…·k) (a + b)ⁿ = C(n,0)aⁿ + C(n,1)aⁿ⁻¹b + … + C(n,k)aⁿ⁻ᵏbᵏ + … + C(n,n)bⁿ Simmetriya: C(n, k) = C(n, n − k) Paskal qaydası: C(n + 1, k + 1) = C(n, k) + C(n, k + 1)

Paskal qaydasının izahı: n + 1 nəfərdən k + 1 nəfər seçirik. Fikrət ya seçilir (qalan n nəfərdən daha k nəfər), ya seçilmir (n nəfərdən k + 1 nəfər).

4 Həll olunmuş nümunələr

1) (x + 2)⁴ = ? Sətir 1, 4, 6, 4, 1: x⁴ + 4·x³·2 + 6·x²·4 + 4·x·8 + 16 = x⁴ + 8x³ + 24x² + 32x + 16 2) C(10, 3) = 10·9·8 / (1·2·3) = 720 / 6 = 120 3) 11⁴ = (10 + 1)⁴ = 10⁴ + 4·10³ + 6·10² + 4·10 + 1 = 14641 (11-in qüvvətləri Paskal sətirlərini "rəqəmlərlə" yazır)
Həyatdan. Şəhər küçələri dama-dama torudur. Evdən məktəbə 3 məhəllə şərqə, 2 məhəllə şimala getmək lazımdır. Ən qısa yolların sayı — 5 addımdan hansı 2-sinin şimala olduğunu seçmək: C(5, 2) = 10. Hər kəsişməyə çatan yolların sayı da Paskal qaydası ilə hesablanır: soldan gələnlər + aşağıdan gələnlər.

5 Olimpiada məsələsi

Məsələ. Sübut et ki, C(n, 0) + C(n, 1) + … + C(n, n) = 2ⁿ və C(n, 0) − C(n, 1) + C(n, 2) − … ± C(n, n) = 0 (n ≥ 1). Həll. (a + b)ⁿ açılışında a = b = 1 qoyaq: (1 + 1)ⁿ = C(n, 0) + C(n, 1) + … + C(n, n), yəni cəm 2ⁿ. a = 1, b = −1 qoyaq: (1 − 1)ⁿ = 0 = C(n, 0) − C(n, 1) + C(n, 2) − … ∎ Mənası: n elementli çoxluğun bütün alt çoxluqlarının sayı 2ⁿ-dir, cüt elementli alt çoxluqlar isə tək elementlilər qədərdir.
Tipik səhvlər
  • Sətir nömrəsini səhv saymaq: (a + b)⁵ üçün 1, 5, 10, 10, 5, 1 sətri lazımdır (ikinci ədəd = n).
  • (x + 2)⁴-də ikinci həddin qüvvətini unutmaq: 6·x²·2² = 24x², 12x² yox.
  • (a − b)ⁿ-də işarələri unutmaq: işarələr növbələşir, b-nin tək qüvvətləri olan hədlər mənfidir.
Yadda saxla
C(n, k) = n·(n − 1)·…·(n − k + 1) / k! (a + b)ⁿ: əmsallar — Paskal üçbucağının n-ci sətri Sətrin cəmi 2ⁿ; C(n, k) = C(n, n − k)
Özünü yoxla: 3 sual
  1. (a − b)⁵ açılışının əmsalları? 1, −5, 10, −10, 5, −1.
  2. C(8, 3) = ? 8·7·6/(1·2·3) = 56.
  3. 101³ = ? (100 + 1)³ = 1 000 000 + 3·10 000 + 3·100 + 1 = 1 030 301.

Dərs 2. Konkret həddin əmsalı və əmsalların cəmi

1 Niyə lazımdır

(2x − 3)¹⁰ açılışında 11 hədd var — hamısını yazmaq uzundur. Olimpiadada adətən bir həddi ("x³-ün əmsalı", "sərbəst hədd") və ya bütün əmsalların cəmini soruşurlar. İkisinin də qısa yolu var.

2 Ümumi hədd

(A + B)ⁿ açılışının ümumi həddi: C(n, k) · Aⁿ⁻ᵏ · Bᵏ, k = 0, 1, …, n x-in lazım olan qüvvətini verən k-nı tap → hesabla

3 Həll olunmuş nümunələr

1) (2x − 3)⁵ açılışında x³-ün əmsalı A = 2x, B = −3: C(5, k)·(2x)⁵⁻ᵏ·(−3)ᵏ x³: 5 − k = 3 → k = 2 C(5, 2)·2³·(−3)² = 10·8·9 = 720 2) (x² + 1/x)⁹ açılışında sərbəst hədd C(9, k)·(x²)⁹⁻ᵏ·(1/x)ᵏ = C(9, k)·x¹⁸⁻²ᵏ⁻ᵏ = C(9, k)·x¹⁸⁻³ᵏ 18 − 3k = 0 → k = 6 C(9, 6) = C(9, 3) = 9·8·7/6 = 84 3) (x − 2/x²)⁶ açılışında sərbəst hədd C(6, k)·x⁶⁻ᵏ·(−2)ᵏ·x⁻²ᵏ → üst 6 − 3k = 0 → k = 2 C(6, 2)·(−2)² = 15·4 = 60

4 Əmsalların cəmi: x = 1, x = 0, x = −1

P(x) = aₙxⁿ + … + a₁x + a₀ Bütün əmsalların cəmi: P(1) Sərbəst hədd: P(0) Cüt qüvvətlərdəki cəm: (P(1) + P(−1)) / 2 Tək qüvvətlərdəki cəm: (P(1) − P(−1)) / 2

Niyə? x = 1 olanda hər hədd öz əmsalına çevrilir. x = −1 olanda cüt qüvvətlər "+", tək qüvvətlər "−" işarə ilə gəlir; toplayanda tək hədlər silinir.

(3x − 2)¹⁰: P(1) = 1¹⁰ = 1 (x² − 3x + 1)²⁰²⁶: P(1) = (−1)²⁰²⁶ = 1 (2x − 1)⁶, cüt qüvvətlər: P(1) = 1, P(−1) = (−3)⁶ = 729 (1 + 729)/2 = 365
Həyatdan. Sikkəni 5 dəfə atırsan. Düz 2 dəfə "gerb" düşməsinin neçə yolu var? 5 atışdan hansı 2-sinin gerb olduğunu seçirik: C(5, 2) = 10. Bütün nəticələrin sayı 2⁵ = 32, deməli ehtimal 10/32. Bu, (a + b)⁵ açılışındakı 10a³b² həddidir.

5 Olimpiada məsələsi

Məsələ. (1 + x)ⁿ açılışında üç ardıcıl əmsal 1 : 2 : 3 nisbətindədir. n-i tap. Həll. Əmsallar C(n, k − 1), C(n, k), C(n, k + 1) olsun. Qonşu əmsalların nisbəti: C(n, k) / C(n, k − 1) = (n − k + 1)/k. (n − k + 1)/k = 2 → n = 3k − 1 (n − k)/(k + 1) = 3/2 → 2n − 2k = 3k + 3 → 2n = 5k + 3 2(3k − 1) = 5k + 3 → k = 5, n = 14 Yoxla: C(14, 4) = 1001, C(14, 5) = 2002, C(14, 6) = 3003 ✓ Cavab: 14.
Tipik səhvlər
  • Əmsala ədədi vuruğun qüvvətini qatmamaq: (2x)³ = 8x³, əmsal C(5, 2)·8·9-dur, C(5, 2)·9 yox.
  • Mənfi işarəni itirmək: (−3)ᵏ tək k-da mənfidir.
  • k-nı x-in üstü ilə qarışdırmaq: (2x − 3)⁵-də x³ üçün k = 2-dir (B-nin qüvvəti), 3 yox.
Yadda saxla
Hədd: C(n, k)·Aⁿ⁻ᵏ·Bᵏ → x-in üstünə görə k tapılır Əmsallar cəmi = P(1), sərbəst hədd = P(0) Cüt qüvvətlər: (P(1) + P(−1))/2
Özünü yoxla: 3 sual
  1. (x + 3)⁴ açılışında x²-nın əmsalı? C(4, 2)·3² = 6·9 = 54.
  2. (x + 1/x)⁸ açılışında sərbəst hədd? 8 − 2k = 0 → k = 4: C(8, 4) = 70.
  3. (5x − 4)²⁰²⁶ açılışında əmsalların cəmi? P(1) = 1²⁰²⁶ = 1.

Dərs 3. aⁿ − bⁿ və aⁿ + bⁿ: nəyə bölünür

1 Niyə lazımdır

"Sübut et ki, 2¹⁰⁰ − 1 ədədi 15-ə bölünür." Bu ədədi hesablamaq olmur, amma onun bölənlərini bir düsturla görmək olur.

2 Düsturlar

aⁿ − bⁿ = (a − b)(aⁿ⁻¹ + aⁿ⁻²b + … + abⁿ⁻² + bⁿ⁻¹) n tək: aⁿ + bⁿ = (a + b)(aⁿ⁻¹ − aⁿ⁻²b + … − abⁿ⁻² + bⁿ⁻¹) Nəticə (a, b — tam ədədlər): • aⁿ − bⁿ həmişə a − b-yə bölünür • n tək olanda aⁿ + bⁿ bölünür a + b-yə • n cüt olanda aⁿ − bⁿ bölünür a + b-yə

İsbatın ideyası (Bezu teoremi ilə). P(x) = xⁿ − bⁿ çoxhədlisində P(b) = 0, deməli P(x) bölünür x − b-yə. n tək olanda Q(x) = xⁿ + bⁿ üçün Q(−b) = −bⁿ + bⁿ = 0, deməli bölünür x + b-yə. n cüt olanda xⁿ − bⁿ üçün x = −b də kökdür.

Qısa yazılış: a mod m — a-nı m-ə böldükdə qalıq; a ≡ b (mod m) — a və b eyni qalıq verir.

3 Həll olunmuş nümunələr

1) 2¹⁰⁰ − 1 bölünür 3-ə və 15-ə 2¹⁰⁰ − 1 = 4⁵⁰ − 1⁵⁰ → bölünür 4 − 1 = 3-ə 2¹⁰⁰ − 1 = 16²⁵ − 1²⁵ → bölünür 16 − 1 = 15-ə 2) 17ⁿ − 11ⁿ istənilən n üçün 6-ya bölünür (17 − 11 = 6) 3) 5²⁰²⁷ + 7²⁰²⁷ bölünür 12-yə (2027 tək, 5 + 7 = 12) 4) 3¹⁰⁰ mod 4 = ? 100 cüt → 3¹⁰⁰ − 1¹⁰⁰ bölünür 3 + 1 = 4-ə → qalıq 1
Həyatdan. Məlum ən böyük sadə ədədlər 2ᵖ − 1 şəklindədir (Mersenn ədədləri); onların axtarışında bütün dünyadan minlərlə kompüter iştirak edir. Niyə üst p sadə olmalıdır? Aşağıdakı olimpiada məsələsi bunu göstərir.

4 Olimpiada məsələləri

Məsələ 1. Sübut et ki, 2ⁿ − 1 sadədirsə, n də sadədir. Həll. Tutaq ki, n = a·b, 1 < a < n. Onda 2ⁿ − 1 = (2ᵃ)ᵇ − 1ᵇ, bu isə 2ᵃ − 1-ə bölünür. 1 < 2ᵃ − 1 < 2ⁿ − 1 — deməli 2ⁿ − 1 mürəkkəbdir. Məsələn, 2⁶ − 1 = 63 bölünür 2² − 1 = 3-ə və 2³ − 1 = 7-yə. ∎
Məsələ 2. Sübut et ki, istənilən natural n üçün 11ⁿ⁺² + 12²ⁿ⁺¹ bölünür 133-ə. Həll. 11ⁿ⁺² = 121·11ⁿ, 12²ⁿ⁺¹ = 12·144ⁿ. 121·11ⁿ + 12·144ⁿ = 133·11ⁿ − 12·11ⁿ + 12·144ⁿ = 133·11ⁿ + 12·(144ⁿ − 11ⁿ) 144ⁿ − 11ⁿ bölünür 144 − 11 = 133-ə. Hər iki toplanan 133-ə bölünür. ∎
Tipik səhvlər
  • aⁿ + bⁿ cüt n-də a + b-yə bölünür demək. 3² + 1² = 10, 4-ə bölünmür.
  • aⁿ − bⁿ bölünür a + b-yə — yalnız cüt n üçün: 3³ − 1 = 26, 4-ə bölünmür.
  • Əsasları uyğunlaşdırmağı unutmaq: 2¹⁰⁰ − 1-də 15-i görmək üçün 2¹⁰⁰ = 16²⁵ yazmaq lazımdır.
Yadda saxla
a − b bölür aⁿ − bⁿ (həmişə) a + b bölür aⁿ + bⁿ (n tək) a + b bölür aⁿ − bⁿ (n cüt)
Özünü yoxla: 3 sual
  1. 7¹⁰⁰ − 3¹⁰⁰ ədədi 40-a bölünürmü? Bəli: 7¹⁰⁰ − 3¹⁰⁰ = 49⁵⁰ − 9⁵⁰, bölünür 49 − 9 = 40-a.
  2. 2²⁰²⁶ + 1 ədədini 5-ə böldükdə qalıq? 2²⁰²⁶ + 1 = 4¹⁰¹³ + 1¹⁰¹³, 1013 tək → bölünür 4 + 1 = 5-ə. Qalıq 0.
  3. 9¹⁰¹ mod 10 = ? 101 tək → 9¹⁰¹ + 1 bölünür 10-a, yəni 9¹⁰¹ ≡ −1 ≡ 9. Son rəqəm 9.

Dərs 4. Binomla qalıq: 7¹⁰⁰ mod 48

1 Niyə lazımdır

7¹⁰⁰ ədədində 85 rəqəm var. Onu 48-ə böldükdə qalığı tapmaq üçün bircə müşahidə kifayətdir: 7² = 49 = 48 + 1.

2 Əsas fikir

(m + 1)ⁿ = mⁿ + C(n,1)mⁿ⁻¹ + … + C(n,n−1)·m + 1 ≡ 1 (mod m) (m − 1)ⁿ ≡ (−1)ⁿ (mod m)

Açılışda sonuncudan başqa bütün hədlərdə m vuruğu var. Deməli qüvvətin əsasını (və ya onun kiçik qüvvətini) m ± 1 şəklinə salmaq lazımdır.

Plan: bᵉ = m ± 1 tap; N = e·q + r; bᴺ = (bᵉ)^q · bʳ ≡ (±1)^q · bʳ

3 Həll olunmuş nümunələr

1) 7¹⁰⁰ mod 48 7² = 49 = 48 + 1 → 7¹⁰⁰ = (48 + 1)⁵⁰ ≡ 1. Cavab: 1 2) 2¹⁰⁰ mod 7 2³ = 8 = 7 + 1; 100 = 3·33 + 1 2¹⁰⁰ = 8³³ · 2 ≡ 1 · 2 = 2. Cavab: 2 3) 3¹⁰⁰ mod 28 3³ = 27 = 28 − 1; 100 = 3·33 + 1 3¹⁰⁰ = 27³³ · 3 ≡ (−1)³³ · 3 = −3 ≡ 25. Cavab: 25 4) 21⁵⁰ ədədinin son iki rəqəmi (mod 100) (20 + 1)⁵⁰ = 1 + 50·20 + C(50, 2)·20² + … üçüncü həddən başlayaraq hamısı 100-ə bölünür ≡ 1 + 1000 = 1001 → son iki rəqəm 01
Həyatdan. Bu gün bazar ertəsidir. 8¹⁰⁰ gündən sonra hansı gün olacaq? 8 = 7 + 1, deməli 8¹⁰⁰ ≡ 1 (mod 7) — həftə cəmi 1 gün sürüşür: çərşənbə axşamı. Təqvim, saat, növbə cədvəli — hamısı qalıq hesabıdır.

4 Olimpiada məsələləri

Məsələ 1. Sübut et ki, 11¹⁰ − 1 ədədi 100-ə bölünür. Həll. 11¹⁰ = (10 + 1)¹⁰ = 1 + 10·10 + C(10, 2)·10² + C(10, 3)·10³ + … 11¹⁰ − 1 = 100 + 45·100 + 120·1000 + … — hər toplanan 100-ə bölünür. ∎
Məsələ 2. Sübut et ki, istənilən natural n üçün 6²ⁿ + 19ⁿ − 2ⁿ⁺¹ bölünür 17-yə. Həll. 6²ⁿ = 36ⁿ, 2ⁿ⁺¹ = 2ⁿ + 2ⁿ. Qruplaşdıraq: (36ⁿ − 2ⁿ) + (19ⁿ − 2ⁿ) 36ⁿ − 2ⁿ bölünür 36 − 2 = 34 = 2·17-yə, 19ⁿ − 2ⁿ bölünür 19 − 2 = 17-yə. Cəm 17-yə bölünür. ∎
Tipik səhvlər
  • (m − 1)ⁿ ≡ −1 yazmaq. Düzü: (−1)ⁿ — cüt n-də 1, tək n-də −1.
  • Mənfi qalığı cavab kimi yazmaq: −3 ≡ 25 (mod 28). Qalıq 0 ilə m − 1 arasındadır.
  • Üstün qalığını unutmaq: 2¹⁰⁰ = (2³)³³·2 — sonda qalan 2¹ vuruğu itməməlidir.
Yadda saxla
(m + 1)ⁿ ≡ 1, (m − 1)ⁿ ≡ (−1)ⁿ (mod m) bᵉ = m ± 1 tap, N = e·q + r (10k + 1)ⁿ ≡ 1 + 10k·n (mod 100)
