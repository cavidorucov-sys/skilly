Viyet teoremi (olimpiada məsələləri)

Məktəb Viyet teoremini bilirsən: x₁ + x₂ = −b/a, x₁x₂ = c/a. Olimpiadada isə kökləri heç tapmırlar — çünki ya çirkindir, ya da lazım deyil. Burada Viyetin gücünü açacaqsan: kökün yüksək qüvvətlərinin cəmi (rekurrent düstur), kub tənlik üçün Viyet, parametrli məsələlərdə köklərin yerləşməsi, kökləri dəyişdirilmiş tənliklər və simmetrik sistemlər.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq. Məktəb mövzusu (Viyet teoremi) bilinir sayılır.

Dərs 1. Simmetrik ifadələr və qüvvətlərin cəmi

1 Niyə lazımdır

x² − 3x + 1 = 0 tənliyinin kökləri (3 ± √5)/2-dir. Soruşurlar: x₁⁵ + x₂⁵ nəyə bərabərdir? Köklərə qüvvət yazıb hesablamaq dəhşətdir. Amma cavab tam ədəddir və Viyetlə bir neçə sətirdə tapılır.

Olimpiada qaydası: kökləri tapma. İfadə kökləri bərabər şəkildə daxil edirsə — Viyet bəs edir.

2 Simmetrik ifadə və əsas düsturlar

Simmetrik ifadə — x₁ və x₂ yerlərini dəyişəndə dəyişməyən ifadədir. Hər belə ifadəni s = x₁ + x₂ və p = x₁x₂ ilə yazmaq olar.

s = x₁ + x₂ = −b/a, p = x₁x₂ = c/a x₁² + x₂² = s² − 2p x₁³ + x₂³ = s³ − 3ps x₁⁴ + x₂⁴ = (s² − 2p)² − 2p² (x₁ − x₂)² = s² − 4p 1/x₁ + 1/x₂ = s/p x₁/x₂ + x₂/x₁ = (s² − 2p)/p

Hamısı bir fikirdən çıxır: (x₁ + x₂)² = x₁² + 2x₁x₂ + x₂².

3 Qüvvətlərin cəmi: rekurrent düstur

Sₙ = x₁ⁿ + x₂ⁿ yazaq. Hər kök x² = sx − p tənliyini ödəyir (tənlik x² − sx + p = 0). Hər iki tərəfi xⁿ⁻²-yə vursaq: xⁿ = s·xⁿ⁻¹ − p·xⁿ⁻². İki kök üçün toplayırıq:

Sₙ = s·Sₙ₋₁ − p·Sₙ₋₂ S₀ = 2 (1 + 1!), S₁ = s
Nümunə 1. x² − 3x + 1 = 0, S₅ = ? s = 3, p = 1. S₀ = 2, S₁ = 3 S₂ = 3·3 − 1·2 = 7 S₃ = 3·7 − 1·3 = 18 S₄ = 3·18 − 1·7 = 47 S₅ = 3·47 − 1·18 = 123 Cavab: 123. Nümunə 2. x + 1/x = 3 olarsa, x⁵ + 1/x⁵ = ? x və 1/x — t² − 3t + 1 = 0 tənliyinin kökləridir (cəm 3, hasil 1). Eyni rekurrent: cavab 123. Nümunə 3. (2 + √3)³ + (2 − √3)³ = ? İki ədədin cəmi 4, hasili 4 − 3 = 1. Yəni t² − 4t + 1 = 0 kökləri. S₀ = 2, S₁ = 4, S₂ = 4·4 − 2 = 14, S₃ = 4·14 − 4 = 52. Yoxla: (2 + √3)³ = 26 + 15√3, cəm 52 ✓.

Olimpiada məsələsi 1. İsbat et: istənilən natural n üçün (3 + √5)ⁿ + (3 − √5)ⁿ tam ədəddir və 2ⁿ-ə bölünür.

Həlli. Cəm 6, hasil 9 − 5 = 4: ədədlər t² − 6t + 4 = 0 kökləridir. Sₙ = 6Sₙ₋₁ − 4Sₙ₋₂, S₀ = 2, S₁ = 6. 1) Rekurrentdən görünür: S₀, S₁ tamdır → bütün Sₙ tamdır. 2) 2ⁿ-ə bölünmə induksiya ilə. S₀ = 2 (2⁰-a bölünür), S₁ = 6 (2¹-ə bölünür). Tutaq ki, 2ⁿ⁻¹ | Sₙ₋₁ və 2ⁿ⁻² | Sₙ₋₂. Onda 6Sₙ₋₁ = 2·3·Sₙ₋₁ → 2ⁿ-ə bölünür, 4Sₙ₋₂ = 2²·Sₙ₋₂ → 2ⁿ-ə bölünür. Fərq də 2ⁿ-ə bölünür: 2ⁿ | Sₙ. ∎ Yoxla: S₂ = 36 − 8 = 28 = 4·7, S₃ = 6·28 − 4·6 = 144 = 8·18.
Həyatdan. Fibonaççi ədədləri də belə rekurrentdir: Fₙ = Fₙ₋₁ + Fₙ₋₂. Onların düsturundakı (1 ± √5)/2 məhz x² = x + 1 tənliyinin kökləridir. Rekurrent ardıcıllıq = kvadrat tənlik.
Tipik səhvlər
  • x₁² + x₂² = (x₁ + x₂)² yazmaq. Ortaq hədd −2x₁x₂ unudulur.
  • S₀ = 1 götürmək. x₁⁰ + x₂⁰ = 1 + 1 = 2.
  • Rekurrentdə p-nin işarəsini pozmaq: x² − 2x − 3 üçün p = −3, onda Sₙ = 2Sₙ₋₁ + 3Sₙ₋₂.
  • Tənlik ax² + bx + c olanda s = −b, p = c götürmək (a-ya bölməyi unutmaq).
Yadda saxla
Kökü tapma — s = −b/a, p = c/a. x₁² + x₂² = s² − 2p, x₁³ + x₂³ = s³ − 3ps Sₙ = s·Sₙ₋₁ − p·Sₙ₋₂, S₀ = 2, S₁ = s Birdən çox qüvvət: x + 1/x = s → x və 1/x kökdür (p = 1).
Özünü yoxla: 3 sual
  1. x² − 5x + 3 = 0 tənliyinin kökləri üçün x₁² + x₂² nədir? s = 5, p = 3: 25 − 6 = 19.
  2. x² − x − 1 = 0 üçün x₁³ + x₂³ nədir? s = 1, p = −1: 1 − 3·(−1)·1 = 4.
  3. x + 1/x = 4 olarsa, x³ + 1/x³ nədir? s = 4, p = 1: 64 − 12 = 52.

Dərs 2. Kub tənlik üçün Viyet teoremi

1 Niyə lazımdır

Kub tənliyin kökləri adətən çirkindir, amma olimpiada onların cəmini, kvadratlarının cəmini, tərs qiymətlərinin cəmini soruşur. İki kök əvəzinə üç kök var — Viyet isə yenə işləyir, sadəcə üç kombinasiya olur.

2 Düsturlar

ax³ + bx² + cx + d = 0 tənliyinin kökləri x₁, x₂, x₃ olsun. Üç elementar simmetrik ifadə:

e₁ = x₁ + x₂ + x₃ = −b/a e₂ = x₁x₂ + x₂x₃ + x₃x₁ = c/a e₃ = x₁x₂x₃ = −d/a

Fənd: tənlik a(x − x₁)(x − x₂)(x − x₃) ilə eynidir, mötərizələri açanda x³ − e₁x² + e₂x − e₃ alınır. İşarələr növbələşir: − + −.

x₁² + x₂² + x₃² = e₁² − 2e₂ 1/x₁ + 1/x₂ + 1/x₃ = e₂/e₃ x₁³ + x₂³ + x₃³ = e₁³ − 3e₁e₂ + 3e₃ (x₁ + x₂)(x₂ + x₃)(x₃ + x₁) = e₁e₂ − e₃

Qüvvətlərin cəmi üçün də rekurrent var. Hər kök x³ = e₁x² − e₂x + e₃ ödəyir, ona görə pₖ = x₁ᵏ + x₂ᵏ + x₃ᵏ üçün (k ≥ 4):

pₖ = e₁·pₖ₋₁ − e₂·pₖ₋₂ + e₃·pₖ₋₃

3 Həll olunmuş nümunələr

Nümunə 1. x³ − 6x² + 11x − 6 = 0. Köklərin kvadratlarının, kublarının cəmi? e₁ = 6, e₂ = 11, e₃ = 6. x₁² + x₂² + x₃² = 36 − 22 = 14. x₁³ + x₂³ + x₃³ = 216 − 3·6·11 + 3·6 = 216 − 198 + 18 = 36. p₄ = e₁p₃ − e₂p₂ + e₃p₁ = 6·36 − 11·14 + 6·6 = 216 − 154 + 36 = 98. Yoxla (köklər 1, 2, 3): 1 + 4 + 9 = 14, 1 + 8 + 27 = 36, 1 + 16 + 81 = 98 ✓. Nümunə 2. x³ + 2x² − 5x − 6 = 0. e₁ = −2, e₂ = −5, e₃ = 6. 1/x₁ + 1/x₂ + 1/x₃ = e₂/e₃ = −5/6. (x₁ + x₂)(x₂ + x₃)(x₃ + x₁) = e₁e₂ − e₃ = 10 − 6 = 4. (Köklər 2, −1, −3: 1/2 − 1 − 1/3 = −5/6 ✓; 1·(−4)·(−1) = 4 ✓.) Nümunə 3 (silsilə). x³ − 7x² + 14x + k = 0 tənliyinin kökləri həndəsi silsilədir. k = ? Kökləri b/q, b, bq götür (ortası b). Cüt hasillərin cəmi: b²/q + b² + b²q = b(b/q + b + bq) = b·e₁. e₂ = b·e₁ → 14 = 7b → b = 2. Hasil: e₃ = b³ = 8 = −k → k = −8. (Köklər 1, 2, 4.)

Ədədi silsilədə kökləri a − d, a, a + d götür: e₁ = 3a, ortadakı a tənliyi özü ödəyir.

Həyatdan. Qutunun tilləri a, b, c-dir. Bütün tillərin cəmi 4e₁, tam səthi 2e₂-dir; diaqonalın kvadratı a² + b² + c² = e₁² − 2e₂. Ölçüləri tapmadan diaqonal tapılır.
Tipik səhvlər
  • e₁ = b/a yazmaq (işarə −), e₃ = d/a yazmaq (düzü −d/a).
  • Baş əmsal 1 deyilsə, a-ya bölməyi unutmaq: 2x³ − 5x² + … üçün e₁ = 5/2.
  • 1/x₁ + 1/x₂ + 1/x₃ üçün e₁/e₃ yazmaq. Düzü: e₂/e₃.
  • Kub kök cəmində +3e₃-ü unutmaq.
Yadda saxla
e₁ = −b/a, e₂ = c/a, e₃ = −d/a Σx² = e₁² − 2e₂, Σ1/x = e₂/e₃ Σx³ = e₁³ − 3e₁e₂ + 3e₃ pₖ = e₁pₖ₋₁ − e₂pₖ₋₂ + e₃pₖ₋₃ Silsilə: ədədi — a − d, a, a + d; həndəsi — b/q, b, bq
Özünü yoxla: 3 sual
  1. x³ − 4x² + x + 6 = 0 üçün x₁² + x₂² + x₃² nədir? e₁ = 4, e₂ = 1: 16 − 2 = 14.
  2. x³ − 2x² − x + 2 = 0 üçün 1/x₁ + 1/x₂ + 1/x₃ nədir? e₂ = −1, e₃ = −2: e₂/e₃ = 1/2.
  3. 2x³ − 5x² + x − 8 = 0 kökləri hasili nədir? −d/a = 8/2 = 4.

Dərs 3. Parametr və köklərin şərtləri

1 Niyə lazımdır

"Parametrin hansı qiymətində tənliyin iki müsbət kökü var?" — olimpiadanın sevimli sualı. Kökləri tapmaq mümkün deyil (parametr var), amma s, p və D işarələri hər şeyi deyir.

2 Köklərin yerləşməsi cədvəli

f(x) = x² − sx + p (baş əmsal müsbət), diskriminant D = s² − 4p:

Həqiqi kökləri var: D ≥ 0 İkisi də müsbət: D ≥ 0, s > 0, p > 0 İkisi də mənfi: D ≥ 0, s < 0, p > 0 Müxtəlif işarəli: p < 0 (D özü müsbət olur) m ədədi köklərin arasında: f(m) < 0 İkisi də m-dən böyük: D ≥ 0, f(m) > 0, s/2 > m

Parabolanın qolları yuxarıdır. m kökləri arasında olanda m-də parabola oxdan aşağıdadır: f(m) < 0. Bu şərt özü iki həqiqi kökün varlığını da təmin edir.

3 Həll olunmuş nümunələr

Nümunə 1. x² − 2(a − 1)x + (a + 5) = 0 tənliyinin iki müsbət kökü var. a-nın qiymətləri? s = 2(a − 1) > 0 → a > 1. p = a + 5 > 0 → a > −5. D/4 = (a − 1)² − (a + 5) = a² − 3a − 4 = (a − 4)(a + 1) ≥ 0 → a ≤ −1 və ya a ≥ 4. Üçünü birləşdir: a ≥ 4. Nümunə 2. x² − 2ax + a + 2 = 0 kökləri arasında 1 ədədi yerləşir. a = ? f(1) = 1 − 2a + a + 2 = 3 − a < 0 → a > 3. (D-ni ayrıca yoxlamağa ehtiyac yoxdur: f(1) < 0 olan parabola oxu kəsir.) Nümunə 3. x² − 6x + k = 0 kökləri üçün x₁ = 2x₂. k = ? x₁ + x₂ = 3x₂ = 6 → x₂ = 2, x₁ = 4. k = x₁x₂ = 8. Yoxla: D = 36 − 32 = 4 > 0 ✓.

Olimpiada məsələsi 2. x² − 2kx + (k + 6) = 0 tənliyinin həqiqi kökləri x₁, x₂-dir. x₁² + x₂²-nin ən kiçik qiymətini tap.

Həlli. s = 2k, p = k + 6. x₁² + x₂² = s² − 2p = 4k² − 2k − 12. Köklər həqiqi olmalıdır: D/4 = k² − (k + 6) = k² − k − 6 = (k − 3)(k + 2) ≥ 0 → k ≤ −2 və ya k ≥ 3. f(k) = 4k² − 2k − 12 parabolasının təpəsi k = 1/4-dir — amma bu nöqtə icazəli deyil! Hər iki icazəli şüada f(k) təpədən uzaqlaşdıqca artır, ona görə minimum sərhəddədir: f(−2) = 16 + 4 − 12 = 8, f(3) = 36 − 6 − 12 = 18. Cavab: 8 (k = −2, tənlik x² + 4x + 4 = 0, x₁ = x₂ = −2).
Həyatdan. Dördbucaqlı sahənin perimetri P, sahəsi S verilib: tərəflər t² − (P/2)t + S = 0 kökləridir. Belə sahə mövcuddur ancaq D = (P/2)² − 4S ≥ 0 olanda. Ən böyük sahə kvadratdır (D = 0) — olimpiada məsələlərinin çoxu bu fikirdir.
Tipik səhvlər
  • Parametr tapılandan sonra D ≥ 0 yoxlamamaq. Misal: "x₁² + x₂² verilib, k tap" tipli məsələlərdə kvadrat tənlikdən çıxan iki k-nın biri çox vaxt həqiqi kök vermir.
  • "İkisi də müsbət" üçün yalnız p > 0 yoxlamaq: ikisi də mənfi ola bilər. s > 0 da lazımdır.
  • f(m) < 0 şərtində baş əmsalın işarəsini nəzərə almamaq (baş əmsal mənfidirsə, şərt f(m) > 0 olur).
  • Minimumu parabolanın təpəsində axtarmaq, amma təpənin parametr üçün icazəli olub-olmadığını yoxlamamaq (məsələ 2).
Yadda saxla
İki müsbət kök: D ≥ 0, s > 0, p > 0 Müxtəlif işarəli: p < 0 m arada: f(m) < 0 (baş əmsal > 0) Parametri tapdın — D ≥ 0 ilə yoxla. Ekstremum: icazəli oblastın sərhədlərinə bax.
Özünü yoxla: 3 sual
  1. x² − 4x + k = 0 kökləri üçün x₁ − x₂ = 2. k nədir? (x₁ − x₂)² = 16 − 4k = 4 → k = 3.
  2. x² − ax + 4 = 0 tənliyinin kökləri eyni işarəlidir. a hansı qiymətləri ala bilər? p = 4 > 0 həmişə; D = a² − 16 ≥ 0 → |a| ≥ 4 (a ≤ −4 və ya a ≥ 4).
  3. x² + ax + (a − 3) = 0 kökləri müxtəlif işarəlidir. a nə olmalıdır? p = a − 3 < 0 → a < 3.

Dərs 4. Kökləri dəyişdirilmiş tənliklər və simmetrik sistemlər

1 Niyə lazımdır

"Kökləri x₁² və x₂² olan kvadrat tənlik qur" — kökləri tapmadan tənlik qurmaq Viyetin tərs istifadəsidir. Eyni fikir iki dəyişənli simmetrik sistemləri də həll edir: x + y və xy tapılır, sonra x, y kvadrat tənliyin kökləridir.

2 Yeni tənlik qurmaq

Yeni köklərin cəmi S və hasili P olarsa, tənlik y² − Sy + P = 0-dır.

Yeni kökləri cəm S hasil P x₁², x₂² s² − 2p p² 1/x₁, 1/x₂ s/p 1/p x₁ + t, x₂ + t s + 2t p + ts + t² k·x₁, k·x₂ ks k²p x₁ + 1/x₂, x₂ + 1/x₁ s + s/p p + 2 + 1/p

Əvəzləmə üsulu (tez): yeni kök y = x + t olarsa, x = y − t-ni tənliyə yaz. y = 1/x olarsa, x = 1/y yaz və y²-yə vur (əmsallar tərsinə düzülür). Kub tənlikdə də eynidir.

3 Həll olunmuş nümunələr

Nümunə 1. x² + 3x − 2 = 0 kökləri x₁, x₂. Kökləri x₁ + 1/x₂ və x₂ + 1/x₁ olan tənlik? s = −3, p = −2. Cəm: s + s/p = −3 + (−3)/(−2) = −3 + 3/2 = −3/2. Hasil: p + 2 + 1/p = −2 + 2 − 1/2 = −1/2. Tənlik: y² + (3/2)y − 1/2 = 0 → 2y² + 3y − 1 = 0. Nümunə 2. x³ − 3x + 1 = 0 kökləri a, b, c. Kökləri a², b², c² olan kub tənlik? Əvəzləmə: x(x² − 3) = −1. Kvadrata yüksəlt: x²(x² − 3)² = 1. y = x² qoy: y(y − 3)² = 1 → y³ − 6y² + 9y − 1 = 0. Yoxla Viyetlə: a² + b² + c² = e₁² − 2e₂ = 0 + 6 = 6 ✓, a²b² + … = e₂² − 2e₁e₃ = 9 ✓, a²b²c² = e₃² = 1 ✓. Nümunə 3 (simmetrik sistem). x + y = 5, x³ + y³ = 65. x³ + y³ = s³ − 3ps → 125 − 15p = 65 → p = 4. x, y — t² − 5t + 4 = 0 kökləri: 1 və 4. Cavab: (1; 4) və (4; 1). Nümunə 4. x² + y² = 13, xy = 6. s² = x² + y² + 2xy = 13 + 12 = 25 → s = 5 və ya s = −5. s = 5: t² − 5t + 6 = 0 → 2 və 3. s = −5: t² + 5t + 6 = 0 → −2 və −3. Cavab: (2; 3), (3; 2), (−2; −3), (−3; −2).

Olimpiada məsələsi 3. Həqiqi a, b, c ədədləri üçün a + b + c = 6 və ab + bc + ca = 9. İsbat et: hər biri [0; 4] parçasındadır.

Həlli. c-ni sabit saxla. Onda a + b = 6 − c, ab = 9 − c(a + b) = 9 − c(6 − c). Deməli, a və b — t² − (6 − c)t + (9 − 6c + c²) = 0 tənliyinin həqiqi kökləridir. Həqiqi olmaq üçün D ≥ 0: D = (6 − c)² − 4(9 − 6c + c²) = 36 − 12c + c² − 36 + 24c − 4c² = 12c − 3c² = 3c(4 − c) ≥ 0 → 0 ≤ c ≤ 4. a, b, c simmetrikdir — eyni mühakimə a və b üçün də doğrudur. ∎ (Məsələn, a = b = 1, c = 4 və ya a = 0, b = c = 3 sərhəd halıdır.)
Həyatdan. Bağın perimetri 28 m, sahəsi 48 m²-dir: tərəflər x + y = 14, xy = 48 sistemindən t² − 14t + 48 = 0 kökləridir — 6 m və 8 m. Qapının ölçülərini bilmədən diaqonal: x² + y² = 196 − 96 = 100, yəni 10 m.
Tipik səhvlər
  • Sistemdə s² = 25 olanda yalnız s = 5 götürmək. s = −5 də həlldir.
  • Yeni tənlikdə y² + Sy + P yazmaq. Düzü: y² − Sy + P.
  • x₁ + t, x₂ + t üçün hasilə yalnız t² əlavə etmək: ts həddi unudulur.
  • Əvəzləmədən sonra tənliyi sadələşdirməyi unutmaq (kəsr məxrəcini atmaq).
Yadda saxla
Yeni tənlik: y² − (yeni cəm)y + (yeni hasil) = 0 x → x + t: x = y − t qoy; x → 1/x: əmsalları tərsinə yaz Simmetrik sistem: s, p tap → t² − st + p = 0 s² = c olsa, iki s var: ±√c a, b həqiqidirsə: D ≥ 0 — hədd şərtlərinin mənbəyi
Özünü yoxla: 3 sual
  1. x² − 3x + 1 = 0 kökləri x₁, x₂. Kökləri 1/x₁, 1/x₂ olan tənlik hansıdır? Əmsalları tərsinə yaz: x² − 3x + 1 = 0 (eyni; kökləri tərsdir, çünki p = 1).
  2. x + y = 6, xy = 5 olarsa, x² + y² nədir? 36 − 10 = 26.
  3. x² + y² = 10, xy = 3 sisteminin neçə həlli (x; y) var? s² = 16 → s = ±4. s = 4: (1; 3), (3; 1); s = −4: (−1; −3), (−3; −1). Cəmi 4.
