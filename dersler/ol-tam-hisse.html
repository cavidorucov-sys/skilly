[x] və {x} funksiyaları

[x] ədədi "aşağı tam ədədə yuvarlaqlayır", {x} isə artığı — kəsr hissəni göstərir. Bu iki funksiya olimpiadada tənliklərdə, bölünmə saymalarında və cəmlərdə tez-tez görünür: "1-dən 2026-ya qədər neçə ədəd 7-yə bölünür?", "100! neçə sıfırla bitir?". Qaydanı bir dəfə anlasan, çox məsələ çox qısa həll olunur.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, olimpiada məsələlərini əvvəl özün həll etməyə çalış, sonra həllə bax. Sonra Oyun və Sınaq.

Dərs 1. Tam və kəsr hissə

1 Niyə lazımdır

135 dəqiqə nə qədərdir? 2 tam saat və 15 dəqiqə. "2 tam saat" — tam hissədir, "15 dəqiqə" — artıqdır. Riyaziyyatda bunu belə yazırıq: [135/60] = 2 və {135/60} = 15/60 = 1/4.

Həyatdan. 47 alma var, qutuya 5-i sığır. Tam dolu qutu: [47/5] = 9. Qalan alma: 47 − 5·9 = 2, yəni {47/5} = 2/5.

2 Əsas fikir

[x] — x-dən böyük olmayan ən böyük tam ədəd {x} = x − [x] [x] ≤ x < [x] + 1 0 ≤ {x} < 1 x = [x] + {x}

Mənfi ədədlərdə diqqət: [−3,4] = −4 (çünki −4 ≤ −3,4 < −3), sıfıra yaxın yox, aşağı tam ədəd. Ona görə {−3,4} = −3,4 − (−4) = 0,6 — kəsr hissə heç vaxt mənfi olmur.

[x + n] = [x] + n {x + n} = {x} (n tam) [x] + [−x] = 0, x tam olanda; −1, x tam olmayanda {x} + {−x} = 0, x tam olanda; 1, x tam olmayanda [x] = n ⇔ n ≤ x < n + 1

Qrafik: y = [x] pilləkən kimidir — hər tam ədəddə bir pillə qalxır. y = {x} isə 0-dan 1-ə qədər düz xətt parçalarıdır (1-ə çatmır, yenidən 0-dan başlayır), period 1.

3 Həll olunmuş nümunə

[−17/5] və {−17/5} = ? −17/5 = −3,4. −4 ≤ −3,4 < −3 → [−17/5] = −4. {−17/5} = −17/5 − (−4) = −17/5 + 20/5 = 3/5. [x] = 3 tənliyini ödəyən x-lər: 3 ≤ x < 4 (sonsuz çox, yarımaralıq).

4 Olimpiada məsələsi

Məsələ 1. Hər həqiqi x üçün [x] + [x + 1/2] = [2x] olduğunu isbat et. Həll. x = n + f, n = [x], 0 ≤ f < 1. n tam ədəd tam hissədən çıxır, ona görə yalnız f-in ½-dən kiçik və ya böyük olması vacibdir. Hal 1: 0 ≤ f < 1/2. [x] = n, [x + 1/2] = [n + f + 1/2] = n (f + 1/2 < 1). 2x = 2n + 2f, 0 ≤ 2f < 1 → [2x] = 2n. Sol tərəf: n + n = 2n ✓ Hal 2: 1/2 ≤ f < 1. [x] = n, [x + 1/2] = n + 1 (1 ≤ f + 1/2 < 3/2). 2x = 2n + 2f, 1 ≤ 2f < 2 → [2x] = 2n + 1. Sol tərəf: n + n + 1 ✓ Hər iki halda bərabərlik doğrudur. ∎ Fikir: x = [x] + {x} yaz, tam hissəni çıx, {x}-i hallara böl.
Tipik səhvlər
  • [−3,4] = −3 yazmaq ("kəsri atdım"). Düz cavab −4. [x] kəsri atmaq deyil, aşağı yuvarlaqlamaqdır.
  • {−3,4} = 0,4 yazmaq. Düz: 0,6 (çünki {x} = x − [x]).
  • [x + y] = [x] + [y] hesab etmək. Doğru deyil: [0,5 + 0,5] = 1, [0,5] + [0,5] = 0. Yalnız tam n üçün [x + n] = [x] + n.
Yadda saxla
x = [x] + {x}, 0 ≤ {x} < 1. [x] = n ⇔ n ≤ x < n + 1. Mənfi x: [x] aşağıya yuvarlaqlanır, {x} ≥ 0. Tam n-i içəridən çıxarmaq olar, qalanı üçün {x}-in hallarına bax.
Özünü yoxla: 3 sual

  3. [x] = −2 tənliyini ödəyən x-lər hansı aralıqdadır? −2 ≤ x < −1.

Dərs 2. [x] və {x} olan tənliklər

1 Niyə lazımdır

[3x − 1] = 5 tənliyi adi tənlik deyil: bir x yox, bütöv aralıq alınır. Bəs {x} = x/3 kimi tənlik? Burada hər şey "tam hissə + kəsr hissə" ayırmasına əsaslanır. Bu dərsdə ikisini də öyrənirik.

Həyatdan. Su sayğacı həcmi yalnız tam litrlərlə göstərir (həqiqi həcmin tam hissəsini). Sayğac 7 göstərirsə, həcm 7 ≤ V < 8 litrdir — cavab bir ədəd yox, aralıqdır. [ ] tənliyinin cavabı da belədir.

2 Əsas fikir

1) [u] = n ⇔ n ≤ u < n + 1 (n mütləq tam!) 2) x = n + f yaz: n = [x] tam, f = {x}, 0 ≤ f < 1. Tənliyi n və f üçün həll et, sonra 0 ≤ f < 1-i yoxla. 3) [ ]² ... kimi tənliklərdə [x]-i yeni dəyişən (n) kimi götür: əvvəl n-i tap (tam olmalıdır), sonra x-i aralıqdan seç.

Üç addım: (a) tam hissəni dəyişənlə əvəz et; (b) əmələ gələn tənliyi həll et; (c) n-in tam olması və f-in [0; 1)-də olması şərtlərini yoxla.

3 Həll olunmuş nümunə

[3x − 1] = 5. 5 ≤ 3x − 1 < 6 → 6 ≤ 3x < 7 → 2 ≤ x < 7/3. Cavab: x ∈ [2; 7/3). [x]² − 5[x] + 6 = 0. [x] = n: n² − 5n + 6 = 0 → n = 2 və ya n = 3. [x] = 2 → 2 ≤ x < 3; [x] = 3 → 3 ≤ x < 4. Cavab: x ∈ [2; 4). x + [x] = 7/2 ? x = n + f: 2n + f = 7/2, 0 ≤ f < 1. 0 ≤ f < 1 olduğundan 2n ≤ 7/2 < 2n + 1, yəni 5/2 < 2n ≤ 7/2. Bu aralıqda cüt ədəd yoxdur (yalnız 3 var, o da təkdir). Həll yoxdur.

4 Olimpiada məsələsi

Məsələ 2. {x} = x/3 tənliyini həll et. Həll. x = n + f, n = [x], f = {x}. Tənlik: f = (n + f)/3. 3f = n + f → 2f = n → f = n/2. Şərt 0 ≤ f < 1 → 0 ≤ n/2 < 1 → n = 0 və ya n = 1 (n tam!). n = 0: f = 0, x = 0. n = 1: f = 1/2, x = 3/2. Yoxlama: {3/2} = 1/2 = (3/2)/3 ✓. Cavab: x = 0 və x = 3/2. ∎ Ümumi: k ≥ 2 tam ədəd olduqda {x} = x/k tənliyinin k − 1 həlli var: x = kn/(k − 1), n = 0, 1, …, k − 2.
Tipik səhvlər
  • [x] = n yazanda n-in tam olmasını unudub, kəsr n tapmaq. Məsələn [x] = 5/2 — mənasızdır (həll yoxdur).
  • Aralığın sağ ucunu daxil etmək. [x] = 2 üçün x = 3 uyğun deyil ([3] = 3).
  • {x} üçün f < 1 şərtini yoxlamamaq — artıq (yalançı) həllər qalır.
Yadda saxla
[u] = n ⇔ n ≤ u < n + 1 (n tam). x = n + f, 0 ≤ f < 1: iki dəyişən + iki şərt. Cavab çox vaxt aralıqdır. Həlli həmişə şərtlə yoxla: n tam, 0 ≤ f < 1.
Özünü yoxla: 3 sual
  1. [2x] = 7 tənliyinin ən kiçik həlli? 7 ≤ 2x < 8 → 7/2 ≤ x < 4. Ən kiçik: 7/2.
  2. [x]² = 4 tənliyinin tam həllərinin cəmi? [x] = ±2; tam x üçün x = −2 və x = 2; cəm 0.
  3. {x} = x/2 tənliyinin neçə həlli var? f = n (n = [x]), 0 ≤ f < 1 → n = 0. Yalnız x = 0: 1 həll.

Dərs 3. Cəmlər və saymada tam hissə

1 Niyə lazımdır

"1-dən 2026-ya qədər neçə ədəd 7-yə bölünür?" Hər ədədi yoxlamırsan: [2026/7] = 289. Tam hissə sayma alətidir: "neçə tam parça sığır" sualının cavabı.

Həyatdan. Meydança 100 m uzunluğundadır, hər 8 m-dən bir dirək qoyulur (başlanğıcdan sonra). Dirəklərin sayı [100/8] = 12. Axırıncı dirək 96 m-dədir.

2 Əsas fikir

1-dən N-ə qədər m-ə bölünən ədədlərin sayı = [N/m] m-ə və ya n-ə bölünən: [N/m] + [N/n] − [N/ƏKOK(m; n)] Lejandr: p sadə ədəd, N! -in p-ə görə üstü = [N/p] + [N/p²] + [N/p³] + … Ermit: [x] + [x + 1/m] + … + [x + (m−1)/m] = [mx]

Lejandr düsturunun səbəbi: p-yə bölünən vuruqlar [N/p] dənədir və hər biri bir p verir; p²-yə bölünənlər isə əlavə bir p verir, və s. Ermit eyniliyi (Dərs 1-dəki m = 2 halının ümumiləşməsi) cəmləri sadələşdirir.

Σ[k/m] (k = 1…n): n = qm + r olarsa 1, 2, …, q−1 qiymətlərinin hər biri m dəfə, q isə r+1 dəfə təkrarlanır

3 Həll olunmuş nümunə

[1/3] + [2/3] + [3/3] + … + [20/3] = ? Qiymətlər: 0 0 1 1 1 2 2 2 3 3 3 4 4 4 5 5 5 6 6 6 (k = 1, …, 20) 20 = 3·6 + 2: 1, 2, 3, 4, 5 hər biri 3 dəfə, 6 isə 3 dəfə (k = 18, 19, 20). Cəm: 3·(1+2+3+4+5) + 6·3 = 45 + 18 = 63. x = 7/4 üçün [x] + [x + 1/3] + [x + 2/3] = [3x] = [21/4] = 5. Yoxla: [1,75] + [2,083…] + [2,41…] = 1 + 2 + 2 = 5 ✓

4 Olimpiada məsələsi

Məsələ 3. 100! = 1·2·3·…·100 ədədi sonunda neçə sıfırla bitir? Həll. Sıfır 10 = 2·5 vuruğudan gəlir. 2-lərin sayı 5-lərdən çoxdur, ona görə sıfırların sayı = 100!-də 5 vuruğunun üstü. 5-ə bölünənlər: [100/5] = 20 25-ə bölünənlər: [100/25] = 4 (hər biri əlavə bir 5 verir) 125 > 100 — dayanırıq. Cəm: 20 + 4 = 24. Cavab: 24 sıfır. ∎ Yoxlama üçün: 25 = 5·5 iki 5 verir, [100/5]-də bir 5 sayılıb, [100/25]-də ikinci.
Tipik səhvlər
  • Lejandrda yalnız [N/p] götürüb 25, 125-i unutmaq. 100! üçün 20 yox, 24 olmalıdır.
  • "m-ə və ya n-ə" sayında kəsişməni çıxmamaq. İkisinə də bölünənlər iki dəfə sayılır.
  • [N/m] bölünən ədədlərin sayıdır, onların cəmi yox.
Yadda saxla
Bölünənlərin sayı: [N/m]. "Və ya": çıx kəsişməni. N!-də p-nin üstü: [N/p] + [N/p²] + [N/p³] + … Sıfırların sayı = 5-in üstü. Ermit: Σ[x + k/m] = [mx].
Özünü yoxla: 3 sual
  1. 1-dən 100-ə qədər neçə ədəd 7-yə bölünür? [100/7] = 14.
  2. 50! neçə sıfırla bitir? [50/5] + [50/25] = 10 + 2 = 12.
  3. x = 3,2 üçün [x] + [x + 1/2] neçədir? [3,2] + [3,7] = 3 + 3 = 6 = [2x] = [6,4] ✓.
