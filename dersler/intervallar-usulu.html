Kvadrat və rasional bərabərsizliklər (intervallar üsulu)

x² − 2x − 3 < 0, (x + 2)(x − 1)(x − 4) ≥ 0, (x − 3)/(x + 2) ≤ 0 — bunların hamısı bir üsulla həll olunur: ifadəni vuruqlara ayır, sıfırlarını ədəd oxunda qeyd et, işarələri yaz. Bu, intervallar üsuludur. Tələlər: məxrəcin sıfırı (həmişə boş nöqtə) və cüt dərəcəli vuruq (işarə dəyişmir).

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Kvadrat bərabərsizliklər

1 Niyə lazımdır

Yuxarı atılan top nə vaxt 15 m-dən yuxarıdadır? Hasarla əhatə olunan sahə nə vaxt 48 m²-dən böyükdür? Belə suallar ax² + bx + c > 0 şəklində bərabərsizliyə gətirir — kvadrat bərabərsizliyə.

2 Əsas fikir: parabolaya bax

y = ax² + bx + c qrafiki parabola, kökləri isə parabolanın Ox oxunu kəsdiyi nöqtələrdir. Bərabərsizlik soruşur: parabola oxdan yuxarıdadır (> 0) yoxsa aşağıda (< 0)?

y = x² − 2x − 3: a = 1 > 0, qollar yuxarı. Köklər −1 və 3. Aralarında parabola oxdan aşağıdadır (mənfi), kənarlarda — yuxarıda (müsbət). Ona görə x² − 2x − 3 < 0 ⇔ −1 < x < 3.

a > 0, köklər x₁ < x₂: ax² + bx + c < 0 ⇔ x₁ < x < x₂ (köklər arası) ax² + bx + c > 0 ⇔ x < x₁ və ya x > x₂ (kənarlar) a < 0 olarsa — hər tərəfi −1-ə vur, işarəni çevir.

3 Həll olunmuş nümunələr

Nümunə 1. x² − 2x − 3 < 0 Köklər (Viyet: cəm 2, hasil −3): x = −1, x = 3 a > 0 → köklər arası: (−1; 3) Tam həllər: 0; 1; 2 → 3 ədəd
Nümunə 2. −x² + x + 6 ≤ 0 −1-ə vur (işarə dönür): x² − x − 6 ≥ 0 Köklər: x = −2, x = 3 a > 0, "≥ 0" → kənarlar, köklər daxil: Cavab: (−∞; −2] ∪ [3; +∞)
Nümunə 3. 2x² − 7x + 3 > 0 D = 49 − 24 = 25, x = (7 ± 5)/4 → x₁ = 1/2, x₂ = 3 Cavab: (−∞; 1/2) ∪ (3; +∞)
Həyatdan. Hasarın uzunluğu 28 m-dir, düzbucaqlı sahənin bir tərəfi x, o biri 14 − x. Sahə ən azı 48 m² olsun: x(14 − x) ≥ 48 → x² − 14x + 48 ≤ 0 → 6 ≤ x ≤ 8. Tərəf 6 m-dən 8 m-ə qədər ola bilər.
Tipik səhvlər
  • a < 0 olanda "köklər arası" qaydasını olduğu kimi tətbiq etmək. Əvvəl −1-ə vur.
  • x² < 9 üçün "x < 3" yazmaq. Düzü: −3 < x < 3 (−5 də x < 3-dür, amma 25 > 9).
  • "≤", "≥" olanda kökləri daxil etməyi unutmaq.
Yadda saxla
Kökləri tap → a-nın işarəsinə bax. a > 0: "< 0" — köklər arası, "> 0" — kənarlar. ≤, ≥ — köklər daxildir.
Özünü yoxla: 3 sual
  1. x² − 9 ≤ 0. Neçə tam həll? [−3; 3]: −3; …; 3 — 7 həll.
  2. x² + 4x > 0. Ən kiçik müsbət tam həll? x(x + 4) > 0 → (−∞; −4) ∪ (0; +∞). Cavab: 1.
  3. x² − 5x + 6 < 0. Neçə tam həll? Köklər 2 və 3, həll (2; 3) — tam ədəd yoxdur. Cavab: 0.

Dərs 2. İntervallar üsulu

1 Niyə lazımdır

Üç vuruq olanda parabola artıq kömək etmir. Amma bir sadə fakt var: (x − a) vuruğu a-dan sağda müsbət, solda mənfidir. Hasilin işarəsi vuruqların işarələrindən asılıdır — və o, yalnız sıfırlardan keçəndə dəyişə bilər.

2 Alqoritm

1. Hər şeyi bir tərəfə keçir: f(x) > 0 (və ya <, ≥, ≤ — sağda 0 qalsın). 2. f(x)-i vuruqlara ayır. 3. Hər vuruğun sıfırını ədəd oxunda qeyd et (≥, ≤ — dolu nöqtə; >, < — boş). 4. Ən sağ intervalda işarəni tap (x çox böyük). 5. Sola doğru işarələri növbələ: +, −, +, … 6. Lazım olan işarəli intervalları götür.

Bütün vuruqlar (x − a) şəklindədirsə, ən sağda işarə +-dır. (3 − x) kimi vuruq varsa, o, ən sağda mənfidir — işarəni nəzərə al.

3 Həll olunmuş nümunə

(x + 2)(x − 1)(x − 4) ≥ 0 Sıfırlar: −2; 1; 4 (≥ — dolu nöqtələr) Ən sağda (məs. x = 10): (+)(+)(+) = + Soldan sağa: − + − + "≥ 0" → "+" intervallar və nöqtələr: Cavab: [−2; 1] ∪ [4; +∞)

İşarə sxemi. Nöqtələr miqyasla çəkilmir — yalnız sıra vacibdir. Rənglənmiş hissələr — həll. Nöqtələr dolu, çünki "≥": vuruq sıfır olanda 0 ≥ 0 doğrudur.

4 "x" arxada olan vuruq

(3 − x)(x + 1) > 0 Sıfırlar: −1; 3 Ən sağda (x = 10): (3 − 10)(10 + 1) = (−)(+) = − Soldan sağa: − + − "> 0" → (−1; 3); tam həllər 0; 1; 2 Başqa yol: −1-ə vur: (x − 3)(x + 1) < 0 — eyni cavab.
Həyatdan. Svetofor kimi: işarə yalnız "sıfır nöqtələrində" dəyişə bilər. Aralarda hasil eyni işarəni saxlayır — ona görə hər intervaldan bircə nöqtə yoxlamaq kifayətdir.
Tipik səhvlər
  • Ən sağda işarəni yoxlamadan "+" yazmaq, halbuki (3 − x) kimi vuruq var.
  • Nöqtələri ədəd oxunda səhv sırada düzmək (məs. 1/2 ilə 1-i qarışdırmaq).
  • "≥" olanda sıfırları daxil etməyi unutmaq.
Yadda saxla
Sıfırlar → oxda nöqtələr → ən sağda işarə → növbələ. (x − a): a-dan sağda +. (a − x): a-dan sağda −.
Özünü yoxla: 3 sual
  1. (x − 1)(x − 3)(x − 5) < 0. Ən böyük tam həll? İşarələr − + − +: (−∞; 1) ∪ (3; 5). Ən böyük tam həll 4.
  2. x(x + 3)(x − 2) ≤ 0. Ən böyük tam həll? Sıfırlar −3; 0; 2; işarələr − + − +: (−∞; −3] ∪ [0; 2]. Cavab: 2.
  3. (2 − x)(x + 5) ≥ 0. Neçə tam həll? Ən sağda −, işarələr − + −: [−5; 2] — 8 həll.

Dərs 3. Rasional bərabərsizliklər

1 Niyə lazımdır

Kəsrin işarəsi hasilin işarəsi kimi tapılır: A/B və A·B eyni işarəlidir. Deməli intervallar üsulu kəsrlərə də işləyir. Yeganə fərq: məxrəc sıfır ola bilməz.

2 Qaydalar

1. Hər şeyi bir tərəfə keçir, ortaq məxrəcə gətir: A(x)/B(x) > 0 (və ya <, ≥, ≤) 2. Surətin sıfırları: ≥, ≤ olanda dolu, >, < olanda boş. 3. Məxrəcin sıfırları: HƏMİŞƏ boş nöqtə. 4. İşarələr — intervallar üsulu ilə.

Məxrəcə vurmaq olmaz! Onun işarəsi məlum deyil: müsbətdirsə işarə qalır, mənfidirsə dönür. Ona görə hər şeyi sola keçirib kəsri sıfırla müqayisə edirik.

3 Həll olunmuş nümunələr

Nümunə 1. (x − 3)/(x + 2) ≤ 0 Surət: x = 3 (dolu). Məxrəc: x = −2 (boş) Ən sağda: +. Soldan sağa: + − + Cavab: (−2; 3]; tam həllər −1; 0; 1; 2; 3 → 5 ədəd
Nümunə 2. 5/(x − 1) ≥ 2 Sola keçir: 5/(x − 1) − 2 ≥ 0 Ortaq məxrəc: (5 − 2(x − 1))/(x − 1) ≥ 0 → (7 − 2x)/(x − 1) ≥ 0 Sıfırlar: 7/2 (dolu), 1 (boş) Ən sağda: (−)/(+) = −. Soldan sağa: − + − Cavab: (1; 7/2]; tam həllər 2; 3

Nümunə 2-nin sxemi. 1 — məxrəcin sıfırı, boş dairə. 7/2 — surətin sıfırı, "≥" olduğu üçün dolu. Yoxla: x = 3: 5/2 ≥ 2 ✓; x = 0: −5 ≥ 2 ✗.

Məxrəcə vurub 5 ≥ 2(x − 1) yazsaydıq, x ≤ 3,5 alardıq — və x = 0 da "həll" olardı. Amma yuxarıda gördük ki, 0 həll deyil. İşarəni nəzərə almadan məxrəcə vurmaq artıq həllər yaradır.

Nümunə 3. (x + 1)(x − 4)/(x − 2) > 0 Sıfırlar: −1; 2 (məxrəc, boş); 4 Soldan sağa: − + − + Cavab: (−1; 2) ∪ (4; +∞)
Həyatdan. 12 km yolu v km/saat sürətlə gedirsən, vaxt 12/v saatdır. Yol 3 saatdan az çəksin: 12/v < 3 → (12 − 3v)/v < 0 → v < 0 və ya v > 4. Sürət mənfi olmur — cavab: 4 km/saatdan çox.
Tipik səhvlər
  • Bərabərsizliyi məxrəcə vurmaq. Hər şeyi bir tərəfə keçir.
  • Məxrəcin sıfırını "≥" olduğu üçün dolu çəkmək. Orada kəsrin mənası yoxdur — həmişə boş.
  • Ortaq məxrəcə gətirərkən mötərizəni açıb işarəni itirmək: 5 − 2(x − 1) = 7 − 2x.
Yadda saxla
A/B-nin işarəsi = A·B-nin işarəsi. Məxrəcə vurma! Hamısını bir tərəfə keçir. Məxrəcin sıfırı — həmişə ○.
Özünü yoxla: 3 sual
  1. (x + 1)/(x − 3) < 0. Neçə tam həll? (−1; 3): 0; 1; 2 — 3 həll.
  2. (x − 2)/(x + 4) ≥ 0. x = −4 həlldirmi? Yox. −4 məxrəci sıfır edir. Həll: (−∞; −4) ∪ [2; +∞).
  3. 1/(x − 1) > 1. Neçə tam həll? (2 − x)/(x − 1) > 0 → (1; 2). Tam həll yoxdur — 0.

Dərs 4. Cüt dərəcəli vuruqlar və xüsusi hallar

1 Niyə lazımdır

"İşarələri növbələ" qaydasının bir istisnası var və imtahan onu çox sevir: (x − a)² vuruğu. Kvadrat heç vaxt mənfi olmur, ona görə a nöqtəsindən keçəndə işarə dəyişmir.

2 Cüt dərəcəli vuruq

(x − a)², (x − a)⁴, … — a nöqtəsində işarə dəyişmir. (x − a), (x − a)³, … — a nöqtəsində işarə dəyişir.
(x − 2)²(x + 1) ≤ 0 Sıfırlar: −1; 2 (ikisi də dolu) Ən sağda: +. 2-dən keçəndə işarə qalır: + −1-dən keçəndə dəyişir: − Soldan sağa: − + + "≤ 0": (−∞; −1] və x = 2 nöqtəsi! Cavab: (−∞; −1] ∪ {2}; ən böyük tam həll 2

2 nöqtəsinin hər iki tərəfində "+" var — işarə dəyişmədi. Amma 2-nin özündə ifadə sıfırdır, "≤ 0" isə sıfıra icazə verir. Ona görə 2 — tək nöqtə kimi həllə daxildir. Bunu unutmaq ən çox yayılmış səhvdir.

3 D = 0 və D < 0

x² − 6x + 9 = (x − 3)² (D = 0) (x − 3)² > 0 → x ≠ 3 (3-dən başqa bütün ədədlər) (x − 3)² ≥ 0 → bütün ədədlər (x − 3)² < 0 → həll yoxdur (x − 3)² ≤ 0 → yalnız x = 3 x² + x + 1 (D = 1 − 4 = −3 < 0, a > 0) Həmişə müsbətdir: x² + x + 1 > 0 → bütün ədədlər x² + x + 1 < 0 → həll yoxdur

Belə vuruq başqa vuruqlarla birlikdə gəlirsə ((x² + x + 1)(x − 5) < 0), onu sadəcə at: o həmişə müsbətdir, işarəyə təsir etmir. Cavab: x < 5.

4 Tətbiq: DMQ və hərəkət

1) √((x + 1)(4 − x)) ifadəsinin DMQ-su Kök altı ≥ 0: (x + 1)(4 − x) ≥ 0 Ən sağda: (+)(−) = −. Soldan sağa: − + − DMQ: [−1; 4] — 6 tam ədəd 2) Top 20 m/s sürətlə yuxarı atılıb: h = 20t − 5t². Neçə saniyə 15 m-dən aşağı olmayan hündürlükdədir? 20t − 5t² ≥ 15 → t² − 4t + 3 ≤ 0 → 1 ≤ t ≤ 3 Cavab: 3 − 1 = 2 saniyə
Həyatdan. Top 1-ci saniyədə 15 m-ə qalxır, 2-ci saniyədə ən yuxarıda (20 m) olur, 3-cü saniyədə yenə 15 m-dən keçib aşağı enir. 15 m-dən yuxarıda olduğu müddət — köklər arasıdır.
Tipik səhvlər
  • Cüt dərəcəli vuruqda işarəni növbələmək.
  • "≤", "≥" olanda cüt dərəcəli vuruğun tək nöqtəsini itirmək: (x − 2)²(x + 1) ≤ 0-da x = 2.
  • ">" olanda həmin nöqtəni çıxarmağı unutmaq: (x − 3)² > 0 — x = 3 həll deyil.
  • D < 0 olanda "həll yoxdur" deyib dayanmaq. Bərabərsizliyin işarəsinə bax: bəzən cavab "bütün ədədlər"dir.
Yadda saxla
(x − a)² — a-da işarə dəyişmir; ≤, ≥ olanda a tək nöqtə kimi daxildir. D < 0, a > 0 — üçhədli həmişə müsbətdir. D = 0 — tam kvadrat.
Özünü yoxla: 3 sual
  1. (x − 1)²(x − 4) < 0. Ən böyük tam həll? x < 4 və x ≠ 1. Cavab: 3.
  2. x² + 4x + 4 ≤ 0. Neçə həll? (x + 2)² ≤ 0 → yalnız x = −2. Bir həll.
  3. √(x² − 4x) ifadəsinin DMQ-suna neçə tam ədəd daxil deyil? x(x − 4) ≥ 0 → (−∞; 0] ∪ [4; +∞). Daxil olmayanlar: 1; 2; 3 — 3 ədəd.
