Çoxhədlilər

Çoxhədli — bir neçə birhədlinin cəmidir: 2x³ − 5x + 7. Onları standart şəklə salmağı, dərəcəsini tapmağı, toplamağı, çıxmağı, vurmağı və birhədliyə bölməyi öyrənəcəksən. Kvadrat tənliklər, vuruqlara ayırma, müxtəsər vurma düsturları — hamısı buradan başlayır.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Çoxhədli, standart şəkil, dərəcə

1 Niyə lazımdır

Qutunun həcmi, otağın sahəsi, dükanın gəliri tez-tez x² + 5x + 6 kimi yazılır. Belə ifadəni səliqəli (standart) yazmasan, iki fərqli görünüşlü ifadənin eyni olduğunu görməzsən, dərəcəsini də səhv deyərsən.

2 Əsas fikir

Çoxhədli — birhədlilərin cəmidir. Hər birhədli onun həddidir. Standart şəkil: hər hədd standart birhədlidir və oxşar hədlər yoxdur (birləşdirilib). Adətən hədləri dərəcənin azalma sırası ilə düzürük.

2x³ − 5x² + x − 7 x³-ün əmsalı 2, x²-nin −5, x-in 1 sərbəst hədd −7 dərəcə 3 (ən böyük üst)

Çoxhədlinin dərəcəsi — standart şəkildə hədlərin dərəcələrindən ən böyüyüdür. İki dəyişən olanda həddin dərəcəsi üstlərin cəmidir: x²y³ — 5-ci dərəcə.

3 Həll olunmuş nümunələr

1) 3x² − 5x + 2x³ − x² + 7 − 2x³ + x x³: 2x³ − 2x³ = 0 (yox olur!) x²: 3x² − x² = 2x² x: −5x + x = −4x Standart şəkil: 2x² − 4x + 7 Dərəcə: 2 (3 yox!) 2) 4x²y³ − 7xy + 2x⁴ dərəcələr: 2 + 3 = 5; 1 + 1 = 2; 4 Çoxhədlinin dərəcəsi: 5
Həyatdan. Fotoqraf x sm-lik kvadrat şəklin ətrafına hər tərəfdən 2 sm haşiyə qoyur. Çərçivəli şəklin sahəsi (x + 4)² = x² + 8x + 16 — 2-ci dərəcəli çoxhədli. Sərbəst hədd 16 — dörd künc kvadratının (2 × 2) cəmi.
Tipik səhvlər
  • Dərəcəni standart şəklə salmadan demək. x³ hədləri silinə bilər.
  • xy-nin dərəcəsini 1 saymaq. Üstlər toplanır: 1 + 1 = 2.
  • Sərbəst həddi işarəsiz yazmaq: x² − 7-də sərbəst hədd −7-dir.
Yadda saxla
Əvvəl oxşar hədləri birləşdir — sonra dərəcə. Dərəcə = ən böyük həddin dərəcəsi. Əmsal və sərbəst hədd işarəsi ilə götürülür.
Özünü yoxla: 3 sual
  1. 5 − 3x + x³ − x³ + 2x²-nin dərəcəsi? x³ silinir: 2x² − 3x + 5, dərəcə 2.
  2. 2x³ − 5 + x − 3-ün sərbəst həddi? −5 − 3 = −8.
  3. 3x²y⁴ − x⁵-in dərəcəsi? 2 + 4 = 6 və 5 → 6.

Dərs 2. Çoxhədlilərin toplanması və çıxılması

1 Niyə lazımdır

Mağazanın gəliri bir çoxhədli, xərci başqa bir çoxhədlidir. Mənfəət = gəlir − xərc. Bu, çoxhədlilərin çıxılmasıdır. Sadə görünür, amma imtahanda ən çox işarə səhvi məhz burada olur.

2 Qayda

P + Q: mötərizələri aç (işarələr qalır), oxşar hədləri birləşdir. P − Q: Q-nun HƏR həddinin işarəsini dəyiş, sonra oxşar hədləri birləşdir.

3 Həll olunmuş nümunələr

P = 3x² − 2x + 5, Q = x² + 4x − 1 1) P + Q = 3x² − 2x + 5 + x² + 4x − 1 = 4x² + 2x + 4 2) P − Q = 3x² − 2x + 5 − x² − 4x + 1 = 2x² − 6x + 6 3) (2a² − ab + b²) − (a² − 3ab − b²) = 2a² − ab + b² − a² + 3ab + b² = a² + 2ab + 2b²
Həyatdan. Ailənin aylıq gəliri 3x + 500, xərci x + 320 manatdır (x — əlavə iş saatlarından gələn pul). Qalan: (3x + 500) − (x + 320) = 2x + 180. x = 60 olanda — 300 manat.
Tipik səhvlər
  • Çıxanda yalnız birinci həddin işarəsini dəyişmək: −(x² + 4x − 1) = −x² − 4x + 1, bütün hədlər!
  • Toplamada üstləri toplamaq: 3x² + x² = 4x², 4x⁴ yox.
  • Olmayan həddi unutmaq: P-də x³ yoxdursa, onun əmsalı 0-dır, Q-dakı x³ nəticəyə olduğu kimi keçir.
Yadda saxla
Toplama: işarələr qalır. Çıxma: çıxılanın bütün işarələri dəyişir. Sonra — oxşar hədlər.
Özünü yoxla: 3 sual
  1. (x² + 3x) + (2x² − 5x + 1). 3x² − 2x + 1.
  2. (4x − 7) − (x² + 4x − 2). 4x − 7 − x² − 4x + 2 = −x² − 5.
  3. P = x³ − 1, Q = x³ + x. P − Q-nin x = 3 olanda qiyməti? P − Q = −x − 1; x = 3: −4.

Dərs 3. Çoxhədlilərin vurulması

1 Niyə lazımdır

Düzbucaqlının sahəsi = uzunluq × en. Tərəflər x + 3 və x + 2 olanda sahə — iki çoxhədlinin hasilidir. Şəkildə görəcəksən: böyük düzbucaqlı dörd kiçik hissəyə bölünür.

2 Qaydalar

Birhədli × çoxhədli: a(b + c − d) = ab + ac − ad Çoxhədli × çoxhədli: (a + b)(c + d) = ac + ad + bc + bd Hər hədd hər həddə vurulur.

2 hədli × 3 hədli = 6 hasil. Hasilləri sayaraq yoxla ki, heç biri unudulmasın. Sonra oxşar hədləri birləşdir.

(x + 3)(x + 2) = x² + 3x + 2x + 6 = x² + 5x + 6. Dörd hissə — dörd hasil.

3 Həll olunmuş nümunələr

1) −3x²(2x² − 5x + 4) = −6x⁴ + 15x³ − 12x² 2) (2x − 3)(x + 4) = 2x² + 8x − 3x − 12 = 2x² + 5x − 12 3) (x + 2)(x² − x + 3) = x³ − x² + 3x + 2x² − 2x + 6 = x³ + x² + x + 6
Həyatdan. Köynək 20 manata satılır, gündə 50 ədəd alınır. Hər 1 manat bahalaşma satışı 2 köynək azaldır. Qiyməti x manat artırsaq, gəlir: (20 + x)(50 − 2x) = 1000 + 10x − 2x². x = 5: 25·40 = 1000. x = 2: 22·46 = 1012 — bir az bahalaşma gəliri artırır.
Tipik səhvlər
  • Hasili unutmaq: (x + 2)(x + 3) = x² + 6. Ortadakı 3x + 2x itib.
  • İşarə: (−3)·(−5x) = +15x.
  • x·x = 2x yazmaq. Düzü: x².
Yadda saxla
Hər hədd × hər hədd (2 × 3 = 6 hasil). Əmsallar vurulur, üstlər toplanır. Sonra oxşar hədlər.
Özünü yoxla: 3 sual
  1. 2x(x² − 3x + 1). 2x³ − 6x² + 2x.
  2. (x − 5)(x + 2). x² + 2x − 5x − 10 = x² − 3x − 10.
  3. (3x + 1)(2x − 1)-də x-in əmsalı? −3x + 2x = −x, əmsal −1.

Dərs 4. Çoxhədlinin birhədliyə bölünməsi

1 Niyə lazımdır

Düzbucaqlı sahənin sahəsi 6x² + 9x m², eni 3x m-dir. Uzunluğu? Sahəni enə bölürük. Bölmə vurmanın tərsidir — və onu yoxlamaq da vurma ilə olur.

2 Qayda

(a + b − c) : m = a : m + b : m − c : m Hər hədd ayrıca bölünür: əmsallar bölünür, üstlər çıxılır: xᵐ : xⁿ = xᵐ⁻ⁿ

Yadda saxla: x² : x² = 1 (sıfır yox!), x : x = 1. Bölən sıfırdan fərqli olmalıdır: x ≠ 0.

3 Həll olunmuş nümunələr

1) (12x⁴ − 8x³ + 4x²) : 4x² (x ≠ 0) 12x⁴ : 4x² = 3x² −8x³ : 4x² = −2x 4x² : 4x² = 1 Cavab: 3x² − 2x + 1 Yoxla: 4x²·(3x² − 2x + 1) = 12x⁴ − 8x³ + 4x² ✓ 2) (15a³b² − 10a²b³) : (−5a²b) (a ≠ 0, b ≠ 0) 15a³b² : (−5a²b) = −3ab −10a²b³ : (−5a²b) = 2b² Cavab: −3ab + 2b² 3) Sahə 6x² + 9x, en 3x (x ≠ 0): uzunluq = (6x² + 9x) : 3x = 2x + 3
Həyatdan. Sinif 4x² + 8x manat yığdı, pul 4x şagird arasında bərabər bölünür. Hər birinə: (4x² + 8x) : 4x = x + 2 manat. x = 6 (24 şagird) — 192 manat, hərəyə 8 manat.
Tipik səhvlər
  • 4x² : 4x² = 0 yazmaq. Ədəd özünə bölünəndə 1 alınır.
  • Yalnız birinci həddi bölmək: (6x² + 9x) : 3x = 2x + 9x — səhv, 2x + 3.
  • Mənfi birhədliyə bölərkən işarəni unutmaq: −10 : (−5) = +2.
Yadda saxla
Hər hədd ayrıca bölünür. Əmsallar bölünür, üstlər çıxılır. Yoxlama: qisməti bölənə vur.
Özünü yoxla: 3 sual
  1. (10x³ − 5x²) : 5x². 2x − 1.
  2. (−6x⁴ + 9x²) : (−3x²). 2x² − 3.
  3. (8x⁵ + 4x³) : 4x³, sonra x = 2. 2x² + 1; x = 2: 9.
