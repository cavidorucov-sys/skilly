Funksional tənliklər

Adi tənlikdə naməlum ədəddir, funksional tənlikdə naməlum funksiyanın özüdür. Məsələn: "f(x + y) = f(x) + f(y) + 2xy, f(1) = 1. f(2026) neçədir?" Funksiyanı tapmaq üçün əsas alət çox sadədir: tənlikdə ağıllı qiymətlər qoymaq. Burada üç üsulu öyrənəcəksən: qiymət qoyma, Koşi tipli tənliklər, x → 1/x əvəzləməsi.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, olimpiada məsələlərini əvvəl özün həll etməyə çalış, sonra həllə bax. Sonra Oyun və Sınaq.

Dərs 1. Qiymət qoyma üsulu

1 Niyə lazımdır

Sənə funksiyanın düsturunu vermirlər. Yalnız bir qayda verirlər: "iki ədədi toplayanda funksiyanın qiymətləri belə bağlanır". Qaydadan funksiyanı bərpa etmək lazımdır — bu, detektiv işidir. İzləri tapmaq üçün qaydaya sadə ədədlər qoyursan: 0, 1, y = x.

Həyatdan. Mağazada qiymət cədvəli: 1 kq alma 3 manat. 2 kq-ın qiyməti 1 kq + 1 kq = 6 manat. Hər yeni kq əvvəlkinə 3 manat əlavə edir. Bu da "f(n + 1) = f(n) + 3" funksional tənliyidir.

2 Əsas fikir

x = 0 və ya y = 0 → f(0)-ı tap x = 1 və ya y = 1 → f(n + 1)-i f(n) ilə bağla (rekurrent) y = x → f(2x)-i f(x) ilə bağla y = −x → f(x) ilə f(−x)-i bağla x və y yerini dəyiş → simmetriya, yeni tənlik

Qaydanı belə tətbiq et: (1) bir neçə kiçik qiymət hesabla (f(1), f(2), f(3), …); (2) qanunu gör; (3) isbat et (adətən induksiya və ya teleskop cəmi); (4) tapılan funksiyanı tənliyə qoyub yoxla.

3 Həll olunmuş nümunə

Natural ədədlərdə f(x + y) = f(x) + f(y) + 2xy və f(1) = 1. f(n) = ? y = 1: f(x + 1) = f(x) + 1 + 2x. f(2) = 1 + 1 + 2 = 4, f(3) = 4 + 1 + 4 = 9, f(4) = 9 + 1 + 6 = 16. Qanun: f(n) = n². Yoxla: (x + y)² = x² + y² + 2xy ✓. f(2026) = 2026² = 4 104 676. f(1) = 2, f(2) = 5 və f(n + 2) = f(n + 1) − f(n). f(7) = ? f(3) = 5 − 2 = 3, f(4) = 3 − 5 = −2, f(5) = −2 − 3 = −5, f(6) = −5 + 2 = −3, f(7) = −3 + 5 = 2 = f(1). Period 6-dır.

4 Olimpiada məsələsi

Məsələ 1. Natural m, n üçün f(m + n) = f(m) + f(n) + mn və f(1) = 1. f(2026) = ? Həll. n = 1 qoyaq: f(m + 1) = f(m) + f(1) + m = f(m) + m + 1. f(2) = f(1) + 2, f(3) = f(2) + 3, …, f(n) = f(n − 1) + n. Hamısını toplasaq (teleskop): f(n) = 1 + 2 + 3 + … + n = n(n + 1)/2. Yoxlama: (m+n)(m+n+1)/2 = m(m+1)/2 + n(n+1)/2 + mn ✓. f(2026) = 2026 · 2027 / 2 = 1013 · 2027 = 2 053 351. ∎ Fikir: bir dəyişəni 1 seç, rekurrent al, cəmlə.
Tipik səhvlər
  • Qanunu 2–3 qiymətdən "görüb" isbat etmədən qəbul etmək. Qanun induksiya və ya teleskoplamaqla əsaslandırılmalıdır.
  • Tapılan funksiyanı tənliyə qoyub yoxlamamaq.
  • f(0) təyin olunmayan yerdə (məsələn, yalnız natural ədədlərdə) x = 0 qoymaq.
  • Teleskop cəmində hədlərin sayını səhv saymaq: n − 1 addım var, n yox.
Yadda saxla
y = 1 → rekurrent: f(n + 1) = f(n) + … Kiçik qiymətlər → qanun → isbat → yoxlama. Teleskop: f(n) = f(1) + [f(2) − f(1)] + … + [f(n) − f(n−1)]. Dövrü rekurrentdə dövrü tap (f(n+2) = f(n+1) − f(n): period 6).
Özünü yoxla: 3 sual
  1. Natural x, y üçün f(x + y) = f(x) + f(y) + 2xy, f(1) = 3. f(2) = ? x = y = 1: f(2) = 3 + 3 + 2 = 8.
  2. f(1) = 1, f(n + 1) = f(n) + n. f(5) = ? 1, 2, 4, 7, 11 → f(5) = 11.
  3. f(1) = 2, f(2) = 5, f(n + 2) = f(n + 1) − f(n). f(13) = ? Period 6; 13 = 6·2 + 1 → f(13) = f(1) = 2.

Dərs 2. Koşi tipli tənliklər

1 Niyə lazımdır

Ən məşhur funksional tənlik: f(x + y) = f(x) + f(y) ("cəmin qiyməti qiymətlərin cəmidir"). Düz mütənasib asılılıq belədir: 3 litr 6 manatdırsa, 5 litr = 3 litr + 2 litr. Bu tənliyin natural, tam və rasional ədədlərdə həlli yalnız f(x) = cx-dir.

Həyatdan. Su sayğacı: 9 litrın qiyməti 21 qəpikdir. 1098 litr = 122 dəfə 9 litr, deməli 122 · 21 = 2562 qəpik. Qiymət həcmə mütənasibdir — Koşi tənliyinin cavabı.

2 Əsas fikir

f(x + y) = f(x) + f(y) ⇒ f(x) = c·x, c = f(1) (ℕ, ℤ, ℚ üzərində) f(xy) = f(x) + f(y) ⇒ hasil cəmə çevrilir (loqarifm kimi), f(1) = 0 f(xy) = f(x)·f(y) ⇒ f sadə ədədlərdəki qiymətlərdən qurulur

Niyə f(x) = cx? (1) x = y = 0 → f(0) = 0. (2) f(n) = n·f(1) — induksiya, n dəfə toplayırıq. (3) y = −x → f(−x) = −f(x), mənfi tam ədədlər də olur. (4) f(1) = q·f(1/q) → f(1/q) = f(1)/q, sonra f(p/q) = (p/q)·f(1).

Diqqət: həqiqi ədədlər üzərində əlavə şərt (artan, kəsilməz, məhdud) lazımdır, əks halda qəribə həllər olur. Məsələdə hansı çoxluq verilib, ona bax.

3 Həll olunmuş nümunə

Natural ədədlərdə f(xy) = f(x)·f(y), f(2) = 3, f(3) = 5. f(72) = ? 72 = 8 · 9 = 2³ · 3² f(72) = f(2)³ · f(3)² = 27 · 25 = 675. Müsbət ədədlərdə f(xy) = f(x) + f(y), f(2) = 1, f(3) = 2. f(12) = ? 12 = 2 · 2 · 3 → f(12) = 1 + 1 + 2 = 4. Həmçinin f(1) = 0 (x = y = 1), f(1/x) = −f(x).

4 Olimpiada məsələsi

Məsələ 2. f: ℚ → ℚ funksiyası bütün rasional x, y üçün f(x + y) = f(x) + f(y) şərtini ödəyir və f(6) = 15. f(2026) = ? Həll. Koşi tənliyi: f(x) = c·x. f(6) = 6c = 15 → c = 5/2. f(2026) = (5/2) · 2026 = 5 · 1013 = 5065. Başqa yol: 2026 = 6 · (2026/6), yəni f(2026) = (2026/6) · f(6) = (1013/3) · 15 = 5065. ∎ Fikir: f(x) = cx; sabiti bir verilmiş qiymətdən tap.
Tipik səhvlər
  • Tənlikləri qarışdırmaq. f(2) = 1 olanda f(xy) = f(x) + f(y) üçün f(8) = 3, f(x + y) = f(x) + f(y) üçün isə f(8) = 4.
  • Natural ədədlərdə f(x + y) = f(x) + f(y) görüb f(0) = 0, f(−1) kimi qiymətlər istifadə etmək (təyin oblastı natural ədədlərdirsə, olmaz).
  • f(xy) = f(x)f(y) üçün hər ədədin ayrıca qiymətini tələb etmək. Əslində yalnız sadə ədədlərin qiymətləri kifayətdir.
Yadda saxla
f(x + y) = f(x) + f(y) ⇒ f(x) = cx (ℕ, ℤ, ℚ), c = f(1). f(xy) = f(x) + f(y) ⇒ f(1) = 0, f(1/x) = −f(x); ədədi sadə vuruqlara ayır. f(xy) = f(x)f(y) ⇒ ədədi sadə vuruqlara ayır, qüvvətləri hesabla.
Özünü yoxla: 3 sual
  1. f: ℚ → ℚ, f(x + y) = f(x) + f(y), f(1) = 4. f(3/2) = ? f(x) = 4x → f(3/2) = 6.
  2. f(xy) = f(x) + f(y), f(2) = 1, f(3) = 2. f(12) = ? 12 = 2·2·3 → 1 + 1 + 2 = 4.
  3. f(xy) = f(x)·f(y), f(2) = 3. f(16) = ? 16 = 2⁴ → 3⁴ = 81.

Dərs 3. f(x) və f(1/x) sistemləri; dəyişən dəyişmə

1 Niyə lazımdır

Bəzən tənlikdə həm f(x), həm də f(1/x) görünür, məsələn f(x) + 2f(1/x) = x. İki naməlum, bir tənlik kimi görünür. Çıxış yolu: tənlikdə x yerinə 1/x qoy — ikinci tənlik alırsan və iki naməlumlu adi sistem həll edirsən.

Həyatdan. Maşın ayrı-ayrılıqda "A→B" və "B→A" üçün qiymət tapmaq: iki sadə tənlik var, iki naməlum var — sistemdir. Burada naməlumlar f(x) və f(1/x)-dir.

2 Əsas fikir

f(x) + k·f(1/x) = g(x) x → 1/x: f(1/x) + k·f(x) = g(1/x) (birinci) − k·(ikinci): (1 − k²)·f(x) = g(x) − k·g(1/x) (x ≠ 0, k ≠ ±1) Eyni fikir: f(x) və f(1 − x); f(x) və f(−x); üç üzvlü dövr x → 1/(1 − x) → (x − 1)/x

Dəyişən dəyişmə: f(2x + 1) = … verilibsə, u = 2x + 1 götür, x = (u − 1)/2 yaz — f-in öz arqumenti ilə düsturu alırsan. f(x − 1/x) = x² + 1/x² üçün kvadratla: (x − 1/x)² = x² + 1/x² − 2, deməli f(u) = u² + 2.

3 Həll olunmuş nümunə

f(2x + 1) = x + 4. f(7) = ? 2x + 1 = 7 → x = 3. f(7) = 3 + 4 = 7. (Ümumi: f(u) = (u − 1)/2 + 4.) f(x − 1/x) = x² + 1/x². f(3) = ? (x − 1/x)² = x² − 2 + 1/x² → x² + 1/x² = (x − 1/x)² + 2. f(u) = u² + 2, f(3) = 11. f(x) + f(1/(1 − x)) = x, f(2) = ? (üç üzvlü dövr) x₁ = 2, x₂ = 1/(1 − 2) = −1, x₃ = 1/(1 + 1) = 1/2, 1/(1 − 1/2) = 2. f(2) + f(−1) = 2; f(−1) + f(1/2) = −1; f(1/2) + f(2) = 1/2. 1-ci − 2-ci + 3-cü: 2f(2) = 2 + 1 + 1/2 = 7/2 → f(2) = 7/4.

4 Olimpiada məsələsi

Məsələ 3. Hər x ≠ 0 üçün f(x) + 2f(1/x) = x. f(x)-i tap, f(2) = ? Həll. Birinci tənlik: f(x) + 2f(1/x) = x. x yerinə 1/x: f(1/x) + 2f(x) = 1/x. İkinciyə 2 vurub birincidən çıxaq: (f(x) + 2f(1/x)) − (4f(x) + 2f(1/x)) = x − 2/x −3f(x) = x − 2/x → f(x) = (2/x − x)/3 = (2 − x²)/(3x). Yoxlama: f(2) = (2 − 4)/6 = −1/3, f(1/2) = (2 − 1/4)/(3/2) = (7/4)·(2/3) = 7/6. f(2) + 2f(1/2) = −1/3 + 7/3 = 2 ✓. Cavab: f(2) = −1/3. ∎ Fikir: x ↔ 1/x əvəzləməsi iki naməlumlu sistem verir.
Tipik səhvlər
  • İkinci tənlikdə sağ tərəfi dəyişməmək: x → 1/x hər yerdə edilir, sağ tərəf də 1/x olur.
  • f(x)-in əmsalını 1 − k götürmək, düzü 1 − k²-dir.
  • Tapılan f-i tənliyə qoyub yoxlamamaq — hesab səhvi çox olur.
  • Dəyişən dəyişmədə x-i u ilə qarışdırmaq: son cavab u (arqument) ilə yazılır.
Yadda saxla
x → 1/x (və ya 1 − x, −x): ikinci tənlik, sonra f(x)-i yox et. f(x) + k f(1/x) = g(x) ⇒ f(x) = [g(x) − k·g(1/x)] / (1 − k²) (x ≠ 0, k ≠ ±1). f(ax + b) = … ⇒ u = ax + b götür (a ≠ 0). Həmişə tapılan funksiyanı tənliyə qoyub yoxla.
Özünü yoxla: 3 sual
  1. f(x) + 2f(1/x) = 3x. f(1) = ? x = 1: 3f(1) = 3 → f(1) = 1.
  2. f(2x + 1) = x + 4. f(7) = ? 2x + 1 = 7 → x = 3; f(7) = 7.
  3. f(x − 1/x) = x² + 1/x². f(3) = ? f(u) = u² + 2 → f(3) = 11.
