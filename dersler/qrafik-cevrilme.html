Riyaziyyat · Buraxılış · DİM: Funksiyalar və qrafiklər

Qrafiklərin çevrilməsi

Yeni qrafiki sıfırdan çəkmək lazım deyil: y = (x − 2)² − 3 — sadəcə sürüşdürülmüş y = x²-dir. Burada qrafiki yuxarı-aşağı, sola-sağa sürüşdürməyi, oxlara görə əks etdirməyi və parabolanın yeni təpəsini tapmağı öyrənəcəksən.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Boss. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Yuxarı və aşağı sürüşmə: y = f(x) + a

1 Niyə lazımdır

Bütün mallar 2 manat bahalaşdı: qiymət qrafiki eyni formada qalır, sadəcə 2 vahid yuxarı qalxır. Riyaziyyatda bu, f(x) + 2-dir.

2 Qayda

y = f(x) + a: a > 0 — a vahid YUXARI a < 0 — |a| vahid AŞAĞI Nöqtə (x; y) → (x; y + a)

Qırıq xətt — y = x². Mavi — x² + 2, təpə (0; 2). Narıncı — x² − 3, təpə (0; −3).

Forma dəyişmir, x-lər dəyişmir — yalnız hər y-ə a əlavə olunur.

3 Həll olunmuş nümunələr

Nümunə 1. f(1) = 4. g(x) = f(x) − 6. g(1) = ? g(1) = f(1) − 6 = 4 − 6 = −2 Nümunə 2. f funksiyasının qiymətlər çoxluğu [−2; 5]. g(x) = f(x) + 3 üçün? Hər qiymət 3 artır: E(g) = [1; 8] Nümunə 3. y = |x| qrafikini 4 vahid aşağı sürüşdür. y = |x| − 4. Təpə (0; −4). Ox ilə kəsişmə: |x| = 4 → x = ±4

Təyin oblastı dəyişmir: qrafik sola-sağa getmir.

Həyatdan. Taksi tarifi: y = 0,5x manat (x — km). Minik haqqı 2 manat əlavə olunanda: y = 0,5x + 2. Qrafik 2 vahid yuxarı qalxdı: 10 km əvvəl 5 manat idi, indi 7 manat.
Tipik səhvlər
  • f(x) − 3-ü "3 vahid sola" sanmaq. Mötərizədən kənardakı ədəd yalnız yuxarı-aşağı aparır.
  • Ən böyük/ən kiçik qiyməti dəyişməmiş saxlamaq. f(x) + a-da hər ikisi a qədər dəyişir.
Yadda saxla
f(x) + a: (x; y) → (x; y + a). a > 0 yuxarı, a < 0 aşağı. D eyni qalır, E-nin ucları a qədər sürüşür.
Özünü yoxla: 3 sual
  1. y = x² − 5 parabolasının təpəsi? y = x²-in təpəsi (0; 0), 5 vahid aşağı: (0; −5).
  2. f(−2) = 3, g(x) = f(x) + 4. g(−2) = ? 3 + 4 = 7.
  3. f-in ən kiçik qiyməti −1. f(x) − 2-nin ən kiçik qiyməti? −1 − 2 = −3.

Dərs 2. Sola və sağa sürüşmə: y = f(x + a)

1 Niyə lazımdır

Avtobus cədvəli 3 saat gecikdi: dünən saat 7-də olan hadisə bu gün saat 10-da olur. Qrafik sağa getdi, düsturda isə t − 3 yazılır. Bu "tərs işarə" imtahanın sevimli tələsidir.

2 Qayda

y = f(x − a), a > 0 → a vahid SAĞA y = f(x + a), a > 0 → a vahid SOLA Nöqtə (x; y) → (x + a; y) (f(x − a) üçün)

Niyə tərsinə? y = (x − 3)² sıfır qiymətini x = 3-də alır: əvvəl x = 0-da baş verən hadisə indi 3 vahid gec, yəni sağda baş verir.

Qırıq — y = x². Mavi — (x − 3)², təpə (3; 0): sağa. Narıncı — (x + 2)², təpə (−2; 0): sola.

3 İki sürüşmə birlikdə: y = f(x − m) + n

y = f(x − m) + n: m sağa (m < 0 — sola), n yuxarı Xüsusi nöqtə (0; 0) → (m; n)

y = |x + 2| − 1: |x|-in təpəsi 2 sola, 1 aşağı → (−2; −1).

y = √(x − 1) + 1: başlanğıc 1 sağa, 1 yuxarı → (1; 1). D(f) = [1; +∞).

Hiperbola: y = 6/(x − 2) + 3 y = 6/x sürüşür: 2 sağa, 3 yuxarı Qolların yaxınlaşdığı xətlər (asimptotlar): x = 2 və y = 3

4 Qrafikdən qiymət oxumaq

Nümunə. f(1) = 5, f(3) = −2. g(x) = f(x + 2). g(1) = ? g(1) = f(1 + 2) = f(3) = −2 Nümunə. D(f) = [−4; 2]. g(x) = f(x − 3). D(g) = ? Qrafik 3 sağa: D(g) = [−1; 5] (yoxla: x = −1 → x − 3 = −4 ✓)

Qayda: g(x₀) = f(x₀ + a) — əvvəl mötərizəni hesabla, sonra f-in qrafikindən oxu.

Həyatdan. Dünənki temperatur qrafiki T = f(t). Bu gün isti hava 2 saat gec gəldi: g(t) = f(t − 2). Dünən saat 12-də 8° idisə, bu gün 8° saat 14-də olacaq: g(14) = f(12) = 8.
Tipik səhvlər
  • f(x − 3)-ü "3 sola" sanmaq. Mötərizənin içində mənfi — sağa.
  • g(1) = f(x + 2)-də 2-ni sonda f-ə əlavə etmək: f(1) + 2. Düzü: f(1 + 2).
  • (x + 2)² − 1 təpəsini (2; −1) yazmaq. Düzü: (−2; −1).
Yadda saxla
f(x − a): sağa a. f(x + a): sola a. (Mötərizədə işarə tərsinə!) y = f(x − m) + n: (0; 0) → (m; n). g(x₀) = f(x₀ + a) — əvvəl arqumenti hesabla.
Özünü yoxla: 3 sual
  1. y = |x − 4| + 2 qrafikinin təpəsi? (4; 2): 4 sağa, 2 yuxarı.
  2. y = √(x + 5) funksiyasının təyin oblastı? x + 5 ≥ 0 → [−5; +∞). Qrafik 5 sola sürüşüb.
  3. f(0) = 7. g(x) = f(x − 3). Hansı x-də g(x) = 7 mütləq olur? x − 3 = 0 → x = 3: g(3) = f(0) = 7.

Dərs 3. Əks etmələr: −f(x), f(−x), |f(x)|

1 Niyə lazımdır

Gölün səthində ağacın əksi — eyni ağacdır, sadəcə "baş aşağı". Qrafiklər də belə əks olunur: Ox-da, Oy-da və ya yalnız aşağı hissə yuxarı qatlanır.

2 −f(x) və f(−x)

y = −f(x): Ox oxuna görə əks (x; y) → (x; −y) y = f(−x): Oy oxuna görə əks (x; y) → (−x; y)

Mavi — y = √x. Narıncı — −√x: Ox-a görə əks, aşağı düşdü. Yaşıl — √(−x): Oy-a görə əks, sola keçdi, D = (−∞; 0].

f(2) = 5: g(x) = −f(x) → g(2) = −5 g(x) = f(−x) → g(−2) = f(2) = 5 y = x² üçün f(−x) = (−x)² = x² — qrafik dəyişmir (Oy-a görə simmetrikdir). y = −x² — budaqları aşağı, təpə (0; 0).

3 |f(x)|

y = |f(x)|: Ox-dan yuxarı hissə qalır, Ox-dan aşağı hissə yuxarı qatlanır

x² − 4 qrafikinin (−2; 2) aralığındakı hissəsi Ox-dan aşağıdadır. Modulda o yuxarı qatlanır: təpə (0; −4) → (0; 4).

|f(x)| heç vaxt mənfi olmur.

Nümunə 1. f(3) = −4. g(x) = |f(x)|. g(3) = |−4| = 4 Nümunə 2. E(f) = [−6; 2]. g(x) = |f(x)|-in ən böyük qiyməti? Modullar: |−6| = 6, |2| = 2 → 6. E(g) = [0; 6] (0 daxildir, çünki f −6-dan 2-yə gedərkən 0-dan keçir) Nümunə 3. E(f) = [−6; 2]. g(x) = −f(x)-in ən böyük qiyməti? Ən aşağı nöqtə ən yuxarı olur: −(−6) = 6. E(g) = [−2; 6]
Həyatdan. Lift binanın 0-cı səviyyəsindən h(t) metr hündürlükdədir (zirzəmidə mənfi). Liftin yerdən məsafəsi — |h(t)|: zirzəmidə 6 m aşağı olmaq da 6 m məsafədir.
Tipik səhvlər
  • −f(x) ilə f(−x)-i qarışdırmaq. Mənfi çöldə — y dəyişir (Ox-a görə), içəridə — x dəyişir (Oy-a görə).
  • |f(x)|-də bütün qrafiki əks etdirmək. Yalnız Ox-dan aşağı hissə qatlanır.
  • f(−x)-də g(2) = f(2) yazmaq. Düzü: g(2) = f(−2).
Yadda saxla
−f(x): (x; y) → (x; −y), Ox-a görə. f(−x): (x; y) → (−x; y), Oy-a görə. |f(x)|: aşağı hissə yuxarı qatlanır, qiymətlər ≥ 0.
Özünü yoxla: 3 sual
  1. f(−1) = 3. g(x) = f(−x). g(1) = ? g(1) = f(−1) = 3.
  2. y = −|x| + 2-nin ən böyük qiyməti? −|x| ≤ 0, ona görə y ≤ 2: ən böyük qiymət 2 (x = 0-da).
  3. y = |x − 3| ilə y = |x| − 3 eynidirmi? Yox. Birincisi |x|-i 3 sağa, ikincisi 3 aşağı sürüşdürür. Təpələr (3; 0) və (0; −3).

Dərs 4. Parabolanın təpəsi və sürüşdürülməsi

1 Niyə lazımdır

Topun ən yüksək nöqtəsi, körpü tağının zirvəsi, mənfəətin maksimumu — hamısı parabolanın təpəsidir. DİM-də "sürüşdürülmüş parabolanın təpəsinin koordinatları" demək olar ki, hər il olur.

2 Təpə şəkli

y = a(x − m)² + n → təpə (m; n) a > 0 — budaqlar yuxarı, n — ən kiçik qiymət a < 0 — budaqlar aşağı, n — ən böyük qiymət

y = (x − 2)² − 3 — y = x²-in 2 sağa, 3 aşağı sürüşməsi. Təpə (2; −3).

Oy ilə kəsişmə: x = 0 → y = 4 − 3 = 1, nöqtə (0; 1).

3 y = x² + bx + c-dən təpəyə

Tam kvadrat ayır: x² + bx + c = (x + b/2)² + c − b²/4 Və ya düsturla: m = −b/(2a), n = y(m)
Nümunə 1. y = x² − 6x + 5 x² − 6x = (x − 3)² − 9 → y = (x − 3)² − 4. Təpə (3; −4) Yoxla düsturla: m = 6/2 = 3, y(3) = 9 − 18 + 5 = −4 ✓ Nümunə 2. y = x² + 4x + 1 parabolasını 5 vahid sağa və 2 vahid yuxarı sürüşdür. y = (x + 2)² − 3, təpə (−2; −3) 5 sağa: −2 + 5 = 3. 2 yuxarı: −3 + 2 = −1. Yeni təpə (3; −1) Yeni parabola: y = (x − 3)² − 1 Nümunə 3. y = −2(x + 1)² + 7. Təpə? Ən böyük qiymət? Təpə (−1; 7). a = −2 < 0 — budaqlar aşağı, ən böyük qiymət 7

4 Sürüşmüş parabolanın qiyməti

y = x² parabolasını 3 sola və 4 aşağı sürüşdürdük: y = (x + 3)² − 4 x = 1 olduqda: (1 + 3)² − 4 = 16 − 4 = 12 Oy ilə kəsişmə (x = 0): 9 − 4 = 5 Ox ilə kəsişmə: (x + 3)² = 4 → x + 3 = ±2 → x = −1, x = −5
Həyatdan. Top h = −5t² + 20t qanunu ilə uçur (t — saniyə, h — metr). Tam kvadrat: h = −5(t² − 4t) = −5(t − 2)² + 20. Təpə (2; 20): top 2 saniyədən sonra 20 m hündürlükdə olur — bu, ən yüksək nöqtədir.
Tipik səhvlər
  • (x + 3)²-dən təpənin absisini 3 götürmək. Düzü −3.
  • Tam kvadrat ayırarkən çıxılan ədədi unutmaq: x² − 6x + 5 ≠ (x − 3)² + 5, çünki (x − 3)² = x² − 6x + 9.
  • "Aşağı sürüşdür" deyəndə absisi dəyişmək. Yuxarı-aşağı — yalnız ordinat, sola-sağa — yalnız absis.
Yadda saxla
y = a(x − m)² + n: təpə (m; n). x² + bx + c: m = −b/2, n = y(m). p sağa: m + p; p sola: m − p; q yuxarı: n + q; q aşağı: n − q.
Özünü yoxla: 3 sual
  1. y = x² + 8x + 10 parabolasının təpəsi? m = −4, y(−4) = 16 − 32 + 10 = −6: (−4; −6).
  2. y = (x − 1)² + 2-ni 4 sola, 5 aşağı sürüşdür. Yeni təpə? (1 − 4; 2 − 5) = (−3; −3).
  3. y = (x − 4)² − 7 Oy oxunu hansı nöqtədə kəsir? x = 0: 16 − 7 = 9 → (0; 9).
