Vuruqlara ayırma

Çoxhədlini hasil şəklində yazmaq: x² − 9 = (x − 3)(x + 3). Bu bacarıq hər yerdə lazımdır — kəsrləri ixtisar edəndə, tənlik həll edəndə, böyük ədədləri kalkulyatorsuz hesablayanda. Dörd üsul öyrənəcəksən: ortaq vuruq, qruplaşdırma, düsturlar və kvadrat üçhədli.

Necə keçmək: əvvəl Giriş testi. Hamısı düz olsa — birbaşa Sınaq. Yoxsa dərsləri sıra ilə oxu, nümunələri kağızda özün təkrarla, sonra Oyun və Sınaq.

Dərs 1. Ortaq vuruğun mötərizə xaricinə çıxarılması və qruplaşdırma

1 Niyə lazımdır

Hesabla: 37·64 + 37·36. İki böyük vurma, sonra toplama? Yox — 37 hər iki həddə var: 37·(64 + 36) = 37·100 = 3700. Bir saniyəlik iş.

Hərflərlə də eynidir. Cəmi hasilə çevirmək — vuruqlara ayırmaq deməkdir. Hasil ilə işləmək asandır: ixtisar etmək, sıfıra bərabər etmək olur.

2 Ortaq vuruq

Paylama qanununu tərsinə oxuyuruq. Bütün hədlərdə olan vuruğu mötərizə xaricinə çıxarırıq:

ab + ac = a(b + c)

Ən böyük ortaq vuruq: əmsalların ƏBOB-u və hər dəyişənin ən kiçik qüvvəti.

1) 12x³ − 18x² ƏBOB(12; 18) = 6, x-in ən kiçik qüvvəti x² 12x³ − 18x² = 6x²(2x − 3) Yoxla: 6x²·2x = 12x³, 6x²·3 = 18x² ✓ 2) 15a²b + 10ab² = 5ab(3a + 2b) 3) 5x + 5 = 5(x + 1) ← mötərizədə 1 qalır, boş yox

3 Qruplaşdırma

Bütün hədlərdə ortaq vuruq yoxdursa, hədləri cüt-cüt qruplaşdır. Hər cütdən ortaq vuruq çıxar — eyni mötərizə alınmalıdır. Sonra onu da çıxar.

ax + ay + bx + by = a(x + y) + b(x + y) = (x + y)(a + b)
4) xy + 3x − 2y − 6 = x(y + 3) − 2(y + 3) ← −2y − 6 = −2(y + 3) = (y + 3)(x − 2) Yoxla: (y + 3)(x − 2) = xy − 2y + 3x − 6 ✓ 5) x³ + 2x² + 5x + 10 = x²(x + 2) + 5(x + 2) = (x + 2)(x² + 5)
Həyatdan. Ailə kinoya 4 bilet (hərəsi 7,5 manat) və 4 popkorn (hərəsi 2,5 manat) aldı. Kassir belə hesablayır: 4·7,5 + 4·2,5 = 4·(7,5 + 2,5) = 4·10 = 40 manat. Bu, ortaq vuruğu mötərizə xaricinə çıxarmaqdır.
Tipik səhvlər
  • Mənfi çıxaranda işarəni dəyişməmək: −2y − 6 = −2(y + 3), −2(y − 3) yox.
  • Mötərizədə 1-i unutmaq: 5x + 5 = 5(x + 1), 5x yox.
  • Ən böyük vuruğu çıxarmamaq: 12x³ − 18x² = 2x(6x² − 9x) — mötərizədə hələ ortaq vuruq (3x) qalır.
Yadda saxla
ab + ac = a(b + c) Ortaq vuruq = ƏBOB(əmsallar) · dəyişənin ən kiçik qüvvəti Qruplaşdırma: cüt-cüt → eyni mötərizə → onu çıxar Həmişə açıb yoxla.
Özünü yoxla: 3 sual
  1. 8x² + 12x ifadəsini vuruqlara ayır. 4x(2x + 3).
  2. ab − 3a + 2b − 6 ifadəsini vuruqlara ayır. a(b − 3) + 2(b − 3) = (b − 3)(a + 2).
  3. Hesabla: 43·17 + 57·17. 17·(43 + 57) = 17·100 = 1700.

Dərs 2. Müxtəsər vurma düsturlarının tətbiqi

1 Niyə lazımdır

Hesabla: 53² − 47². Kvadratları hesablayıb çıxmaq uzun işdir. Düsturla: (53 − 47)(53 + 47) = 6·100 = 600. Müxtəsər vurma düsturlarını sağdan sola oxusan, onlar vuruqlara ayırma alətinə çevrilir.

2 Düsturlar

a² − b² = (a − b)(a + b) a² + 2ab + b² = (a + b)² a² − 2ab + b² = (a − b)² a³ − b³ = (a − b)(a² + ab + b²) a³ + b³ = (a + b)(a² − ab + b²)

Böyük kvadratdan kiçik kvadrat kəsilib. Qalan fiquru iki düzbucaqlıya bölüb yan-yana qoysan, tərəfləri a − b və a + b olan düzbucaqlı alınır.

3 Həll olunmuş nümunələr

1) 9x² − 25 = (3x)² − 5² = (3x − 5)(3x + 5) 2) 4x² − 12x + 9 4x² = (2x)², 9 = 3², orta hədd: 2·2x·3 = 12x ✓ = (2x − 3)² 3) x³ − 8 = x³ − 2³ = (x − 2)(x² + 2x + 4) 4) 2x³ − 50x = 2x(x² − 25) = 2x(x − 5)(x + 5) ← əvvəl ortaq vuruq, sonra düstur 5) 53² − 47² = (53 − 47)(53 + 47) = 6·100 = 600
Həyatdan. Kvadrat meydançanın tərəfi 65 m-dir. Ortasında tərəfi 35 m olan kvadrat çəmənlik var. Qalan hissənin sahəsi: 65² − 35² = (65 − 35)(65 + 35) = 30·100 = 3000 m².
Tipik səhvlər
  • (a − b)² = a² − b² yazmaq. Düzü: a² − 2ab + b².
  • x² + 9 ifadəsini (x − 3)(x + 3) kimi ayırmaq. Kvadratların cəmi bu düsturla ayrılmır.
  • Tam kvadratı yoxlamamaq: x² + 6x + 4 tam kvadrat deyil, çünki 4 = 2², amma 2·x·2 = 4x ≠ 6x.
  • a³ − b³-də ikinci mötərizənin işarəsi: a² + ab + b² (hamısı +).
Yadda saxla
a² − b² = (a − b)(a + b) a² ± 2ab + b² = (a ± b)² a³ ∓ b³ = (a ∓ b)(a² ± ab + b²) Əvvəl ortaq vuruğu çıxar, sonra düsturu axtar.
Özünü yoxla: 3 sual
  1. x² − 64 ifadəsini vuruqlara ayır. (x − 8)(x + 8).
  2. x² + 10x + 25 ifadəsini vuruqlara ayır. (x + 5)², çünki 2·x·5 = 10x.
  3. Hesabla: 101² − 99². (101 − 99)(101 + 99) = 2·200 = 400.

Dərs 3. Kvadrat üçhədlinin vuruqlara ayrılması

1 Niyə lazımdır

x² − 7x + 12 nə ortaq vuruqla, nə də düsturla ayrılır. Amma imtahanda belə üçhədlilər çox olur: kəsri ixtisar etmək üçün onları hasil kimi yazmaq lazımdır. Açar — kvadrat tənliyin kökləri.

2 Əsas fikir

Əgər x₁ və x₂ — ax² + bx + c = 0 tənliyinin kökləridirsə:

ax² + bx + c = a(x − x₁)(x − x₂) (a ≠ 0, D ≥ 0)
D > 0 — iki vuruq: a(x − x₁)(x − x₂) D = 0 — kvadratın a əmsalına hasili: a(x − x₁)² D < 0 — həqiqi əmsallı xətti vuruqlara ayrılmır

Kök 3-dürsə, uyğun vuruq (x − 3), kök −2-dirsə, uyğun vuruq (x + 2). İşarə tərsinə dönür.

3 Həll olunmuş nümunələr

1) x² − 7x + 12 Viyet: x₁ + x₂ = 7, x₁·x₂ = 12 → x₁ = 3, x₂ = 4 x² − 7x + 12 = (x − 3)(x − 4)
2) 2x² + 5x − 3 D = 25 + 24 = 49, x = (−5 ± 7)/4 → x₁ = 1/2, x₂ = −3 2x² + 5x − 3 = 2(x − 1/2)(x + 3) = (2x − 1)(x + 3) Yoxla: (2x − 1)(x + 3) = 2x² + 6x − x − 3 ✓
3) 3x² − 12x + 12 = 3(x² − 4x + 4) = 3(x − 2)² (D = 0) 4) x² + x + 5: D = 1 − 20 < 0 → vuruqlara ayrılmır

4 Tətbiq: kəsrin ixtisarı

(x² − 7x + 12)/(x − 3) = (x − 3)(x − 4)/(x − 3) = x − 4 (x ≠ 3)
Həyatdan. Düzbucaqlı otağın sahəsi x² + 7x + 12 m²-dir. Tərəflər? x² + 7x + 12 = (x + 3)(x + 4), yəni tərəflər x + 3 və x + 4 metrdir. x = 5 olsa — 8 m və 9 m, sahə 72 m². Yoxla: 25 + 35 + 12 = 72 ✓
Tipik səhvlər
  • a-nı unutmaq: 2x² + 5x − 3 = (x − 1/2)(x + 3) yanlışdır — açsan, x² alınır, 2x² yox.
  • İşarəni səhv qoymaq: kök 3 → vuruq (x − 3), (x + 3) yox.
  • D < 0 olanda vuruq "uydurmaq". Belə üçhədli vuruqlara ayrılmır.
Yadda saxla
ax² + bx + c = a(x − x₁)(x − x₂) Kökləri tap (Viyet və ya D) → a-nı unutma → aç və yoxla.
Özünü yoxla: 3 sual
  1. x² − x − 6 ifadəsini vuruqlara ayır. Köklər 3 və −2: (x − 3)(x + 2).
  2. 2x² − 7x + 3 ifadəsini vuruqlara ayır. D = 49 − 24 = 25, x = (7 ± 5)/4 → 3 və 1/2. 2(x − 3)(x − 1/2) = (x − 3)(2x − 1).
  3. x² + 2x + 7 vuruqlara ayrılırmı? Yox: D = 4 − 28 = −24 < 0.

Dərs 4. Kvadrat üçhədlidən tam kvadratın ayrılması

1 Niyə lazımdır

Şəkildəki iki qutu blokunun hündürlüyü eynidir — hər birində 2 sıra. Bu ortaq vuruqdur: 2·3 + 2·2 = 2·(3 + 2).

"İfadənin ən kiçik qiymətini tap" — imtahanda tez-tez çıxan sualdır. x² − 6x + 14 üçün bütün x-ləri yoxlamaq olmaz. Amma ifadəni (x − 3)² + 5 kimi yazsan, cavab görünür: kvadrat ən azı 0-dır, deməli ifadə ən azı 5-dir.

2 Əsas fikir

x-in əmsalının yarısını götür, onun kvadratını əlavə et və dərhal çıx:

x² + 2px + q = (x² + 2px + p²) − p² + q = (x + p)² + (q − p²)
(x + p)² ≥ 0 → ən kiçik qiymət q − p², x = −p olduqda

3 Həll olunmuş nümunələr

1) x² − 6x + 14 x-in əmsalı −6, yarısı −3, kvadratı 9 = (x² − 6x + 9) − 9 + 14 = (x − 3)² + 5 Ən kiçik qiymət 5 (x = 3 olduqda)
2) x² + 8x + 7 = (x + 4)² − 16 + 7 = (x + 4)² − 9 Bu, kvadratların fərqidir: (x + 4)² − 3² = (x + 4 − 3)(x + 4 + 3) = (x + 1)(x + 7) ← tam kvadrat vuruqlara ayırmağa da kömək edir
3) 2x² − 8x + 3 = 2(x² − 4x) + 3 = 2(x² − 4x + 4) − 8 + 3 ← mötərizədə +4, xaricdə 2·4 = 8 çıxırıq = 2(x − 2)² − 5 Ən kiçik qiymət −5 (x = 2 olduqda)

4 Həyatdan

Həyatdan: ən böyük bağ. 20 m hasarla düzbucaqlı bağ çəpərləmək lazımdır. Bir tərəf x, o biri 10 − x. Sahə:
x(10 − x) = −x² + 10x = −(x² − 10x + 25) + 25 = 25 − (x − 5)².
Kvadrat 0 olanda sahə ən böyükdür: x = 5, sahə 25 m². Deməli eyni hasarla ən böyük sahəni kvadrat bağ verir.
Tipik səhvlər
  • Əlavə etdiyin kvadratı çıxmağı unutmaq: x² − 6x + 14 = (x − 3)² + 14 yanlışdır, 9-u çıxmaq lazımdır.
  • Ən kiçik qiyməti alan x-in işarəsi: (x + 4)² sıfır olur x = −4 olanda.
  • a ≠ 1 olanda xaricə çıxan ədədi unutmaq: nümunə 3-də 4 yox, 2·4 = 8 çıxılır.
Yadda saxla
x² + 2px + q = (x + p)² + (q − p²) Kvadrat ≥ 0 → ən kiçik qiymət q − p² (x = −p).
Özünü yoxla: 3 sual
  1. x² + 4x + 1 ifadəsini (x + m)² + n şəklində yaz. (x + 2)² − 3.
  2. x² − 10x + 30 ifadəsinin ən kiçik qiyməti nədir? (x − 5)² + 5 → ən kiçik qiymət 5 (x = 5 olduqda).
  3. Niyə x² − 2x + 3 həmişə müsbətdir? x² − 2x + 3 = (x − 1)² + 2 ≥ 2 > 0.
