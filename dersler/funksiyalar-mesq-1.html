Xətti funksiya: y = kx + b

Dərs — əvvəl bunu oxu

1 Funksiya nədir

Funksiya bir qaydadır: hər x-ə bir y uyğun gəlir. Onu maşın kimi təsəvvür et: x daxil olur, qayda işləyir, y çıxır.

Qayda y = 2x + 4 olsun. Bu o deməkdir: "x-i 2-yə vur, üstünə 4 gəl".

x−3−2−1012
y = 2x + 4−202468

Özün yoxla: x = 1 → 2·1 + 4 = 6. Cədvəldəki hər rəqəmi bir dəfə kağızda hesabla.

2 Qrafik cədvəlin şəklidir

Cədvəldəki hər cüt (x; y) koordinat müstəvisində bir nöqtədir: (−2; 0), (0; 4), (1; 6)… Bu nöqtələrin hamısı bir düz xəttin üstünə düşür. Ona görə y = kx + b şəklində funksiyaya xətti deyilir.

3 b: xəttin Oy oxunu kəsdiyi yer

Oy oxunun üstündəki hər nöqtədə x = 0. Onda y = k·0 + b = b. Deməli, qrafik Oy oxunu həmişə (0; b) nöqtəsində kəsir. y = 2x + 4 üçün bu, (0; 4)-dür. b-ni dəyişəndə xətt yuxarı-aşağı sürüşür, mailliyi dəyişmir.

4 k: xəttin mailliyi

Cədvələ yenidən bax: x hər dəfə 1 artanda y 2 artır. Bu 2 elə k-dır. İstənilən iki nöqtədən:

k = (y₂ − y₁) / (x₂ − x₁)

Məsələn (0; 4) və (2; 8): k = (8 − 4) / (2 − 0) = 2.

  • k > 0: soldan sağa xətt qalxır (funksiya artandır).
  • k < 0: xətt enir (azalandır).
  • k = 0: xətt üfüqidir, y dəyişmir.

5 Ox oxu ilə kəsişmə

Ox oxunun üstündəki hər nöqtədə y = 0. Ona görə 0 = kx + b tənliyini həll edirik:

2x + 4 = 0 → 2x = −4 → x = −2 → (−2; 0)

Diqqət: cavab nöqtədir, (−2; 0). Sınaqda variantlarda (0; −4) kimi tələlər olur. O, Oy oxu ilə kəsişmədir.

6 İki xəttin kəsişməsi

Kəsişmə nöqtəsi hər iki xəttin üstündədir, yəni orada y-lər bərabərdir. y = x + 1 və y = −x + 5: x + 1 = −x + 5 → x = 2, y = 3 → (2; 3).

Özün sına: sürgüləri tərpət

Sına: k-nı mənfi et, xətt nə edir? b-ni dəyiş, mailliyi dəyişirmi?

Kvadrat funksiya: y = ax² + bx + c

Dərs — əvvəl bunu oxu

1 Ən sadə parabola: y = x²

x−3−2−10123
y = x²9410149

Nöqtələr düz xəttə düşmür, "U" şəklində əyri alınır. Buna parabola deyilir. İki şeyə bax:

  • Simmetriya: x = 2 və x = −2 eyni y = 4 verir. Parabola bir şaquli xəttə görə güzgü kimidir.
  • Təpə: ən aşağı nöqtə (0; 0)-dır. Bütün məsələlərin açarı təpədir.

2 a: parabola hara açılır

  • a > 0: yuxarı açılır. Təpə ən aşağı nöqtədir, yəni funksiyanın ən kiçik qiyməti var.
  • a < 0: aşağı açılır. Təpə ən yuxarı nöqtədir, yəni ən böyük qiyməti var.
  • |a| böyüdükcə parabola daralır.

3 c: Oy oxu ilə kəsişmə

Xətti funksiyadakı kimi: x = 0 qoy, y = c alınır. Qrafik Oy oxunu (0; c) nöqtəsində kəsir.

4 Ox oxu ilə kəsişmə: köklər

Ox oxunda y = 0, yəni ax² + bx + c = 0 kvadrat tənliyini həll edirik. Neçə kəsişmə olduğunu diskriminant deyir:

D = b² − 4ac
  • D > 0: iki nöqtədə kəsir.
  • D = 0: Ox oxuna bir nöqtədə toxunur (təpə oxun üstündədir).
  • D < 0: Ox oxunu kəsmir.

a = 1 olanda Viyet teoremi tez işləyir: köklərin cəmi −b, hasili c-dir.

5 Təpənin düsturu haradan gəlir

Parabola simmetrikdir, ona görə təpə iki kökün düz ortasındadır. Ortanı tapmaq üçün kökləri toplayıb 2-yə bölürük. Viyetə görə köklərin cəmi −b/a-dır. Deməli:

x₀ = −b / (2a), y₀ = y(x₀)

y₀ funksiyanın ən kiçik (a > 0) və ya ən böyük (a < 0) qiymətidir. Düsturu əzbərləmək lazım deyil, "köklərin ortası" fikrini yadda saxla.

6 Hamısı bir nümunədə: y = x² − 2x − 3

a = 1 > 0 → yuxarı açılır, ən kiçik qiymət var Oy: x = 0 → y = −3 → (0; −3) Ox: x² − 2x − 3 = 0, Viyet: cəm 2, hasil −3 → x = −1, x = 3 Təpə: x₀ = (−1 + 3) / 2 = 1 (və ya −(−2) / (2·1) = 1) y₀ = 1² − 2·1 − 3 = −4 → ən kiçik qiymət −4
Özün sına: sürgüləri tərpət

Sına: a-nı mənfi et. c-ni elə seç ki, D = 0 olsun və parabola Ox oxuna toxunsun.
